Key tester

This page records which key chords the browser lets a page see. Click here once, then press each chord in the list. A row turns to delivered when the page receives it. A chord the browser keeps for itself never arrives, and usually does something else instead (a new tab, another window).

Results are kept in this browser, so they survive a chord that closes the tab: open the page again and carry on. Chords marked may close this tab are best pressed last. Run it once in a normal tab and once in an installed app window; the two differ.
