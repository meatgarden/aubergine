ガイド

短く実践的なガイドです。完全なリファレンスは README です。

  • Aubergine をインストールする

    必要なもの、1行のインストーラー、それが変えるもの、よくある問題の解決方法。

  • WSL を使って Windows にインストール

    WSL 2 の中で Aubergine を動かし、Windows のブラウザーから使います。Linux の手順は実行済みで、Windows ではまだ何も試していません。

  • 複数のコーディングエージェントを同時に動かす

    キャンバス、待機の数、キュー、作業コピー、ワークフローを1つのツアーで。

  • Aubergine の Claude Code

    Aubergine が Claude Code のために自ら行うことと、それぞれがどこにあるか。

  • Codex と ChatGPT

    ほかのプログラムと同じようにターミナルで動く Codex、それが報告できること、Claude Code 向けにだけ作られているもの。

  • 作業コピー

    エージェントごとに専用のチェックアウトとブランチを渡し、2つのエージェントが同じファイルを編集しないようにします。

  • 再起動のあともターミナルを残す

    ブラウザーを閉じたとき、Aubergine を再起動したとき、コンピューターを再起動したときにそれぞれ何が残るか、そして続きから再開する方法。

  • ターミナルを閉じてもプロセスを動かし続ける

    タブ、ウィンドウ、ブラウザーを閉じても何も終わりません。tmux が与えてくれるものを、tmux を覚えずに。

  • tmux を覚えずに tmux を使う

    ウィンドウを閉じても残るシェル。プレフィックスキーも設定もいらず、あなた自身の tmux には触れません。

  • Claude Code の完了や待機を知る

    すべてのターミナルの working、waiting for you、finished の表示、For you の数、次に待っているターミナルへ移るキー、開いているページからの通知。

  • Claude Code の会話を再開する

    動いていたターミナルでの Resume agent、フォルダーごとの過去の会話、そしてどこまで進んでいたかを教えてくれるもの。

  • ターミナルが多すぎるときに目当てのものを見つける

    キャンバス、状態を言葉で示すすべてのターミナルの一覧、フィルター、タグ、ターミナルの出力の検索。

  • スマートフォンからエージェントを確認する

    ほかのデバイスから Aubergine を使います。デバイスごとにコードでペアリングします。1台の Mac で一度実行しただけで、実際のスマートフォンでは試していません。

  • キュー、For you、スケジュール

    仕事を一度で割り振り、あなたを待っているものをすべて確認し、決まった時刻にタスクを実行します。

  • Aubergine とほかのツールの比較

    Conductor、Claude Squad、Vibe Kanban、cmux、Warp、Paradev を Aubergine と並べて比べます。各ツールが自分について文書にしていることにもとづきます。

  • セキュリティとプライバシー

    守られているもの、守られていないもの。

  • FAQ

    よくある質問への短い答え。

5分で動かす

tmux 3.2 以降と Node.js 22 以降の入った macOS が必要です。brew install tmux node で両方が入ります。

npm install -g @meatgarden/aubergine
