複数のコーディングエージェントを同時に動かす方法

エージェント2つなら簡単です。5つになると混乱します。どれが止まっているのか、どれがあなたを待っているのか、どれがあのファイルを変えたのか。Aubergine はまさにそのときのために作られています。あなた自身のコンピューターで動きます。

1. エージェントごとに、1つのキャンバス上のターミナルを渡す

ターミナル一覧の上にある New terminal（新しいターミナル）をクリックするか N を押して、そこでエージェントを起動します。ターミナルはタイトルバーでドラッグし、サイズを変え、フレームでまとめられます。関連する作業は1つのキャンバスに、別々の作業は別々のキャンバス（タブ）やプロジェクトに置きます。プロジェクトはそれぞれ自分のターミナル、キュー、スケジュールを持ちます。

どのターミナルも tmux セッション内の本物のシェルです。ブラウザーを閉じても Aubergine を止めても、エージェントは動き続けます。

2. どのエージェントがあなたを必要としているかを見る

各ターミナルは、処理中・アイドル・あなた待ちのどれかを表示します。その状態は画面を読んで得たものではなく、シェルのフックとエージェント自身から来ます。上部の For you の横の数と W キーで、次に待っているターミナルへ直接移動できます。

For you という1つの一覧に、人を待つものがすべて集まります。質問、承認する実行、確認すべき完了したタスク、そして理由付きの失敗したタスク。

3. キューから仕事を割り振る

タスクを一度書いてキューに入れます。あなたが指示すると空いているエージェントが引き受け、同時に動く数には上限があります。繰り返す仕事にはスケジュールを設定します。エージェントはタスクを提案したりあなたに質問したりできますが、あなたが受け入れるまで何も始まりません。

4. エージェントごとの変更を分けておく

1つのフォルダーにいる2つのエージェントは同じファイルを編集します。それぞれを専用の作業コピーで起動しましょう。専用のブランチ上の別のチェックアウトなので、各エージェントの作業を分けて読めます。Aubergine があなたの代わりにマージ、プッシュ、リベースすることはありません。

5. エージェントにステップを渡し、関門で決める

ワークフローは、エージェントが従う順番付きのステップの一覧で、今どこにいるかを示す帯が付きます。ステップは、あなたが承認するか差し戻すのを待つこともできます。進行中のすべての実行が1つのボードに表示されます。

しないこと

  • モデルを呼ぶことも、あなたの代わりに選ぶこともしません。エージェントはあなたのものです。
  • あなたにできることをエージェントがするのを防ぎはしません。エージェントはあなたとして動きます。何が守られ何が守られないかはセキュリティを参照してください。
  • 現在は1台のコンピューターで動きます。ほかの人とのキャンバスの共有やクラウドでのエージェントの実行はロードマップにあり、まだ作られていません。

5分で動かす

tmux 3.2 以降と Node.js 22 以降の入った macOS が必要です。brew install tmux node で両方が入ります。

npm install -g @meatgarden/aubergine
