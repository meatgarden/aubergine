Aubergine のインストール方法

1つのコマンドでインストールし、1つのコマンドで起動します。ツアーを含めて約5分です。

必要なもの

  • macOS。Linux でも同じように動くはずですが、まだテストしていません。
  • tmux 3.2 以降と Node.js 22 以降。インストーラーには pnpm も必要です。

Homebrew なら、1行で両方が入ります（インストーラーを使うなら pnpm も加えます）：

brew install tmux node

インストールと起動

  1. npm から Aubergine をインストールします（必要なのは tmux と Node.js だけです）：

    npm install -g @meatgarden/aubergine

    または、pnpm も必要でソースからビルドするインストーラーを使います：

    curl -fsSL https://raw.githubusercontent.com/thirstyeggplant/aubergine/main/install.sh | sh

  2. 起動して、サインイン済みのブラウザーを開きます。

    aubergine start --open

  3. ツアーを試します。空のキャンバスの中央にある Show me around（案内して）をクリックします。代役のエージェントがいくつか並ぶ「Demo」という名前のキャンバスが作られ、8つの短いステップで案内します。デモの中に本物はなく、aubergine demo --remove で取り除けます。

先にスクリプトを読みたいですか？ダウンロードして読み、sh install.sh --dry-run を実行すれば、何も変えずに何をするかが分かります。

インストーラーが変えるもの

2つだけです。インストールフォルダー（~/.aubergine、または AUBERGINE_HOME）と、aubergine という名前のリンク1つで、リンクは PATH 上の書き込めるフォルダーに置かれます。先にすべてを確認し、何か足りなければ何も変えません。

しないこと：sudo の使用、シェルの起動ファイルの編集、Node.js・pnpm・tmux のインストール、データフォルダーへの変更。

うまくいかないとき

まず aubergine doctor を実行してください。よくある原因を確認します。

見えるものすること
「This browser is not signed in yet」そのブラウザーでサインインのリンクを一度開きます。aubergine open --print で再び出力されます。
tmux がない、または古すぎるというページtmux をインストールまたは更新し（brew install tmux）、サーバーを再起動します。
ポートが使用中でサーバーが起動しない別のポートを使います：AUBERGINE_PORT=4700 aubergine start。
aubergine: command not foundリンクが PATH にありません。インストーラーが、シェルの起動ファイルに加える1行を出力します。
ターミナルに状態のバッジが出ない状態の表示には zsh が必要で、更新前に作られたセッションは古いシェルのままです。パークして、新しいターミナルを起動してください。

停止、更新、アンインストール

  • Ctrl+C でサーバーを停止します。ターミナルは動き続けます。サーバーを再び起動してページを再読み込みすれば戻ります。
  • 更新は、npm でインストールした場合は npm install -g @meatgarden/aubergine@latest、インストーラーを使った場合は aubergine update で行います。その後サーバーを再起動します。
  • アンインストールは aubergine uninstall で行います。リンクを削除し、確認の後でインストーラーが作ったコピーを削除します。データは決して削除せず、ターミナルも終了しません。
  • ログイン時に起動するには aubergine service install を使います。そうすれば、あとはブラウザーを開くだけです。
