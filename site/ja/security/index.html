セキュリティとプライバシー

Aubergine がターミナルを守るためにすること、そして同じくらい大事な、しないこと。要するに、ローカルで動き、エージェントのために動く前に尋ね、それでもエージェントはあなたとして動く、ということです。

すべてはあなたのコンピューターに

  • サーバーは 127.0.0.1 にだけバインドします。すべてのリクエストとすべての WebSocket のアップグレードで Host と Origin が確認され、ブラウザーはアクセス用の Cookie を持っている必要があります。
  • ほかのデバイスからの Aubergine の利用は、あなたが設定するまでオフです。同じコンピューター上の何かが、設定に書いた名前で HTTPS を中継し、各ブラウザーは使い捨てのコードでペアリングされ、失効させられます。ペアリングしたデバイスは、オーナーにできることをすべてできます。方法は Using Aubergine from elsewhere にあります。
  • Aubergine はモデルを呼ばず、自分からネットワークリクエストを始めることもありません。例外は2つです。あなたが求めたときにライブラリのソース（Git のアドレス）を取得すること、そしてインストールされサインイン済みの場合に、あなた自身の gh ツールにターミナルのブランチのプルリクエストを尋ねることです。
  • デスクトップ通知は開いているページから出ます。あなたのコンピューターから外に出るものはありません。

3種類の呼び出し元、それぞれを個別に判断

すべてのリクエストは、何かを調べる前に、呼び出し元が何をしてよいかと照らし合わせて確認されます。権限のない呼び出し元は、答えから何も知ることができません。呼び出し元は、あなた（ブラウザーでサインイン済み）、エージェントのセッション、API トークンです。

  • API トークンにはスコープがあります。秘密は一度だけ表示され、保存されません。保存されるのはハッシュだけです。トークンでの呼び出しはアクティビティログに記録されます。誰が、何を、どう終わったか。秘密も送った内容も記録しません。
  • どのトークンにも決してできないこと：トークンの作成や失効、アクティビティログの閲覧、設定の変更、そして Aubergine の外のターミナルに関すること全般。
  • ターミナルへのアクセスは2つの別々のスコープです。読むためのものと入力するためのもので、それぞれあなたが選ぶセッションに限られます。ターミナルを people only（人だけ）にすると、すべてのトークンに対して閉じられます。
  • エージェント自身の資格情報は狭いものです。自分の注意状態の設定、自分のノートへの追記、自分の状態の報告、自分がいる実行の読み取りができます。ほかのターミナル、キャンバス、トークンには届きません。

エージェントが単独ではできないこと

  • エージェントやプログラムが書いたもの（ワークフローやステップ）は、あなたがレビューする下書きとして届きます。受け入れられるのはあなただけです。
  • 人を待つステップを承認したり差し戻したりできるのは人だけです。ルール、スケジュール、デモはあなただけのものです。
  • Aubergine がエージェントのターミナルに入力するのは、「次のステップを読んで」のような少数の決まった文だけです。あなたが保存したものも、エージェントが書いたものも入力されません。
  • ライブラリからインストールするには、表示されたとおりの内容をあなたが受け入れる必要があります。

これが守らないもの

エージェントはあなたとして動きます。ターミナルのエージェントは、コマンドの実行、ファイルの読み取り、そしてその気になればあなた自身のブラウザーのセッションの利用も含め、そのターミナルであなたができることは何でもできます。

  • 承認は鍵ではありません。あなたとして動くエージェントは、あなたとして決められます。決定は記録されますが、防がれはしません。
  • 作業コピーはサンドボックスではありません。作業を分けておくもので、エージェントを閉じ込めるものではありません。
  • ライブラリの項目に対する管理はレビュー画面です。項目は、エージェントが自分にできるすべてを使って従う指示です。読んでいないものはインストールしないでください。
  • エージェント向けのガイドは助言であって、鍵ではありません。

インストーラー

変えるのは2つです。自分のフォルダーと、aubergine という名前のリンク1つ。sudo は使わず、シェルの起動ファイルも編集せず、データフォルダーには決して触れません。aubergine uninstall は自分が作ったものだけを削除します。

問題を報告する

GitHub で issue を作成してください。秘密やトークンは書かないでください。

5分で動かす

tmux 3.2 以降と Node.js 22 以降の入った macOS が必要です。brew install tmux node で両方が入ります。

npm install -g @meatgarden/aubergine
