Aubergine と Claude Squad

2つは同じ土台に立っています。各エージェントは tmux セッションで、それぞれ専用の Git の worktree にあり、どちらも無料のオープンソースです。Claude Squad はターミナルの中のプログラムです。Aubergine はブラウザーのページで、そこにターミナルが並びます。

情報の出どころ。ここでの Claude Squad についての記述は、2026年11月26日に読んだそのリポジトリと README にもとづきます。Claude Squad は動かしていません。間違いや古い情報があれば教えてください。

どちらを選ぶか

Claude Squad を選ぶのは、ターミナルの中で暮らしていて、エージェントを worktree で起動しそのブランチをプッシュする小さなプログラムがそこに1つあればよく、それ以上は要らない場合です。

Aubergine を選ぶのは、複数のエージェントが働く様子を一度に見て、どれがあなたを待っているかを知り、その周りにキュー、スケジュール、API がほしい場合です。

Claude Squad とは

自身の説明によれば、Claude Code、Codex、Gemini などのローカルのエージェントを、別々のワークスペースで複数管理するターミナルアプリです。cs で起動すると、1つのターミナルウィンドウに、プレビューと差分タブの付いたセッションの一覧が出ます。各セッションは、専用ブランチ上の Git の worktree にある tmux セッションです。tmux と gh が必要で、AGPL-3.0 ライセンスです。

違うところ

1つずつか、全部一度にか。Claude Squad は一覧と、選んだセッションのプレビューを見せます。Aubergine はすべてのターミナルをキャンバスにライブで描くので、5つのエージェントは目に見える5つのターミナルで、1つの一覧がそれぞれの状態を言葉で伝えます。

誰が待っているか。Claude Squad の README には、エージェントが待っている、または終わったと知らせることについて何も見つかりませんでした。Aubergine は待っているターミナルに色で印を付け、待っているものの数を上部に示し、キーで次のものへ移り、開いているページから通知を送れます。

エージェントの周りにあるもの。Aubergine には、上限付きのタスクのキュー、スケジュール、人が承認するステップのあるワークフロー、各ターミナルのノートとフィールド、HTTP API、MCP サーバーがあります。Claude Squad はセッションとそのブランチに絞っています。

Claude Squad にあって Aubergine にないもの

  • すでに開いているターミナルの中で、サーバーもブラウザーもなしに動きます。ほかのターミナルプログラムと同じように SSH 越しに使えます。Aubergine をほかの場所から使うには、トンネルかプロキシが必要です。
  • ブランチをコミットしてプッシュしてくれ、作業をコミットしてセッションを一時停止します。Aubergine はコミットもプッシュも決してしません。
  • エージェントのプロンプトを自動で受け入れる実験的なモード。Aubergine があなたの代わりにエージェントに答えることは決してありません。

よくある質問

Aubergine は Claude Squad の代わりになりますか？

はい。同じ仕事を別のやり方でします。どちらも各エージェントを tmux セッションで動かし、それぞれに専用ブランチ上の Git の worktree を与えられます。Claude Squad はターミナルの中のプログラムから、Aubergine はすべてのターミナルが見えるブラウザーのページからそれを行います。

どちらも tmux を使いますか？

はい。Claude Squad は tmux を前提条件に挙げ、エージェントごとに tmux セッションを作ります。Aubergine は tmux 3.2 以降が必要で、専用のソケットと専用の設定で動かすので、あなた自身の tmux には触れません。

Claude Squad は Claude Code 以外のエージェントでも使えますか？

README によれば、既定のプログラムは claude で、Codex、Gemini、Aider などほかのものは -p で指定します。Aubergine はどのコマンドラインのプログラムでもターミナルで動かします。エージェントのために自ら行うことは Claude Code 向けに作られています。

それぞれのライセンスは何ですか？

Claude Squad は AGPL-3.0、Aubergine は MIT ライセンスです。どちらも無料です。

Aubergine は Claude Squad とも Anthropic とも関係ありません。Claude Squad は smtg-ai のプロジェクトの名前で、Claude は Anthropic の商標です。
