Aubergine と Paradev（旧 Superset）

Paradev は、2026年10月まで Superset と呼ばれていたデスクトップアプリです。Aubergine と同じく MIT ライセンスで、どのコマンドラインエージェントも動かし、Git の worktree で作業します。プラン、スマートフォンアプリ、クラウドのあるアプリです。Aubergine はあなた自身のコンピューター上のサーバーとブラウザーのページで、そのどれもありません。

情報の出どころ。ここでの Paradev についての記述は、2026年11月26日に読んだそのドキュメント、変更履歴、リポジトリにもとづきます。Paradev は動かしていません。間違いや古い情報があれば教えてください。

名前について。2026年10月25日の変更履歴には、Superset は Paradev になり、アカウント、ワークスペース、設定、superset コマンドは引き継がれるとあります。データツールの Apache Superset ではありません。

どちらを選ぶか

Paradev を選ぶのは、タスクごとに worktree を作り、差分、チェック、マージまで運ぶデスクトップアプリがほしく、払えばスマートフォンアプリとクラウドも使いたい場合です。

Aubergine を選ぶのは、あなた自身のコンピューターで、アカウントなしに、すべての部分を無料で使いたい場合です。並んだターミナル、キュー、スケジュール、ほかのデバイスからの利用。

Paradev とは

自身の説明によれば、Claude Code、Codex、そしてどのコーディングエージェントにも使えるオープンソースのワークスペースです。ターミナルアプリではなくデスクトップアプリで、エージェントはチャットとして、またはターミナルの中で動きます。どのタスクにも専用の worktree、ブランチ、ターミナルがあり、1つのサイドバーにすべてのセッションがプロジェクトごとに表示されます。プルリクエストのチェックとマージのある差分ビューアー、コマンド、SDK、MCP サーバーがあり、有料プランではスマートフォンアプリ、リモートアクセス、クラウドのワークスペース、自動化が使えます。

違うところ

何が無料か。Paradev は、ローカルのワークスペース、アプリ、コマンドを含む1人用の無料プランを挙げています。自動化、スマートフォンアプリ、リモートアクセスは有料プランです。Aubergine にはプランがありません。キューも、スケジュールも、ほかのデバイスからの利用も、MIT ライセンスの1つのプログラムにすべて入っていて、アカウントも要りません。

サイドバーか、キャンバスか。Paradev はセッションを、タブとペインのあるサイドバーで見せます。Aubergine はターミナルを、パンとズームのできるキャンバスに置くので、たくさんのターミナルが同時にライブで目に入り、その横にすべての一覧があります。

ターミナルがウィンドウより長生きする仕組み。どちらもウィンドウを閉じてもエージェントを動かし続けます。Paradev は独自のバックグラウンドのデーモンで。そのドキュメントによれば、Paradev を完全に終了するとすべてのターミナルが終わります。Aubergine は tmux で。Aubergine 自体を止めても動き続けます。コンピューターの再起動では、どちらも終わります。

Paradev にあって Aubergine にないもの

  • エージェントの変更にコメントしたり編集したりでき、プルリクエストのチェックを見てマージできる差分ビューアー。Aubergine は何が変わったかを示し、コミット、プッシュ、マージは決してしません。
  • デスクトップアプリ、iOS と Android のアプリ、クラウドのワークスペース、そしてエージェントがあなたを必要とするときのチャイムと Dock のバッジ。Aubergine はブラウザーのページで、音は鳴らしません。
  • レビューの依頼、Slack のメッセージ、イシュー、Webhook をきっかけに動く自動化と、多くのエージェントが状態を報告するようにインストールするフック。Aubergine は外から何も起動せず、エージェントが待っていることに自ら気づくのは Claude Code についてだけです。

よくある質問

Aubergine は Paradev（Superset）の代わりになりますか？

複数のコマンドラインエージェントを、それぞれ専用の Git の worktree でローカルに動かすことについては、なります。しかもすべての機能が無料です。ただし同じものの置き換えではありません。Aubergine には、デスクトップアプリもスマートフォンアプリも、差分へのコメントも、プルリクエストやマージも、クラウドもありません。

Superset と Paradev は同じものですか？

はい。2026年10月25日の変更履歴には Superset は Paradev になったとあり、README にはコマンドは今も superset だとあります。どちらも Apache Superset とは関係ありません。

どちらもオープンソースですか？

どちらも MIT ライセンスです。Paradev は、スマートフォンアプリ、リモートアクセス、クラウド、自動化のためのプランも販売しています。Aubergine は何も販売していません。

Paradev は Linux や Windows で動きますか？

ドキュメントには、macOS と実験的な Linux 版があり、Windows はまだ使えないとあります。Aubergine は macOS 向けに作られ、Linux ではコンテナの中でだけ動かしました。Windows では WSL 2 の中でだけ動き、それはまだ試していません。

Aubergine は Paradev およびその開発元の Superset Inc. とは関係ありません。Paradev と Superset は彼らの名前です。彼らも Aubergine も Apache Superset とは関係ありません。
