Aubergine と Vibe Kanban

どちらもオープンソースで、あなた自身のコンピューターで動き、ブラウザーで使います。Vibe Kanban は作業から始めます。ボード上のイシューを、1つずつエージェントに渡します。Aubergine はエージェントから始めます。ターミナルが並び、その横にキューがあります。

情報の出どころ。ここでの Vibe Kanban についての記述は、2026年11月26日に読んだそのドキュメントとリポジトリにもとづきます。Vibe Kanban は動かしていません。間違いや古い情報があれば教えてください。

Vibe Kanban の現状。2026年4月10日、開発元は次のように書きました。開発元の会社 bloop は事業を終えること、プロジェクトはコミュニティが保守するオープンソースとして続くこと、リモートのサービスは取り除かれるがローカルのワークスペースは動き続けること。このページを書いた時点では、ドキュメントと料金ページはまだそのサービスを説明していました。リリースは続いています。

どちらを選ぶか

Vibe Kanban を選ぶのは、イシュー単位で考える場合です。ボードで計画し、各カードをエージェントに渡し、その差分をコメント付きでレビューし、マージします。

Aubergine を選ぶのは、エージェントそのものを、ウィンドウより長生きするターミナルとして目に入れておき、作業はあなたが指示したときにだけキューから渡したい場合です。

Vibe Kanban とは

自身の説明によれば、開発者がコーディングエージェントとともにコーディングのタスクを追うためのカンバンボードです。npx vibe-kanban でローカルのサーバーが起動し、そのページが開きます。イシューはワークスペースになります。選んだリポジトリの Git の worktree、名前で知っている10以上のエージェントのうち1つとの会話、その横の変更、そしてプルリクエストとマージ。Apache-2.0 ライセンスです。

違うところ

会話か、ターミナルか。Vibe Kanban はエージェントを、変更を横に添えた会話のパネルとして見せます。Aubergine はエージェント自身のターミナルを見せ、それをキャンバスにたくさん同時に並べます。

どのプログラムでも。Vibe Kanban は対応するエージェントを名前で挙げています。Aubergine のターミナルはシェルです。どのコマンドラインエージェントもそこで動き、ビルドも、テストの実行も、サーバーも動きます。Aubergine がエージェントのために自ら行うことは Claude Code 向けに作られています。

閉じると何が終わるか。Vibe Kanban のドキュメントには、サーバーが止まったときに動いているエージェントがどうなるかについて何も見つかりませんでした。Aubergine ではどのターミナルも tmux セッションで、Aubergine を止めてもブラウザーを閉じても何も終わりません。

Vibe Kanban にあって Aubergine にないもの

  • 優先度、タグ、サブイシューのあるイシューのカンバンボード。Aubergine にあるのはタスクのキューと動いているワークフローのボードで、イシュートラッカーではありません。
  • エージェントに送り返せるインラインコメント付きの差分と、その先のプルリクエスト、リベース、マージ。Aubergine は何が変わったかを示し、コミットもマージも決してしません。
  • 文書に記載された対応環境に Windows があること、音、そして名前で知っているエージェントのより長い一覧。

よくある質問

Aubergine は Vibe Kanban の代わりになりますか？

複数のエージェントをローカルの Git の worktree で動かし、どれがあなたを必要としているかを見ることについては、なります。形は違います。Vibe Kanban に会話付きのイシューのボードがあるところに、Aubergine にはキャンバス上のターミナルとタスクのキューがあり、Aubergine はプルリクエストを開かず、何もマージしません。

Vibe Kanban はまだ保守されていますか？

開発元は2026年4月10日に、開発元の会社は事業を終え、プロジェクトはコミュニティが保守するオープンソースとして続くと書きました。その後もリポジトリにはリリースがあります。今の状況はリポジトリで確認してください。

どちらもローカルで動きますか？

はい。どちらも、あなた自身のコンピューター上のサーバーと、ブラウザーのページです。Vibe Kanban は、ボードとチームの機能のための任意のサインインを文書にしています。Aubergine にはアカウントがまったくありません。

それぞれどのエージェントに対応していますか？

Vibe Kanban は10以上を名前で挙げており、その中に Claude Code、Codex、Gemini CLI、GitHub Copilot、Amp、Cursor、OpenCode があります。Aubergine はどのコマンドラインのプログラムでもターミナルで動かします。メニューからエージェントを起動すること、待っていることに気づくこと、会話を再開することは Claude Code 向けに作られています。

Aubergine は Vibe Kanban およびその開発元とは関係ありません。Vibe Kanban は Bloop AI Limited が始めたプロジェクトの名前です。
