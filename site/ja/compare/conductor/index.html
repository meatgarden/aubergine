Aubergine と Conductor

どちらも複数のコーディングエージェントを同時に、それぞれ専用の Git の worktree で動かします。Conductor は、チャット、差分ビューアー、クラウドのある Mac アプリです。Aubergine は、あなた自身のコンピューター上で動く無料のオープンソースのサーバーで、普通のターミナルをブラウザーのページに並べて見せます。

情報の出どころ。ここでの Conductor についての記述は、2026年11月26日に読んだそのドキュメントと変更履歴にもとづきます。Conductor は動かしていません。間違いや古い情報があれば教えてください。

Conductor の現状。2026年11月4日、その変更履歴は Conductor が Meta に加わり、終了に向かうと伝えました。11月13日には、Conductor は終了しないと伝えました。このページを書いた時点では、サイトの一部にまだ最初の知らせが残っていました。今の状況は変更履歴で確認してください。

どちらを選ぶか

Conductor を選ぶのは、タスクをプロンプトからマージ済みのプルリクエストまで運ぶ Mac アプリと、Mac の電源が切れている間も作業が進むクラウドがほしい場合です。

Aubergine を選ぶのは、エージェントを一度に全部見える普通のターミナルとして扱い、ウィンドウを閉じても tmux で動き続け、サインインするものがなく、ソースが公開されているものがほしい場合です。

Conductor とは

自身の説明によれば、コードベースで多くのコーディングエージェントを並行して動かす Mac アプリです。作業の1つひとつがワークスペースで、1つのブランチ上の Git の worktree に、チャット、ターミナル、ブラウザーのタブが付きます。Mac にすでにあるサインインのまま Claude Code、Codex、Cursor、OpenCode を動かし、差分ビューアー、プルリクエスト、iOS アプリ、そしてエージェントがサンドボックスで動く有料のクラウドがあります。

違うところ

チャットではなくターミナル。Conductor はエージェントをワークスペースの中のチャットとして見せ、その横にターミナルモードがあります。Aubergine はエージェント自身のターミナルを、どのターミナルアプリでも動くのと同じように見せ、それをパンとズームのできるキャンバスにたくさん並べます。

閉じると何が終わるか。Conductor のドキュメントによれば、ローカルのセッションはアプリを閉じるか Mac をシャットダウンすると終わり、クラウドのセッションは続きます。Aubergine ではどのターミナルも tmux セッションなので、ブラウザーを閉じても Aubergine を止めても何も終わりません。コンピューターの再起動では、どちらも終わります。

あなたのコンピューターの外には何もない。Conductor は、アカウント、クラウド、スマートフォンアプリのための中継、利用状況の分析を文書にしています。Aubergine にはアカウントも自前のサービスもありません。サーバーは 127.0.0.1 で待ち受け、ほかのデバイスからの利用はあなたが動かすプロキシを通ります。

Conductor にあって Aubergine にないもの

  • 行にコメントしてそのコメントをエージェントに送り返せる差分ビューアーと、その先のプルリクエスト、チェック、マージ。Aubergine は作業コピーで何が変わったかを示し、コミット、プッシュ、マージは決してしません。
  • Mac の電源が切れていてもエージェントが動き続けるクラウドと、そこでスケジュールどおりに動くルーティン。Aubergine のスケジュールは、あなたのコンピューターが動いている間に、そのコンピューターで実行されます。
  • iOS アプリと完了の音。Aubergine にはアプリがなく、音も鳴らしません。

よくある質問

Aubergine は Conductor の代わりになりますか？

自分のコンピューターで複数のコマンドラインエージェントを動かすことについては、なります。各エージェントはキャンバス上にターミナルを持ち、求めれば専用の Git の worktree も持ちます。ただし同じものの置き換えではありません。Aubergine にはチャット画面も、プルリクエストやマージも、クラウドも、スマートフォンアプリもありません。

Conductor はオープンソースですか？

いいえ。利用規約ではプロプライエタリとされ、公開リポジトリは見つかりませんでした。ドキュメントによれば、ローカルのアプリは無料で使え、クラウドのワークスペースには有料プランが必要です。Aubergine は MIT ライセンスで、有料プランはありません。

Conductor は Linux や Windows で動きますか？

ドキュメントには、Windows と Linux ではまだ使えないとあります。Aubergine は macOS 向けに作られ、Linux ではコンテナの中でだけ動かしました。Windows では WSL 2 の中でだけ動き、それはまだ試していません。

Conductor と Aubergine を一緒に使えますか？

妨げるものはありません。どちらも同じリポジトリの Git の worktree で作業し、それぞれが自分の worktree を作ります。2つを並べて動かしたことはありません。

Aubergine は Conductor およびその開発元とは関係ありません。Conductor は彼らの製品の名前です。利用規約には Melty Labs, Inc. の名があり、サイトには Conductor from Meta とあります。

tmux 3.2 以降と Node.js 22 以降の入った macOS が必要です。brew install tmux node で両方が入ります。
