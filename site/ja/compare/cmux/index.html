Aubergine と cmux

これらのページの中で最も近い組み合わせです。どちらもコーディングエージェントのために作られたターミナルで、どちらもコマンドラインから起動できるエージェントなら何でも動かし、どちらもオープンソースです。cmux はネイティブの macOS のターミナルアプリです。Aubergine はあなたのコンピューター上のサーバーと、ブラウザーの中のターミナルのキャンバスです。

情報の出どころ。ここでの cmux についての記述は、2026年11月26日に読んだそのサイトとドキュメントとリポジトリにもとづきます。cmux は動かしていません。間違いや古い情報があれば教えてください。

どちらを選ぶか

cmux を選ぶのは、ペイン、アプリ内ブラウザー、macOS の通知を持つ速いネイティブの Mac ターミナルアプリがほしく、その上に自分なりの働き方をスクリプトで組む場合です。

Aubergine を選ぶのは、モードを選ばなくてもアプリを閉じたまま動き続けるエージェント、エージェントごとに作られる worktree、そしてすでに組み込まれたキュー、スケジュール、承認がほしい場合です。

cmux とは

自身の説明によれば、libghostty の上に作られ、縦のタブとコーディングエージェント向けの通知を持つ macOS のターミナルで、Swift で書かれています。サイドバーにワークスペースが並び、それぞれのブランチ、プルリクエスト、フォルダー、最新の通知が表示されます。ワークスペースはタブ付きのペインに分割できます。どの操作もコマンドであり、Unix ソケット上のメッセージでもあります。アプリは GPL-3.0-or-later ライセンスで無料です。クラウドのマシンとベータ版の iOS アプリは、アカウントと有料プランで使えます。

違うところ

閉じると何が終わるか。cmux のドキュメントによれば、終了するとレイアウトとフォルダーは保存されますが、動いているプロセスは保たれません。ローカルの tmux モードにオプトインした場合は別です。Aubergine では tmux はモードではなく、どのターミナルも最初から tmux セッションです。どちらも、コンピューターの再起動を越えてプロセスを保つことはありません。

部品か、その周りのものか。cmux は自らをソリューションではなく部品と呼び、組み立てるためのコマンドとソケットを渡します。Aubergine には、Git の worktree による作業コピー、上限付きのキュー、スケジュール、承認付きのワークフロー、あなたを待つものの1つの一覧が付いてきます。

アプリか、ページか。cmux はシステムが描く Mac アプリです。Aubergine はブラウザーの中のページです。ネイティブのターミナルより描画は遅く、あなたが動かすプロキシを通じてペアリングしたほかのブラウザーから使えます。

cmux にあって Aubergine にないもの

  • libghostty によるネイティブのターミナル、分割ペイン、そしてコマンドで操作できるアプリ内ブラウザー。Aubergine はターミナルをブラウザーのページに描き、ペインはありません。ターミナルはキャンバスに置かれます。
  • ペインがあなたを必要とするときの macOS の通知とカスタムコマンド。ターミナルがすでに使っているエスケープシーケンスによって、どのプログラムでも働きます。Aubergine は Claude Code 向けに作られたフックでエージェントが待っていることに気づき、通知は開いているページからだけです。
  • リモートのマシン上のワークスペースのための cmux ssh、ベータ版の iOS アプリ、有料プランのクラウドのマシン。

よくある質問

Aubergine は cmux の代わりになりますか？

はい。どちらも、複数のコーディングエージェントを動かし、どれがあなたを必要としているかを見るためのターミナルです。cmux はネイティブの macOS アプリで、Aubergine は tmux の上でブラウザーの中で動き、作業コピー、キュー、スケジュール、ワークフローを加えます。

cmux には tmux が必要ですか？

いいえ。ドキュメントには tmux は必須ではないとあり、cmux の終了時に動いているプロセスを保つための、オプトインのローカル tmux モードがあります。Aubergine は tmux 3.2 以降が必要で、すべてのターミナルをその中で動かします。

cmux は Linux や Windows で動きますか？

README には、今のところ macOS のみ、macOS 14 以降とあります。Aubergine は macOS 向けに作られ、Linux ではコンテナの中でだけ動かしました。Windows では WSL 2 の中でだけ動き、それはまだ試していません。

どちらも無料のオープンソースですか？

cmux のアプリは GPL-3.0-or-later ライセンスで無料で、クラウドには有料プランがあります。サーバーのソフトウェアは別のライセンスです。Aubergine は MIT ライセンスで、有料プランはありません。

Aubergine は cmux およびその開発元とは関係ありません。cmux は Manaflow, Inc. の製品の名前です。

5分で動かす

tmux 3.2 以降と Node.js 22 以降の入った macOS が必要です。brew install tmux node で両方が入ります。

npm install -g @meatgarden/aubergine
