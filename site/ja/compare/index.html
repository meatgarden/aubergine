複数のコーディングエージェントを動かすツールの比較

同じ場面のための7つのツールです。複数のコーディングエージェントが働き、あなたがその真ん中にいる場面。Aubergine を Conductor、Claude Squad、Vibe Kanban、cmux、Warp、Paradev と並べ、それぞれに1ページずつ用意しました。

このページの書き方。ほかのツールについての記述は、2026年11月26日に読んだそのツール自身のサイト、ドキュメント、リポジトリにもとづき、各ページからリンクしています。ほかのツールは動かしていません。ドキュメントに何も書かれていない点は、そのツールにできないとは書かず、何も見つからなかったと書いています。これらのツールは変化が速いです。間違いや古い情報があれば教えてください。修正します。

7つすべてを並べて

ツールどんなものか動く環境ソースと価格エージェントを分けておく閉じたとき
Aubergineあなた自身のコンピューター上のサーバーと、ブラウザーのページmacOS。Linux はコンテナの中だけ。Windows は WSL 2 の中で、未検証。tmux と Node.js が必要MIT、無料。有料プランもアカウントもなし求めたときに、ターミナルごとに専用ブランチ上の Git の worktreeターミナルは tmux で動き続ける。コンピューターを再起動すると動いていたものは終わる
ConductorMac のデスクトップアプリ。ホストされたクラウドと iOS アプリ付きmacOS のみクローズドソース。ローカルのアプリは無料、クラウドには有料プランが必要ワークスペースごとに Git の worktree とブランチ。クラウドではサンドボックスローカルのセッションはアプリとともに終わる。クラウドのセッションは続く
Claude Squadターミナルの中のプログラム。cs で起動macOS と Linux。Windows では WSL 経由の tmux で。tmux と gh が必要AGPL-3.0、無料それぞれに tmux セッションと、専用ブランチ上の Git の worktreeセッションは tmux セッション。何が保たれるかは README に書かれていない
Vibe Kanbanあなた自身のコンピューター上のサーバーと、ブラウザーのページmacOS、Linux、Windows。npx で起動Apache-2.0、無料。サインインは任意ワークスペースごとに Git の worktreeドキュメントには何も見つからない
cmuxネイティブの macOS のターミナルアプリmacOS 14 以降のみGPL-3.0-or-later のアプリ、無料、アカウント不要。クラウドには有料プランエージェント用に worktree を作るものは見つからない。クラウドでは別々のマシンレイアウトとフォルダーは戻る。動いているプロセスはオプトインの tmux モードでのみ
Warp自分のエージェントを持つデスクトップのターミナルアプリと、クラウドのエージェントmacOS、Windows、Linuxクライアントは AGPL-3.0 のオープンソース。無料プランと有料プラン。ログインは任意あなたが作った Git の worktree を認識する。クラウドのエージェントにはコンテナウィンドウ、タブ、最近の出力は戻る。動いているプログラムについては何も見つからない
Paradev以前 Superset と呼ばれていたデスクトップアプリ。スマートフォンアプリとクラウド付きmacOS。実験的な Linux 版。Windows はなしMIT。1人用の無料プランと有料プランタスクごとに worktree、ブランチ、ターミナル完全に終了するまで、ターミナルはデーモンで動き続ける。再起動で終わる

それぞれのページ

各ページには、2つを並べた表の全体、違うところ、そして相手のツールにあって Aubergine にないものがあります。

  • Aubergine と Conductor

    Conductor を選ぶのは、タスクをプロンプトからマージ済みのプルリクエストまで運ぶ Mac アプリと、Mac の電源が切れている間も作業が進むクラウドがほしい場合です。

  • Aubergine と Claude Squad

    Claude Squad を選ぶのは、ターミナルの中で暮らしていて、エージェントを worktree で起動しそのブランチをプッシュする小さなプログラムがそこに1つあればよく、それ以上は要らない場合です。

  • Aubergine と Vibe Kanban

    Vibe Kanban を選ぶのは、イシュー単位で考える場合です。ボードで計画し、各カードをエージェントに渡し、その差分をコメント付きでレビューし、マージします。

  • Aubergine と cmux

    cmux を選ぶのは、ペイン、アプリ内ブラウザー、macOS の通知を持つ速いネイティブの Mac ターミナルアプリがほしく、その上に自分なりの働き方をスクリプトで組む場合です。

  • Aubergine と Warp

    Warp を選ぶのは、Windows や Linux でも、何でもこなす1つのターミナルアプリがほしく、自分のエージェントが組み込まれ、スケジュールできるクラウドのエージェントがほしい場合です。

  • Aubergine と Paradev（旧 Superset）

    Paradev を選ぶのは、タスクごとに worktree を作り、差分、チェック、マージまで運ぶデスクトップアプリがほしく、払えばスマートフォンアプリとクラウドも使いたい場合です。

Aubergine の軸にあるもの

  • 普通のターミナル。エージェントは、どのターミナルアプリでも動くのと同じように Aubergine で動きます。上にチャット画面はなく、エージェントが出力するものとあなたの間には何もありません。
  • すべてが見える。パンとズームができるキャンバスにターミナルが並び、すべてのターミナルとその状態を言葉で示す1つの一覧があります。目当てのターミナルを見つけるを参照してください。
  • ウィンドウを閉じても何も終わらない。どのターミナルも tmux セッションなので、ブラウザーも Aubergine 自体も止まって構わず、エージェントは動き続けます。再起動で何が残るかを参照してください。
  • あなたのコンピューターだけ。アカウントも、クラウドも、有料プランも、自分のモデルもありません。サーバーは 127.0.0.1 で待ち受けます。セキュリティを参照してください。
  • 決めるのは人。エージェントが提案したものはあなたのレビューを待ち、ワークフローの承認はあなただけのもので、For you という1つの一覧に、あなたを待つものがすべて集まります。キューを参照してください。

Aubergine にないもの

  • デスクトップアプリもスマートフォンアプリもありません。ブラウザーの中のページです。ほかのデバイスは、あなたが動かすプロキシを通じてペアリングできます。それは1台の Mac で一度実行しただけで、実際のスマートフォンでは一度も試していません。
  • プルリクエストもマージもありません。作業コピーで何が変わったかをファイルごとに示し、コミット、プッシュ、リベース、マージは決してしません。
  • クラウドはありません。エージェントは Aubergine が動くコンピューター上で動き、スケジュールはそのコンピューターが動いている間にだけ実行されます。
  • 音もプッシュもありません。通知は、ブラウザーで開いている Aubergine のページから届きます。
  • macOS 向けに作られています。Linux ではコンテナの中でだけ動かしました。Windows では WSL 2 の中でだけ動き、それはまだ試していません。
  • 主に Claude Code 向け。どのコマンドラインエージェントもターミナルで動きますが、Aubergine がエージェントのために自ら行うこと（待っていることに気づく、会話を再開する）は Claude Code 向けに作られています。ほかのエージェントは aubergine コマンドを通じて報告します。

よくある質問

複数の Claude Code エージェントを同時に動かすのに最適なツールは何ですか？

エージェントの周りに何を求めるかによります。差分、プルリクエスト、マージのある Mac アプリなら Conductor か Paradev。いつも使っているターミナルの中のプログラムなら Claude Squad。イシューのボードなら Vibe Kanban。ネイティブの Mac ターミナルなら cmux。自分のエージェントとクラウドのエージェントを持つターミナルなら Warp。ブラウザーのページに普通のターミナルを並べ、tmux で動かし続け、アカウントが要らないものなら Aubergine です。

これらのツールのうち、オープンソースはどれですか？

2026年11月26日に読んだ時点では、Aubergine（MIT）、Paradev（MIT）、Vibe Kanban（Apache-2.0）、Claude Squad（AGPL-3.0）、cmux のアプリ（GPL-3.0-or-later）、Warp のクライアント（AGPL-3.0）です。Conductor は利用規約でプロプライエタリとされています。

これらのツールのうち、Linux や Windows で動くのはどれですか？

それぞれのドキュメントによれば、Warp は macOS、Windows、Linux。Vibe Kanban も3つすべて。Claude Squad は macOS と Linux、Windows では WSL 経由の tmux で。Paradev は macOS と、実験的な Linux 版。Conductor と cmux は macOS だけです。Aubergine は macOS 向けに作られ、Linux ではコンテナの中でだけ動かしました。Windows では WSL 2 の中でだけ動き、まだ試していません。

アプリを閉じた後もエージェントが動き続けるのはどれですか？

Aubergine と Claude Squad は、各エージェントを tmux セッションで動かします。Paradev は、ウィンドウを閉じてもターミナルを保つバックグラウンドのデーモンを文書にしています。cmux が動いているプロセスを保つのは、オプトインの tmux モードのときだけです。Conductor は、ローカルのセッションはアプリとともに終わるとしています。Warp が復元するのはウィンドウと最近の出力で、動いているプログラムではありません。Conductor、cmux、Warp、Paradev にはそれぞれ、エージェントが動き続けるクラウドもあります。Aubergine も含め、どれもコンピューターの再起動を越えてローカルのエージェントを動かし続けることはできません。

tmux 3.2 以降と Node.js 22 以降の入った macOS が必要です。brew install tmux node で両方が入ります。

npm install -g @meatgarden/aubergine
