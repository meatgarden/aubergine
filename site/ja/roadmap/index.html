チームとつながり

人が一緒に働くこと、そしてすでに使っているツールからエージェントに届くこと。

  • マルチプレイヤー

    ほかの人やそのエージェントとキャンバスを共有します。誰がどこで作業しているかを見て、待っているエージェントをチームメイトに渡し、一緒に答えます。

  • チャットのインターフェース

    チームのチャットアプリからエージェントに頼み、その質問に答えます。ブラウザーと同じ ID と設定で。

  • チケットとプルリクエスト

    issue をキューのタスクにし、作業コピーからプルリクエストを開き、結果をチケットに報告します。

  • 監視、Webhook、トリアージ

    何かが起きたら作業を始めます。失敗した CI ジョブ、アラート、監視している変更、ほかのサービスからの呼び出し。何をタスクにするかはルールが決めます。

  • 共有スキルとマーケットプレイス

    エージェントのスキルを許可によって共有し、承認を経てチーム全体に広げ、Git から取り込み、公開カタログでレビュー済みの項目を見つけます。

  • 人と部屋のための記憶

    エージェントが学んだことを、人ごと、共有の部屋ごとに、ほかと分けて保ちます。

ほかにも：モデル、共有、厳しさに関する管理者の設定 · セルフホストのチームサーバー · チーム向けのサインイン（SSO と MFA） · 人、トークン、エージェントごとの使用量の上限 · ターミナルを共有せずに共有できる読み取り専用のレポート · 「For you」の一覧のスマートフォン向け表示 · 社内ツールへのレビュー済みコネクター · ほかのチャットアプリ · 選んだ人に公開する小さな社内ウェブアプリ。

クラウド

ノートパソコンを起こしておかなくても動くエージェント。

  • クラウドのサンドボックスで動くエージェント

    エージェントを隔離されたクラウドのサンドボックスで動かし、ローカルのものと同じキャンバスで見ます。サンドボックスはアイドル時に眠り、必要に応じて起き、実行の間もストレージを保ちます。

  • エージェントのプール

    タスクごとにターミナルを指定する代わりに、仕事を説明してエージェントのプールに引き受けさせます。

  • 用意済みの環境

    依存関係、ツール、スキル、ファイル、変数を一度保存し、新しいターミナルやクラウドのエージェントをそこから始めます。

  • 長い、複数段階の作業

    何時間も何日も段階的に動くタスク。各段階の後に確認があり、進み具合は再起動しても残ります。

  • 1コマンドでクラウドにデプロイ

    チームで共有する Aubergine を、1つのコマンドであなた自身のクラウドアカウントに置きます。

  • 目で見られる作業

    クラウドのエージェントが、作ったもののスクリーンショットや短い録画を、あなたの「For you」の一覧に返します。

ほかにも：ほかのマシンのエージェントのための HTTP 経由の MCP · テスト済みの Linux サポート · zsh 以外のシェル統合。

制御

エージェントがどこまでしてよいか、そして何をしたかの記録。

  • 承認モード

    エージェントが単独でどこまでしてよいかを選びます。すべての操作を承認する、危険なものだけ承認する、または何も承認しない。

  • コマンドのポリシーとスクリーニング

    承認が必要なコマンドや常に拒否するコマンドのルール、そしてエージェントが読む前に外部の内容をスクリーニングする任意の機能。

  • リポジトリごとのリスクレベル

    大事なところでは厳しく、そうでないところでは緩く。

  • 完全な監査証跡

    今日記録されているトークンの呼び出しを超えて、誰が、または何が何をしたかをプロジェクトごとに記録します。

  • エージェントの作業を元に戻す

    作業コピーをタスクの前まで戻す、またはそのブランチを一度に破棄します。

  • 管理者の設定

    どのモデルを使ってよいか、共有をどう扱うかについてのチーム全体の設定。

ほかにも：ターミナル、タスク、スケジュールごとのモデルの選択。

品質

作業が完了と呼ばれる前に行われる確認。

  • 品質ゲート

    レビュー、テスト、セキュリティチェックが合格を報告するまで、実行は終われません。

  • プルリクエストのレビュー

    エージェントがプルリクエストをレビューし、あなたの「For you」の一覧に報告します。

  • ブラウザーを使ったテスト

    エージェントがブラウザーを操作して変更をテストし、結果を返します。

  • 作る前に計画

    エージェントが計画を提案し、ファイルに触れる前にあなたの承認を待ちます。

  • タスクのレシピ

    テストの生成、レビュー、依存関係と秘密のスキャン、ドキュメントを最新に保つための、用意済みのワークフロー。

  • 成果の指標

    タスクから完了までの時間、エージェントがあなたを待った頻度、誰が始めたかごとの使用量を、プロジェクトごとに。

ほかにも：障害の報告書。エージェントが調査し、ポストモーテムの下書きを作ります。

あらゆる場所で

Aubergine に届き、その上に作るための、より多くの方法。

  • 公開 SDK

    型付きクライアントをインストール可能なパッケージとして、その後 Python などほかの言語のクライアントも。

  • エディターの拡張機能

    VS Code などのエディターの中に、ターミナルと「For you」の一覧を表示します。エディターを離れる必要はありません。

  • デスクトップアプリ

    ブラウザータブの代わりに、メニューバーのアイコンを持つパッケージ化されたアプリ。

  • Windows のサポート

    Windows そのもので Aubergine を動かす。今は Windows 向けのガイドのとおり WSL 2 の中でだけ動き、Windows ではまだ誰も試していません。

自分好みに

今のテーマ、色、キーを超えて、ページをもっと自分の形に。

  • 条件で変わる見た目

    プロジェクトごと、またはタグの付いたターミナルごとのテーマやアクセント。今どこにいるかがひと目でわかります。

  • テンプレート

    ターミナルのタイトルと一覧の行に何を表示するかを、自分のテンプレートで決める。

  • 自分のスタイルシート

    ページに読み込む custom.css ファイル。文書化され、安定して保たれるフック付き。

  • プラグイン

    自分のコードを完全な制御のもとでページに読み込む。名前の付いた差し込み口を通しても、それを越えても。ほかの人のコード向けの隔離モードは、のちに加わるかもしれません。

予定中の作業は方向であって、約束ではありません。リリース済みのものはリポジトリで分かります。

5分で動かす

tmux 3.2 以降と Node.js 22 以降の入った macOS が必要です。brew install tmux node で両方が入ります。

npm install -g @meatgarden/aubergine
