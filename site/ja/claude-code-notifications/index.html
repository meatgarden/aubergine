Claude Code の完了やあなた待ちを知る

Claude Code に仕事を任せてほかのことをし、20分後に戻ってみると、2分目からずっと「はい」を待っていた。Aubergine は、どのターミナルが作業中で、どれがあなた待ちで、どれが完了したかを1つのページに表示します。

よくあるやり方

Claude Code は、止まったとき（Stop）や通知を送るとき（Notification）などの時点で、フック、つまりあなた自身のコマンドを実行します。よくある答えは、Claude Code の設定に音を鳴らしたりデスクトップ通知を出したりするフックを書くことです。それで動きますが、スクリプトを書いて保守するのはあなたです。

Aubergine がすること

Claude Code を Aubergine から起動します：ターミナル一覧の上にある New terminal ▾ → Claude Code、または C。Aubergine は、自分のデータフォルダーに生成してコマンドラインで指定する設定ファイルを使って claude を起動します。あなた自身の Claude Code の設定には触れません。そのファイルのフックが、エージェントの動きをページに伝えます。

  • プロンプトを送ると、ターミナルは working（作業中）と表示し、プロンプトはノートのログに加わります。
  • エージェントがあなたを必要とすると（権限の確認、または入力を待ってアイドルになったとき）、枠線が待機中の色になり、タイトルと一覧の行に waiting for you（あなた待ち）と出ます。
  • 止まると、ターミナルは finished（完了）と表示します。

ページの右上にある For you の横の数は、すべてのプロジェクトにわたってあなたを待っているものすべてです。質問のあるターミナル、承認する実行、読む下書き、提案されたタスク。押すと Runs が開き、その Waiting for you 列がその一覧です。キャンバスのタブには、そのターミナルのうちいくつが待っているかが出ます。

次に待っているもの。どのターミナルもキーボードを持っていないとき、W で次にあなたを待っているターミナルへ移ります。macOS では ⌃⌘J でターミナルの中からも移れます。それ以外の環境ではパレットにあります。

開いているページからの通知。Settings → Notifications に Notify me on the desktop when a terminal starts waiting（ターミナルが待ち始めたらデスクトップに通知する）があります。オンにすると、ターミナルが待ち始めたときやエージェントが完了したときに、そのターミナルを見ていなければ、ページがブラウザーの通知を出します。ブラウザーは一度だけ許可を求めます。

ルール。Runs の Rules タブで、タスクが完了した、失敗した、あなたを必要としている、何かを尋ねられた、スケジュールが発火した、または実行できなかったときに Notify me（通知する）ルールを作れます。開いているページからの通知で、何が起きたかを一文で伝えます。

ほかのエージェントと、自分で入力した claude

Aubergine はターミナルの出力を読んで推測しません。ほかのエージェントやプログラムは、自分のターミナルで aubergine attention waiting "what it needs"、aubergine attention working、aubergine attention done を実行して、同じことを自分で伝えます。aubergine guide --snippet は、エージェントが会話の始めに読むファイル用の5行を出力します。その5行がエージェントに aubergine guide を実行するよう伝え、これらのコマンドはそこで説明されます。

普通のターミナルで claude と入力して起動した Claude Code は、Aubergine にとってはプログラムを実行中のシェルにすぎず、waiting for you にはなりません。代わりにメニューから起動するか、aubergine hooks print が出力するフックを自分の設定に手で加えてください。フックは Aubergine のターミナルの外では何もしません。

しないこと

  • 独自の音はありません。Aubergine は音を鳴らしません。通知で音が鳴るのは、ブラウザーやシステムが通知で音を鳴らす設定のときだけです。
  • ページが開いていなければ何も届きません。通知はブラウザーで開いている Aubergine のページから出ます。サーバーが自分で送ることはありません。すべてのページを閉じていても、ターミナルは waiting for you と表示したままで、ページを開けば数がそこにあります。
  • スマートフォンへのプッシュはありません。アプリもプッシュサービスもありません。スマートフォンのブラウザーをペアリングして同じページを開くことはできます。スマートフォンからエージェントを確認するを参照してください。ただし実際のスマートフォンでは試していません。
  • 確認したこと。ブラウザーのテストは、ブラウザー自身の通知の代役に対して通知を確認しています。本物の通知がどう見えるか、そもそも表示されるかは、ブラウザーとシステムの通知の設定次第です。

よくある質問

Claude Code が終わったときに通知を受け取るには？

Claude Code を Aubergine から起動し、Settings → Notifications で Notify me on the desktop when a terminal starts waiting をオンにします。すると開いているページが、ターミナルがあなたを待ち始めたときやエージェントが完了したときにブラウザーの通知を出します。通知がなくても、ターミナルは finished と表示します。

Claude Code が入力を必要とするときに音を鳴らせますか？

Aubergine は音を鳴らしません。ブラウザーやシステムが鳴らす設定なら、通知で音が鳴ります。Claude Code の設定に自分のフックを書けば音を鳴らせます。Aubergine がその設定に書き込むことはありません。

複数動かしているとき、どの Claude Code のセッションが待っているかを見るには？

Aubergine では、待っているターミナルの枠線と状態が待機中の色になり、一覧の行に waiting for you と出て、For you の横の数が待っているものの数を示します。W で次のものへ移ります。

ブラウザーを閉じていても通知されますか？

いいえ。通知は開いている Aubergine のページから出ます。状態は保存されるので、ページを開き直すと待っているターミナルに印が付いています。

Claude Code 以外のエージェントでも動きますか？

自動ではありません。フックは Claude Code 向けに作られています。ほかのエージェントも、自分の指示でそうするよう書かれていれば、aubergine attention waiting、working、done で同じことを伝えられます。aubergine guide --snippet がその指示用の行を出力します。
