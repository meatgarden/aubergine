再起動のあとに Claude Code の会話を再開する

コンピューターが再起動した、あるいはターミナルを閉じてしまい、Claude Code の会話が消えたように見える。Claude Code は会話を保存しています。Aubergine は各ターミナルがどの会話にいたかを覚えていて、ボタン1つで戻します。

よくあるやり方

ターミナルで、会話をしていたフォルダーにいる状態で：claude --continue はそこで最も新しい会話を続け、claude --resume は一覧から選ばせるか、会話の ID を受け取ります。難しいのはフォルダーと選択です。1つのフォルダーに複数のエージェントがいると、最も新しい会話が目当てのものとは限りません。

Aubergine がすること

ターミナルは自分の会話を覚えています。Claude Code を Aubergine から起動すると（New terminal ▾ → Claude Code、または C）、フックがどの会話にいるかを Aubergine に伝え、Aubergine はその ID をターミナルとともに保存します。

シェルがプロンプトに戻ると、ターミナルのタイトルバーに Resume agent（エージェントを再開）が出ます。エージェントを終了したときや、コンピューターが再起動してターミナルが最後のフォルダーで新しいシェルとして戻ったときです。--resume とその ID を付けて Claude Code を再び起動し、起動コマンドには設定のもの（agents.claudeCommand、既定は claude）を使います。

ワークフローの実行の途中なら、Resume agent はその実行についてもう一度エージェントに伝えるので、実行が止まっているステップから続けます。

Past conversations…（過去の会話、パレット ⌘K から）、またはターミナルの詳細にある「Past conversations in this folder…」は、フォルダー内の Claude Code の過去の会話を一覧します。名前か最初に言ったこと、最後に動いた時刻、何回やり取りしたか、今キャンバス上のターミナルがその会話にいるかどうか。Read は読み取り専用で表示します。Open on the canvas はそのフォルダーで新しいターミナルを起動してその会話を再開し、Open a copy は会話を分岐させ、元はそのまま残します。すでにその会話にいるターミナルがあれば、先に確認されます。

検索。パレットで @ といくつかの語を入力すると、キャンバス上のターミナルのフォルダーにある過去の会話を検索できます。求められたときに上限の範囲で記録を読み、途中で打ち切ったときはそう伝えます。コマンドラインでは、aubergine history が一覧し、aubergine history open <id> が1つを開きます。

どこまで進んでいたか。ターミナルのノートは要約とログを保ち、送ったプロンプトはひとつずつログに加わります。詳細にある Ask its agent for a recap（エージェントに振り返りを頼む）を押すと、エージェントが aubergine recap --write で現状を書き、ターミナルとともに保存されます。30分以上たって戻ると、While you were away（離れている間）がその間に変わったことを一覧します。

Aubergine の外のターミナルにある会話

ターミナルアプリのタブでエージェントを終了し、同じフォルダーで aubergine here --claude を実行します。キャンバス上の新しいターミナルが --continue で Claude Code を起動し、今度は状態が表示されます。aubergine move はあなたの Claude Code のタブを一覧し、それぞれの会話のコピーをキャンバスで起動します。--stop を付けると、あなたが確認したあと、アイドルのエージェントに先に終了するよう求めます。

しないこと

  • Claude Code 自身の記録を、Aubergine のものではない形式のまま読みます。Claude Code はそのファイルの形式を内部のものとしていて、バージョンによって変わります。再開には Claude Code 自身の --resume を ID とともに使います。名前、回数、記録は Aubergine がファイルを読んだもので、Claude Code を更新したあとは欠けたり薄くなったりすることがあります。読めない記録は読めないと表示され、空の会話として見せることはありません。
  • 何もコピーも保存もしません。一覧、記録、検索は、求められたときに読み、閉じると捨てます。Aubergine が会話を変更、名前変更、削除することはなく、エージェントもトークンも Aubergine を通じて会話を読むことはできません。
  • 途中の作業はやり直されません。止まったときにエージェントがしていたことは、あなたが頼むまで再開されません。
  • ほかのエージェントには Resume agent はありません。Aubergine はほかのエージェントの会話を知らず、その過去の会話も一覧しません。同じターミナルで、そのエージェント自身の再開の方法で起動し直し、ノートを読んでどこまで進んでいたかを伝えてください。
  • 自分で入力した claude は覚えられません。ただし、aubergine hooks print が出力するフックを自分の Claude Code の設定に加えていれば別です。
  • 確認したこと。会話の記録の読み取りは、作り物の記録に対してテストしています。Claude Code のすべてのバージョンに対しては確認していません。

よくある質問

ターミナルを閉じたあとに Claude Code のセッションを再開するには？

同じフォルダーで、claude --continue は最も新しい会話を、claude --resume は選んだ会話を開きます。Aubergine ではブラウザーを閉じても何も終わらず、エージェントを終了したターミナルはタイトルバーに Resume agent を出します。

再起動のあとに Claude Code の会話を再開するには？

再起動のあと、Aubergine の各ターミナルは最後のフォルダーで新しいシェルとして戻ります。Claude Code を Aubergine から起動していたなら、タイトルバーの Resume agent が、そのターミナルがいた会話で再び起動します。

古い Claude Code の会話を見つけるには？

パレットの Past conversations… がフォルダーごとに一覧し、読み取り専用の記録も見られます。パレットで @ といくつかの語を入力すると検索できます。一覧に出るのは Claude Code がまだ保存しているものだけです。

claude --continue と claude --resume の違いは何ですか？

--continue はフォルダー内で最も新しい会話を続け、--resume は選んだ会話か ID を受け取ります。Resume agent はターミナルが覚えている ID で --resume を使うので、どの会話が最も新しいかには左右されません。

2つのターミナルで同じ Claude Code の会話を続けられますか？

Aubergine は確認せずに1つの会話を2回開くことはしません。1つの会話に2つのエージェントがいると、互いのメッセージが失われるからです。すでにその会話にいるターミナルか、会話を分岐させるコピーかを選べます。
