キュー、「For you」、スケジュール

互いにつながる2つの一覧です。キューはエージェントの仕事を、For you は人を待つものすべてを持ちます。スケジュールは決まった時刻にキューへタスクを加えます。

キュー

ページ上部の Runs を開き（または Q を押し）、Add task（タスクを追加）をクリックします。タスクにはタイトル、すること、そして任意でフォルダー、ワークフロー、誰が引き受けてよいかがあります。初期状態では、エージェントが空いているどのターミナルでも引き受けられます。ターミナルを1つ指定することも、新しいエージェントのターミナルを起動させることもでき、フォルダーがリポジトリ内にあればそのターミナルは専用の作業コピーで動きます。

  • Start next は、今引き受け手のいる最初のタスクを始めます。普通のシェルにタスクが渡されることはありません。
  • At most N at once（同時に最大 N 個）、変えなければ3です。Hold は新しい開始を止め、動いているものには触れません。
  • Start by itself は、あなたがオンにするまでオフです。タイマーで確認するものはありません。
  • 順番はあなたが決めます。タスクをドラッグするか、矢印キーを使います。
  • タスクは自分の実行に従います。実行が承認を待つ間は needs you、終わると done、止まると理由の文とともに failed。自動で再試行されることはありません。

For you

質問のあるターミナル、承認待ちやブロックされた実行、読むべき下書きやインストール、キューに提案されたタスク、完了したタスクと失敗したタスク、エージェントが提出した一覧、ターミナルがなくなった作業コピー。上部の For you の横の数と「next waiting」は同じ一覧です。ほとんどは書かれたものではなく集められたもので、対象そのものが済むと項目は消えます。

今やるべきではない仕事を見つけたエージェントはタスクを提案でき、人が必要なエージェントはあなたに頼めます：

aubergine task add "Add a test for the retry" --details "it should fail without the fix"
aubergine ask "the staging key expires this week: rotate it, or say who can"

どちらもあなたの一覧に届きます。提案は、あなたが受け入れるまで何も始めません。

スケジュール

スケジュールは、時刻、曜日、実行するもの、実行する場所です。時刻になるとキューにタスクを1つ加え、キューがそれを始めます。Runs ページの Schedules の下、または aubergine schedule で扱います。時刻はこのコンピューターの時計によります。式はなく、1日1回より頻繁なものはありません。

aubergine schedule add "My morning list" --at 08:30 --days weekdays \
  --element "Morning list" --new Main
aubergine schedule run "My morning list"

aubergine schedule run はスケジュールを今すぐ試します。

予定どおりにいかないとき

  • コンピューターが起きていて、Aubergine が動いている必要があります。スリープ中に過ぎた時刻は、6時間以内であれば復帰したときに遅れとして1回だけ実行されます。それ以外は missed（逃した）と記録されます。
  • スケジュールの前のタスクがまだ待っているか作業中の間は、新しいタスクを加えず、スキップしたと表示します。
  • 指定したもの（ターミナル、ステップ、キャンバス）がなくなっていれば実行せず、あなたの一覧に1つの項目でそう伝えます。

ルール

Rules では、「タスクが完了・失敗・自分待ちになったとき、またはスケジュールが発火・見逃されたとき、通知する、または保存済みのステップを実行する」と決められます。ルールを書けるのはあなただけです。プログラムもエージェントもルールを追加・変更できず、ルールが自分自身を発火させることもできません。

Aubergine はモデルを呼ばず、どのアプリの資格情報も持ちません。タスクやスケジュールは実行を始めるだけで、仕事は引き受けたエージェントが自分のツールで行います。

5分で動かす

tmux 3.2 以降と Node.js 22 以降の入った macOS が必要です。brew install tmux node で両方が入ります。

npm install -g @meatgarden/aubergine
