ターミナルが多すぎるときに目当てのものを見つける

タブが20個、ほとんどが zsh という名前で、3つでエージェントが動いていて、そのうち1つがあなたを待っている。Aubergine はすべてのターミナルをキャンバスと、それぞれが何をしているかを示す1つの一覧に置くので、どこに置いたかではなく、何であるかでターミナルを見つけられます。

よくあるやり方

タブやウィンドウに名前を付ける（たいていのターミナルアプリでできます）、ウィンドウをペインに分割する、名前付きの tmux のセッションとウィンドウを使う、タイル型ウィンドウマネージャーに配置させる。これらはターミナルを置くのには役立ちますが、あなたを必要としているものを見つけるには、やはり見て回ることになります。

Aubergine がすること

キャンバス。ターミナルが横に並び、どれもライブです。タイトルでドラッグし、端でサイズを変え、タイトルをダブルクリックして名前を変えます。タイトルの点で色を付けられます。フレーム（New terminal ▾ → Frame、または G）はターミナルをラベルの下にまとめ、一緒に動かします。

キャンバスとプロジェクト。複数のキャンバスを、タブ、1つのリスト、または左の列として表示でき、それぞれに自分のアドレスがあります。プロジェクトは自分のキャンバス、ターミナル、キュー、待っているものの一覧を持ち、左上の切り替えでプロジェクト間を移ります。

すべてのターミナルの1つの一覧。サイドパネルの Terminals は、各ターミナルを状態の言葉（working、waiting for you、finished、失敗したコマンド）、実行のステップ、最後に動いた時刻とともに、このキャンバスかすべてのキャンバスについて一覧します。上の入力欄で、名前、フォルダー、コマンド、ノート、タグからターミナルを探せます。

Filter（フィルター）には、フィルター（waiting for me、busy、unread、has an agent、parked、tags）と一覧の並べ方があります。キャンバスごと、またはキャンバス順、最終更新順、最終入力順、名前順の1つの平らな一覧です。

キャンバス上の Go to…、または ⌘K がパレットです。名前、フォルダー、コマンド、ノートの一部を入力します。その Terminal output の欄はターミナルが出力したもの（tmux が各ターミナルについて保持する最後の50,000行）を検索し、結果を選ぶとそのターミナルがその箇所までさかのぼって開きます。

マップ（ボタンは Go to… の横）は、キャンバス全体を小さく表示し、それを動かせます。Fit（F）ですべてを一度に表示します。

ターミナルが何のためにあるか。各ターミナルの横にはノート（要約とログ）があり、詳細にはタグ、リンク、Ticket: DEMO-12 のようなフィールドがあります。エージェントは aubergine コマンドで、自分のターミナルの名前、要約、フィールドを書けます。

ターミナルを単独で。タイトルの Tab ↗ で、/t/<terminal> にあるそれ専用のブラウザーのタブで開きます。詳細とノートはボタン1つで出せます。

Tab と Shift+Tab は一覧に表示された順にターミナルをたどり、W は次にあなたを待っているものへ移ります。

しないこと

  • 自動で並べることはしません。ターミナルはあなたが置いた場所にあり（新しいものは表示の中央近くの空いた場所に入ります）、あなたかそのエージェントが付けた名前を保ちます。
  • 数は約束しません。ライブのターミナルを保つのは見ているキャンバスだけです。大きくズームアウトするとターミナルは画面の画像を表示し、画面外ではページに負担をかけません。それでも各ターミナルはあなたのコンピューター上のシェルです。一覧は単体テストで1,000個のターミナルでテストしており（一覧、フィルター、1画面分だけの描画）、手で判断するために3つのキャンバスに90個のターミナルを入れるスクリプトがあります。どちらもあなたのコンピューターについての約束ではありません。
  • ターミナルアプリのタブは表示されません。Open elsewhere（O）はそこで開いているターミナルを一覧し、1つずつ、同じフォルダーの新しいターミナルとして持ってきます。タブで動いているプログラムはそのタブに残ります。

よくある質問

たくさんのターミナルウィンドウを整理するには？

Aubergine では、作業ごとに1つのキャンバスを使い、ターミナルを名前と色を付けて横に並べ、関係するものをフレームで囲み、それぞれが何をしているかを示す1つの一覧ですべてを見渡します。

どのターミナルがあるコマンドを実行しているかを見つけるには？

一覧の上の入力欄は、ターミナルの名前、フォルダー、コマンド、ノート、タグに一致させます。パレット（⌘K）はすべてのキャンバスで同じことをします。ターミナルのタイトルには実行中のものが表示されます。

すべてのターミナルの出力を検索できますか？

はい、まだ動いているものなら。パレットの Terminal output の欄は、検索したときに各ターミナルの履歴を、パークしたものも含めて、tmux が保持する範囲（50,000行）まで読みます。インデックスも記録も作りません。

Aubergine はいくつのターミナルを扱えますか？

決まった上限はありません。一覧は1,000個のターミナルでテストしており、90個ずつの3つのキャンバスを手で確認しました。各ターミナルはあくまでシェルなので、あなたのコンピューターが動かせる量で決まります。

ターミナルに名前と色を付けられますか？

はい。ターミナルのタイトルをダブルクリックして名前を変え、タイトルの点で13色のうち1つか自分の色を選びます。キャンバスにも名前と色があります。
