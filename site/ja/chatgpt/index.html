Codex と ChatGPT

Codex は OpenAI のコマンドラインのコーディングエージェントです。インストールとサインインはご自身で行います。Aubergine では、ほかのプログラムと同じようにターミナルで動きます。

まだ試していません

Aubergine で本物の Codex を動かした人はまだいません。このページに書いてあるのは、ターミナル内のあらゆるプログラムと aubergine コマンドのために Aubergine が行うことで、これは作られテストされています。Codex 自体がそこでどう振る舞うかは、まだ見ていません。試したら結果を教えてください。

起動する

New terminal（新しいターミナル）または N でターミナルを開き、ほかのターミナルと同じように Codex を起動します。Aubergine はモデルを呼ばず、キーも持ちません。Codex に必要なものは、サインインしたときにあなたが渡しています。

今日できること

Aubergine があらゆるターミナルのために行うことすべて：

  • 横に並べる

    1つのキャンバスに好きなだけターミナルを置き、キャンバスはタブで切り替えます。

  • コマンドの状態

    zsh なら、ターミナルのタイトルにコマンドが実行中であることと、そのコマンドが表示されます。

  • 色、ノート、フィールド

    ターミナルに色を付け、要約とログのあるノートを残し、チケットや担当者のようなフィールドを持たせられます。

  • パーク

    × でターミナルをパークします。キャンバスから外れても動き続け、Parked で戻せます。

  • ターミナルを単独で開く

    ターミナルを専用のブラウザータブで開き、詳細とノートを横に添えられます。

  • 作業コピー

    Shell in a folder or a working copy… または aubergine new --copy は、専用のチェックアウトの専用ブランチでターミナルを起動します。2つのエージェントが同じファイルを編集することはありません。

  • 出力の検索

    ⌘K はすべてのターミナルが出力したものを検索し、一致した箇所までスクロールした状態でターミナルを開きます。

コマンドで伝えられること

Aubergine のどのターミナルにも aubergine コマンドと、そのターミナル専用の資格情報があります。そこで動くプログラムは、Codex も含め、それを使えます：

  • aubergine attention waiting "…"

    ターミナルを waiting for you（あなた待ち）にし、必要なことを添えます。残りは aubergine attention working と aubergine attention done で伝えます。

  • aubergine note "…"

    ターミナルのノートのログに1行加えます。

  • aubergine describe

    ターミナルに作業に合った名前を付け、要約を保ちます。aubergine link add と aubergine field set で作業のリンクとフィールドを加えます。あなたが自分で書いたものが優先されます。

  • aubergine workflow status

    ワークフローの現在のステップを読みます。aubergine workflow done で完了を報告し、次のステップを出力します。

  • aubergine task add

    キューにタスクを提案します。aubergine ask は人にしかできないことをあなたに頼みます。どちらもあなたの一覧で待ちます。

伝え方

Codex は伝えられるまで Aubergine のことを知りません。これは、プロジェクトでの会話のたびに最初にエージェントが読む指示に貼り付ける5行を出力します。どこに置くかはエージェント自身のドキュメントに書かれています：

aubergine guide --snippet

その行は、Aubergine のターミナルにいるときに一度 aubergine guide を実行するよう伝え、残りはガイドが説明します。Aubergine は行を出力するだけで、どのファイルにも書き込みません。

エージェントが MCP サーバーを起動できるなら、aubergine mcp が同じことをツールとして提供します。Aubergine のターミナル内では、そのターミナル自身の作業にアドレスもトークンも要りません。

現在は Claude Code 向けにだけ作られているもの

Aubergine がエージェントのために自ら行うことは、Claude Code 向けに作られています。Codex については、現在：

  • New terminal メニューにはありません。ターミナルで自分で起動します。
  • Aubergine はそれをエージェントとして見ません。自動では waiting や finished にならず、aubergine attention を実行したときだけです。
  • 何も入力されません。そのターミナルでワークフローを始めても何も入力されず、自分で伝えるための行が表示されます。振り返りやメッセージも知らされません。
  • キューはタスクを渡しません。タスクは、エージェントが見えていて空いているターミナルにだけ渡ります。
  • Resume agent も、過去の会話の一覧も、設定の一覧も、Aubergine のツールのダイアログもありません。
  • aubergine move と aubergine here --claude が持ってくるのは Claude Code だけです。
  • ターミナルに名前を付けることや要約を保つことは促されません。

すべては Claude Code のページにあります。

ブラウザーの ChatGPT

ブラウザータブの ChatGPT はウェブページで、ターミナルのプログラムではありません。そのためキャンバスでは動きません。

Aubergine は OpenAI と提携していません。Codex および ChatGPT は OpenAI の商標です。

5分で動かす

tmux 3.2 以降と Node.js 22 以降の入った macOS が必要です。brew install tmux node で両方が入ります。

npm install -g @meatgarden/aubergine
