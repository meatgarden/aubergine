Aubergine নিজে ইংরেজিতে: এর বোতাম, মেনু আর ছবি সবই ইংরেজি।

এই পেজটি ইংরেজি থেকে মেশিন দিয়ে অনুবাদ করা। সংশোধন পাঠান।

  1. Aubergine
  2. WSL দিয়ে Windows

WSL দিয়ে Windows-এ Aubergine ইনস্টল করুন

Aubergine সরাসরি Windows-এ চলে না। এটি WSL 2-এর ভেতরে চলে, যা Windows-এর দেওয়া Linux, আর আপনি এটি আপনার Windows ব্রাউজার থেকে ব্যবহার করেন।

কী চেষ্টা করা হয়েছে। Linux-এর ধাপগুলো ২৫ নভেম্বর ২০২৬-এ একটি কন্টেইনারে Ubuntu 24.04.5 (x86_64)-এ চালানো হয়েছে, WSL-এ নয়, npm থেকে Aubergine 0.2.2 দিয়ে: এটি নিজের টার্মিনাল লাইব্রেরি কম্পাইল করেছে, চালু হয়েছে, একটি ব্রাউজারকে সাইন ইন করিয়েছে, আর একটি টার্মিনাল ও ডেমো চালিয়েছে। nvm দিয়ে Node.js ইনস্টল করা সেখানে চালানো হয়নি, কারণ Node.js 22 আগে থেকেই ইনস্টল করা ছিল। এই পেজের কিছুই এখনো Windows-এ চালানো হয়নি। আপনি চেষ্টা করলে আমাদের জানান কেমন হলো।

আপনার যা লাগবে

Windows 11, বা Windows 10 ভার্সন 2004 (বিল্ড 19041) বা নতুন, যেখানে একটি কমান্ডে WSL 2 ইনস্টল করা যায়। বিস্তারিত আছে Microsoft-এর WSL ইনস্টল করার পেজে।

ইনস্টল করুন আর চালু করুন

  1. WSL ইনস্টল করুন। PowerShell অ্যাডমিনিস্ট্রেটর হিসেবে খুলুন, এটি চালান, আর শেষ হলে Windows রিস্টার্ট করুন। এটি Ubuntu-সহ WSL 2 ইনস্টল করে।

    wsl --install

    রিস্টার্টের পরে Start মেনু থেকে Ubuntu খুলুন আর তার জন্য একটি ইউজার নেম ও পাসওয়ার্ড বেছে নিন। নিচের প্রতিটি কমান্ড সেখানেই, Ubuntu-তে টাইপ করা হয়।

  2. Aubergine-এর যা লাগে তা ইনস্টল করুন: tmux, zsh আর Git, এবং যে টুলগুলো এর টার্মিনাল লাইব্রেরি কম্পাইল করে, কারণ Linux-এর জন্য এর কিছুই আগে থেকে বানানো নেই।

    sudo apt update

    sudo apt install -y tmux zsh git build-essential python3

    Node.js 22 ইনস্টল করুন। Ubuntu-র নিজের প্যাকেজটি ভার্সন 18, যা খুব পুরোনো। একটি পরিচিত উপায় হলো nvm: এটি ইনস্টল করুন, একটি নতুন Ubuntu উইন্ডো খুলুন, তারপর Node.js 22 ইনস্টল করুন।

    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash

    nvm install 22

    এখন node -v-এর v22 বা নতুন দেখানোর কথা।

  3. npm থেকে Aubergine ইনস্টল করুন। ইনস্টলের সময় এটি নিজের টার্মিনাল লাইব্রেরি কম্পাইল করে; পরীক্ষায় পুরো ইনস্টলে ১৩ সেকেন্ড লেগেছিল।

    npm install -g @meatgarden/aubergine

  4. চালু করুন, আর ওই উইন্ডোটি খোলা রাখুন:

    aubergine start

    আপনার ব্রাউজার সাইন ইন করুন। দ্বিতীয় একটি Ubuntu উইন্ডোতে সাইন-ইন ঠিকানাটি প্রিন্ট করুন, তারপর Windows-এ আপনার ব্রাউজারে খুলুন। এটি ওই ব্রাউজারকে সাইন ইন করায়, তাই একে পাসওয়ার্ডের মতো রাখুন।

    aubergine open --print

    এরপর ওই ব্রাউজারে http://127.0.0.1:4600 নিজেই কাজ করে। ফাঁকা ক্যানভাসে Show me around ট্যুর শুরু করে।

জেনে রাখা ভালো

  • আপনার প্রজেক্টগুলো Ubuntu-তে রাখুন, তার হোম ফোল্ডারে, /mnt/c-এর নিচে নয়, যেখানে Windows-এর ফাইলে একটি ধীর সেতু দিয়ে পৌঁছাতে হয়।
  • আপনার এজেন্টগুলো Ubuntu-র ভেতরে ইনস্টল করুন, Claude Code, Codex বা অন্য যেকোনোটি, যেকোনো Linux-এর মতোই। Windows-এ ইনস্টল করা এজেন্ট Aubergine-এর টার্মিনালে থাকে না।
  • WSL যতক্ষণ চলে, টার্মিনালগুলোও ততক্ষণ থাকে। ব্রাউজার বন্ধ করলে কিছুই শেষ হয় না, আর aubergine start-এর উইন্ডোতে Ctrl+C কেবল সার্ভার থামায়। WSL থামলে, Windows রিস্টার্ট হলে বা wsl --shutdown-এর পরে, টার্মিনালগুলো শেষ হয়, আর পরের aubergine start তাদের শেষ ফোল্ডারে নতুন শেল খোলে, যেমন Mac রিস্টার্টের পরে।
  • bash না zsh। Ubuntu-র শেল bash, আর টার্মিনাল তাতে ঠিকমতো চলে। টার্মিনালে কমান্ডের অবস্থা (ব্যস্ত, ব্যর্থ কমান্ডের এক্সিট কোড) কেবল zsh থেকে আসে: পরীক্ষায় একটি zsh টার্মিনাল ব্যর্থ কমান্ডের পরে exit 3 দেখিয়েছিল। এটি পেতে Ubuntu-তে zsh-কে আপনার শেল করুন।
  • যা সেখানে নেই: লগইনে চালু হওয়া কেবল macOS-এ কাজ করে (aubergine service install তা-ই বলে), আর Open on desktop-এ Windows-এর টার্মিনাল অ্যাপের কোনো সেটিং নেই। পরীক্ষায় aubergine open খোলার মতো কোনো ব্রাউজার পায়নি; aubergine open --print সবসময় কাজ করে।
  • Windows-এ কীগুলো ব্রাউজারের ডকুমেন্টেশন দেখে বেছে নেওয়া, মাপা হয়নি: দেখুন docs/keys.md। প্যালেট সবসময় কাজ করে।

কিছু গোলমাল হলে

প্রথমে Ubuntu-তে aubergine doctor চালান। এটি Node.js, tmux, Git আর সার্ভার পরীক্ষা করে।

আপনি যা দেখছেনযা করবেন
Aubergine ইনস্টল করার সময় node-pty কম্পাইল করতে গিয়ে ব্যর্থ হয়বিল্ড টুলগুলো নেই। ধাপ ২-এর apt লাইনগুলো চালান, তারপর Aubergine আবার ইনস্টল করুন।
একটি পেজ যা বলে tmux নেই বা খুব পুরোনোUbuntu 24.04-এর tmux হলো 3.4, যথেষ্ট নতুন: sudo apt install -y tmux, তারপর সার্ভার আবার চালু করুন।
node -v v22-এর চেয়ে পুরোনো ভার্সন দেখায়ধাপ ২-এর মতো Node.js 22 ইনস্টল করুন, একটি নতুন Ubuntu উইন্ডো খুলুন, আর Aubergine আবার ইনস্টল করুন।
ঠিকানাটি Windows-এর ব্রাউজারে খোলে নাদেখুন aubergine start এখনো Ubuntu-তে চলছে কি না। তারপর Microsoft-এর WSL-এ নেটওয়ার্কিং-এর পেজ দেখুন; এটি Aubergine দিয়ে চেষ্টা করা হয়নি।
