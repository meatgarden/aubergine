রিস্টার্টের পরে Claude Code-এর কথোপকথন আবার শুরু করুন

কম্পিউটার রিস্টার্ট হয়েছে, বা আপনি টার্মিনাল বন্ধ করেছেন, আর Claude Code-এর কথোপকথন হারিয়ে গেছে মনে হচ্ছে। Claude Code এটি রেখে দেয়। Aubergine মনে রাখে প্রতিটি টার্মিনাল কোন কথোপকথনে ছিল আর একটি বোতামে তা ফিরিয়ে আনে।

সাধারণত লোকে কী করে

একটি টার্মিনালে, যে ফোল্ডারে কথোপকথনটি ছিল সেখানে: claude --continue সেখানকার সবচেয়ে সাম্প্রতিক কথোপকথন চালিয়ে নেয়, আর claude --resume আপনাকে একটি তালিকা থেকে বেছে নিতে দেয়, বা কথোপকথনের ID নেয়। সমস্যা হলো ফোল্ডার আর বাছাই: এক ফোল্ডারে কয়েকটি এজেন্ট থাকলে সবচেয়ে সাম্প্রতিকটি সবসময় আপনার চাওয়াটি নয়।

Aubergine কী করে

টার্মিনাল তার কথোপকথন মনে রাখে। Claude Code Aubergine থেকে চালু হলে (New terminal ▾ → Claude Code, বা C), তার হুকগুলো Aubergine-কে জানায় এটি কোন কথোপকথনে আছে, আর Aubergine সেই ID টার্মিনালের সঙ্গে রাখে।

Resume agent (এজেন্ট আবার শুরু) টার্মিনালের টাইটেল বারে দেখা যায় যখন তার শেল আবার প্রম্পটে ফেরে: আপনি এজেন্ট থেকে বেরিয়েছেন, বা কম্পিউটার রিস্টার্ট হয়ে টার্মিনাল তার শেষ ফোল্ডারে একটি নতুন শেল হিসেবে ফিরেছে। এটি Claude Code-কে --resume আর সেই ID দিয়ে আবার চালু করে, আপনার সেটিংসের লঞ্চ কমান্ড দিয়ে (agents.claudeCommand, ডিফল্টভাবে claude)।

কোনো ওয়ার্কফ্লোর রানে, Resume agent এজেন্টকে রানের কথাও আবার জানায়, যাতে রান যে ধাপে আছে সেখান থেকেই সে এগোয়।

Past conversations… (আগের কথোপকথন), প্যালেটে (⌘K), বা টার্মিনালের বিবরণে “Past conversations in this folder…”, একটি ফোল্ডারে Claude Code-এর আগের কথোপকথনগুলোর তালিকা দেয়: নাম বা আপনার বলা প্রথম কথা, শেষ কখন সক্রিয় ছিল, আপনি কতবার কথা বলেছেন, আর এখন কোনো ক্যানভাসের কোনো টার্মিনাল তাতে আছে কি না। Read এটি কেবল পড়ার জন্য দেখায়। Open on the canvas সেই ফোল্ডারে একটি নতুন টার্মিনাল চালু করে যাতে কথোপকথনটি আবার শুরু হয়, আর Open a copy তার একটি শাখা শুরু করে আর আসলটিকে যেমন আছে তেমন রাখে। কোনো টার্মিনাল আগে থেকেই সেই কথোপকথনে থাকলে, আগে আপনাকে জিজ্ঞেস করা হয়।

সার্চ। আপনার ক্যানভাসের টার্মিনালগুলোর ফোল্ডারে পুরোনো কথোপকথন খুঁজতে প্যালেটে @ আর কয়েকটি শব্দ টাইপ করুন। এটি আপনি চাইলে, সীমার মধ্যে, রেকর্ডগুলো পড়ে, আর খোঁজা মাঝপথে থামলে তা বলে। কমান্ড লাইনে aubergine history তালিকা দেখায় আর aubergine history open <id> একটি খোলে।

কাজ কোথায় ছিল। টার্মিনালের নোট তার সারাংশ আর একটি লগ রাখে, আর আপনার পাঠানো প্রতিটি প্রম্পট লগে যোগ হয়। এর বিবরণে Ask its agent for a recap (এর এজেন্টের কাছে রিক্যাপ চান) এজেন্টকে দিয়ে aubergine recap --write দিয়ে লেখায় সে কোথায় আছে, যা টার্মিনালের সঙ্গে থাকে। 30 মিনিটের বেশি পরে ফিরলে While you were away (আপনি না থাকার সময়) দেখায় এর মধ্যে কী বদলেছে।

Aubergine-এর বাইরের টার্মিনালের কথোপকথন

আপনার টার্মিনাল অ্যাপের একটি ট্যাবে এজেন্ট থেকে বেরিয়ে আসুন, তারপর একই ফোল্ডারে aubergine here --claude চালান: ক্যানভাসে একটি নতুন টার্মিনাল Claude Code-কে --continue দিয়ে চালু করে, এবার তার অবস্থা দেখা যায়। aubergine move আপনার Claude Code ট্যাবগুলোর তালিকা দেয় আর প্রতিটি কথোপকথনের একটি কপি ক্যানভাসে চালু করে; --stop দিলে আপনি নিশ্চিত করার পরে এটি idle এজেন্টকে আগে বেরিয়ে আসতে বলে।

এটি কী করে না

  • এটি Claude Code-এর নিজস্ব রেকর্ড পড়ে, এমন গঠনে যা Aubergine-এর নয়। Claude Code সেই ফাইলগুলোর গঠনকে অভ্যন্তরীণ বলে, আর সংস্করণ বদলালে তা বদলায়। আবার শুরু করা ID সহ Claude Code-এর নিজস্ব --resume ব্যবহার করে; নাম, সংখ্যা আর ট্রান্সক্রিপ্ট হলো Aubergine-এর ফাইল পড়া, আর Claude Code-এর আপডেটের পরে না-ও থাকতে পারে বা কম আসতে পারে। যে রেকর্ড এটি পড়তে পারে না সেটির ব্যাপারে তা-ই বলা হয়, খালি কথোপকথন হিসেবে দেখানো হয় না।
  • কিছুই কপি করা বা রাখা হয় না। একটি তালিকা, ট্রান্সক্রিপ্ট বা সার্চ আপনি চাইলে পড়া হয় আর বন্ধ করলে ফেলে দেওয়া হয়। Aubergine কখনো কোনো কথোপকথন বদলায় না, নাম বদলায় না বা মুছে ফেলে না, আর কোনো এজেন্ট বা টোকেন এর মাধ্যমে কথোপকথন পড়তে পারে না।
  • চলতি কাজ আবার করা হয় না। থামার সময় এজেন্ট যা করছিল, তা আপনি না বলা পর্যন্ত আবার শুরু হয় না।
  • অন্য এজেন্টের জন্য Resume agent নেই। Aubergine অন্য এজেন্টের কথোপকথন জানে না, আর তার পুরোনো কথোপকথনের তালিকাও দেয় না। সেই এজেন্টের নিজস্ব আবার-শুরুর উপায়ে একই টার্মিনালে তাকে আবার চালু করুন, আর নোট পড়ে তাকে জানান সে কোথায় ছিল।
  • নিজে টাইপ করা claude মনে রাখা হয় না, যদি না আপনি aubergine hooks print-এর প্রিন্ট করা হুকগুলো আপনার নিজের Claude Code সেটিংসে যোগ করে থাকেন।
  • কী যাচাই করা হয়েছে। কথোপকথনের রেকর্ড পড়া পরীক্ষা করা হয়েছে বানানো রেকর্ডের ওপর। Claude Code-এর প্রতিটি সংস্করণের সঙ্গে যাচাই করা হয়নি।

প্রশ্ন

টার্মিনাল বন্ধ করার পরে Claude Code সেশন কীভাবে আবার শুরু করব?

একই ফোল্ডারে, claude --continue সবচেয়ে সাম্প্রতিক কথোপকথন নেয় আর claude --resume আপনাকে বেছে নিতে দেয়। Aubergine-এ ব্রাউজার বন্ধ করলে কিছুই শেষ হয় না, আর যে টার্মিনালের এজেন্ট থেকে আপনি বেরিয়েছেন তা তার টাইটেল বারে Resume agent দেখায়।

রিবুটের পরে Claude Code-এর কথোপকথন কীভাবে আবার শুরু করব?

রিস্টার্টের পরে প্রতিটি Aubergine টার্মিনাল তার শেষ ফোল্ডারে একটি নতুন শেল হিসেবে ফেরে। যেখানে Claude Code Aubergine থেকে চালু হয়েছিল, সেখানে টাইটেল বারে Resume agent সেই টার্মিনাল যে কথোপকথনে ছিল তাতেই এটিকে আবার চালু করে।

Claude Code-এর একটি পুরোনো কথোপকথন কীভাবে খুঁজব?

প্যালেটে Past conversations… একটি ফোল্ডারের জন্য তালিকা দেখায়, কেবল পড়ার ট্রান্সক্রিপ্ট সহ; প্যালেটে @ আর কয়েকটি শব্দ সেগুলোতে খোঁজে। Claude Code এখনো যা রাখে কেবল তা-ই তালিকায় থাকে।

claude --continue আর claude --resume-এর পার্থক্য কী?

--continue ফোল্ডারের সবচেয়ে সাম্প্রতিক কথোপকথন চালিয়ে নেয়; --resume নেয় আপনি যেটি বাছেন, বা একটি ID। Resume agent টার্মিনালের মনে রাখা ID দিয়ে --resume ব্যবহার করে, তাই কোন কথোপকথন সবচেয়ে সাম্প্রতিক ছিল তার ওপর নির্ভর করে না।

দুটি টার্মিনাল কি একই Claude Code কথোপকথন চালিয়ে যেতে পারে?

Aubergine জিজ্ঞেস না করে একটি কথোপকথন দুবার খোলে না: এক কথোপকথনে দুটি এজেন্ট একে অপরের বার্তা হারায়। আপনাকে দেওয়া হয় আগে থেকে তাতে থাকা টার্মিনালটি, বা একটি কপি, যা কথোপকথনের শাখা তৈরি করে।
