Aubergine Claude Code-এর জন্য কী করে

Claude Code যেকোনো প্রোগ্রামের মতো Aubergine টার্মিনালে চলে। Aubergine থেকে চালু করলে এটি ক্যানভাসকে জানায়ও যে কী করছে, আর Aubergine একে তথ্য দিতে পারে, আবার শুরু করতে পারে আর দেখাতে পারে এটি কীভাবে সেট আপ করা। এই হলো সবটুকু, যে ক্রমে আপনি এর দেখা পান।

Claude Code আপনি নিজে ইনস্টল করেন আর নিজে সাইন ইন করেন। Aubergine কোনো মডেল কল করে না আর কোনো key রাখে না: এটি আপনার কাছে আগে থেকে থাকা claude কমান্ডটি চালু করে।

  1. মেনু থেকে চালু করুন

    New terminal ▾ → Claude Code, বা কোনো টার্মিনালের কাছে কিবোর্ড না থাকলে C, একটি নতুন টার্মিনালে claude চালু করে, এমন একটি সেটিংস ফাইল দিয়ে যা Aubergine নিজের ডেটা ফোল্ডারে লেখে। আপনার নিজের Claude Code কনফিগারেশনে হাত দেওয়া হয় না।

    এটি যে কমান্ড চালু করে তা সেটিংসের agents.claudeCommand, আপনি না বদলালে claude; Aubergine শেষে নিজের ফ্ল্যাগ যোগ করে।

    কোথায়: New terminal-এর পাশের মেনু, টার্মিনালের তালিকার একদম উপরে।

  2. দেখুন কখন কাজ করছে, অপেক্ষা করছে আর শেষ করছে

    সেই সেটিংস ফাইলের হুকগুলো ক্যানভাসকে জানায় এজেন্ট কী করছে। আপনি একটি প্রম্পট পাঠালে প্রম্পটটি টার্মিনালের নোট লগে যোগ হয় আর টার্মিনাল working দেখায়। এজেন্টের আপনাকে দরকার হলে, অনুমতির প্রশ্ন নিয়ে বা ইনপুটের অপেক্ষায় idle থাকায়, এর রেখা অপেক্ষার রঙ নেয় আর এর শিরোনাম ও সারিতে লেখা থাকে waiting for you (আপনার অপেক্ষায়)। থেমে গেলে দেখায় finished।

    W পরের অপেক্ষমাণ টার্মিনালে নিয়ে যায়, আর Notify অপেক্ষা শুরু করা টার্মিনালের জন্য ডেস্কটপ নোটিফিকেশন চালু করে। প্রম্পটে গোপন তথ্য থাকতে পারে: "agents": { "logPrompts": false }, config.json-এ, সেগুলো নোট লগের বাইরে রাখে।

    কোথায়: টার্মিনালের শিরোনাম, তালিকায় তার সারি, আর উপরে For you-এর পাশের সংখ্যা।

  3. যে Claude Code আপনি নিজে চালু করেছেন

    সাধারণ টার্মিনালে হাতে টাইপ করলে claude যেকোনো প্রোগ্রামের মতো কাজ করে, কিন্তু Aubergine শুধু দেখে একটি শেল সেটি চালাতে busy: কোনো waiting for you নেই, আর সেখানে ওয়ার্কফ্লো শুরু করলে তার জন্য কিছু টাইপ হয় না। এটি বদলাতে হুকগুলো প্রিন্ট করুন আর হাতে আপনার নিজের Claude Code সেটিংসে যোগ করুন। Aubergine টার্মিনালের বাইরে সেগুলো কিছুই করে না।

    aubergine hooks print

  4. এটি নিজের নাম দেয় আর একটি সারাংশ রাখে

    Aubergine যে এজেন্ট চালু করে, শুরুতেই তাকে বলা হয় aubergine describe, aubergine link add আর aubergine field set দিয়ে তার টার্মিনালের নাম কাজের নামে রাখতে আর একটি সারাংশ রাখতে, আর নিজের নাম বা সারাংশ ছাড়া থামলে একবার মনে করিয়ে দেওয়া হয়। আপনি নিজে যা লেখেন সেটাই থাকে; একই বিষয়ে এজেন্ট যা বলে, তা পাশে Use this সহ অপেক্ষা করে। মনে করিয়ে দেওয়া Settings-এ বন্ধ করা যায়।

    কোথায়: টার্মিনালের বিবরণ, তার নাম, সারাংশ, ফিল্ড আর লিংক সহ।

  5. ওয়ার্কফ্লো, টাস্ক, রিক্যাপ আর বার্তা এর কাছে পৌঁছায়

    Aubergine একটি টার্মিনালে চারটি নির্দিষ্ট বাক্য টাইপ করে, আর শুধু এগুলোই: যে একটি ওয়ার্কফ্লো শুরু হয়েছে, যে এজেন্টকে কিছু লিখতে বলা হয়েছে, যে আপনি একটি রিক্যাপ চেয়েছেন, আর যে একটি বার্তা অপেক্ষা করছে। প্রতিটি বাক্য এজেন্টের চালানোর জন্য একটি কমান্ড বলে দেয়। বাক্য শুধু সেখানেই টাইপ হয় যেখানে কিবোর্ড কোনো এজেন্টের কাছে আছে বলে দেখা যায়: এমন এজেন্ট যাকে Aubergine চালু করেছে, বা যার সেটিংসে aubergine hooks print-এর হুক আছে।

    একইভাবে, কিউয়ের টাস্ক শুধু এমন টার্মিনালে যায় যেখানে এমন এজেন্ট সামনে আছে আর ফাঁকা, আর Claude Code on a workflow… একটি নতুন টার্মিনাল চালু করে যার এজেন্টকে তার প্রথম প্রম্পটেই রানের কথা জানানো হয়।

    কোথায়: টার্মিনালের শিরোনামের মেনুতে Run a workflow…, আর পেজের উপরে Runs।

  6. Resume agent

    Aubergine মনে রাখে কোনো এজেন্ট টার্মিনাল কোন কথোপকথনে ছিল। এর শেল আবার প্রম্পটে ফিরলে, কারণ আপনি এজেন্ট থেকে বেরিয়েছেন বা কম্পিউটার রিস্টার্ট হয়েছে, টার্মিনাল Resume agent (এজেন্ট আবার শুরু) দেখায়, যা এজেন্টকে সেই কথোপকথনেই আবার চালু করে। কোনো রানে থাকা টার্মিনালে এটি এজেন্টকে রানের কথাও আবার জানায়।

    কোথায়: টার্মিনালের টাইটেল বার।

  7. পুরোনো কথোপকথন

    Past conversations… একটি ফোল্ডারে এজেন্টের আগের কথোপকথনগুলোর তালিকা দেখায়: একটি পড়ুন, ক্যানভাসে খুলুন, বা এমন একটি কপি খুলুন যা আসলটিকে যেমন আছে তেমন রাখে। খুঁজতে প্যালেটে @ আর কয়েকটি শব্দ টাইপ করুন; aubergine history কমান্ড লাইনে তালিকা দেখায়। যা পড়া হয় তা রাখা হয় না, আর কোনো টোকেন বা এজেন্ট Aubergine-এর মাধ্যমে কথোপকথন পড়তে পারে না।

    এটি Claude Code-এর রাখা ফাইলগুলো পড়ে। সেগুলোর গঠন Claude Code-এর অভ্যন্তরীণ, আর সংস্করণ বদলালে তা বদলায়। এজেন্টের আপডেটের পরে নাম আর ট্রান্সক্রিপ্ট কম আসতে পারে, আর যে রেকর্ড Aubergine পড়তে পারে না সেটির ব্যাপারে তা-ই বলা হয়, কখনো খালি দেখানো হয় না।

    কোথায়: প্যালেট (⌘K), আর টার্মিনালের বিবরণে “Past conversations in this folder…”।

  8. এটি কীভাবে সেট আপ করা

    এজেন্টের কনফিগারেশন ফাইল অনুযায়ী তাকে কী কী দেওয়া হয়েছে তার তালিকা: MCP সার্ভার, প্লাগইন, হুক, স্কিল, অনুমতির নিয়ম আর সেটিংস ফাইল, প্রতিটির সঙ্গে কোথা থেকে এসেছে, আর Aubergine কী যোগ করেছে। শুধু নাম, কখনো কোনো মান বা গোপন তথ্য নয়। এটি বলে এজেন্ট কীভাবে সেট আপ করা, চলমান এজেন্ট কী লোড করেছে তা নয়, আর স্পষ্ট বলে কী জানা সম্ভব নয়, যেমন আপনার অ্যাকাউন্টের সঙ্গে আসা কানেক্টর।

    কোথায়: টার্মিনালে ⚙ on, প্যালেটে “What is switched on for this agent…”, আর টার্মিনালের বিবরণ।

  9. এর জন্য Aubergine-এর টুল

    Claude Code with Aubergine tools… আগে জিজ্ঞেস করে এজেন্ট কী করতে পারবে: None (কিছুই না); Its own work only (শুধু নিজের কাজ), টার্মিনালের নিজের ক্রেডেনশিয়াল দিয়ে; বা More…, আপনার বেছে নেওয়া স্কোপ, যার জন্য সেই একটি টার্মিনালের জন্য একটি টোকেন বানানো হয় আর টার্মিনাল চিরতরে বন্ধ হলে বাতিল হয়। টুলগুলো হলো aubergine mcp, যা এজেন্টকে তার লঞ্চ লাইনে দেওয়া হয়; এর নিজের কনফিগারেশন লেখা হয় না।

    কোথায়: New terminal-এর পাশের মেনু।

  10. আগে থেকে খোলা Claude Code নিয়ে আসুন

    চলমান এজেন্টকে সরানো যায় না, কিন্তু তার কথোপকথন আনা যায়। Open elsewhere আপনার Claude Code ট্যাবগুলো দেখায়, Fork to canvas সহ আর, idle এজেন্টের জন্য, Stop and resume here সহ, যা আগে আপনাকে জিজ্ঞেস করে। কোনো টার্মিনাল থেকে aubergine move একই কাজ করে, আর aubergine here --claude ক্যানভাসে Claude Code চালু করে, সেই ফোল্ডারের শেষ কথোপকথন চালিয়ে।

    কোথায়: ক্যানভাসের উপরের বারে Open elsewhere, বা O।

  11. নিজস্ব ওয়ার্কিং কপিতে

    aubergine here --copy --claude Claude Code-কে রিপোজিটরির নিজস্ব চেকআউটে, নিজস্ব ব্রাঞ্চে চালু করে, যাতে দুটি এজেন্ট কখনো একই ফাইল না বদলায়। টুল সহ Claude Code টার্মিনালের ডায়ালগেও একই বিকল্প আছে।

কী পরীক্ষা করা হয়েছে

Aubergine-এর সঙ্গে আসা ডেমো নকল এজেন্ট ব্যবহার করে, ছোট স্ক্রিপ্ট যা আসল এজেন্টের মতোই একই কমান্ড আর হুক চালায়, আসল Claude Code নয়। আসল এজেন্ট দিয়ে অনুমোদন, ওয়ার্কিং কপি, কিউয়ের টাস্ক আর শিডিউল এখনো পরীক্ষা করা হয়নি।

অন্য এজেন্ট এর বেশিরভাগই aubergine কমান্ড দিয়ে জানাতে পারে: দেখুন Codex আর ChatGPT।

Aubergine-এর সঙ্গে Anthropic-এর কোনো সম্পর্ক নেই। Claude আর Claude Code হলো Anthropic-এর ট্রেডমার্ক।

npm install -g @meatgarden/aubergine
