গাইড

ছোট, কাজের গাইড। পুরো রেফারেন্স হলো README।

  • Aubergine ইনস্টল করুন

    যা লাগবে, এক লাইনের ইনস্টলার, এটি কী বদলায়, আর সাধারণ সমস্যার সমাধান।

  • WSL দিয়ে Windows-এ ইনস্টল করুন

    Aubergine WSL 2-এর ভেতরে চালান আর আপনার Windows ব্রাউজার থেকে ব্যবহার করুন। Linux-এর ধাপগুলো চালানো হয়েছে; Windows-এ এখনো কিছু চেষ্টা করা হয়নি।

  • একসঙ্গে কয়েকটি কোডিং এজেন্ট চালান

    ক্যানভাস, অপেক্ষার সংখ্যা, কিউ, ওয়ার্কিং কপি আর ওয়ার্কফ্লো, একটি ট্যুরে।

  • Aubergine-এ Claude Code

    Aubergine নিজে থেকে Claude Code-এর জন্য কী করে, আর কোন জিনিস কোথায়।

  • Codex আর ChatGPT

    যেকোনো প্রোগ্রামের মতো টার্মিনালে Codex, এটি কী জানাতে পারে, আর কী শুধু Claude Code-এর জন্য তৈরি।

  • ওয়ার্কিং কপি

    প্রতিটি এজেন্টকে নিজস্ব চেকআউট আর ব্রাঞ্চ দিন, যাতে দুটি এজেন্ট কখনো একই ফাইল না বদলায়।

  • রিস্টার্টের পরেও টার্মিনাল রেখে দিন

    ব্রাউজার বন্ধ করা, Aubergine রিস্টার্ট করা আর কম্পিউটার রিস্টার্ট করা, প্রতিটি কী রেখে দেয়, আর যেখানে ছিলেন সেখান থেকে কীভাবে আবার শুরু করবেন।

  • টার্মিনাল বন্ধ করার পরেও প্রসেস চালু রাখুন

    ট্যাব, উইন্ডো বা ব্রাউজার বন্ধ করুন, কিছুই শেষ হয় না: tmux যা দেয়, tmux না শিখেই।

  • tmux না শিখেই tmux

    উইন্ডো বন্ধের পরেও চলা শেল, কোনো প্রিফিক্স key আর কনফিগারেশন ছাড়া, আর আপনার নিজের tmux যেমন ছিল তেমনই।

  • জানুন কখন Claude Code শেষ করেছে বা অপেক্ষা করছে

    প্রতিটি টার্মিনালে working, waiting for you আর finished, For you-এর সংখ্যা, পরের অপেক্ষমাণ টার্মিনালের key আর খোলা পেজ থেকে নোটিফিকেশন।

  • Claude Code-এর কথোপকথন আবার শুরু করুন

    যে টার্মিনালে এটি চলেছিল সেখানে Resume agent, একটি ফোল্ডারের পুরোনো কথোপকথন, আর যা বলে দেয় কাজ কোথায় ছিল।

  • অনেক টার্মিনাল থাকলে ঠিকটি খুঁজে নিন

    একটি ক্যানভাস, প্রতিটি টার্মিনালের একটি তালিকা যাতে তার অবস্থা কথায় লেখা, ফিল্টার, ট্যাগ আর টার্মিনালগুলো যা ছেপেছে তাতে সার্চ।

  • ফোন থেকে এজেন্টদের খোঁজ নিন

    অন্য ডিভাইস থেকে Aubergine-এ পৌঁছানো, প্রতিটি ডিভাইস একটি কোড দিয়ে যুক্ত। একটি Mac-এ একবার চালানো হয়েছে; আসল ফোনে পরীক্ষা করা হয়নি।

  • কিউ, For you আর শিডিউল

    কাজ একবার ভাগ করে দিন, আপনার অপেক্ষায় থাকা সবকিছু দেখুন, আর নির্দিষ্ট সময়ে টাস্ক চালান।

  • অন্য টুলের সঙ্গে Aubergine-এর তুলনা

    Aubergine-এর পাশে Conductor, Claude Squad, Vibe Kanban, cmux, Warp আর Paradev, প্রতিটি নিজের সম্পর্কে যা লিখে রেখেছে তা থেকে।

  • নিরাপত্তা আর গোপনীয়তা

    কী সুরক্ষিত, আর কী নয়।

  • প্রশ্নোত্তর

    সাধারণ প্রশ্নের ছোট উত্তর।

পাঁচ মিনিটে চালু

আপনার লাগবে macOS, সঙ্গে tmux 3.2 বা নতুনতর আর Node.js 22 বা নতুনতর। brew install tmux node দুটোই এনে দেয়।

npm install -g @meatgarden/aubergine
