Aubergine নিজে ইংরেজিতে: এর বোতাম, মেনু আর ছবি সবই ইংরেজি।

এই পেজটি ইংরেজি থেকে মেশিন দিয়ে অনুবাদ করা। সংশোধন পাঠান।

  1. Aubergine
  2. ইনস্টল

Aubergine কীভাবে ইনস্টল করবেন

একটি কমান্ড ইনস্টল করে, একটি চালু করে। ট্যুর সহ মোটামুটি পাঁচ মিনিট।

যা লাগবে

  • macOS. Linux-এ এখন পর্যন্ত কেবল কন্টেইনারের ভেতরে চালানো হয়েছে: Ubuntu 24.04-এ npm প্যাকেজ আর Debian-এ কন্টেইনার ইমেজ। Windows নিজে সমর্থিত নয়; Aubergine WSL 2-এর ভেতরে চলতে পারে, যা এখনো চেষ্টা করা হয়নি: দেখুন WSL দিয়ে Windows-এ ইনস্টল করুন।
  • tmux 3.2 বা নতুনতর আর Node.js 22 বা নতুনতর। ইনস্টলারের pnpm-ও লাগে।

Homebrew থাকলে একটি লাইনেই দুটো পাবেন (ইনস্টলারের জন্য pnpm যোগ করুন):

brew install tmux node

ইনস্টল আর চালু করুন

  1. npm থেকে Aubergine ইনস্টল করুন (শুধু tmux আর Node.js লাগে):

    npm install -g @meatgarden/aubergine

    অথবা ইনস্টলার দিয়ে, যার pnpm-ও লাগে আর যা সোর্স থেকে বিল্ড করে:

    curl -fsSL https://raw.githubusercontent.com/thirstyeggplant/aubergine/main/install.sh | sh

  2. চালু করুন আর ব্রাউজার সাইন ইন করা অবস্থায় খুলুন।

    aubergine start --open

  3. ট্যুর নিন। ফাঁকা ক্যানভাসের মাঝখানে Show me around-এ ক্লিক করুন। এটি “Demo” নামের একটি ক্যানভাস বানায়, কয়েকটি নকল এজেন্ট সহ, আর আটটি ছোট ধাপে আপনাকে ঘুরিয়ে দেখায়। ডেমোর কিছুই আসল নয়, আর aubergine demo --remove সেটি সরিয়ে দেয়।

আগে স্ক্রিপ্টটি পড়তে চান? ডাউনলোড করুন, পড়ুন, আর sh install.sh --dry-run চালান, কিছু না বদলে এটি কী করত তা দেখতে।

ইনস্টলার কী বদলায়

শুধু দুটি জিনিস: ইনস্টল ফোল্ডার (~/.aubergine, বা AUBERGINE_HOME) আর aubergine নামের একটি লিংক, আপনার PATH-এর এমন একটি ফোল্ডারে যেখানে আপনি লিখতে পারেন। এটি আগে সবকিছু যাচাই করে, আর কিছু না থাকলে কিছুই বদলায় না।

এটি করে না: sudo ব্যবহার, আপনার শেলের স্টার্টআপ ফাইল সম্পাদনা, Node.js, pnpm বা tmux ইনস্টল, বা আপনার ডেটা ফোল্ডারে হাত দেওয়া।

কিছু গোলমাল হলে

প্রথমে aubergine doctor চালান। এটি সাধারণ কারণগুলো যাচাই করে।

আপনি যা দেখছেনযা করবেন
“This browser is not signed in yet”সেই ব্রাউজারে সাইন-ইন লিংকটি একবার খুলুন। aubergine open --print সেটি আবার প্রিন্ট করে।
একটি পেজ যা বলে tmux নেই বা খুব পুরোনোtmux ইনস্টল বা আপগ্রেড করুন (brew install tmux), তারপর সার্ভার রিস্টার্ট করুন।
পোর্ট আগে থেকেই ব্যবহৃত, তাই সার্ভার চালু হচ্ছে নাঅন্য পোর্ট ব্যবহার করুন: AUBERGINE_PORT=4700 aubergine start।
aubergine: command not foundলিংকটি আপনার PATH-এ নেই। ইনস্টলার সেই একটি লাইন প্রিন্ট করে যা আপনার শেলের স্টার্টআপ ফাইলে যোগ করতে হবে।
একটি টার্মিনালে কোনো স্ট্যাটাস ব্যাজ দেখা যাচ্ছে নাস্ট্যাটাসের জন্য zsh লাগে, আর আপডেটের আগে তৈরি সেশন তার পুরোনো শেলই রাখে। সেটি পার্ক করুন আর নতুন একটি চালু করুন।

থামানো, আপডেট, আনইনস্টল

  • Ctrl+C দিয়ে সার্ভার থামান। আপনার টার্মিনালগুলো চলতে থাকে; ফিরে পেতে সার্ভার আবার চালু করুন আর পেজ রিলোড করুন।
  • আপডেট: npm দিয়ে ইনস্টল করে থাকলে npm install -g @meatgarden/aubergine@latest দিয়ে; ইনস্টলার ব্যবহার করে থাকলে aubergine update দিয়ে। তারপর সার্ভার রিস্টার্ট করুন।
  • আনইনস্টল: aubergine uninstall দিয়ে। এটি লিংকটি সরায় আর, জিজ্ঞেস করার পরে, ইনস্টলারের বানানো কপিটি। এটি কখনো আপনার ডেটা মোছে না আর কখনো আপনার টার্মিনাল বন্ধ করে না।
  • লগইনের সময় চালু: aubergine service install দিয়ে, যাতে আপনাকে শুধু ব্রাউজার খুলতে হয়।
