Aubergine vs Claude Squad

দুটি একই ভিতের ওপর দাঁড়িয়ে: প্রতিটি এজেন্ট একটি tmux সেশনে, প্রতিটি নিজস্ব Git worktree-তে, দুটিই বিনামূল্যে আর ওপেন সোর্স। Claude Squad আপনার টার্মিনালের ভেতরে একটি প্রোগ্রাম। Aubergine আপনার ব্রাউজারে একটি পেজ, যেখানে টার্মিনালগুলো পাশাপাশি থাকে।

এটি কোথা থেকে। এখানে Claude Squad সম্পর্কে যা বলা হয়েছে তা এর রিপোজিটরি আর README থেকে, ২৬ নভেম্বর ২০২৬-এ যেমন পড়া হয়েছে। আমরা Claude Squad চালিয়ে দেখিনি। কিছু ভুল বা পুরোনো হলে আমাদের জানান।

কোনটি বেছে নেবেন

Claude Squad বেছে নিন যদি আপনি টার্মিনালেই থাকেন আর সেখানে একটি ছোট প্রোগ্রাম চান যা worktree-তে এজেন্ট চালু করে আর তাদের ব্রাঞ্চ push করে, তার বেশি কিছু নয়।

Aubergine বেছে নিন যদি একসঙ্গে কয়েকটি এজেন্টকে কাজ করতে দেখতে চান, জানতে চান কোনটি আপনার অপেক্ষায়, আর তাদের চারপাশে একটি কিউ, শিডিউল আর একটি API চান।

Claude Squad কী

এর নিজের বর্ণনা অনুযায়ী, একটি টার্মিনাল অ্যাপ যা আলাদা আলাদা ওয়ার্কস্পেসে কয়েকটি Claude Code, Codex, Gemini আর অন্য লোকাল এজেন্ট সামলায়। আপনি একে চালু করেন cs হিসেবে: একটি টার্মিনাল উইন্ডোতে সেশনের একটি তালিকা, একটি প্রিভিউ আর একটি ডিফ ট্যাব সহ। প্রতিটি সেশন নিজস্ব ব্রাঞ্চে একটি Git worktree-তে একটি tmux সেশন। এর জন্য tmux আর gh লাগে, আর এটি AGPL-3.0 লাইসেন্সে।

কোথায় তারা আলাদা

একবারে একটি, নাকি সবগুলো একসঙ্গে। Claude Squad একটি তালিকা আর আপনার বেছে নেওয়া সেশনের প্রিভিউ দেখায়। Aubergine প্রতিটি টার্মিনাল একটি ক্যানভাসে লাইভ আঁকে, তাই পাঁচটি এজেন্ট মানে চোখের সামনে পাঁচটি টার্মিনাল, আর একটি তালিকা প্রতিটির অবস্থা কথায় বলে।

কে অপেক্ষা করছে। কোনো এজেন্ট অপেক্ষা করছে বা শেষ করেছে তা জানানো নিয়ে আমরা Claude Squad-এর README-তে কিছু পাইনি। Aubergine অপেক্ষমাণ টার্মিনাল রঙে চিহ্নিত করে, উপরে অপেক্ষায় থাকা সবকিছু গোনে, একটি key দিয়ে পরেরটিতে যায়, আর খোলা পেজ থেকে নোটিফিকেশন পাঠাতে পারে।

এজেন্টদের চারপাশে কী আছে। Aubergine-এ আছে সীমা সহ টাস্কের একটি কিউ, শিডিউল, এমন ধাপ সহ ওয়ার্কফ্লো যা একজন মানুষ অনুমোদন করেন, প্রতিটি টার্মিনালে নোট আর ফিল্ড, একটি HTTP API আর একটি MCP সার্ভার। Claude Squad সেশন আর তাদের ব্রাঞ্চেই সীমাবদ্ধ থাকে।

Claude Squad-এর যা আছে আর Aubergine-এর নেই

  • এটি আপনার আগে থেকে খোলা টার্মিনালের ভেতরেই চলে, কোনো সার্ভার বা ব্রাউজার ছাড়া। যেকোনো টার্মিনাল প্রোগ্রামের মতো এটি SSH-এর ওপর কাজ করে; অন্য জায়গা থেকে Aubergine ব্যবহারে একটি টানেল বা প্রক্সি লাগে।
  • এটি আপনার হয়ে একটি ব্রাঞ্চ commit আর push করে, আর কাজ commit করে একটি সেশন থামিয়ে রাখে। Aubergine কখনো commit বা push করে না।
  • একটি পরীক্ষামূলক মোড, যা নিজে থেকেই এজেন্টের প্রম্পট মেনে নেয়। Aubergine কখনো আপনার হয়ে এজেন্টকে উত্তর দেয় না।

প্রশ্ন

Aubergine কি Claude Squad-এর বিকল্প?

হ্যাঁ, একই কাজ অন্যভাবে করার জন্য। দুটিই প্রতিটি এজেন্টকে একটি tmux সেশনে চালায় আর প্রতিটিকে নিজস্ব ব্রাঞ্চে একটি Git worktree দিতে পারে। Claude Squad তা করে আপনার টার্মিনালের একটি প্রোগ্রাম থেকে; Aubergine আপনার ব্রাউজারের একটি পেজ থেকে, প্রতিটি টার্মিনাল চোখের সামনে রেখে।

দুটিই কি tmux ব্যবহার করে?

হ্যাঁ। Claude Squad tmux-কে পূর্বশর্ত হিসেবে উল্লেখ করে আর প্রতিটি এজেন্টের জন্য একটি tmux সেশন বানায়। Aubergine-এর tmux 3.2 বা নতুনতর লাগে আর এটি tmux চালায় নিজের একটি সকেটে, নিজের কনফিগারেশন দিয়ে, তাই আপনার নিজের tmux-এ হাত দেওয়া হয় না।

Claude Squad কি Claude Code ছাড়া অন্য এজেন্টের সঙ্গে কাজ করে?

এর README বলে ডিফল্ট প্রোগ্রাম claude, আর অন্য কোনোটি, যেমন Codex, Gemini বা Aider, -p দিয়ে নাম দিয়ে বলা হয়। Aubergine টার্মিনালে যেকোনো কমান্ড-লাইন প্রোগ্রাম চালায়; নিজে থেকে কোনো এজেন্টের জন্য যা করে তা Claude Code-এর জন্য তৈরি।

কোনটির কোন লাইসেন্স?

Claude Squad AGPL-3.0-এ, Aubergine MIT লাইসেন্সে। দুটিই বিনামূল্যে।

Claude Squad বা Anthropic-এর সঙ্গে Aubergine-এর কোনো সম্পর্ক নেই। Claude Squad হলো smtg-ai প্রজেক্টের নাম; Claude হলো Anthropic-এর ট্রেডমার্ক।

পাঁচ মিনিটে চালু

npm install -g @meatgarden/aubergine
