Aubergine নিজে ইংরেজিতে: এর বোতাম, মেনু আর ছবি সবই ইংরেজি।

এই পেজটি ইংরেজি থেকে মেশিন দিয়ে অনুবাদ করা। সংশোধন পাঠান।

  1. Aubergine
  2. তুলনা

একাধিক কোডিং এজেন্ট চালানোর টুল, তুলনায়

একই মুহূর্তের জন্য সাতটি টুল: একাধিক কোডিং এজেন্ট কাজে, আর আপনি মাঝখানে। এখানে Conductor, Claude Squad, Vibe Kanban, cmux, Warp আর Paradev-এর পাশে Aubergine, প্রতিটির জন্য একটি করে পেজ সহ।

এটি কীভাবে লেখা হয়েছে। এই পেজগুলো অন্য কোনো টুল সম্পর্কে যা বলে, তা সেই টুলের নিজের সাইট, ডকুমেন্টেশন আর রিপোজিটরি থেকে, ২৬ নভেম্বর ২০২৬-এ যেমন পড়া হয়েছে, আর প্রতিটি পেজে সেগুলোর লিংক আছে। আমরা অন্য টুলগুলো চালিয়ে দেখিনি। যেখানে তাদের ডকুমেন্টেশন কিছু বলে না, সেখানে পেজ বলে যে কিছু পাওয়া যায়নি, টুলটি তা পারে না এমন নয়। এই টুলগুলো দ্রুত বদলায়: এখানে কিছু ভুল বা পুরোনো হলে আমাদের জানান, তা ঠিক করা হবে।

সাতটিই, পাশাপাশি

টুলএটি কীকোথায় চলেসোর্স আর দামএজেন্টদের আলাদা রাখাবন্ধ করলে
Aubergineআপনার নিজের কম্পিউটারে একটি সার্ভার আর আপনার ব্রাউজারে একটি পেজmacOS; Linux শুধু কন্টেইনারে; Windows WSL 2-এর ভেতরে, চেষ্টা করা হয়নি। tmux আর Node.js লাগেMIT, বিনামূল্যে; কোনো পেইড প্ল্যান নেই, অ্যাকাউন্টও নেইআপনি চাইলে একটি টার্মিনালের জন্য নিজস্ব ব্রাঞ্চে একটি Git worktreeটার্মিনাল tmux-এ চলতে থাকে; কম্পিউটার রিস্টার্ট করলে যা চলছিল তা শেষ হয়
Conductorএকটি Mac ডেস্কটপ অ্যাপ, হোস্ট করা ক্লাউড আর একটি iOS অ্যাপ সহশুধু macOSক্লোজড সোর্স; লোকাল অ্যাপ বিনামূল্যে, এর ক্লাউডের জন্য পেইড প্ল্যান লাগেপ্রতিটি ওয়ার্কস্পেসের জন্য একটি Git worktree আর ব্রাঞ্চ; এর ক্লাউডে স্যান্ডবক্সলোকাল সেশন অ্যাপের সঙ্গে শেষ হয়; ক্লাউড সেশন চলতে থাকে
Claude Squadআপনার টার্মিনালে একটি প্রোগ্রাম, চালু হয় cs হিসেবেmacOS আর Linux; Windows-এ WSL-এর মাধ্যমে tmux দিয়ে। tmux আর gh লাগেAGPL-3.0, বিনামূল্যেপ্রতিটির জন্য একটি tmux সেশন আর নিজস্ব ব্রাঞ্চে একটি Git worktreeসেশনগুলো tmux সেশন; কী রাখা হয় তা এর README বলে না
Vibe Kanbanআপনার নিজের কম্পিউটারে একটি সার্ভার আর আপনার ব্রাউজারে একটি পেজmacOS, Linux আর Windows; চালু হয় npx দিয়েApache-2.0, বিনামূল্যে; সাইন-ইন ঐচ্ছিকপ্রতিটি ওয়ার্কস্পেসের জন্য Git worktreeএর ডকুমেন্টেশনে কিছু পাওয়া যায়নি
cmuxএকটি নেটিভ macOS টার্মিনাল অ্যাপশুধু macOS 14 বা পরের সংস্করণGPL-3.0-or-later অ্যাপ, বিনামূল্যে, অ্যাকাউন্ট লাগে না; এর ক্লাউডের জন্য পেইড প্ল্যানকোনো এজেন্টের জন্য worktree বানায় এমন কিছু পাওয়া যায়নি; এর ক্লাউডে আলাদা মেশিনলেআউট আর ফোল্ডার ফিরে আসে; চালু প্রসেস শুধু এর ঐচ্ছিক tmux মোডে
Warpনিজের একটি এজেন্ট সহ একটি ডেস্কটপ টার্মিনাল অ্যাপ, আর ক্লাউড এজেন্টmacOS, Windows আর Linuxক্লায়েন্ট AGPL-3.0-এ ওপেন সোর্স; একটি ফ্রি প্ল্যান আর কয়েকটি পেইড প্ল্যান; লগ ইন ঐচ্ছিকআপনার বানানো Git worktree চেনে; এর ক্লাউড এজেন্টের জন্য কন্টেইনারউইন্ডো, ট্যাব আর সাম্প্রতিক আউটপুট ফিরে আসে; চলমান প্রোগ্রাম নিয়ে কিছু পাওয়া যায়নি
Paradevএকটি ডেস্কটপ অ্যাপ, একসময় নাম ছিল Superset, ফোন অ্যাপ আর একটি ক্লাউড সহmacOS; একটি পরীক্ষামূলক Linux বিল্ড; Windows নেইMIT; এক জনের জন্য একটি ফ্রি প্ল্যান, আর পেইড প্ল্যানপ্রতিটি টাস্কের জন্য একটি worktree, একটি ব্রাঞ্চ আর একটি টার্মিনালপুরোপুরি বন্ধ না করা পর্যন্ত টার্মিনাল এর ডেমনে চলতে থাকে; রিস্টার্ট করলে শেষ হয়

প্রতিটির জন্য একটি পেজ

প্রতিটি পেজে দুটির পুরো টেবিল আছে, কোথায় তারা আলাদা, আর অন্য টুলটির কী আছে যা Aubergine-এর নেই।

  • Aubergine vs Conductor

    Conductor বেছে নিন যদি এমন একটি Mac অ্যাপ চান যা একটি কাজকে প্রম্পট থেকে merge করা পুল রিকোয়েস্ট পর্যন্ত নিয়ে যায়, আর আপনার Mac বন্ধ থাকার সময়েও চলতে থাকা কাজের জন্য একটি ক্লাউড থাকে।

  • Aubergine vs Claude Squad

    Claude Squad বেছে নিন যদি আপনি টার্মিনালেই থাকেন আর সেখানে একটি ছোট প্রোগ্রাম চান যা worktree-তে এজেন্ট চালু করে আর তাদের ব্রাঞ্চ push করে, তার বেশি কিছু নয়।

  • Aubergine vs Vibe Kanban

    Vibe Kanban বেছে নিন যদি আপনি ইস্যু ধরে ভাবেন: বোর্ডে পরিকল্পনা করুন, প্রতিটি কার্ড একটি এজেন্টের হাতে দিন, মন্তব্য সহ তার ডিফ পর্যালোচনা করুন, আর merge করুন।

  • Aubergine vs cmux

    cmux বেছে নিন যদি প্যান, অ্যাপের ভেতরে একটি ব্রাউজার আর macOS নোটিফিকেশন সহ একটি দ্রুত নেটিভ Mac টার্মিনাল অ্যাপ চান, আর এর ওপর নিজের কাজের ধরন নিজেই স্ক্রিপ্ট করে নেন।

  • Aubergine vs Warp

    Warp বেছে নিন যদি সবকিছুর জন্য একটি টার্মিনাল অ্যাপ চান, Windows আর Linux-এও, নিজের এজেন্ট ভেতরে তৈরি আর শিডিউল করা যায় এমন ক্লাউড এজেন্ট সহ।

  • Aubergine vs Paradev, আগে Superset

    Paradev বেছে নিন যদি এমন একটি ডেস্কটপ অ্যাপ চান যা প্রতিটি টাস্কের জন্য একটি worktree বানায় আর তাকে ডিফ, চেক আর merge পর্যন্ত নিয়ে যায়, আর টাকা দিলে ফোন অ্যাপ আর একটি ক্লাউড।

Aubergine যা ঘিরে তৈরি

  • সাধারণ টার্মিনাল। একটি এজেন্ট Aubergine-এ ঠিক সেভাবেই চলে যেভাবে যেকোনো টার্মিনাল অ্যাপে চলে। এর ওপর কোনো চ্যাট ভিউ নেই, আর আপনার ও এর প্রিন্ট করা লেখার মাঝে কিছু নেই।
  • সবগুলো চোখের সামনে। টার্মিনালগুলো একটি ক্যানভাসে পাশাপাশি থাকে, যা আপনি সরান আর জুম করেন, সঙ্গে প্রতিটি টার্মিনাল আর তার অবস্থা কথায় লেখা একটি তালিকা। দেখুন ঠিক টার্মিনালটি খুঁজে নিন।
  • উইন্ডো বন্ধ করলে কিছুই শেষ হয় না। প্রতিটি টার্মিনাল একটি tmux সেশন, তাই ব্রাউজার আর Aubergine নিজেও থেমে যেতে পারে, আর আপনার এজেন্টরা চলতে থাকে। দেখুন রিস্টার্টে কী থাকে।
  • শুধু আপনার কম্পিউটার। কোনো অ্যাকাউন্ট নেই, ক্লাউড নেই, পেইড প্ল্যান নেই, নিজের কোনো মডেলও নেই; সার্ভার শোনে 127.0.0.1-এ। দেখুন নিরাপত্তা।
  • সিদ্ধান্ত নেন একজন মানুষ। একটি এজেন্ট যা প্রস্তাব করে তা আপনার পর্যালোচনার অপেক্ষায় থাকে, ওয়ার্কফ্লোর অনুমোদন শুধু আপনার, আর একটি তালিকা, For you, আপনার অপেক্ষায় থাকা সবকিছু রাখে। দেখুন কিউ।

If your IT department has to approve it

Some companies do not allow developer tools that need an account with their maker, that send code or terminal output to the maker's cloud, or whose source cannot be read. Aubergine has none of these: it runs on your own computer, its server listens on 127.0.0.1, it has no account and no cloud, it calls no model, and it is open source under the MIT license, so a security team can read all of it.

The agents you run in it are a separate question. Each sends what it sends to its own provider and needs its own approval; Aubergine changes nothing about that. What Aubergine protects, and what it does not, is on the security page.

Aubergine-এর যা নেই

  • কোনো ডেস্কটপ অ্যাপ নেই, ফোন অ্যাপও নেই। এটি আপনার ব্রাউজারে একটি পেজ। আপনার চালানো একটি প্রক্সির মাধ্যমে অন্য ডিভাইস যুক্ত করা যায়; তা একটি Mac-এ একবার চালানো হয়েছে, আসল ফোনে কখনো নয়।
  • কোনো পুল রিকোয়েস্ট নেই, merge-ও নেই। এটি একটি ওয়ার্কিং কপিতে কী বদলেছে তা ফাইল ধরে ধরে দেখায়, আর কখনো commit, push, rebase বা merge করে না।
  • কোনো ক্লাউড নেই। এজেন্টরা সেই কম্পিউটারেই চলে যেখানে Aubergine চলে, আর শিডিউল চলে শুধু সেটি চালু থাকলে।
  • কোনো শব্দ নেই, পুশও নেই। নোটিফিকেশন আসে আপনার ব্রাউজারে খোলা একটি Aubergine পেজ থেকে।
  • macOS-এর জন্য তৈরি। Linux-এ এটি শুধু কন্টেইনারে চালানো হয়েছে; Windows-এ এটি শুধু WSL 2-এর ভেতরে চলে, যা চেষ্টা করা হয়নি।
  • সবচেয়ে বেশি Claude Code-এর জন্য। যেকোনো কমান্ড-লাইন এজেন্ট টার্মিনালে চলে, কিন্তু Aubergine নিজে থেকে কোনো এজেন্টের জন্য যা করে (এটি যে অপেক্ষা করছে তা দেখা, কথোপকথন আবার শুরু করা) তা Claude Code-এর জন্য তৈরি; অন্য এজেন্ট aubergine কমান্ড দিয়ে জানায়।

একসঙ্গে কয়েকটি Claude Code এজেন্ট চালানোর সবচেয়ে ভালো টুল কোনটি?

তা নির্ভর করে এজেন্টদের চারপাশে আপনি কী চান তার ওপর। ডিফ, পুল রিকোয়েস্ট আর merge সহ একটি Mac অ্যাপের জন্য: Conductor বা Paradev। আপনি আগে থেকে যে টার্মিনাল ব্যবহার করেন তার ভেতরে একটি প্রোগ্রামের জন্য: Claude Squad। ইস্যুর একটি বোর্ডের জন্য: Vibe Kanban। একটি নেটিভ Mac টার্মিনালের জন্য: cmux। নিজের এজেন্ট আর ক্লাউড এজেন্ট সহ একটি টার্মিনালের জন্য: Warp। ব্রাউজারের একটি পেজে পাশাপাশি সাধারণ টার্মিনাল, tmux দিয়ে চালু রাখা, কোনো অ্যাকাউন্ট ছাড়া: Aubergine।

এই টুলগুলোর মধ্যে কোনগুলো ওপেন সোর্স?

২৬ নভেম্বর ২০২৬-এ যেমন পড়া হয়েছে: Aubergine (MIT), Paradev (MIT), Vibe Kanban (Apache-2.0), Claude Squad (AGPL-3.0), cmux অ্যাপ (GPL-3.0-or-later) আর Warp ক্লায়েন্ট (AGPL-3.0)। Conductor-এর শর্তাবলি একে proprietary বলে।

এই টুলগুলোর মধ্যে কোনগুলো Linux বা Windows-এ চলে?

তাদের নিজেদের ডকুমেন্টেশন অনুযায়ী: Warp চলে macOS, Windows আর Linux-এ; Vibe Kanban তিনটিতেই; Claude Squad macOS আর Linux-এ, আর Windows-এ WSL-এর মাধ্যমে tmux দিয়ে; Paradev macOS-এ, সঙ্গে একটি পরীক্ষামূলক Linux বিল্ড; Conductor আর cmux শুধু macOS-এ। Aubergine macOS-এর জন্য তৈরি, Linux-এ শুধু কন্টেইনারে চালানো হয়েছে, আর Windows-এ শুধু WSL 2-এর ভেতরে চলে, যা এখনো চেষ্টা করা হয়নি।

অ্যাপ বন্ধ করার পরেও কোনগুলো এজেন্টদের চালু রাখে?

Aubergine আর Claude Squad প্রতিটি এজেন্টকে একটি tmux সেশনে চালায়। Paradev একটি ব্যাকগ্রাউন্ড ডেমনের কথা লিখেছে, যা উইন্ডো বন্ধ হলে টার্মিনাল রেখে দেয়। cmux চালু প্রসেস রাখে শুধু তার ঐচ্ছিক tmux মোডে। Conductor বলে লোকাল সেশন অ্যাপের সঙ্গেই শেষ হয়। Warp উইন্ডো আর সাম্প্রতিক আউটপুট ফিরিয়ে আনে, চলমান প্রোগ্রাম নয়। Conductor, cmux, Warp আর Paradev প্রত্যেকেরই একটি ক্লাউডও আছে, যেখানে এজেন্টরা চলতে থাকে। কোনোটিই, Aubergine সহ, কম্পিউটার রিস্টার্টের মধ্য দিয়ে একটি লোকাল এজেন্টকে চালু রাখে না।

পাঁচ মিনিটে চালু

আপনার লাগবে macOS, সঙ্গে tmux 3.2 বা নতুনতর আর Node.js 22 বা নতুনতর। brew install tmux node দুটোই এনে দেয়।

npm install -g @meatgarden/aubergine
