Aubergine / Install

How to install Aubergine

One command installs it, one starts it. About five minutes, including the tour.

Requirements

  • macOS. Linux should work the same way but has not been tested yet.
  • tmux 3.2 or newer, Node.js 22 or newer, and pnpm.

With Homebrew, one line gets all three:

brew install tmux node pnpm

Install and start

  1. Install Aubergine from npm (needs tmux and Node.js only): 
    npm install -g @meatgarden/aubergine
    Or with the installer, which also needs pnpm and builds from the source: 
    curl -fsSL https://raw.githubusercontent.com/thirstyeggplant/aubergine/main/install.sh | sh
  2. Start it and open your browser, signed in. 
    aubergine start --open
  3. Take the tour. Click Show me around in the middle of the empty canvas. It makes a canvas named “Demo” with a few stand-in agents and walks you through eight short steps. Nothing in the demo is real, and aubergine demo --remove takes it away.

Prefer to read the script first? Download it, read it, and run sh install.sh --dry-run to see what it would do without changing anything.

What the installer changes

Two things only: the install folder (~/.aubergine, or AUBERGINE_HOME) and one link named aubergine in a folder on your PATH that you can write to. It checks everything first and changes nothing if something is missing.

It does not use sudo, edit your shell startup files, install Node.js, pnpm or tmux, or touch your data folder.

If something goes wrong

Run aubergine doctor first. It checks the usual causes.

What you seeWhat to do
“This browser is not signed in yet”Open the /auth?token=… link the server printed when it started.
A page saying tmux is missing or too oldInstall or upgrade tmux (brew install tmux), then restart the server.
The server will not start because the port is takenUse another port: AUBERGINE_PORT=4700 aubergine start.
aubergine: command not foundThe link is not on your PATH. The installer prints the one line to add to your shell's startup file.
A terminal shows no status badgesStatus needs zsh, and a session made before an update keeps its old shell. Park it and start a new one.

Stop, update, uninstall

  • Stop the server with Ctrl+C. Your terminals keep running; start the server again and reload the page to get them back.
  • Update with aubergine update, then restart the server.
  • Uninstall with aubergine uninstall. It removes the link and, after asking, the copy the installer made. It never removes your data and never ends your terminals.
  • Start at login with aubergine service install, so you only ever open the browser.
