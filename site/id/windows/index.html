Instal Aubergine di Windows dengan WSL

Aubergine tidak berjalan di Windows sendiri. Ia berjalan di dalam WSL 2, Linux yang disediakan Windows, dan Anda memakainya dari browser Windows Anda.

Apa yang dicoba. Langkah Linux dijalankan pada 25 November 2026 di Ubuntu 24.04.5 (x86_64) di dalam kontainer, bukan di WSL, dengan Aubergine 0.2.2 dari npm: ia mengompilasi pustaka terminalnya, berjalan, memasukkan sebuah browser, serta menjalankan terminal dan demo. Instalasi Node.js dengan nvm tidak dijalankan di sana, karena Node.js 22 sudah terpasang. Belum ada isi halaman ini yang dijalankan di Windows. Jika Anda mencobanya, ceritakan hasilnya.

Yang Anda butuhkan

Windows 11, atau Windows 10 versi 2004 (build 19041) atau lebih baru, tempat WSL 2 bisa dipasang dengan satu perintah. Halaman Microsoft tentang memasang WSL berisi rinciannya.

Instal dan jalankan

  1. Pasang WSL. Buka PowerShell sebagai administrator, jalankan ini, lalu mulai ulang Windows setelah selesai. Ini memasang WSL 2 dengan Ubuntu.

    wsl --install

    Setelah dimulai ulang, buka Ubuntu dari menu Start dan pilih nama pengguna serta kata sandi untuknya. Semua perintah di bawah diketik di sana, di Ubuntu.

  2. Pasang yang dibutuhkan Aubergine: tmux, zsh, dan Git, serta alat yang mengompilasi pustaka terminalnya, yang tidak punya versi siap pakai untuk Linux.

    sudo apt update

    sudo apt install -y tmux zsh git build-essential python3

    Pasang Node.js 22. Paket bawaan Ubuntu adalah versi 18, terlalu lama. Salah satu cara yang dikenal luas adalah nvm: pasang nvm, buka jendela Ubuntu baru, lalu pasang Node.js 22.

    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash

    nvm install 22

    node -v sekarang seharusnya menunjukkan v22 atau lebih baru.

  3. Pasang Aubergine dari npm. Ia mengompilasi pustaka terminalnya saat dipasang; dalam uji coba, seluruh instalasi memakan 13 detik.

    npm install -g @meatgarden/aubergine

  4. Jalankan, dan biarkan jendela itu terbuka:

    aubergine start

    Masukkan browser Anda. Di jendela Ubuntu kedua, tampilkan alamat masuk, lalu buka di browser Anda di Windows. Alamat itu memasukkan browser tersebut, jadi perlakukan seperti kata sandi.

    aubergine open --print

    Setelah itu, http://127.0.0.1:4600 bisa dibuka langsung di browser itu. Di kanvas kosong, Show me around memulai tur.

Perlu diketahui

  • Simpan proyek Anda di Ubuntu, di folder rumahnya, bukan di bawah /mnt/c, tempat berkas Windows dijangkau lewat jembatan yang lebih lambat.
  • Pasang agen Anda di dalam Ubuntu, Claude Code, Codex, atau yang lain, seperti di Linux mana pun. Agen yang dipasang di Windows tidak ada di terminal Aubergine.
  • Terminal hidup selama WSL berjalan. Menutup browser tidak mengakhiri apa pun, dan Ctrl+C di jendela aubergine start hanya menghentikan server. Saat WSL berhenti, karena Windows dimulai ulang atau setelah wsl --shutdown, terminal berakhir, dan aubergine start berikutnya membuka shell baru di folder terakhirnya, seperti setelah Mac dimulai ulang.
  • bash atau zsh. Shell Ubuntu adalah bash, dan terminal berfungsi di dalamnya. Status perintah di terminal (sibuk, kode keluar perintah yang gagal) hanya datang dari zsh: dalam uji coba, terminal zsh menampilkan exit 3 setelah perintah gagal. Jadikan zsh shell Anda di Ubuntu untuk mendapatkannya.
  • Yang tidak ada: mulai saat login hanya berfungsi di macOS (aubergine service install mengatakannya), dan Open on desktop tidak punya pengaturan untuk aplikasi terminal Windows. aubergine open tidak menemukan browser untuk dibuka dalam uji coba; aubergine open --print selalu berfungsi.
  • Pintasan tombol di Windows dipilih dari dokumentasi browser dan belum diukur: lihat docs/keys.md. Palet selalu berfungsi.

Jika ada yang salah

Jalankan dulu aubergine doctor di Ubuntu. Ia memeriksa Node.js, tmux, Git, dan server.

Selanjutnya

Menghentikan, memperbarui, dan mencopot sama seperti di halaman instalasi, dan selebihnya ada di README.

npm install -g @meatgarden/aubergine
