Melanjutkan percakapan Claude Code setelah mulai ulang

Komputer dimulai ulang, atau Anda menutup terminal, dan percakapan Claude Code tampak hilang. Claude Code menyimpannya. Aubergine mengingat percakapan mana tempat setiap terminal berada dan mengembalikannya dengan satu tombol.

Yang biasanya dilakukan orang

Di terminal, di folder tempat percakapan itu berlangsung: claude --continue melanjutkan percakapan terbaru di sana, dan claude --resume membiarkan Anda memilih dari daftar, atau menerima ID percakapan. Masalahnya ada pada folder dan pilihan: dengan beberapa agen di satu folder, yang terbaru belum tentu yang Anda maksud.

Apa yang dilakukan Aubergine

Terminal mengingat percakapannya. Jika Claude Code dijalankan dari Aubergine (New terminal ▾ → Claude Code, atau C), hook-nya memberi tahu Aubergine percakapan mana yang sedang berlangsung, dan Aubergine menyimpan ID itu bersama terminal.

Resume agent (lanjutkan agen) ditawarkan di bilah judul terminal begitu shell-nya kembali ke prompt: Anda keluar dari agen, atau komputer dimulai ulang dan terminal kembali sebagai shell baru di folder terakhirnya. Ia menjalankan Claude Code lagi dengan --resume dan ID itu, memakai perintah peluncur dari pengaturan Anda (agents.claudeCommand, bawaannya claude).

Pada sebuah run workflow, Resume agent juga memberi tahu agen tentang run itu lagi, sehingga agen melanjutkan dari langkah tempat run berada.

Past conversations… (percakapan sebelumnya) di palet (⌘K), atau “Past conversations in this folder…” di detail terminal, mendaftar percakapan Claude Code sebelumnya di sebuah folder: nama atau hal pertama yang Anda katakan, kapan terakhir aktif, berapa kali Anda berbicara, dan apakah ada terminal di kanvas yang sedang memakainya. Read menampilkannya, hanya-baca. Open on the canvas menjalankan terminal baru di folder itu yang melanjutkan percakapan tersebut, dan Open a copy memulai cabangnya dan membiarkan aslinya seperti semula. Jika sudah ada terminal di percakapan itu, Anda ditanya dulu.

Pencarian. Ketik @ dan beberapa kata di palet untuk mencari percakapan sebelumnya di folder-folder terminal di kanvas Anda. Catatannya dibaca saat Anda meminta, dalam batas tertentu, dan ia mengatakan jika pencarian terpotong. Di command line, aubergine history mendaftarnya dan aubergine history open <id> membuka salah satunya.

Sampai mana ia. Catatan terminal menyimpan ringkasan dan log, dan setiap prompt yang Anda kirim ditambahkan ke log. Ask its agent for a recap (minta rekap ke agennya) di detailnya membuat agen menulis posisinya dengan aubergine recap --write, disimpan bersama terminal. Saat Anda kembali setelah lebih dari 30 menit, While you were away (selama Anda pergi) mendaftar apa yang berubah sementara itu.

Percakapan di terminal di luar Aubergine

Di tab aplikasi terminal Anda, keluar dari agen, lalu jalankan aubergine here --claude di folder yang sama: terminal baru di kanvas menjalankan Claude Code dengan --continue, kini dengan statusnya ditampilkan. aubergine move mendaftar tab Claude Code Anda dan menjalankan salinan setiap percakapan di kanvas; dengan --stop ia meminta agen yang diam untuk keluar dulu, setelah Anda mengonfirmasi.

Apa yang tidak dilakukannya

  • Ia membaca catatan milik Claude Code sendiri, dalam format yang bukan milik Aubergine. Claude Code menyebut format file itu internal, dan format itu berubah antarversi. Melanjutkan memakai --resume milik Claude Code sendiri dengan ID-nya; nama, hitungan, dan transkrip adalah hasil Aubergine membaca file-file itu, dan bisa hilang atau lebih sedikit setelah Claude Code diperbarui. Catatan yang tidak bisa dibaca dinyatakan begitu, bukan ditampilkan sebagai percakapan kosong.
  • Tidak ada yang disalin atau disimpan. Daftar, transkrip, atau pencarian dibaca saat Anda meminta dan dibuang saat Anda menutupnya. Aubergine tidak pernah mengubah, mengganti nama, atau menghapus percakapan, dan tidak ada agen atau token yang bisa membaca percakapan lewat Aubergine.
  • Pekerjaan yang sedang berjalan tidak diulang. Apa yang sedang dikerjakan agen saat berhenti tidak dimulai lagi sampai Anda memintanya.
  • Tidak ada Resume agent untuk agen lain. Aubergine tidak mengetahui percakapan agen lain, dan tidak mendaftar percakapan sebelumnya untuknya. Jalankan lagi di terminal yang sama dengan cara melanjutkan milik agen itu sendiri, dan baca catatannya untuk memberi tahu sampai mana ia.
  • claude yang Anda ketik sendiri tidak diingat, kecuali Anda menambahkan hook yang dicetak aubergine hooks print ke pengaturan Claude Code Anda sendiri.
  • Apa yang diperiksa. Pembacaan catatan percakapan diuji dengan catatan buatan. Belum diperiksa dengan setiap versi Claude Code.

Pertanyaan

Bagaimana melanjutkan sesi Claude Code setelah menutup terminal?

Di folder yang sama, claude --continue mengambil percakapan terbaru dan claude --resume membiarkan Anda memilih. Di Aubergine, menutup browser tidak mengakhiri apa pun, dan terminal yang agennya Anda tutup menawarkan Resume agent di bilah judulnya.

Bagaimana melanjutkan percakapan Claude Code setelah reboot?

Setelah mulai ulang, setiap terminal Aubergine kembali sebagai shell baru di folder terakhirnya. Jika Claude Code dijalankan dari Aubergine, Resume agent di bilah judul menjalankannya lagi di percakapan tempat terminal itu berada.

Bagaimana menemukan percakapan Claude Code yang lama?

Past conversations… di palet mendaftarnya untuk sebuah folder, dengan transkrip hanya-baca; @ dan beberapa kata di palet mencarinya. Hanya yang masih disimpan Claude Code yang terdaftar.

Apa bedanya claude --continue dan claude --resume?

--continue melanjutkan percakapan terbaru di folder itu; --resume mengambil yang Anda pilih, atau sebuah ID. Resume agent memakai --resume dengan ID yang diingat terminal, jadi ia tidak bergantung pada percakapan mana yang terbaru.

Bisakah dua terminal melanjutkan percakapan Claude Code yang sama?

Aubergine tidak membuka satu percakapan dua kali tanpa bertanya: dua agen di satu percakapan saling kehilangan pesan. Anda ditawari terminal yang sudah ada di percakapan itu, atau salinan, yang membuat cabang percakapan.
