Codex dan ChatGPT

Codex adalah agen coding command-line dari OpenAI. Anda menginstalnya dan masuk ke dalamnya sendiri; di Aubergine ia berjalan di terminal seperti program lain.

Belum dicoba

Belum ada yang menjalankan Codex sungguhan di Aubergine. Isi halaman ini adalah apa yang dilakukan Aubergine untuk program apa pun di terminal dan untuk perintah aubergine, yang sudah dibuat dan diuji; bagaimana Codex sendiri berperilaku di sana belum terlihat. Jika Anda mencobanya, ceritakan hasilnya.

Menjalankannya

Buka terminal dengan New terminal, atau N, dan jalankan Codex di dalamnya seperti di terminal mana pun. Aubergine tidak memanggil model dan tidak menyimpan kunci: apa yang dibutuhkan Codex sudah Anda berikan saat masuk ke dalamnya.

Apa yang berfungsi hari ini

Semua yang dilakukan Aubergine untuk terminal mana pun:

  • Berdampingan

    Terminal sebanyak yang Anda mau di satu kanvas, dan kanvas sebagai tab.

  • Status perintah

    Dengan zsh, judul terminal menunjukkan bahwa sebuah perintah sedang berjalan, dan perintah apa.

  • Warna, catatan, dan field

    Beri terminalnya warna, simpan catatan dengan ringkasan dan log, dan field seperti tiket atau pemilik.

  • Menyimpan terminal (parking)

    × menyimpan terminal: ia meninggalkan kanvas dan tetap berjalan, dan Parked mengembalikannya.

  • Satu terminal tersendiri

    Buka terminal di tab browser tersendiri, dengan detail dan catatannya di sebelahnya.

  • Salinan kerja

    Shell in a folder or a working copy…, atau aubergine new --copy, menjalankan terminal di checkout-nya sendiri di branch sendiri, sehingga dua agen tidak pernah mengedit file yang sama.

  • Pencarian output

    ⌘K mencari apa yang dicetak setiap terminal, dan membuka terminal yang sudah digulir kembali ke hasil yang cocok.

Apa yang bisa ia sampaikan lewat perintah

Setiap terminal Aubergine punya perintah aubergine dan kredensial khusus untuk terminal itu saja. Program apa pun di sana, termasuk Codex, bisa memakainya:

  • aubergine attention waiting "…"

    Menandai terminal sebagai waiting for you, beserta apa yang dibutuhkannya; aubergine attention working dan aubergine attention done menyampaikan sisanya.

  • aubergine note "…"

    Menambahkan satu baris ke log catatan terminal.

  • aubergine describe

    Menamai terminal sesuai pekerjaan dan menyimpan ringkasannya; aubergine link add dan aubergine field set menambahkan link dan field pekerjaan itu. Apa yang Anda tulis sendiri yang berlaku.

  • aubergine workflow status

    Membaca langkah workflow saat ini; aubergine workflow done melaporkannya selesai dan mencetak langkah berikutnya.

  • aubergine task add

    Mengusulkan tugas untuk antrean, dan aubergine ask meminta Anda melakukan sesuatu yang hanya bisa dilakukan orang. Keduanya menunggu di daftar Anda.

Cara memberitahunya

Codex tidak tahu tentang Aubergine sampai diberi tahu. Perintah ini mencetak lima baris untuk ditempel ke instruksi yang dibaca agen Anda di awal setiap percakapan dalam sebuah proyek; dokumentasinya sendiri menjelaskan di mana baris itu ditaruh:

aubergine guide --snippet

Baris-baris itu menyuruhnya menjalankan aubergine guide sekali saat berada di terminal Aubergine, dan panduan itu menjelaskan sisanya. Aubergine hanya mencetak baris-baris itu dan tidak pernah menulisnya ke file mana pun.

Jika agen Anda bisa menjalankan server MCP, aubergine mcp menawarkan hal yang sama sebagai alat; di dalam terminal Aubergine ia tidak memerlukan alamat maupun token untuk pekerjaan terminal itu sendiri.

Hari ini hanya dibuat untuk Claude Code

Hal-hal yang dilakukan Aubergine sendiri untuk sebuah agen dibuat untuk Claude Code. Untuk Codex, hari ini:

  • Ia tidak ada di menu New terminal: Anda menjalankannya sendiri di terminal.
  • Aubergine tidak melihatnya sebagai agen: ia tidak ditandai menunggu atau selesai dengan sendirinya, hanya saat ia menjalankan aubergine attention.
  • Tidak ada yang diketikkan untuknya: workflow yang dimulai di terminalnya tidak mengetikkan apa pun dan menampilkan baris yang harus Anda berikan sendiri, dan rekap atau pesan tidak diberitahukan kepadanya.
  • Antrean tidak memberinya tugas: tugas hanya diberikan ke terminal yang terlihat punya agen dan sedang bebas.
  • Tidak ada Resume agent, tidak ada daftar percakapan lama, tidak ada daftar bagaimana ia disiapkan, dan tidak ada dialog untuk alat Aubergine.
  • aubergine move dan aubergine here --claude hanya memindahkan Claude Code.
  • Ia tidak diingatkan untuk menamai terminalnya atau menyimpan ringkasan.

Semuanya ada di halaman Claude Code.

ChatGPT di browser

ChatGPT di tab browser adalah halaman web, bukan program di terminal, jadi ia tidak berjalan di kanvas.

Aubergine tidak berafiliasi dengan OpenAI. Codex dan ChatGPT adalah merek dagang OpenAI.
