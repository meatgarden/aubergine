Tahu kapan Claude Code selesai atau menunggu Anda

Anda memberi Claude Code sebuah tugas, beralih ke hal lain, dan kembali dua puluh menit kemudian hanya untuk mendapati ia sudah menunggu jawaban ya sejak menit kedua. Aubergine menunjukkan terminal mana yang sedang bekerja, mana yang menunggu Anda, dan mana yang sudah selesai, di satu halaman.

Yang biasanya dilakukan orang

Claude Code menjalankan hook, yaitu perintah buatan Anda sendiri, pada momen seperti saat ia berhenti (Stop) atau mengirim notifikasi (Notification). Jawaban yang biasa adalah hook di pengaturan Claude Code Anda yang memutar suara atau menampilkan notifikasi desktop. Itu berfungsi, dan skripnya Anda tulis dan rawat sendiri.

Apa yang dilakukan Aubergine

Jalankan Claude Code dari Aubergine: New terminal ▾ → Claude Code di bagian atas daftar terminal, atau C. Aubergine menjalankan claude dengan file pengaturan yang dibuatnya di folder datanya sendiri dan disebut di command line. Konfigurasi Claude Code Anda sendiri tidak disentuh. Hook di file itu memberi tahu halaman apa yang dikerjakan agen:

  • saat Anda mengirim prompt, terminal menampilkan working, dan prompt itu ditambahkan ke log catatannya;
  • saat agen membutuhkan Anda (pertanyaan izin, atau ia diam menunggu input), garisnya berganti ke warna menunggu, dan judul serta barisnya di daftar bertuliskan waiting for you;
  • saat berhenti, terminal menampilkan finished.

Angka di samping For you, di kanan atas halaman, adalah semua yang menunggu Anda, di semua proyek: terminal yang punya pertanyaan, serta run yang perlu disetujui, draf untuk dibaca, dan tugas yang diusulkan. Menekannya membuka Runs, yang kolom Waiting for you-nya adalah daftar itu. Tab sebuah kanvas menunjukkan berapa terminalnya yang menunggu.

Terminal berikutnya yang menunggu. W pindah ke terminal berikutnya yang menunggu Anda saat tidak ada terminal yang memegang keyboard; di macOS ⌃⌘J melakukannya juga dari dalam terminal. Di tempat lain, ini ada di palet.

Notifikasi dari halaman yang terbuka. Settings → Notifications berisi Notify me on the desktop when a terminal starts waiting (beri tahu saya di desktop saat terminal mulai menunggu). Jika dinyalakan, halaman menampilkan notifikasi browser Anda saat sebuah terminal mulai menunggu atau agennya selesai, kecuali Anda sedang melihat terminal itu. Browser meminta izin Anda sekali.

Aturan. Di tab Rules pada Runs, sebuah aturan bisa Notify me (memberi tahu Anda) saat tugas selesai, tugas gagal, tugas membutuhkan Anda, ada yang diminta dari Anda, atau jadwal berjalan atau tidak bisa berjalan: notifikasi dari halaman yang terbuka, dengan satu kalimat tentang apa yang terjadi.

Agen lain, dan claude yang Anda ketik sendiri

Aubergine tidak membaca output terminal untuk menebak. Agen lain mana pun, atau program apa pun, menyampaikan hal yang sama sendiri dengan aubergine attention waiting "what it needs", aubergine attention working dan aubergine attention done di terminalnya. aubergine guide --snippet mencetak lima baris untuk file yang dibaca agen Anda di awal percakapan; baris itu menyuruhnya menjalankan aubergine guide, yang menjelaskan perintah-perintah ini.

Claude Code yang Anda jalankan dengan mengetik claude di terminal biasa, bagi Aubergine, adalah shell yang sibuk menjalankan sebuah program: tidak ada waiting for you. Jalankan dari menu saja, atau tambahkan sendiri hook yang dicetak aubergine hooks print ke pengaturan Anda; hook itu tidak melakukan apa-apa di luar terminal Aubergine.

Apa yang tidak dilakukannya

  • Tidak ada suara sendiri. Aubergine tidak memutar suara apa pun. Notifikasi bersuara hanya jika browser atau sistem Anda membuat notifikasi bersuara.
  • Tidak ada apa-apa saat tidak ada halaman yang terbuka. Notifikasi datang dari halaman Aubergine yang terbuka di browser Anda; server tidak mengirim apa pun sendiri. Saat semua halaman tertutup, terminal tetap bertuliskan waiting for you, dan angkanya ada saat Anda membuka halaman.
  • Tidak ada push ke ponsel. Tidak ada aplikasi dan tidak ada layanan push. Browser ponsel bisa dipasangkan untuk membuka halaman yang sama; lihat Memantau agen dari ponsel Anda, yang belum dicoba di ponsel sungguhan.
  • Apa yang diperiksa. Uji browser memeriksa notifikasi terhadap pengganti notifikasi milik browser. Seperti apa notifikasi sungguhan, dan apakah ia ditampilkan sama sekali, bergantung pada browser Anda dan pengaturan sistem Anda untuknya.

Pertanyaan

Bagaimana mendapat notifikasi saat Claude Code selesai?

Jalankan Claude Code dari Aubergine, lalu nyalakan Notify me on the desktop when a terminal starts waiting di Settings → Notifications. Halaman yang terbuka lalu menampilkan notifikasi browser saat sebuah terminal mulai menunggu Anda atau agennya selesai. Tanpa notifikasi pun, terminal bertuliskan finished.

Bisakah Claude Code memutar suara saat membutuhkan input?

Aubergine tidak memutar suara. Notifikasi bersuara jika browser atau sistem Anda membuatnya bersuara. Hook buatan Anda sendiri di pengaturan Claude Code bisa memutar suara; Aubergine tidak pernah menulis ke pengaturan itu.

Bagaimana melihat sesi Claude Code mana yang menunggu saat saya menjalankan beberapa?

Di Aubergine garis dan status terminal yang menunggu berwarna menunggu, barisnya di daftar bertuliskan waiting for you, dan angka di samping For you menunjukkan berapa banyak yang menunggu. W pindah ke yang berikutnya.

Apakah saya mendapat notifikasi saat browser ditutup?

Tidak. Notifikasi datang dari halaman Aubergine yang terbuka. Statusnya disimpan, jadi terminal yang menunggu sudah ditandai saat Anda membuka halaman lagi.

Apakah ini berfungsi dengan agen selain Claude Code?

Tidak dengan sendirinya: hook-nya dibuat untuk Claude Code. Agen lain mana pun bisa melaporkan hal yang sama dengan aubergine attention waiting, working dan done saat instruksinya sendiri menyuruhnya begitu; aubergine guide --snippet mencetak baris untuk instruksi itu.
