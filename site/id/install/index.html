Cara menginstal Aubergine

Satu perintah untuk menginstal, satu untuk menjalankan. Sekitar lima menit, termasuk tur.

Persyaratan

  • macOS. Di Linux baru dijalankan di dalam kontainer: paket npm di Ubuntu 24.04 dan image kontainer di Debian. Windows sendiri tidak didukung; Aubergine bisa berjalan di dalam WSL 2, tetapi itu belum dicoba: lihat Instal di Windows dengan WSL.
  • tmux 3.2 atau lebih baru dan Node.js 22 atau lebih baru. Installer juga memerlukan pnpm.

Dengan Homebrew, satu baris memasang keduanya (tambahkan pnpm untuk installer):

brew install tmux node

Instal dan jalankan

  1. Instal Aubergine dari npm (hanya perlu tmux dan Node.js):

    npm install -g @meatgarden/aubergine

    Atau dengan installer, yang juga memerlukan pnpm dan membangun dari kode sumber:

    curl -fsSL https://raw.githubusercontent.com/thirstyeggplant/aubergine/main/install.sh | sh

  2. Jalankan dan buka browser Anda dalam keadaan sudah masuk.

    aubergine start --open

  3. Ikuti tur. Klik Show me around di tengah kanvas kosong. Ia membuat kanvas bernama “Demo” dengan beberapa agen pengganti dan memandu Anda melalui delapan langkah singkat. Tidak ada yang sungguhan di demo, dan aubergine demo --remove menghapusnya.

Lebih suka membaca skripnya dulu? Unduh, baca, lalu jalankan sh install.sh --dry-run untuk melihat apa yang akan dilakukannya tanpa mengubah apa pun.

Apa yang diubah installer

Hanya dua hal: folder instalasi (~/.aubergine, atau AUBERGINE_HOME) dan satu link bernama aubergine di folder pada PATH Anda yang bisa Anda tulisi. Ia memeriksa semuanya terlebih dahulu dan tidak mengubah apa pun jika ada yang kurang.

Ia tidak memakai sudo, mengedit file startup shell Anda, menginstal Node.js, pnpm, atau tmux, atau menyentuh folder data Anda.

Jika ada yang salah

Jalankan aubergine doctor dulu. Ia memeriksa penyebab yang biasa.

Yang Anda lihatYang perlu dilakukan
“This browser is not signed in yet”Buka link masuk sekali di browser itu. aubergine open --print mencetaknya lagi.
Halaman yang menyatakan tmux tidak ada atau terlalu lamaInstal atau perbarui tmux (brew install tmux), lalu mulai ulang server.
Server tidak mau berjalan karena port sudah dipakaiPakai port lain: AUBERGINE_PORT=4700 aubergine start.
aubergine: command not foundLink tidak ada di PATH Anda. Installer mencetak satu baris yang perlu ditambahkan ke file startup shell Anda.
Terminal tidak menampilkan badge statusStatus memerlukan zsh, dan sesi yang dibuat sebelum pembaruan tetap memakai shell lamanya. Simpan (park) terminal itu dan mulai yang baru.

Menghentikan, memperbarui, menghapus

  • Hentikan server dengan Ctrl+C. Terminal Anda tetap berjalan; jalankan server lagi dan muat ulang halaman untuk mendapatkannya kembali.
  • Perbarui, jika Anda menginstal dengan npm, dengan npm install -g @meatgarden/aubergine@latest; jika memakai installer, dengan aubergine update. Lalu mulai ulang server.
  • Hapus dengan aubergine uninstall. Ia menghapus link dan, setelah bertanya, salinan yang dibuat installer. Ia tidak pernah menghapus data Anda dan tidak pernah mengakhiri terminal Anda.
  • Jalankan saat login dengan aubergine service install, sehingga Anda cukup membuka browser.

Selanjutnya

Baca cara menjalankan beberapa agen coding sekaligus, atau panduan. Referensi lengkapnya ada di README.
