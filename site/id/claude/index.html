Apa yang dilakukan Aubergine untuk Claude Code

Claude Code berjalan di terminal Aubergine seperti program lain. Jika dijalankan dari Aubergine, ia juga memberi tahu kanvas apa yang sedang ia kerjakan, dan Aubergine bisa memberinya arahan, melanjutkannya, dan menunjukkan bagaimana ia disiapkan. Inilah semuanya, sesuai urutan Anda menjumpainya.

Anda sendiri yang menginstal Claude Code dan masuk ke dalamnya. Aubergine tidak memanggil model dan tidak menyimpan kunci: ia menjalankan perintah claude yang sudah Anda punya.

  1. Jalankan dari menu

    New terminal ▾ → Claude Code, atau C saat tidak ada terminal yang memegang keyboard, menjalankan claude di terminal baru dengan file pengaturan yang ditulis Aubergine di folder datanya sendiri. Konfigurasi Claude Code Anda sendiri tidak disentuh.

    Perintah yang dijalankan adalah agents.claudeCommand di pengaturan, yaitu claude kecuali Anda mengubahnya; Aubergine menambahkan flag-nya sendiri di akhir.

    Lokasi: menu di samping New terminal, di bagian atas daftar terminal.

  2. Lihat saat ia bekerja, menunggu, dan selesai

    Hook di file pengaturan itu memberi tahu kanvas apa yang dikerjakan agen. Saat Anda mengirim prompt, prompt itu ditambahkan ke log catatan terminal dan terminal menampilkan working. Saat agen membutuhkan Anda, karena pertanyaan izin atau karena ia diam menunggu input, garisnya berganti ke warna menunggu dan judul serta barisnya bertuliskan waiting for you. Saat berhenti, ia menampilkan finished.

    W pindah ke terminal berikutnya yang menunggu, dan Notify menyalakan notifikasi desktop untuk terminal yang mulai menunggu. Prompt bisa berisi rahasia: "agents": { "logPrompts": false } di config.json menjauhkannya dari log catatan.

    Lokasi: judul terminal, barisnya di daftar, dan angka di samping For you di bagian atas.

  3. Claude Code yang Anda jalankan sendiri

    Diketik manual di terminal biasa, claude bekerja seperti program lain, tetapi Aubergine hanya melihat shell yang sibuk menjalankannya: tidak ada waiting for you, dan tidak ada yang diketikkan untuknya saat Anda memulai workflow di sana. Untuk mengubahnya, cetak hook-nya dan tambahkan sendiri ke pengaturan Claude Code Anda. Hook itu tidak melakukan apa-apa di luar terminal Aubergine.

    aubergine hooks print

  4. Ia menamai dirinya dan menyimpan ringkasan

    Agen yang dijalankan Aubergine diberi tahu saat mulai untuk menamai terminalnya sesuai pekerjaan dan menyimpan ringkasan, dengan aubergine describe, aubergine link add dan aubergine field set, dan diingatkan sekali saat berhenti tanpa nama sendiri atau tanpa ringkasan. Apa yang Anda tulis sendiri yang berlaku; apa yang dikatakan agen tentang hal yang sama menunggu di sebelahnya dengan Use this. Pengingat bisa dimatikan di Settings.

    Lokasi: detail terminal, dengan nama, ringkasan, field, dan link-nya.

  5. Workflow, tugas, rekap, dan pesan sampai kepadanya

    Aubergine mengetikkan empat kalimat tetap ke terminal, dan hanya ini: bahwa sebuah workflow dimulai, bahwa agen diminta menulis sesuatu, bahwa Anda meminta rekap, dan bahwa ada pesan yang menunggu. Masing-masing menyebut satu perintah untuk dijalankan agen. Kalimat hanya diketikkan di tempat yang terlihat ada agen memegang keyboard: agen yang dijalankan Aubergine, atau agen yang pengaturannya berisi hook dari aubergine hooks print.

    Dengan cara yang sama, tugas dari antrean hanya diberikan ke terminal yang agennya seperti itu sedang di depan dan bebas, dan Claude Code on a workflow… membuka terminal baru yang agennya diberi tahu tentang run itu di prompt pertamanya.

    Lokasi: Run a workflow… di menu judul terminal, dan Runs di bagian atas halaman.

  6. Resume agent

    Aubergine mengingat di percakapan mana sebuah terminal agen berada. Saat shell-nya kembali ke prompt, karena Anda keluar dari agen atau komputer dimulai ulang, terminal menawarkan Resume agent (lanjutkan agen), yang menjalankan agen lagi di percakapan itu. Pada terminal yang sedang dalam sebuah run, ia juga memberi tahu agen tentang run itu lagi.

    Lokasi: bilah judul terminal.

  7. Percakapan lama

    Past conversations… mendaftar percakapan agen sebelumnya di sebuah folder: baca salah satunya, buka di kanvas, atau buka salinan yang membiarkan aslinya tetap seperti semula. Ketik @ dan beberapa kata di palet untuk mencarinya; aubergine history mendaftarnya di command line. Tidak ada yang dibaca disimpan, dan tidak ada token maupun agen yang bisa membaca percakapan lewat Aubergine.

    Ia membaca file yang disimpan Claude Code. Formatnya bersifat internal bagi Claude Code dan berubah antarversi. Setelah agen diperbarui, nama dan transkrip mungkin lebih sedikit, dan catatan yang tidak bisa dibaca Aubergine dinyatakan begitu, tidak pernah ditampilkan sebagai kosong.

    Lokasi: palet (⌘K), dan “Past conversations in this folder…” di detail terminal.

  8. Bagaimana ia disiapkan

    Daftar apa saja yang menurut file konfigurasi agen telah diberikan kepadanya: server MCP, plugin, hook, skill, aturan izin, dan file pengaturan, masing-masing dengan asalnya, dan apa yang ditambahkan Aubergine. Hanya nama, tidak pernah nilai atau rahasia. Daftar ini menunjukkan bagaimana agen disiapkan, bukan apa yang sudah dimuat agen yang sedang berjalan, dan menyatakan dengan jelas apa yang tidak bisa ia ketahui, seperti konektor yang datang dari akun Anda.

    Lokasi: ⚙ on di terminal, “What is switched on for this agent…” di palet, dan detail terminal.

  9. Alat Aubergine untuknya

    Claude Code with Aubergine tools… pertama-tama menanyakan apa yang boleh dilakukan agen: None (tidak ada); Its own work only (hanya pekerjaannya sendiri), dengan kredensial terminal itu sendiri; atau More… (lainnya), lingkup yang Anda pilih, di mana sebuah token dibuat untuk satu terminal itu dan dicabut saat terminal diakhiri untuk selamanya. Alatnya adalah aubergine mcp, diberikan ke agen di baris peluncurannya; konfigurasi agen itu sendiri tidak ditulis.

    Lokasi: menu di samping New terminal.

  10. Pindahkan Claude Code yang sudah Anda buka

    Agen yang sedang berjalan tidak bisa dipindahkan, tetapi percakapannya bisa. Open elsewhere mendaftar tab Claude Code Anda, dengan Fork to canvas dan, untuk agen yang diam, Stop and resume here, yang bertanya kepada Anda dulu. Dari terminal, aubergine move melakukan hal yang sama, dan aubergine here --claude menjalankan Claude Code di kanvas yang melanjutkan percakapan terakhir folder itu.

    Lokasi: Open elsewhere di bilah di atas kanvas, atau O.

  11. Di salinan kerjanya sendiri

    aubergine here --copy --claude menjalankan Claude Code di checkout repositori miliknya sendiri, di branch sendiri, sehingga dua agen tidak pernah mengedit file yang sama. Dialog untuk terminal Claude Code dengan alat punya pilihan yang sama.

Apa yang sudah dicoba

Demo yang disertakan dengan Aubergine memakai pengganti, yaitu skrip pendek yang menjalankan perintah dan hook yang sama seperti agen sungguhan, bukan Claude Code sungguhan. Dengan agen sungguhan, persetujuan, salinan kerja, tugas dari antrean, dan jadwal belum dicoba.

Agen lain bisa menyampaikan sebagian besar hal ini lewat perintah aubergine: lihat Codex dan ChatGPT.

Aubergine tidak berafiliasi dengan Anthropic. Claude dan Claude Code adalah merek dagang Anthropic.

Siap dipakai dalam lima menit

Anda memerlukan macOS dengan tmux 3.2 atau lebih baru dan Node.js 22 atau lebih baru. brew install tmux node memasang keduanya.

npm install -g @meatgarden/aubergine
