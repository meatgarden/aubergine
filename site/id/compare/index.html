Alat untuk menjalankan beberapa agen coding, dibandingkan

Tujuh alat untuk saat yang sama: lebih dari satu agen coding bekerja, dan Anda di tengahnya. Inilah Aubergine di samping Conductor, Claude Squad, Vibe Kanban, cmux, Warp, dan Paradev, dengan satu halaman untuk masing-masing.

Bagaimana ini ditulis. Apa yang dikatakan halaman-halaman ini tentang alat lain berasal dari situs, dokumentasi, dan repositori alat itu sendiri sebagaimana dibaca pada 26 November 2026, dan setiap halaman menautkannya. Kami belum menjalankan alat-alat lain itu. Jika dokumentasinya tidak mengatakan apa-apa, halaman ini menyebut bahwa tidak ada yang ditemukan, bukan bahwa alat itu tidak bisa melakukannya. Alat-alat ini cepat berubah: jika ada yang salah atau usang di sini, beri tahu kami dan akan diperbaiki.

Satu halaman untuk masing-masing

Setiap halaman berisi tabel lengkap untuk keduanya, di mana keduanya berbeda, dan apa yang dimiliki alat lain itu yang tidak dimiliki Aubergine.

  • Aubergine vs Conductor

    Pilih Conductor jika Anda ingin aplikasi Mac yang membawa tugas dari prompt sampai pull request yang di-merge, dengan cloud untuk pekerjaan yang tetap berjalan saat Mac Anda mati.

  • Aubergine vs Claude Squad

    Pilih Claude Squad jika Anda hidup di terminal dan ingin satu program kecil di sana yang menjalankan agen di worktree dan melakukan push branch-nya, dan tidak lebih.

  • Aubergine vs Vibe Kanban

    Pilih Vibe Kanban jika Anda berpikir dalam issue: merencanakan di papan, menyerahkan setiap kartu ke agen, meninjau diff-nya dengan komentar, lalu merge.

  • Aubergine vs cmux

    Pilih cmux jika Anda ingin aplikasi terminal Mac native yang cepat dengan panel, browser di dalam aplikasi, dan notifikasi macOS, dan Anda menyusun cara kerja Anda sendiri di atasnya dengan skrip.

  • Aubergine vs Warp

    Pilih Warp jika Anda ingin satu aplikasi terminal untuk segalanya, juga di Windows dan Linux, dengan agennya sendiri di dalamnya dan agen cloud yang bisa Anda jadwalkan.

  • Aubergine vs Paradev, dulu Superset

    Pilih Paradev jika Anda ingin aplikasi desktop yang membuat worktree untuk setiap tugas dan membawanya melalui diff, check, dan merge, dengan aplikasi ponsel dan cloud jika Anda membayarnya.

Dasar Aubergine dibangun

  • Terminal biasa. Agen berjalan di Aubergine seperti di aplikasi terminal mana pun. Tidak ada tampilan chat di atasnya dan tidak ada apa pun di antara Anda dan apa yang dicetaknya.
  • Semuanya terlihat. Terminal berdiri berdampingan di kanvas yang bisa Anda geser dan zoom, dengan satu daftar semua terminal dan statusnya dalam kata-kata. Lihat Temukan terminal yang tepat.
  • Menutup jendela tidak mengakhiri apa pun. Setiap terminal adalah sesi tmux, sehingga browser dan Aubergine sendiri bisa berhenti sementara agen Anda tetap berjalan. Lihat apa yang bertahan saat dimulai ulang.
  • Hanya komputer Anda. Tanpa akun, tanpa cloud, tanpa paket berbayar, dan tanpa model sendiri; server mendengarkan di 127.0.0.1. Lihat keamanan.
  • Orang yang memutuskan. Apa yang diusulkan agen menunggu tinjauan Anda, persetujuan dalam workflow hanya milik Anda, dan satu daftar, For you, memuat semua yang menunggu Anda. Lihat antrean.

If your IT department has to approve it

Some companies do not allow developer tools that need an account with their maker, that send code or terminal output to the maker's cloud, or whose source cannot be read. Aubergine has none of these: it runs on your own computer, its server listens on 127.0.0.1, it has no account and no cloud, it calls no model, and it is open source under the MIT license, so a security team can read all of it.

The agents you run in it are a separate question. Each sends what it sends to its own provider and needs its own approval; Aubergine changes nothing about that. What Aubergine protects, and what it does not, is on the security page.

Apa yang tidak dimiliki Aubergine

  • Tidak ada aplikasi desktop dan tidak ada aplikasi ponsel. Aubergine adalah halaman di browser Anda. Perangkat lain bisa dipasangkan lewat proxy yang Anda jalankan; itu dijalankan sekali di satu Mac dan belum pernah di ponsel sungguhan.
  • Tidak ada pull request dan tidak ada merge. Aubergine menunjukkan apa yang berubah di salinan kerja, file demi file, dan tidak pernah melakukan commit, push, rebase, atau merge.
  • Tidak ada cloud. Agen berjalan di komputer tempat Aubergine berjalan, dan jadwal hanya berjalan selama komputer itu menyala.
  • Tidak ada suara dan tidak ada push. Notifikasi datang dari halaman Aubergine yang terbuka di browser Anda.
  • Dibuat untuk macOS. Di Linux baru dijalankan di dalam kontainer; di Windows hanya berjalan di dalam WSL 2, dan itu belum dicoba.
  • Paling banyak untuk Claude Code. Agen command-line apa pun berjalan di terminal, tetapi hal-hal yang dilakukan Aubergine sendiri untuk agen (melihat bahwa agen menunggu, melanjutkan percakapan) dibuat untuk Claude Code; agen lain melapor lewat perintah aubergine.

Pertanyaan

Apa alat terbaik untuk menjalankan beberapa agen Claude Code sekaligus?

Tergantung apa yang Anda inginkan di sekitar agen. Untuk aplikasi Mac dengan diff, pull request, dan merge: Conductor atau Paradev. Untuk program di dalam terminal yang sudah Anda pakai: Claude Squad. Untuk papan issue: Vibe Kanban. Untuk terminal Mac native: cmux. Untuk terminal dengan agennya sendiri dan agen cloud: Warp. Untuk terminal biasa berdampingan di halaman browser, tetap berjalan berkat tmux, tanpa akun: Aubergine.

Alat mana saja yang open source?

Sebagaimana dibaca pada 26 November 2026: Aubergine (MIT), Paradev (MIT), Vibe Kanban (Apache-2.0), Claude Squad (AGPL-3.0), aplikasi cmux (GPL-3.0-or-later), dan klien Warp (AGPL-3.0). Ketentuan Conductor menyebutnya proprietary.

Alat mana saja yang berjalan di Linux atau Windows?

Menurut dokumentasi masing-masing: Warp di macOS, Windows, dan Linux; Vibe Kanban di ketiganya; Claude Squad di macOS dan Linux, dan di Windows dengan tmux lewat WSL; Paradev di macOS dengan build Linux eksperimental; Conductor dan cmux hanya di macOS. Aubergine dibuat untuk macOS, di Linux baru dijalankan di dalam kontainer, dan di Windows hanya berjalan di dalam WSL 2, yang belum dicoba.

Alat mana yang menjaga agen tetap berjalan setelah aplikasinya ditutup?

Aubergine dan Claude Squad menjalankan setiap agen di sesi tmux. Paradev mendokumentasikan daemon latar belakang yang menjaga terminal saat jendelanya ditutup. cmux menjaga proses yang hidup hanya di mode tmux opsionalnya. Conductor menyebut sesi lokal berakhir bersama aplikasinya. Warp memulihkan jendela dan output terbaru, bukan program yang sedang berjalan. Conductor, cmux, Warp, dan Paradev masing-masing juga punya cloud tempat agen tetap berjalan. Tidak ada satu pun, termasuk Aubergine, yang menjaga agen lokal tetap berjalan saat komputer dimulai ulang.
