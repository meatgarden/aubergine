Aubergine vs Claude Squad

Keduanya berdiri di dasar yang sama: setiap agen di sesi tmux, masing-masing di worktree Git sendiri, keduanya gratis dan open source. Claude Squad adalah program di dalam terminal Anda. Aubergine adalah halaman di browser Anda tempat terminal berdiri berdampingan.

Sumber informasi ini. Apa yang dikatakan di sini tentang Claude Squad berasal dari repositori dan README-nya sebagaimana dibaca pada 26 November 2026. Kami belum menjalankan Claude Squad. Jika ada yang salah atau usang, beri tahu kami.

Mana yang dipilih

Pilih Claude Squad jika Anda hidup di terminal dan ingin satu program kecil di sana yang menjalankan agen di worktree dan melakukan push branch-nya, dan tidak lebih.

Pilih Aubergine jika Anda ingin melihat beberapa agen bekerja sekaligus, tahu mana yang menunggu Anda, dan punya antrean, jadwal, dan API di sekitarnya.

Apa itu Claude Squad

Menurut deskripsinya sendiri, aplikasi terminal yang mengelola beberapa agen lokal seperti Claude Code, Codex, Gemini, dan lainnya di workspace terpisah. Anda menjalankannya sebagai cs: daftar sesi dengan pratinjau dan tab diff, di satu jendela terminal. Setiap sesi adalah sesi tmux di worktree Git pada branch-nya sendiri. Claude Squad memerlukan tmux dan gh, dan berada di bawah lisensi AGPL-3.0.

Di mana keduanya berbeda

Satu per satu, atau semuanya sekaligus. Claude Squad menampilkan daftar dan pratinjau sesi yang Anda pilih. Aubergine menggambar setiap terminal secara langsung di kanvas, sehingga lima agen adalah lima terminal yang terlihat, dan satu daftar menyebut status masing-masing dalam kata-kata.

Siapa yang menunggu. Kami tidak menemukan apa pun di README Claude Squad tentang pemberitahuan bahwa agen menunggu atau selesai. Aubergine menandai terminal yang menunggu dengan warna, menghitung yang menunggu di bagian atas, pindah ke yang berikutnya dengan satu tombol, dan bisa mengirim notifikasi dari halaman yang terbuka.

Apa yang ada di sekitar agen. Aubergine punya antrean tugas dengan batas, jadwal, workflow dengan langkah yang disetujui orang, catatan dan field di setiap terminal, API HTTP, dan server MCP. Claude Squad terbatas pada sesi dan branch-nya.

Apa yang dimiliki Claude Squad dan tidak dimiliki Aubergine

  • Claude Squad berjalan di dalam terminal yang sudah Anda buka, tanpa server dan tanpa browser. Ia bekerja lewat SSH seperti program terminal lain; Aubergine dari tempat lain memerlukan tunnel atau proxy.
  • Claude Squad melakukan commit dan push branch untuk Anda, dan menjeda sesi dengan melakukan commit pekerjaannya. Aubergine tidak pernah melakukan commit atau push.
  • Mode eksperimental yang menerima prompt agen dengan sendirinya. Aubergine tidak pernah menjawab agen untuk Anda.

Pertanyaan

Apakah Aubergine alternatif untuk Claude Squad?

Ya, untuk pekerjaan yang sama dengan cara lain. Keduanya menjalankan setiap agen di sesi tmux dan bisa memberi masing-masing worktree Git di branch sendiri. Claude Squad melakukannya dari program di terminal Anda; Aubergine dari halaman di browser Anda dengan semua terminal terlihat.

Apakah keduanya memakai tmux?

Ya. Claude Squad mencantumkan tmux sebagai prasyarat dan membuat sesi tmux untuk setiap agen. Aubergine memerlukan tmux 3.2 atau lebih baru dan menjalankannya di socket sendiri dengan konfigurasinya sendiri, sehingga tmux Anda sendiri tidak terganggu.

Apakah Claude Squad bekerja dengan agen selain Claude Code?

README-nya menyebut program bawaannya claude dan program lain, seperti Codex, Gemini, atau Aider, disebut dengan -p. Aubergine menjalankan program command-line apa pun di terminal; hal-hal yang dilakukannya sendiri untuk agen dibuat untuk Claude Code.

Lisensi apa yang dimiliki masing-masing?

Claude Squad berada di bawah AGPL-3.0, Aubergine di bawah lisensi MIT. Keduanya gratis.

Aubergine tidak berafiliasi dengan Claude Squad atau dengan Anthropic. Claude Squad adalah nama proyek smtg-ai; Claude adalah merek dagang Anthropic.

Siap dipakai dalam lima menit

Anda memerlukan macOS dengan tmux 3.2 atau lebih baru dan Node.js 22 atau lebih baru. brew install tmux node memasang keduanya.

npm install -g @meatgarden/aubergine
