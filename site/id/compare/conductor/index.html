Aubergine vs Conductor

Keduanya menjalankan beberapa agen coding sekaligus, masing-masing di worktree Git sendiri. Conductor adalah aplikasi Mac dengan chat, penampil diff, dan cloud. Aubergine adalah server gratis dan open source di komputer Anda sendiri yang menampilkan terminal biasa berdampingan di halaman browser.

Sumber informasi ini. Apa yang dikatakan di sini tentang Conductor berasal dari dokumentasinya dan changelog-nya sebagaimana dibaca pada 26 November 2026. Kami belum menjalankan Conductor. Jika ada yang salah atau usang, beri tahu kami.

Posisi Conductor. Pada 4 November 2026 changelog-nya menyebut Conductor bergabung dengan Meta dan akan dihentikan bertahap; pada 13 November changelog itu menyebut Conductor tidak ditutup. Sebagian situsnya masih memuat pesan pertama saat ini ditulis. Baca changelog-nya untuk mengetahui posisinya sekarang.

Mana yang dipilih

Pilih Conductor jika Anda ingin aplikasi Mac yang membawa tugas dari prompt sampai pull request yang di-merge, dengan cloud untuk pekerjaan yang tetap berjalan saat Mac Anda mati.

Pilih Aubergine jika Anda ingin agen Anda sebagai terminal biasa yang bisa Anda lihat sekaligus, tetap berjalan di tmux saat jendela ditutup, tanpa apa pun untuk login, dan dengan kode sumber terbuka.

Apa itu Conductor

Menurut deskripsinya sendiri, aplikasi Mac yang menjalankan banyak agen coding secara paralel di codebase Anda. Setiap pekerjaan adalah sebuah workspace: worktree Git di satu branch, dengan tab chat, terminal, dan browser. Conductor menjalankan Claude Code, Codex, Cursor, dan OpenCode dengan login yang sudah ada di Mac Anda, dan punya penampil diff, pull request, aplikasi iOS, dan cloud berbayar tempat agen berjalan di sandbox.

Di mana keduanya berbeda

Terminal, bukan chat. Conductor menampilkan agen sebagai chat di workspace, dengan mode terminal di sampingnya. Aubergine menampilkan terminal agen itu sendiri, seperti saat berjalan di aplikasi terminal mana pun, dan menata banyak terminal di kanvas yang bisa Anda geser dan zoom.

Apa yang berakhir saat ditutup. Dokumentasi Conductor menyebut sesi lokal berakhir saat Anda menutup aplikasinya atau mematikan Mac, dan sesi cloud tetap berjalan. Di Aubergine setiap terminal adalah sesi tmux: menutup browser atau menghentikan Aubergine tidak mengakhiri apa pun. Mulai ulang komputer mengakhirinya, di keduanya.

Tidak ada apa pun di luar komputer Anda. Conductor mendokumentasikan akun, cloud, relay untuk aplikasi ponselnya, dan analitik penggunaan. Aubergine tidak punya akun dan tidak punya layanan sendiri: server mendengarkan di 127.0.0.1, dan pemakaian dari perangkat lain lewat proxy yang Anda jalankan.

Apa yang dimiliki Conductor dan tidak dimiliki Aubergine

  • Penampil diff tempat Anda mengomentari baris dan mengirim komentarnya kembali ke agen, lalu pull request, check, dan merge. Aubergine menunjukkan apa yang berubah di salinan kerja dan tidak pernah melakukan commit, push, atau merge.
  • Cloud tempat agen tetap berjalan saat Mac Anda mati, dan rutinitas yang berjalan di sana sesuai jadwal. Jadwal Aubergine berjalan di komputer Anda, selama komputer itu menyala.
  • Aplikasi iOS dan suara saat selesai. Aubergine tidak punya aplikasi dan tidak memutar suara.

Pertanyaan

Apakah Aubergine alternatif untuk Conductor?

Untuk menjalankan beberapa agen command-line di komputer Anda sendiri, ya: setiap agen punya terminal di kanvas dan, jika Anda minta, worktree Git sendiri. Ini bukan pengganti yang setara: Aubergine tidak punya tampilan chat, tidak ada pull request atau merge, tidak ada cloud, dan tidak ada aplikasi ponsel.

Apakah Conductor open source?

Tidak: ketentuannya menyebutnya proprietary, dan kami tidak menemukan repositori publik. Dokumentasinya menyebut aplikasi lokalnya gratis dipakai dan workspace cloud memerlukan paket berbayar. Aubergine berada di bawah lisensi MIT dan tidak punya paket berbayar.

Apakah Conductor berjalan di Linux atau Windows?

Dokumentasinya menyebut Conductor belum tersedia untuk Windows atau Linux. Aubergine dibuat untuk macOS, di Linux baru dijalankan di dalam kontainer, dan di Windows hanya berjalan di dalam WSL 2, dan itu belum dicoba.

Bisakah saya memakai Conductor dan Aubergine bersama-sama?

Tidak ada yang menghalanginya: keduanya bekerja di worktree Git dari repositori yang sama, masing-masing membuat worktree sendiri. Kami belum menjalankan keduanya berdampingan.

Aubergine tidak berafiliasi dengan Conductor atau pembuatnya. Conductor adalah nama produk mereka: ketentuannya menyebut Melty Labs, Inc., dan situsnya menyebut Conductor from Meta.

Siap dipakai dalam lima menit

Anda memerlukan macOS dengan tmux 3.2 atau lebih baru dan Node.js 22 atau lebih baru. brew install tmux node memasang keduanya.

npm install -g @meatgarden/aubergine
