Aubergine vs Paradev, dulu Superset

Paradev adalah aplikasi desktop yang bernama Superset sampai Oktober 2026. Seperti Aubergine, Paradev berada di bawah lisensi MIT, menjalankan agen command-line apa pun, dan bekerja di worktree Git. Paradev adalah aplikasi dengan paket, aplikasi ponsel, dan cloud; Aubergine adalah server di komputer Anda sendiri dan halaman di browser Anda, tanpa semua itu.

Sumber informasi ini. Apa yang dikatakan di sini tentang Paradev berasal dari dokumentasinya, changelog-nya, dan repositorinya sebagaimana dibaca pada 26 November 2026. Kami belum menjalankan Paradev. Jika ada yang salah atau usang, beri tahu kami.

Namanya. Changelog-nya untuk 25 Oktober 2026 menyebut Superset kini menjadi Paradev dan bahwa akun, workspace, pengaturan, dan perintah superset tetap terbawa. Ini bukan Apache Superset, alat data itu.

Mana yang dipilih

Pilih Paradev jika Anda ingin aplikasi desktop yang membuat worktree untuk setiap tugas dan membawanya melalui diff, check, dan merge, dengan aplikasi ponsel dan cloud jika Anda membayarnya.

Pilih Aubergine jika Anda ingin setiap bagian gratis di komputer Anda sendiri tanpa akun: terminal berdampingan, antrean, jadwal, dan pemakaian dari perangkat lain.

Apa itu Paradev

Menurut deskripsinya sendiri, workspace open source untuk Claude Code, Codex, dan agen coding apa pun: aplikasi desktop, bukan aplikasi terminal, tempat agen berjalan sebagai chat atau di terminal. Setiap tugas punya worktree, branch, dan terminal sendiri; satu bilah samping menampilkan semua sesi per proyek. Paradev punya penampil diff dengan check pull request dan merge, sebuah perintah, SDK, dan server MCP, dan di paket berbayar aplikasi ponsel, akses jarak jauh, workspace cloud, dan otomatisasi.

Di mana keduanya berbeda

Apa yang gratis. Paradev mencantumkan paket gratis untuk satu orang dengan workspace lokal, aplikasinya, dan perintahnya; otomatisasi, aplikasi ponsel, dan akses jarak jauh ada di paket berbayar. Aubergine tidak punya paket: antreannya, jadwalnya, dan pemakaian dari perangkat lain semuanya ada di satu program berlisensi MIT, tanpa akun.

Bilah samping atau kanvas. Paradev menampilkan sesi di bilah samping dengan tab dan panel. Aubergine menempatkan terminal di kanvas yang bisa Anda geser dan zoom, sehingga banyak terminal hidup terlihat sekaligus, dengan satu daftar semuanya di sampingnya.

Bagaimana terminal bertahan lebih lama dari jendelanya. Keduanya menjaga agen tetap berjalan saat jendela ditutup: Paradev lewat daemon latar belakangnya sendiri, yang menurut dokumentasinya mengakhiri setiap terminal saat Anda keluar dari Paradev sepenuhnya; Aubergine lewat tmux, yang tetap berjalan saat Aubergine sendiri dihentikan. Mulai ulang komputer mengakhirinya, di keduanya.

Apa yang dimiliki Paradev dan tidak dimiliki Aubergine

  • Penampil diff tempat Anda mengomentari dan mengedit perubahan agen, memantau check pull request, dan melakukan merge. Aubergine menunjukkan apa yang berubah dan tidak pernah melakukan commit, push, atau merge.
  • Aplikasi desktop, aplikasi iOS dan Android, workspace cloud, serta bunyi lonceng dan badge di dock saat agen membutuhkan Anda. Aubergine adalah halaman browser dan tidak memutar suara.
  • Otomatisasi yang dipicu oleh permintaan tinjauan, pesan Slack, issue, atau webhook, dan hook yang dipasangnya agar banyak agen melaporkan statusnya. Aubergine tidak menjalankan apa pun dari luar, dan melihat agen menunggu dengan sendirinya hanya untuk Claude Code.

Pertanyaan

Apakah Aubergine alternatif untuk Paradev (Superset)?

Untuk menjalankan beberapa agen command-line secara lokal, masing-masing di worktree Git sendiri, ya, dan dengan setiap fitur gratis. Ini bukan pengganti yang setara: Aubergine tidak punya aplikasi desktop atau ponsel, tidak ada komentar diff, tidak ada pull request atau merge, dan tidak ada cloud.

Apakah Superset sama dengan Paradev?

Ya. Changelog-nya untuk 25 Oktober 2026 menyebut Superset kini menjadi Paradev, dan README-nya menyebut perintahnya masih superset. Keduanya tidak terkait dengan Apache Superset.

Apakah keduanya open source?

Keduanya berada di bawah lisensi MIT. Paradev juga menjual paket untuk aplikasi ponselnya, akses jarak jauh, cloud, dan otomatisasi; Aubergine tidak menjual apa pun.

Apakah Paradev berjalan di Linux atau Windows?

Dokumentasinya menyebut macOS, dengan build Linux eksperimental, dan bahwa Windows belum tersedia. Aubergine dibuat untuk macOS, di Linux baru dijalankan di dalam kontainer, dan di Windows hanya berjalan di dalam WSL 2, dan itu belum dicoba.

Aubergine tidak berafiliasi dengan Paradev atau pembuatnya, Superset Inc. Paradev dan Superset adalah nama mereka; baik mereka maupun Aubergine tidak terkait dengan Apache Superset.

Siap dipakai dalam lima menit

Anda memerlukan macOS dengan tmux 3.2 atau lebih baru dan Node.js 22 atau lebih baru. brew install tmux node memasang keduanya.

npm install -g @meatgarden/aubergine
