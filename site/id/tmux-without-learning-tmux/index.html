tmux tanpa belajar tmux

tmux menjaga shell Anda tetap berjalan saat jendela ditutup. tmux juga meminta Anda mempelajari tombol prefiks, mode salin, dan file konfigurasi. Aubergine menjalankan tmux untuk Anda, dan Anda memakai setiap terminal di halaman browser seperti terminal lainnya.

Untuk siapa

Untuk orang yang menginginkan apa yang diberikan tmux, yaitu shell yang bertahan lebih lama dari jendelanya, tanpa tombol dan konfigurasinya. Jika Anda sudah memakai tmux sehari-hari, tetap pakai: Aubergine tidak mengusik tmux Anda.

Yang biasanya dilakukan orang

Belajar tmux: tombol prefiks (Ctrl+B kecuali Anda mengubahnya) sebelum setiap perintah, tmux attach untuk kembali, dan beberapa baris di ~/.tmux.conf untuk mouse dan clipboard. Atau screen, alat sejenis yang lebih tua. Inilah setiap hal sehari-hari di tmux bawaan dan di Aubergine:

Apa yang dilakukan Aubergine

Socket sendiri dan konfigurasi sendiri. Aubergine memulai tmux di socket miliknya sendiri, bernama aubergine, dengan file konfigurasi miliknya sendiri alih-alih milik Anda: tanpa baris status, tanpa tombol prefiks, mouse menyala, riwayat 50.000 baris. Setiap terminal adalah satu sesi tmux dengan satu shell, yaitu login shell Anda. tmux Anda sendiri, sesi-sesinya, dan ~/.tmux.conf Anda tidak disentuh.

Roda mouse menggulir ke belakang di terminal yang memegang keyboard; di tempat lain di kanvas, roda mouse memperbesar dan memperkecil.

Pilih dengan mouse dan teks itu tersalin ke clipboard Anda saat tombol dilepas: tmux menyerahkan apa yang dipilih ke halaman dengan OSC 52, escape sequence yang dipakai terminal untuk clipboard, dan halaman menaruhnya di sana. Tempel dengan ⌘V (Ctrl+Shift+V di luar macOS). Tempelan beberapa baris diberi bracket, sehingga shell tidak menjalankannya baris demi baris.

Ubah ukuran dengan menyeret tepi terminal di kanvas, dan shell mendapat ukuran barunya. Terminal yang terbuka di dua tempat sekaligus punya satu ukuran, yang ditentukan oleh tampilan tempat Anda terakhir mengetik.

Di bawahnya tetap tmux. aubergine attach <name> menampilkan terminal di jendela aplikasi terminal Anda, dan Open on desktop (buka di desktop) di menu terminal melakukannya untuk Anda (di macOS di Terminal atau iTerm; di Linux dengan command line yang Anda atur). Saat server berhenti, tmux -L aubergine ls dan tmux -L aubergine attach -t <id> tetap menjangkau setiap shell.

Yang Anda butuhkan

tmux 3.2 atau lebih baru, dipasang oleh Anda sendiri: brew install tmux di macOS, paket sistem Anda di Linux. Aubergine tidak memasangnya, dan menampilkan halaman yang mengatakannya jika tmux tidak ada atau terlalu lama. Judul terminal menunjukkan perintah yang berjalan dan bagaimana perintah terakhir berakhir dengan zsh; shell lain berjalan tanpa itu.

Apa yang bukan dirinya

  • Bukan tmux di server jarak jauh. tmux milik Aubergine berjalan di komputer tempat servernya berjalan. Untuk shell di mesin yang Anda jangkau lewat SSH, tmux di mesin itu tetap alatnya. Aubergine sendiri bisa berjalan di mesin lain (Memakai Aubergine dari tempat lain); itu baru dijalankan di dalam kontainer.
  • Sesi tmux Anda sendiri tidak ditampilkan. Kanvas hanya berisi terminal Aubergine. aubergine scan mendaftar shell interaktif yang terbuka di komputer ini di luar Aubergine, dan aubergine import atau aubergine here memberi salah satunya terminal baru di kanvas di folder yang sama; program yang berjalan di yang lama tetap di sana. Baris yang ditawarkan aubergine shell-hook print untuk .zshrc Anda tidak melakukan apa-apa di dalam tmux.
  • Tanpa tombol tmux dan tanpa panel. Tidak ada tombol prefiks, dan binding tmux Anda sendiri tidak berlaku. Selama terminal memegang keyboard, setiap tombol masuk ke program di dalamnya, kecuali beberapa kombinasi yang dipilih agar tidak dibutuhkan shell, editor, atau tmux mana pun.
  • Tidak di Windows sendiri. Ia membutuhkan tmux dan shell Unix; di Windows ia berjalan di dalam WSL 2. Lihat Windows dengan WSL.

Pertanyaan

Bisakah saya memakai tmux tanpa mempelajari pintasannya?

Ya. Aubergine menjalankan tmux tanpa tombol prefiks dan tanpa baris status, jadi Anda tidak pernah mengetik perintah tmux: tutup tab untuk pergi, buka halaman untuk kembali, gulir dengan roda mouse, salin dengan memilih.

Apakah Aubergine mengubah konfigurasi tmux saya?

Tidak. Ia menjalankan tmux di socket miliknya sendiri, aubergine, dengan file konfigurasi miliknya sendiri. Server tmux Anda, sesi-sesinya, dan ~/.tmux.conf Anda dibiarkan seperti semula.

Bagaimana menggulir dan menyalin di terminal Aubergine?

Klik terminal untuk memberinya keyboard, lalu pakai roda mouse untuk menggulir ke belakang. Pilih teks dengan mouse: teks itu ada di clipboard Anda saat tombol dilepas. Tempel dengan ⌘V, atau Ctrl+Shift+V di luar macOS.

Bisakah saya menyambung ke terminal Aubergine dari aplikasi terminal saya sendiri?

Ya: aubergine attach <name>, atau Open on desktop di menu terminal. Di kedua tempat itu terminalnya sama; apa yang Anda ketik di satu tempat terlihat di tempat lain.

Bisakah Aubergine menggantikan tmux di server yang saya masuki lewat SSH?

Tidak begitu saja: terminalnya ada di mesin tempat servernya berjalan. Ia bisa berjalan di server dan dipakai dari browser Anda lewat tunnel SSH atau proxy, yang baru dijalankan di dalam kontainer, belum pernah di mesin cloud.
