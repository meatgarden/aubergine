tmux without learning tmux

tmux keeps your shells running when the window closes. It also asks you to learn a prefix key, copy mode and a configuration file. Aubergine runs tmux for you, and you use each terminal in a browser page as you would any terminal.

Who it is for

For people who want what tmux gives, shells that outlive the window, without its keys and its configuration. If you already live in tmux, keep it: Aubergine leaves your tmux alone.

What people usually do

Learn tmux: a prefix key (Ctrl+B unless you change it) before each command, tmux attach to come back, and lines in ~/.tmux.conf for the mouse and the clipboard. Or screen, an older tool of the same kind. Here is what each everyday thing is in tmux by default and in Aubergine:

What Aubergine does

Its own socket and its own configuration. Aubergine starts tmux on a socket of its own, named aubergine, with a configuration file of its own instead of yours: no status line, no prefix key, the mouse on, 50,000 lines of history. Each terminal is one tmux session with one shell, your login shell. Your own tmux, its sessions and your ~/.tmux.conf are not touched.

The wheel scrolls back through the terminal that has the keyboard; anywhere else on the canvas it zooms.

Select with the mouse and it is copied to your clipboard when you let go: tmux hands what was selected to the page with OSC 52, the escape sequence terminals use for the clipboard, and the page puts it there. Paste with ⌘V (Ctrl+Shift+V outside macOS). A paste of several lines is bracketed, so a shell does not run it line by line.

Resize by dragging a terminal's edges on the canvas, and the shell gets its new size. A terminal open in two places at once has one size, set by the view you typed into last.

It is still tmux underneath. aubergine attach <name> shows a terminal in a window of your terminal app, and Open on desktop in a terminal's menu does that for you (on macOS in Terminal or iTerm; on Linux with a command line you set). With the server stopped, tmux -L aubergine ls and tmux -L aubergine attach -t <id> still reach every shell.

What you need

tmux 3.2 or newer, installed by you: brew install tmux on macOS, your system's package on Linux. Aubergine does not install it, and shows a page saying so when it is missing or older. A terminal's title shows the command running and how the last one ended with zsh; other shells run without that.

What it is not

  • Not tmux on a remote server. Aubergine's tmux runs on the computer its server runs on. For a shell on a machine you reach with SSH, tmux on that machine is still the tool. Aubergine itself can run on another machine (Using Aubergine from elsewhere); that has been run in containers only.
  • Your own tmux sessions are not shown. The canvas holds Aubergine's terminals only. aubergine scan lists the interactive shells open on this computer outside Aubergine, and aubergine import or aubergine here gives one a new terminal on the canvas in the same folder; a program running in the old one stays there. The lines that aubergine shell-hook print offers for your .zshrc do nothing inside tmux.
  • No tmux keys and no panes. There is no prefix key, and your own tmux bindings do not apply. While a terminal has the keyboard every key goes to the program in it, except a few chords chosen so that no shell, editor or tmux needs them.
  • Not on Windows itself. It needs tmux and a Unix shell; on Windows it runs inside WSL 2. See Windows with WSL.

Pertanyaan

Can I use tmux without learning the shortcuts?

Yes. Aubergine runs tmux with no prefix key and no status line, so you never type a tmux command: close the tab to leave, open the page to come back, scroll with the wheel, copy by selecting.

Does Aubergine change my tmux configuration?

No. It runs tmux on a socket of its own, aubergine, with a configuration file of its own. Your tmux server, its sessions and your ~/.tmux.conf are left as they are.

How do I scroll and copy in Aubergine's terminals?

Click a terminal to give it the keyboard, then use the wheel to scroll back. Select text with the mouse: it is on your clipboard when you let go. Paste with ⌘V, or Ctrl+Shift+V outside macOS.

Can I attach to an Aubergine terminal from my own terminal app?

Yes: aubergine attach <name>, or Open on desktop in the terminal's menu. It is the same terminal in both places; what you type in one shows in the other.

Can Aubergine replace tmux on a server I SSH into?

Not as such: its terminals are on the machine its server runs on. It can run on a server and be used from your browser through an SSH tunnel or a proxy, which has been run in containers only, never on a cloud machine.
