Pertanyaan yang sering diajukan

Jawaban singkat. Panduan membahas lebih dalam.

Apa itu Aubergine?

Kanvas lokal berbasis browser berisi sesi terminal. Setiap terminal adalah node yang bisa Anda atur dan pakai, sehingga Anda bisa menjalankan beberapa agen coding sekaligus dan melihat mana yang sedang menunggu Anda.

Apakah Aubergine gratis dan open source?

Ya. Aubergine gratis dan kode sumbernya ada di GitHub.

Apa yang saya perlukan untuk menjalankan Aubergine?

macOS dengan tmux 3.2 atau lebih baru dan Node.js 22 atau lebih baru; installer juga membutuhkan pnpm. Di Linux baru dijalankan di dalam kontainer. Di Windows hanya berjalan di dalam WSL 2, dan itu belum dicoba: lihat panduan untuk Windows.

Apakah ia bekerja dengan agen coding apa pun?

Aubergine menjalankan terminal biasa, jadi agen command-line apa pun bisa berjalan di dalamnya. Hal-hal yang dilakukan Aubergine sendiri untuk sebuah agen, seperti melihat bahwa ia menunggu, dibuat untuk Claude Code; agen lain mana pun, termasuk Codex, bisa melaporkan statusnya lewat perintah aubergine dan API lokal, dan bisa memakai server MCP yang hanya mendaftar apa yang diizinkan tokennya.

Apakah Aubergine mengirim terminal atau kode saya ke suatu tempat?

Tidak. Semuanya berjalan di komputer Anda sendiri. Server hanya mendengarkan di 127.0.0.1.

Apakah Aubergine memanggil model AI?

Tidak. Agen Anda yang melakukannya. Aubergine hanya menjalankan terminal mereka dan memantaunya, dan tidak menyimpan kunci untuk model apa pun.

Apa yang terjadi pada terminal saya saat browser ditutup?

Terminal tetap berjalan. Setiap sesi adalah sesi tmux yang bertahan lebih lama dari browser maupun server Aubergine.

Bagaimana saya tahu agen mana yang sedang menunggu saya?

Setiap terminal menunjukkan apakah ia sibuk, diam, atau menunggu. Angka di samping For you di bagian atas halaman dan daftar For you mengumpulkan semua yang membutuhkan Anda.

Bagaimana agar dua agen tidak mengedit file yang sama?

Jalankan setiap terminal di salinan kerjanya sendiri: checkout miliknya sendiri di branch sendiri. Aubergine tidak pernah melakukan merge atau push untuk Anda.

Bisakah saya memberi agen daftar langkah untuk diikuti?

Ya. Workflow adalah daftar langkah berurutan, dengan strip yang menunjukkan posisi agen. Sebuah langkah bisa menunggu Anda menyetujui atau mengembalikannya.

Bisakah agen saling berbicara?

Ya, dengan batas. Pesan antarterminal punya pengirim yang bernama, jeda, dan blokir, dan tertutup secara bawaan untuk setiap kanvas.

Apakah ada API?

Ya. API HTTP lokal dengan token berlingkup, klien bertipe, dan server MCP yang hanya mendaftar alat yang boleh dipakai sebuah kredensial.

Bisakah saya membuka satu terminal tersendiri?

Ya. Tab ↗ di judul terminal membukanya di tab browser tersendiri: terminal yang sama, bukan salinan, dengan detail dan catatannya di sebelahnya saat Anda minta. Menutup tab tidak mengakhiri apa pun.

Bisakah saya menyimpan tiket atau pemilik bersama sebuah terminal?

Ya. Sebuah terminal punya field, pasangan label dan nilai, di detailnya. Agen di dalamnya bisa mengatur field-nya sendiri dengan aubergine field set; jika Anda mengatur label yang sama, milik Anda yang tetap.

Apakah Aubergine akan mendukung beberapa orang atau agen di cloud?

Keduanya direncanakan dan belum ada yang dibuat. Lihat peta jalan. Hari ini semuanya berjalan di satu komputer.

Apa yang diubah installer di komputer saya?

Dua hal: folder instalasi (~/.aubergine) dan satu link bernama aubergine. Ia tidak pernah memakai sudo, tidak pernah mengedit file startup shell Anda, dan tidak pernah menginstal Node.js, pnpm, atau tmux.
