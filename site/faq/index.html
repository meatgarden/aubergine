Aubergine / FAQ

Frequently asked questions

Short answers. The guides go deeper.

What is Aubergine?

A local, browser-based canvas of terminal sessions. Each terminal is a node you can arrange and use, so you can run several coding agents at once and see which one is waiting for you.

Is Aubergine free and open source?

Yes. It is free and its source is on GitHub.

What do I need to run Aubergine?

macOS with tmux 3.2 or newer, Node.js 22 or newer, and pnpm. Linux should work but has not been tested yet. Windows is not supported.

Does it work with any coding agent?

Aubergine runs ordinary terminals, so any command-line agent can run in one. Agents can also report their status through a command and a local API, and can use an MCP server that lists only what their token allows.

Does Aubergine send my terminals or code anywhere?

No. Everything runs on your own computer. The server listens on 127.0.0.1 only.

Does Aubergine call an AI model?

No. Your agents do. Aubergine only runs their terminals and keeps track of them.

What happens to my terminals when I close the browser?

They keep running. Each session is a tmux session that outlives both the browser and the Aubergine server.

How do I know which agent is waiting for me?

Each terminal shows whether it is busy, idle or waiting. A count at the top of the canvas and the For you list gather everything that needs you.

How do I keep two agents from editing the same files?

Start each terminal in its own working copy: its own checkout on its own branch. Aubergine never merges or pushes for you.

Can I give an agent a list of steps to follow?

Yes. A workflow is an ordered list of steps, with a strip that shows where the agent is. A step can wait for you to approve or send back.

Can agents talk to each other?

Yes, within limits. Messages between terminals have named senders, pauses and blocks, and are closed by default for each canvas.

Is there an API?

Yes. A local HTTP API with scoped tokens, a typed client, and an MCP server that lists only the tools a credential may use.

Will Aubergine support several people or agents in the cloud?

Both are planned and neither is built. See the roadmap. Today everything runs on one computer.

What does the installer change on my computer?

Two things: the install folder (~/.aubergine) and one link named aubergine. It never uses sudo, never edits your shell startup files and never installs Node.js, pnpm or tmux.
