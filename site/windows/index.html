Install Aubergine on Windows with WSL

Aubergine does not run on Windows itself. It runs inside WSL 2, the Linux that Windows provides, and you use it from your Windows browser.

What was tried. The Linux steps were run on 25 November 2026 on Ubuntu 24.04.5 (x86_64) in a container, not in WSL, with Aubergine 0.2.2 from npm: it compiled its terminal library, started, signed a browser in, ran a terminal and the demo. Installing Node.js with nvm was not run there, since Node.js 22 was already installed. Nothing on this page has been run on Windows yet. If you try it, please tell us how it went.

What you need

Windows 11, or Windows 10 version 2004 (build 19041) or newer, where WSL 2 can be installed with one command. Microsoft's page on installing WSL has the details.

Install and start

  1. Install WSL. Open PowerShell as administrator, run this, and restart Windows when it is done. It installs WSL 2 with Ubuntu.

    wsl --install

    After the restart, open Ubuntu from the Start menu and choose a user name and a password for it. Every command below is typed there, in Ubuntu.

  2. Install what Aubergine needs: tmux, zsh and Git, and the tools that compile its terminal library, which has nothing ready-made for Linux.

    sudo apt update

    sudo apt install -y tmux zsh git build-essential python3

    Install Node.js 22. Ubuntu's own package is version 18, which is too old. One well-known way is nvm: install it, open a new Ubuntu window, then install Node.js 22.

    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash

    nvm install 22

    node -v should now say v22 or newer.

  3. Install Aubergine from npm. It compiles its terminal library while it installs; the whole install took 13 seconds in the trial.

    npm install -g @meatgarden/aubergine

  4. Start it, and leave that window open:

    aubergine start

    Sign your browser in. In a second Ubuntu window, print the sign-in address, then open it in your browser on Windows. It signs that browser in, so treat it like a password.

    aubergine open --print

    After that, http://127.0.0.1:4600 works on its own in that browser. On an empty canvas, Show me around starts the tour.

Good to know

  • Keep your projects in Ubuntu, in its home folder, not under /mnt/c, where the files of Windows are reached through a slower bridge.
  • Install your agents inside Ubuntu, Claude Code, Codex or any other, as you would on any Linux. An agent installed in Windows is not in Aubergine's terminals.
  • Terminals live as long as WSL runs. Closing the browser ends nothing, and Ctrl+C in the window of aubergine start stops only the server. When WSL stops, because Windows restarts or after wsl --shutdown, the terminals end, and the next aubergine start opens fresh shells in their last folders, as after a restart on a Mac.
  • bash or zsh. Ubuntu's shell is bash, and terminals work in it. Command status on a terminal (busy, a failed command's exit code) comes from zsh only: in the trial a zsh terminal showed exit 3 after a failed command. Make zsh your shell in Ubuntu to have it.
  • Not there: start at login works with macOS only (aubergine service install says so), and Open on desktop has no setting for a Windows terminal app. aubergine open could not find a browser to open in the trial; aubergine open --print always works.
  • Keys on Windows were chosen from what browsers document and have not been measured: see docs/keys.md. The palette always works.

If something goes wrong

Run aubergine doctor in Ubuntu first. It checks Node.js, tmux, Git and the server.

What you seeWhat to do
Installing Aubergine fails while it compiles node-ptyThe build tools are missing. Run the apt lines of step 2, then install Aubergine again.
A page saying tmux is missing or too oldUbuntu 24.04's tmux is 3.4, which is new enough: sudo apt install -y tmux, then start the server again.
node -v says a version older than v22Install Node.js 22 as in step 2, open a new Ubuntu window, and install Aubergine again.
The address does not open in the browser on WindowsCheck that aubergine start is still running in Ubuntu. Then see Microsoft's page on networking in WSL; this has not been tried with Aubergine.
