가이드

짧고 실용적인 가이드입니다. 전체 참조 문서는 README입니다.

  • Aubergine 설치

    요구 사항, 한 줄 설치 프로그램, 그것이 바꾸는 것, 흔한 문제의 해결법.

  • WSL로 Windows에 설치하기

    WSL 2 안에서 Aubergine을 실행하고 Windows 브라우저에서 사용합니다. Linux 단계는 실행해 봤고, Windows에서는 아직 아무것도 시도하지 않았습니다.

  • 여러 코딩 에이전트를 한꺼번에 실행하기

    캔버스, 대기 수, 대기열, 작업 사본, 워크플로를 한 번에 둘러봅니다.

  • Aubergine의 Claude Code

    Aubergine이 Claude Code를 위해 스스로 해 주는 일과, 각각이 어디에 있는지.

  • Codex와 ChatGPT

    여느 프로그램처럼 터미널에서 실행되는 Codex, 보고할 수 있는 것, 그리고 Claude Code 전용으로만 만들어진 것.

  • 작업 사본

    각 에이전트에게 자체 체크아웃과 브랜치를 주어 두 에이전트가 같은 파일을 편집하는 일이 없게 합니다.

  • 재시작 후에도 터미널 유지하기

    브라우저를 닫을 때, Aubergine을 다시 시작할 때, 컴퓨터를 다시 시작할 때 각각 무엇이 남는지, 그리고 하던 곳에서 이어 가는 방법.

  • Keep a process running after you close the terminal

    Close the tab, the window or the browser and nothing ends: what tmux gives, without learning tmux.

  • tmux without learning tmux

    Shells that outlive the window, with no prefix key and no configuration, and your own tmux left alone.

  • Know when Claude Code is done or waiting

    Working, waiting for you and finished on every terminal, the For you count, the next waiting key and notifications in the open page.

  • Resume a Claude Code conversation

    Resume agent on the terminal it ran in, past conversations in a folder, and what tells you where it stood.

  • Find the right terminal when you have too many

    A canvas, one list of every terminal with its state in words, filters, tags and search of what terminals printed.

  • Check on your agents from your phone

    Reaching Aubergine from another device, each one paired with a code. Run once on one Mac; not tried on a real phone.

  • 대기열, For you, 일정

    일을 한 번에 나눠 주고, 여러분을 기다리는 모든 것을 보고, 정해진 시각에 작업을 실행합니다.

  • 보안과 개인정보

    무엇이 보호되고 무엇이 보호되지 않는지.

tmux 3.2 이상과 Node.js 22 이상이 설치된 macOS가 필요합니다. brew install tmux node로 둘 다 설치할 수 있습니다.

npm install -g @meatgarden/aubergine
