Aubergine vs Conductor

둘 다 여러 코딩 에이전트를 한꺼번에, 각각 자체 Git 워크트리에서 실행합니다. Conductor는 채팅, diff 뷰어, 클라우드가 있는 Mac 앱입니다. Aubergine은 여러분 컴퓨터에서 실행되는 무료 오픈 소스 서버로, 평범한 터미널을 브라우저 페이지에 나란히 보여 줍니다.

출처. 여기서 Conductor에 대해 말하는 내용은 2026년 11월 26일에 읽은 문서와 변경 기록에서 가져왔습니다. Conductor를 실행해 보지는 않았습니다. 틀렸거나 오래된 내용이 있다면 알려 주세요.

Conductor의 현재 상황. 2026년 11월 4일 변경 기록에는 Conductor가 Meta에 합류하며 서비스를 정리할 것이라고 적혀 있었고, 11월 13일에는 Conductor가 서비스를 종료하지 않는다고 적혀 있었습니다. 이 글을 쓸 때 사이트 일부에는 아직 첫 번째 메시지가 남아 있었습니다. 지금 상황은 변경 기록을 읽어 보세요.

무엇을 고를까

Conductor를 고르세요: 작업을 프롬프트에서 병합된 풀 리퀘스트까지 가져가는 Mac 앱과, Mac이 꺼져 있는 동안에도 계속되는 작업을 위한 클라우드를 원한다면.

Aubergine을 고르세요: 에이전트를 한눈에 볼 수 있는 평범한 터미널로 두고, 창을 닫아도 tmux에서 계속 실행되며, 로그인할 것이 없고 소스가 공개된 것을 원한다면.

Conductor란

스스로의 설명에 따르면, 여러분의 코드베이스에서 많은 코딩 에이전트를 병렬로 실행하는 Mac 앱입니다. 각 작업은 워크스페이스입니다. 브랜치 하나의 Git 워크트리에 채팅, 터미널, 브라우저 탭이 있습니다. Mac에 이미 로그인된 계정으로 Claude Code, Codex, Cursor, OpenCode를 실행하며, diff 뷰어, 풀 리퀘스트, iOS 앱, 그리고 에이전트가 샌드박스에서 실행되는 유료 클라우드가 있습니다.

서로 다른 점

채팅이 아니라 터미널. Conductor는 에이전트를 워크스페이스 속 채팅으로 보여 주고, 그 옆에 터미널 모드가 있습니다. Aubergine은 여느 터미널 앱에서처럼 실행되는 에이전트 자체의 터미널을 보여 주고, 여러 개를 이동하고 확대·축소하는 캔버스 위에 배치합니다.

닫으면 끝나는 것. Conductor의 문서에 따르면 앱을 닫거나 Mac을 끄면 로컬 세션이 끝나고, 클라우드 세션은 계속됩니다. Aubergine에서는 모든 터미널이 tmux 세션이므로, 브라우저를 닫거나 Aubergine을 멈춰도 아무것도 끝나지 않습니다. 컴퓨터를 다시 시작하면 둘 다 끝납니다.

컴퓨터 밖에는 아무것도 없습니다. Conductor는 계정, 클라우드, 휴대폰 앱을 위한 릴레이, 사용 분석을 문서화하고 있습니다. Aubergine에는 계정도 자체 서비스도 없습니다. 서버는 127.0.0.1에서 수신하며, 다른 기기에서 쓸 때는 여러분이 운영하는 프록시를 거칩니다.

Conductor에는 있고 Aubergine에는 없는 것

  • 줄에 댓글을 달아 에이전트에게 돌려보내는 diff 뷰어, 그리고 풀 리퀘스트, 검사, 병합. Aubergine은 작업 사본에서 무엇이 바뀌었는지 보여 줄 뿐, 커밋, 푸시, 병합은 하지 않습니다.
  • Mac이 꺼져 있어도 에이전트가 계속 일하는 클라우드와, 그곳에서 일정에 따라 실행되는 루틴. Aubergine의 일정은 여러분 컴퓨터가 켜져 있을 때 그 컴퓨터에서 실행됩니다.
  • iOS 앱과 완료 알림음. Aubergine에는 앱이 없고 소리를 내지 않습니다.

질문

Aubergine은 Conductor의 대안인가요?

여러분 컴퓨터에서 여러 명령줄 에이전트를 실행하는 용도라면 그렇습니다. 각 에이전트는 캔버스 위에 터미널을 갖고, 요청하면 자체 Git 워크트리도 갖습니다. 다만 똑같은 대체품은 아닙니다. Aubergine에는 채팅 화면, 풀 리퀘스트나 병합, 클라우드, 휴대폰 앱이 없습니다.

Conductor는 오픈 소스인가요?

아니요. 약관은 Conductor를 독점 소프트웨어라고 하며, 공개 저장소는 찾지 못했습니다. 문서에 따르면 로컬 앱은 무료로 쓸 수 있고 클라우드 워크스페이스에는 유료 요금제가 필요합니다. Aubergine은 MIT 라이선스이며 유료 요금제가 없습니다.

Conductor는 Linux나 Windows에서 실행되나요?

문서에 따르면 아직 Windows나 Linux용은 없습니다. Aubergine은 macOS용으로 만들었고, Linux에서는 컨테이너 안에서만 실행해 봤으며, Windows에서는 WSL 2 안에서만 실행되고 이는 시도해 보지 않았습니다.

Conductor와 Aubergine을 함께 쓸 수 있나요?

막는 것은 없습니다. 둘 다 같은 저장소의 Git 워크트리에서 일하며, 각자 자기 워크트리를 만듭니다. 둘을 나란히 실행해 보지는 않았습니다.

Aubergine은 Conductor나 그 제작사와 관계가 없습니다. Conductor는 그들의 제품 이름입니다. 약관에는 Melty Labs, Inc.가 적혀 있고, 사이트에는 Conductor from Meta라고 적혀 있습니다.

5분이면 시작합니다

tmux 3.2 이상과 Node.js 22 이상이 설치된 macOS가 필요합니다. brew install tmux node로 둘 다 설치할 수 있습니다.

npm install -g @meatgarden/aubergine
