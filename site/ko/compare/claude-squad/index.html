Aubergine vs Claude Squad

둘은 같은 기반 위에 있습니다. 각 에이전트는 tmux 세션에, 각각 자체 Git 워크트리에 있고, 둘 다 무료 오픈 소스입니다. Claude Squad는 터미널 안의 프로그램입니다. Aubergine은 터미널이 나란히 놓이는 브라우저 속 페이지입니다.

출처. 여기서 Claude Squad에 대해 말하는 내용은 2026년 11월 26일에 읽은 저장소와 README에서 가져왔습니다. Claude Squad를 실행해 보지는 않았습니다. 틀렸거나 오래된 내용이 있다면 알려 주세요.

무엇을 고를까

Claude Squad를 고르세요: 터미널에서 살다시피 하고, 그곳에서 워크트리에 에이전트를 시작하고 브랜치를 푸시해 주는 작은 프로그램 하나만 원하며, 그 이상은 원하지 않는다면.

Aubergine을 고르세요: 여러 에이전트가 일하는 모습을 한꺼번에 보고, 어느 것이 여러분을 기다리는지 알고, 그 주위에 대기열, 일정, API를 두고 싶다면.

Claude Squad란

스스로의 설명에 따르면, 여러 Claude Code, Codex, Gemini 및 기타 로컬 에이전트를 별도의 워크스페이스에서 관리하는 터미널 앱입니다. cs로 시작하며, 터미널 창 하나에 세션 목록과 미리 보기, diff 탭이 있습니다. 각 세션은 자체 브랜치의 Git 워크트리에 있는 tmux 세션입니다. tmux와 gh가 필요하며, AGPL-3.0 라이선스입니다.

서로 다른 점

한 번에 하나, 또는 한꺼번에 모두. Claude Squad는 목록과, 고른 세션의 미리 보기를 보여 줍니다. Aubergine은 모든 터미널을 캔버스 위에 실시간으로 그리므로, 에이전트 다섯이면 눈앞에 터미널 다섯이 있고, 목록 하나가 각각의 상태를 글로 알려 줍니다.

누가 기다리는지. Claude Squad의 README에서 에이전트가 기다리거나 끝났다는 것을 알려 주는 기능에 대해서는 찾은 것이 없습니다. Aubergine은 기다리는 터미널을 색으로 표시하고, 기다리는 것의 수를 맨 위에 세어 보여 주고, 키 하나로 다음 터미널로 가며, 열린 페이지에서 알림을 보낼 수 있습니다.

에이전트 주위에 있는 것. Aubergine에는 한도가 있는 작업 대기열, 일정, 사람이 승인하는 단계가 있는 워크플로, 터미널마다의 노트와 필드, HTTP API, MCP 서버가 있습니다. Claude Squad는 세션과 그 브랜치에 집중합니다.

Claude Squad에는 있고 Aubergine에는 없는 것

  • 서버도 브라우저도 없이, 이미 열어 둔 터미널 안에서 실행됩니다. 여느 터미널 프로그램처럼 SSH로도 동작합니다. Aubergine을 다른 곳에서 쓰려면 터널이나 프록시가 필요합니다.
  • 브랜치를 대신 커밋하고 푸시하며, 작업을 커밋해서 세션을 일시 정지합니다. Aubergine은 커밋하거나 푸시하지 않습니다.
  • 에이전트의 프롬프트를 스스로 수락하는 실험적 모드. Aubergine은 에이전트에게 여러분 대신 답하지 않습니다.

질문

Aubergine은 Claude Squad의 대안인가요?

네, 같은 일을 다른 방식으로 합니다. 둘 다 각 에이전트를 tmux 세션에서 실행하며, 각각에 자체 브랜치의 Git 워크트리를 줄 수 있습니다. Claude Squad는 터미널 속 프로그램에서, Aubergine은 모든 터미널이 한눈에 보이는 브라우저 속 페이지에서 합니다.

둘 다 tmux를 쓰나요?

네. Claude Squad는 tmux를 사전 요구 사항으로 적고 있으며 에이전트마다 tmux 세션을 만듭니다. Aubergine은 tmux 3.2 이상이 필요하며, 자체 소켓과 자체 설정으로 실행하므로 여러분의 tmux는 건드리지 않습니다.

Claude Squad는 Claude Code 외의 에이전트와도 동작하나요?

README에 따르면 기본 프로그램은 claude이고, Codex, Gemini, Aider 같은 다른 프로그램은 -p로 지정합니다. Aubergine은 모든 명령줄 프로그램을 터미널에서 실행합니다. Aubergine이 에이전트를 위해 스스로 해 주는 일은 Claude Code에 맞춰 만들어져 있습니다.

각각 어떤 라이선스인가요?

Claude Squad는 AGPL-3.0, Aubergine은 MIT 라이선스입니다. 둘 다 무료입니다.

Aubergine은 Claude Squad나 Anthropic과 관계가 없습니다. Claude Squad는 smtg-ai 프로젝트의 이름이고, Claude는 Anthropic의 상표입니다.

5분이면 시작합니다

tmux 3.2 이상과 Node.js 22 이상이 설치된 macOS가 필요합니다. brew install tmux node로 둘 다 설치할 수 있습니다.

npm install -g @meatgarden/aubergine
