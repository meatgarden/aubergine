Aubergine vs Paradev(이전 이름 Superset)

Paradev는 2026년 10월까지 Superset이라 불린 데스크톱 앱입니다. Aubergine처럼 MIT 라이선스이고, 모든 명령줄 에이전트를 실행하며, Git 워크트리에서 일합니다. 요금제, 휴대폰 앱, 클라우드가 있는 앱입니다. Aubergine은 여러분 컴퓨터의 서버와 브라우저 속 페이지이며, 그 어느 것도 없습니다.

출처. 여기서 Paradev에 대해 말하는 내용은 2026년 11월 26일에 읽은 문서, 변경 기록, 저장소에서 가져왔습니다. Paradev를 실행해 보지는 않았습니다. 틀렸거나 오래된 내용이 있다면 알려 주세요.

이름. 2026년 10월 25일 변경 기록에 따르면 Superset은 이제 Paradev이며, 계정, 워크스페이스, 설정, superset 명령은 그대로 이어집니다. 데이터 도구인 Apache Superset과는 다릅니다.

무엇을 고를까

Paradev를 고르세요: 모든 작업에 워크트리를 만들어 diff, 검사, 병합까지 가져가는 데스크톱 앱과, 비용을 내면 휴대폰 앱과 클라우드를 원한다면.

Aubergine을 고르세요: 계정 없이 여러분 컴퓨터에서 모든 부분이 무료이기를 원한다면. 나란히 놓인 터미널, 대기열, 일정, 다른 기기에서의 사용.

Paradev란

스스로의 설명에 따르면, Claude Code, Codex 및 모든 코딩 에이전트를 위한 오픈 소스 워크스페이스입니다. 터미널 앱이 아닌 데스크톱 앱이며, 에이전트는 채팅으로 또는 터미널에서 실행됩니다. 모든 작업에 자체 워크트리, 브랜치, 터미널이 있고, 사이드바 하나가 모든 세션을 프로젝트별로 보여 줍니다. 풀 리퀘스트 검사와 병합이 있는 diff 뷰어, 명령, SDK, MCP 서버가 있으며, 유료 요금제에는 휴대폰 앱, 원격 접속, 클라우드 워크스페이스, 자동화가 있습니다.

서로 다른 점

무엇이 무료인지. Paradev는 로컬 워크스페이스, 앱, 명령을 쓸 수 있는 1인용 무료 요금제를 두고 있으며, 자동화, 휴대폰 앱, 원격 접속은 유료 요금제에 있습니다. Aubergine에는 요금제가 없습니다. 대기열, 일정, 다른 기기에서의 사용 모두 MIT 라이선스인 하나의 프로그램에 들어 있으며, 계정도 필요 없습니다.

사이드바냐 캔버스냐. Paradev는 세션을 탭과 창(pane)이 있는 사이드바에 보여 줍니다. Aubergine은 터미널을 이동하고 확대·축소하는 캔버스 위에 배치하므로, 여러 개가 실시간으로 한꺼번에 보이고, 그 옆에 전부를 담은 목록 하나가 있습니다.

터미널이 창보다 오래 사는 방식. 둘 다 창을 닫아도 에이전트를 계속 실행합니다. Paradev는 자체 백그라운드 데몬을 통해서인데, 문서에 따르면 Paradev를 완전히 종료하면 모든 터미널이 끝납니다. Aubergine은 tmux를 통해서이며, Aubergine 자체가 멈춰도 계속됩니다. 컴퓨터를 다시 시작하면 둘 다 끝납니다.

Paradev에는 있고 Aubergine에는 없는 것

  • 에이전트의 변경에 댓글을 달고 편집하고, 풀 리퀘스트의 검사를 지켜보고 병합하는 diff 뷰어. Aubergine은 무엇이 바뀌었는지 보여 줄 뿐, 커밋, 푸시, 병합은 하지 않습니다.
  • 데스크톱 앱, iOS와 Android 앱, 클라우드 워크스페이스, 그리고 에이전트가 여러분을 필요로 할 때의 알림음과 Dock 배지. Aubergine은 브라우저 페이지이며 소리를 내지 않습니다.
  • 리뷰 요청, Slack 메시지, 이슈, 웹훅으로 시작되는 자동화, 그리고 많은 에이전트가 상태를 보고하도록 설치하는 훅. Aubergine은 외부에서 아무것도 시작하지 않으며, 에이전트가 기다리는 것을 스스로 알아차리는 것은 Claude Code에 대해서만입니다.

질문

Aubergine은 Paradev(Superset)의 대안인가요?

여러 명령줄 에이전트를 로컬에서 각각 자체 Git 워크트리로 실행하는 용도라면 그렇고, 모든 기능이 무료입니다. 다만 똑같은 대체품은 아닙니다. Aubergine에는 데스크톱 앱이나 휴대폰 앱, diff 댓글, 풀 리퀘스트나 병합, 클라우드가 없습니다.

Superset과 Paradev는 같은 것인가요?

네. 2026년 10월 25일 변경 기록에 따르면 Superset은 이제 Paradev이며, README에 따르면 명령은 여전히 superset입니다. 어느 쪽도 Apache Superset과는 관계가 없습니다.

둘 다 오픈 소스인가요?

둘 다 MIT 라이선스입니다. Paradev는 휴대폰 앱, 원격 접속, 클라우드, 자동화를 위한 요금제도 판매합니다. Aubergine은 아무것도 판매하지 않습니다.

Paradev는 Linux나 Windows에서 실행되나요?

문서에 따르면 macOS에서 실행되고, 실험적인 Linux 빌드가 있으며, Windows는 아직 지원하지 않습니다. Aubergine은 macOS용으로 만들었고, Linux에서는 컨테이너 안에서만 실행해 봤으며, Windows에서는 WSL 2 안에서만 실행되고 이는 시도해 보지 않았습니다.

Aubergine은 Paradev나 그 제작사인 Superset Inc.와 관계가 없습니다. Paradev와 Superset은 그들의 이름이며, 그들도 Aubergine도 Apache Superset과는 관계가 없습니다.

5분이면 시작합니다

tmux 3.2 이상과 Node.js 22 이상이 설치된 macOS가 필요합니다. brew install tmux node로 둘 다 설치할 수 있습니다.

npm install -g @meatgarden/aubergine
