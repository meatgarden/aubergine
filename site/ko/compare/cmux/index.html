Aubergine vs cmux

이 페이지들 중 가장 가까운 짝입니다. 둘 다 코딩 에이전트를 위해 만든 터미널이고, 둘 다 명령줄에서 시작할 수 있는 모든 에이전트를 실행하며, 둘 다 오픈 소스입니다. cmux는 네이티브 macOS 터미널 앱입니다. Aubergine은 여러분 컴퓨터의 서버이자 브라우저 속 터미널 캔버스입니다.

출처. 여기서 cmux에 대해 말하는 내용은 2026년 11월 26일에 읽은 사이트와 문서, 그리고 저장소에서 가져왔습니다. cmux를 실행해 보지는 않았습니다. 틀렸거나 오래된 내용이 있다면 알려 주세요.

무엇을 고를까

cmux를 고르세요: 창 분할, 앱 내 브라우저, macOS 알림이 있는 빠른 네이티브 Mac 터미널 앱을 원하고, 그 위에 자기만의 작업 방식을 스크립트로 만든다면.

Aubergine을 고르세요: 모드를 고르지 않아도 앱을 닫은 뒤 계속 실행되는 에이전트, 대신 만들어 주는 에이전트별 워크트리, 그리고 이미 만들어진 대기열, 일정, 승인을 원한다면.

cmux란

스스로의 설명에 따르면, libghostty 위에 만든 macOS 터미널로, 세로 탭과 코딩 에이전트용 알림이 있으며 Swift로 작성되었습니다. 사이드바에는 워크스페이스가 브랜치, 풀 리퀘스트, 폴더, 최근 알림과 함께 나열되고, 워크스페이스는 탭이 있는 창(pane)으로 나뉩니다. 모든 동작은 명령이자 Unix 소켓의 메시지이기도 합니다. 앱은 GPL-3.0-or-later 라이선스이며 무료입니다. 클라우드 머신과 베타 iOS 앱에는 계정과 유료 요금제가 따릅니다.

서로 다른 점

닫으면 끝나는 것. cmux의 문서에 따르면 종료할 때 레이아웃과 폴더는 저장되지만, 로컬 tmux 모드를 직접 켜지 않으면 실행 중인 프로세스는 유지되지 않습니다. Aubergine에서 tmux는 모드가 아닙니다. 모든 터미널이 처음부터 tmux 세션입니다. 둘 다 컴퓨터를 다시 시작하는 동안 프로세스를 유지하지는 못합니다.

기본 요소냐, 그 주위의 것들이냐. cmux는 스스로를 솔루션이 아닌 기본 요소(primitive)라 부르며, 무언가를 만들 수 있도록 명령과 소켓을 줍니다. Aubergine에는 Git 워크트리의 작업 사본, 한도가 있는 대기열, 일정, 승인이 있는 워크플로, 그리고 여러분을 기다리는 것을 담은 목록 하나가 들어 있습니다.

앱이냐 페이지냐. cmux는 시스템이 그리는 Mac 앱입니다. Aubergine은 브라우저 속 페이지입니다. 네이티브 터미널보다 그리는 속도는 느리고, 여러분이 운영하는 프록시를 통해 페어링한 다른 브라우저에서 접속할 수 있습니다.

cmux에는 있고 Aubergine에는 없는 것

  • libghostty 기반의 네이티브 터미널, 창 분할, 그리고 명령으로 조작할 수 있는 앱 내 브라우저. Aubergine은 브라우저 페이지에 터미널을 그리며 창 분할이 없습니다. 터미널은 캔버스 위에 배치됩니다.
  • 창(pane)이 여러분을 필요로 할 때의 macOS 알림과 사용자 지정 명령. 터미널이 이미 쓰는 이스케이프 시퀀스로 작동하므로 어떤 프로그램에서든 됩니다. Aubergine은 Claude Code에 맞춰 만든 훅으로 에이전트가 기다리는 것을 알아차리며, 열린 페이지에서만 알립니다.
  • 원격 머신의 워크스페이스를 위한 cmux ssh, 베타 iOS 앱, 유료 요금제의 클라우드 머신.

질문

Aubergine은 cmux의 대안인가요?

네. 둘 다 여러 코딩 에이전트를 실행하고 어느 것이 여러분을 필요로 하는지 보기 위한 터미널입니다. cmux는 네이티브 macOS 앱이고, Aubergine은 tmux 위에서 브라우저로 실행되며 작업 사본, 대기열, 일정, 워크플로가 더해져 있습니다.

cmux에는 tmux가 필요한가요?

아니요. 문서에 따르면 tmux는 필요하지 않으며, cmux를 종료할 때 실행 중인 프로세스를 유지하기 위한 로컬 tmux 모드를 선택적으로 제공합니다. Aubergine은 tmux 3.2 이상이 필요하며 모든 터미널을 그 안에서 실행합니다.

cmux는 Linux나 Windows에서 실행되나요?

README에 따르면 현재는 macOS만, macOS 14 이상에서 실행됩니다. Aubergine은 macOS용으로 만들었고, Linux에서는 컨테이너 안에서만 실행해 봤으며, Windows에서는 WSL 2 안에서만 실행되고 이는 시도해 보지 않았습니다.

둘 다 무료 오픈 소스인가요?

cmux 앱은 GPL-3.0-or-later 라이선스이며 무료이고, 클라우드에는 유료 요금제가 있습니다. 서버 소프트웨어는 다른 라이선스입니다. Aubergine은 MIT 라이선스이며 유료 요금제가 없습니다.

Aubergine은 cmux나 그 제작사와 관계가 없습니다. cmux는 Manaflow, Inc.의 제품 이름입니다.

5분이면 시작합니다

tmux 3.2 이상과 Node.js 22 이상이 설치된 macOS가 필요합니다. brew install tmux node로 둘 다 설치할 수 있습니다.

npm install -g @meatgarden/aubergine
