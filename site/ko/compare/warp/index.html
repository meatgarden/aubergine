이 페이지는 영어 원문을 기계 번역한 것입니다. 수정 제안 보내기.

Aubergine vs Warp

Warp는 자체 에이전트, 요금제, 클라우드를 갖춘 완전한 터미널 앱이며, 다른 명령줄 에이전트도 탭과 창(pane)에서 실행합니다. Aubergine은 범위가 더 좁습니다. 모델을 호출하지 않고, 터미널 앱을 대신하지도 않습니다. 이미 쓰는 에이전트를 브라우저 페이지에 나란히 실행하고, 계속 실행되게 합니다.

출처. 여기서 Warp에 대해 말하는 내용은 2026년 11월 26일에 읽은 문서와 가격 페이지에서 가져왔으며, 여러 코딩 에이전트를 실행하는 것에 대해서만 다룹니다. Warp는 그 밖에도 많은 일을 합니다. 이 비교를 위해 Warp를 실행해 보지는 않았습니다. 틀렸거나 오래된 내용이 있다면 알려 주세요.

무엇을 고를까

Warp를 고르세요: Windows와 Linux에서도 쓸 수 있고, 자체 에이전트가 내장되어 있으며, 일정을 정할 수 있는 클라우드 에이전트가 있는, 모든 것을 위한 터미널 앱 하나를 원한다면.

Aubergine을 고르세요: 이미 마음에 드는 터미널과 에이전트가 있고, 그 사이에 빠진 것만 원한다면. 모두 한눈에 보이고, 계속 실행되며, 계정도 자체 모델도 없습니다.

Warp란

스스로의 설명에 따르면, 에이전트형 개발 환경입니다. macOS, Windows, Linux용 데스크톱 터미널이며, 클라이언트는 AGPL-3.0 오픈 소스입니다. 자체 Warp Agent가 있어 Warp를 통하거나 여러분의 키로 모델을 호출하고, Claude Code, Codex, Gemini CLI 같은 다른 명령줄 에이전트를 탭과 창(pane)에서 실행하며, 활성 에이전트 전체를 보여 주는 패널, 알림, 코드 리뷰 패널, 그리고 일정에 따라 실행되는 클라우드 에이전트가 있습니다.

서로 다른 점

자체 모델이 있느냐, 없느냐. Warp에는 자체 에이전트가 있고, 그 사용료를 내는 요금제와 여러분의 키를 쓰는 선택지가 있습니다. Aubergine은 모델을 호출하지 않고 키를 보관하지 않습니다. 그 터미널의 에이전트는 여러분이 직접 설치하고 로그인한 것입니다.

닫으면 끝나는 것. Warp의 문서에 따르면 창, 탭, 창(pane), 최근 출력을 복원합니다. 실행 중인 프로그램이 유지된다는 내용은 찾지 못했습니다. Aubergine에서는 모든 터미널이 tmux 세션이므로, 브라우저나 Aubergine 자체가 멈춰도 에이전트는 계속 일합니다.

에이전트에 어디서 접속할 수 있는지. Warp는 실행 중인 세션을 클라우드에 게시해 휴대폰이나 브라우저에서 조종할 수 있게 합니다. Aubergine에는 클라우드가 없습니다. 다른 기기는 여러분 컴퓨터에서 운영하는 프록시를 통해 코드로 페어링한 브라우저이며, Mac 한 대에서 한 번 시도해 봤습니다.

Warp에는 있고 Aubergine에는 없는 것

  • 문서화된 플랫폼으로서의 Windows와 Linux, 데스크톱 앱으로. Aubergine은 macOS용으로 만들었습니다.
  • 자체 에이전트, 그리고 일정에 따라 또는 Slack, Linear, GitHub 같은 다른 서비스에서 시작되는 클라우드 에이전트. Aubergine은 외부에서 아무것도 시작하지 않으며, 일정을 위해 네트워크에 접속하지 않습니다.
  • 터미널 앱이 갖춘 그 밖의 모든 것: 명령 편집기, 출력 블록, 여러 에이전트에 대한 알림. Aubergine은 Claude Code에 맞춰 만든 훅으로 에이전트가 기다리는 것을 알아차립니다.

질문

Aubergine은 Warp의 대안인가요?

Warp가 하는 일 중 하나에 대해서만 그렇습니다. 여러 명령줄 코딩 에이전트를 실행하고 어느 것이 여러분을 필요로 하는지 보는 일입니다. Aubergine은 터미널 앱이 아니며 자체 에이전트도 없습니다. Warp든 어떤 터미널이든 그대로 쓰면서 에이전트에는 Aubergine을 쓸 수 있습니다.

계정이나 유료 요금제가 필요한가요?

Warp의 문서에 따르면 터미널을 쓰는 데 로그인은 선택이며, 가격 페이지에는 무료 요금제와 유료 요금제가 나와 있습니다. Aubergine에는 계정도 요금제도 없습니다.

Warp는 오픈 소스인가요?

문서에 따르면 Warp의 클라이언트는 AGPL-3.0 오픈 소스입니다. Aubergine은 MIT 라이선스입니다.

Warp와 Aubergine을 함께 쓸 수 있나요?

네, 여느 터미널 앱과 마찬가지입니다. Aubergine의 터미널은 tmux 세션이며, aubergine attach <name>은 그것을 실행한 터미널 앱의 창에 터미널 하나를 보여 줍니다. Warp에서 이를 시도해 보지는 않았습니다.

Aubergine은 Warp와 관계가 없습니다. Warp는 Warp라는 이름으로 사업하는 Denver Technologies, Inc.의 상표입니다.

5분이면 시작합니다

tmux 3.2 이상과 Node.js 22 이상이 설치된 macOS가 필요합니다. brew install tmux node로 둘 다 설치할 수 있습니다.

npm install -g @meatgarden/aubergine
