Aubergine vs Vibe Kanban

Both are open source, run on your own computer and are used in a browser. Vibe Kanban starts from the work: issues on a board, each handed to an agent. Aubergine starts from the agents: terminals side by side, with a queue beside them.

Where this comes from. What is said here about Vibe Kanban is from its documentation and its repository as read on 26 November 2026. We have not run Vibe Kanban. If something is wrong or out of date, tell us.

Where Vibe Kanban stands. On 10 April 2026 its makers wrote that bloop, the company behind it, was shutting down, that the project goes on as open source maintained by its community, and that its remote services would be removed while local workspaces keep working. Its documentation and pricing page still described those services when this was written; releases have continued.

Which to pick

Pick Vibe Kanban if you think in issues: plan on a board, hand each card to an agent, review its diff with comments, and merge.

Pick Aubergine if you want the agents themselves in view as terminals that outlive the window, and work handed out from a queue only when you say so.

What Vibe Kanban is

By its own description, a kanban board for developers to track coding tasks with coding agents. npx vibe-kanban starts a local server and opens its page. An issue becomes a workspace: Git worktrees for the repositories you chose, a conversation with one of ten or more agents it knows by name, the changes beside it, then a pull request and a merge. It is under the Apache-2.0 license.

Where they differ

A conversation or a terminal. Vibe Kanban shows an agent as a conversation panel with its changes beside it. Aubergine shows the agent's own terminal, and many of them at once on a canvas.

Any program. Vibe Kanban lists the agents it supports by name. An Aubergine terminal is a shell: any command-line agent runs in it, and so does a build, a test run or a server. What Aubergine does by itself for an agent is built for Claude Code.

What closing it ends. We found nothing in Vibe Kanban's documentation about what happens to a running agent when its server stops. In Aubergine every terminal is a tmux session, and stopping Aubergine or closing the browser ends nothing.

What Vibe Kanban has that Aubergine does not

  • A kanban board of issues with priorities, tags and sub-issues. Aubergine has a queue of tasks and a board of running workflows, not an issue tracker.
  • Diffs with inline comments sent back to the agent, then pull requests, rebase and merge. Aubergine shows what changed and never commits or merges.
  • Windows among its documented platforms, sounds, and a longer list of agents it knows by name.

Questions

Is Aubergine an alternative to Vibe Kanban?

For running several agents locally in Git worktrees and seeing which needs you, yes. It is a different shape: Aubergine has terminals on a canvas and a queue of tasks where Vibe Kanban has a board of issues with conversations, and Aubergine opens no pull request and merges nothing.

Is Vibe Kanban still maintained?

Its makers wrote on 10 April 2026 that the company behind it was shutting down and that the project continues as open source maintained by its community. Its repository has had releases since. Read its repository for where it stands now.

Do both run locally?

Yes. Each is a server on your own computer with a page in your browser. Vibe Kanban documents an optional sign-in for its board and team features; Aubergine has no account at all.

Which agents does each support?

Vibe Kanban names more than ten, among them Claude Code, Codex, Gemini CLI, GitHub Copilot, Amp, Cursor and OpenCode. Aubergine runs any command-line program in a terminal; starting an agent from the menu, seeing that it waits and resuming its conversation are built for Claude Code.

Aubergine is not affiliated with Vibe Kanban or its makers. Vibe Kanban is the name of the project begun by Bloop AI Limited.
