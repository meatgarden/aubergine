Aubergine vs Vibe Kanban

둘 다 오픈 소스이고, 여러분 컴퓨터에서 실행되며, 브라우저에서 씁니다. Vibe Kanban은 일에서 시작합니다. 보드 위의 이슈를 하나씩 에이전트에게 맡깁니다. Aubergine은 에이전트에서 시작합니다. 터미널이 나란히 놓이고, 그 옆에 대기열이 있습니다.

출처. 여기서 Vibe Kanban에 대해 말하는 내용은 2026년 11월 26일에 읽은 문서와 저장소에서 가져왔습니다. Vibe Kanban을 실행해 보지는 않았습니다. 틀렸거나 오래된 내용이 있다면 알려 주세요.

Vibe Kanban의 현재 상황. 2026년 4월 10일 제작사는 이를 만든 회사인 bloop이 문을 닫으며, 프로젝트는 커뮤니티가 유지하는 오픈 소스로 계속되고, 원격 서비스는 없어지지만 로컬 워크스페이스는 계속 동작한다고 썼습니다. 이 글을 쓸 때 문서와 가격 페이지에는 아직 그 서비스들이 설명되어 있었고, 릴리스는 계속 나오고 있습니다.

무엇을 고를까

Vibe Kanban을 고르세요: 이슈 단위로 생각한다면. 보드에서 계획하고, 카드를 하나씩 에이전트에게 맡기고, diff를 댓글과 함께 검토하고, 병합합니다.

Aubergine을 고르세요: 에이전트 자체를 창보다 오래 사는 터미널로 눈앞에 두고, 여러분이 말할 때만 대기열에서 일이 나가기를 원한다면.

Vibe Kanban이란

스스로의 설명에 따르면, 개발자가 코딩 에이전트와 함께 코딩 작업을 추적하는 칸반 보드입니다. npx vibe-kanban은 로컬 서버를 시작하고 그 페이지를 엽니다. 이슈는 워크스페이스가 됩니다. 고른 저장소들의 Git 워크트리, 이름으로 아는 열 가지 이상의 에이전트 중 하나와의 대화, 그 옆의 변경 사항, 그다음 풀 리퀘스트와 병합. Apache-2.0 라이선스입니다.

서로 다른 점

대화냐 터미널이냐. Vibe Kanban은 에이전트를 대화 패널로 보여 주고, 그 옆에 변경 사항을 둡니다. Aubergine은 에이전트 자체의 터미널을 보여 주며, 여러 개를 캔버스 위에 한꺼번에 보여 줍니다.

어떤 프로그램이든. Vibe Kanban은 지원하는 에이전트를 이름으로 나열합니다. Aubergine 터미널은 셸입니다. 명령줄 에이전트라면 무엇이든 그 안에서 실행되고, 빌드, 테스트 실행, 서버도 마찬가지입니다. Aubergine이 에이전트를 위해 스스로 해 주는 일은 Claude Code에 맞춰 만들어져 있습니다.

닫으면 끝나는 것. Vibe Kanban의 문서에서 서버가 멈출 때 실행 중인 에이전트가 어떻게 되는지에 대해서는 찾은 것이 없습니다. Aubergine에서는 모든 터미널이 tmux 세션이며, Aubergine을 멈추거나 브라우저를 닫아도 아무것도 끝나지 않습니다.

Vibe Kanban에는 있고 Aubergine에는 없는 것

  • 우선순위, 태그, 하위 이슈가 있는 이슈 칸반 보드. Aubergine에는 작업 대기열과 실행 중인 워크플로의 보드가 있을 뿐, 이슈 트래커는 아닙니다.
  • 에이전트에게 돌려보내는 인라인 댓글이 달린 diff, 그다음 풀 리퀘스트, 리베이스, 병합. Aubergine은 무엇이 바뀌었는지 보여 줄 뿐, 커밋하거나 병합하지 않습니다.
  • 문서화된 플랫폼에 Windows가 있고, 소리가 있으며, 이름으로 아는 에이전트 목록이 더 깁니다.

질문

Aubergine은 Vibe Kanban의 대안인가요?

여러 에이전트를 로컬의 Git 워크트리에서 실행하고 어느 것이 여러분을 필요로 하는지 보는 용도라면 그렇습니다. 형태는 다릅니다. Vibe Kanban에 대화가 딸린 이슈 보드가 있는 자리에 Aubergine에는 캔버스 위의 터미널과 작업 대기열이 있으며, Aubergine은 풀 리퀘스트를 열지 않고 아무것도 병합하지 않습니다.

Vibe Kanban은 아직 유지되고 있나요?

제작사는 2026년 4월 10일에, 이를 만든 회사가 문을 닫으며 프로젝트는 커뮤니티가 유지하는 오픈 소스로 계속된다고 썼습니다. 저장소에는 그 뒤로도 릴리스가 있었습니다. 지금 상황은 저장소를 읽어 보세요.

둘 다 로컬에서 실행되나요?

네. 둘 다 여러분 컴퓨터의 서버와 브라우저 속 페이지입니다. Vibe Kanban은 보드와 팀 기능을 위한 선택적 로그인을 문서화하고 있습니다. Aubergine에는 계정이 전혀 없습니다.

각각 어떤 에이전트를 지원하나요?

Vibe Kanban은 열 가지 이상을 이름으로 들며, 그중에는 Claude Code, Codex, Gemini CLI, GitHub Copilot, Amp, Cursor, OpenCode가 있습니다. Aubergine은 모든 명령줄 프로그램을 터미널에서 실행합니다. 메뉴에서 에이전트를 시작하기, 기다리는 것을 알아차리기, 대화를 재개하기는 Claude Code에 맞춰 만들어져 있습니다.

Aubergine은 Vibe Kanban이나 그 제작사와 관계가 없습니다. Vibe Kanban은 Bloop AI Limited가 시작한 프로젝트의 이름입니다.

5분이면 시작합니다

tmux 3.2 이상과 Node.js 22 이상이 설치된 macOS가 필요합니다. brew install tmux node로 둘 다 설치할 수 있습니다.

npm install -g @meatgarden/aubergine
