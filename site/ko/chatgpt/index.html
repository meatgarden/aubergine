Codex와 ChatGPT

Codex는 OpenAI의 명령줄 코딩 에이전트입니다. 여러분이 직접 설치하고 로그인하며, Aubergine에서는 다른 프로그램처럼 터미널에서 실행됩니다.

아직 시험하지 않음

아직 아무도 Aubergine에서 실제 Codex를 실행해 보지 않았습니다. 이 페이지의 내용은 Aubergine이 터미널 속 모든 프로그램과 aubergine 명령에 대해 하는 일이며, 이는 만들어지고 테스트되었습니다. Codex 자체가 그곳에서 어떻게 동작하는지는 확인되지 않았습니다. 시험해 보셨다면 결과를 알려 주세요.

시작하기

New terminal 또는 N으로 터미널을 열고, 다른 터미널에서처럼 그 안에서 Codex를 시작하세요. Aubergine은 모델을 호출하지 않고 키를 보관하지 않습니다. Codex에 필요한 것은 로그인할 때 여러분이 이미 주었습니다.

지금 동작하는 것

Aubergine이 모든 터미널에 해 주는 모든 것:

  • 나란히

    하나의 캔버스에 원하는 만큼의 터미널, 그리고 탭으로 된 캔버스.

  • 명령 상태

    zsh에서는 터미널 제목에 명령이 실행 중인지, 어떤 명령인지가 표시됩니다.

  • 색, 노트, 필드

    터미널에 색을 지정하고, 요약과 로그가 있는 노트를 남기고, 티켓이나 담당자 같은 필드를 둘 수 있습니다.

  • 잠시 치워 두기

    ×는 터미널을 치워 둡니다(park). 캔버스에서 사라지지만 계속 실행되며, Parked에서 다시 불러옵니다.

  • 터미널 하나만 따로

    세부 정보와 노트를 옆에 둔 채, 터미널을 별도의 브라우저 탭에서 엽니다.

  • 작업 사본

    Shell in a folder or a working copy… 또는 aubergine new --copy는 자체 체크아웃의 자체 브랜치에서 터미널을 시작하므로, 두 에이전트가 같은 파일을 편집하는 일이 없습니다.

  • 출력 검색

    ⌘K는 모든 터미널이 출력한 내용을 검색하고, 일치하는 곳까지 스크롤된 상태로 터미널을 엽니다.

명령으로 알릴 수 있는 것

모든 Aubergine 터미널에는 aubergine 명령과 그 터미널만을 위한 자격 증명이 있습니다. Codex를 포함해 그 안의 어떤 프로그램이든 이를 사용할 수 있습니다.

  • aubergine attention waiting "…"

    필요한 것과 함께 터미널을 waiting for you로 표시합니다. 나머지는 aubergine attention working과 aubergine attention done이 알립니다.

  • aubergine note "…"

    터미널의 노트 로그에 한 줄을 추가합니다.

  • aubergine describe

    작업에 맞게 터미널 이름을 짓고 요약을 유지합니다. aubergine link add와 aubergine field set은 작업의 링크와 필드를 추가합니다. 여러분이 직접 쓴 것이 우선합니다.

  • aubergine workflow status

    워크플로의 현재 단계를 읽습니다. aubergine workflow done은 단계 완료를 보고하고 다음 단계를 출력합니다.

  • aubergine task add

    대기열에 작업을 제안하며, aubergine ask는 사람만 할 수 있는 일을 여러분에게 요청합니다. 둘 다 여러분의 목록에서 기다립니다.

알려 주는 방법

Codex는 알려 주기 전까지 Aubergine에 대해 모릅니다. 이 명령은 프로젝트의 모든 대화가 시작될 때 에이전트가 읽는 지침에 붙여 넣을 다섯 줄을 출력합니다. 어디에 넣는지는 에이전트 자체 문서에 나와 있습니다.

aubergine guide --snippet

이 줄들은 Aubergine 터미널 안에 있을 때 aubergine guide를 한 번 실행하라고 알려 주고, 나머지는 가이드가 알려 줍니다. Aubergine은 줄을 출력만 하며, 어떤 파일에도 쓰지 않습니다.

에이전트가 MCP 서버를 시작할 수 있다면 aubergine mcp가 같은 기능을 도구로 제공합니다. Aubergine 터미널 안에서는 터미널 자체 작업에 주소도 토큰도 필요 없습니다.

현재 Claude Code 전용으로만 만들어진 것

Aubergine이 에이전트를 위해 스스로 해 주는 일은 Claude Code에 맞춰 만들어져 있습니다. Codex의 경우 현재는 다음과 같습니다.

  • New terminal 메뉴에 없습니다. 터미널에서 직접 시작해야 합니다.
  • Aubergine은 이를 에이전트로 보지 않습니다. 스스로 대기나 완료로 표시되지 않고, aubergine attention을 실행할 때만 표시됩니다.
  • 대신 입력해 주는 것이 없습니다. 그 터미널에서 시작한 워크플로는 아무것도 입력하지 않고 직접 전해 줄 줄을 보여 주며, 요약이나 메시지도 알려 주지 않습니다.
  • 대기열은 작업을 주지 않습니다. 작업은 에이전트가 보이고 한가한 터미널로만 갑니다.
  • Resume agent도, 지난 대화 목록도, 설정 상태 목록도, Aubergine 도구를 위한 대화 상자도 없습니다.
  • aubergine move와 aubergine here --claude는 Claude Code만 가져옵니다.
  • 터미널 이름을 짓거나 요약을 유지하라는 안내를 받지 않습니다.

전체 내용은 Claude Code 페이지에 있습니다.

브라우저의 ChatGPT

브라우저 탭의 ChatGPT는 터미널 속 프로그램이 아니라 웹 페이지이므로, 캔버스에서 실행되지 않습니다.

Aubergine은 OpenAI와 제휴 관계가 없습니다. Codex와 ChatGPT는 OpenAI의 상표입니다.

5분이면 시작합니다

tmux 3.2 이상과 Node.js 22 이상이 설치된 macOS가 필요합니다. brew install tmux node로 둘 다 설치할 수 있습니다.

npm install -g @meatgarden/aubergine
