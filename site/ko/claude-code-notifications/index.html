Claude Code가 끝났는지, 여러분을 기다리는지 알기

Claude Code에 작업을 맡기고 다른 일을 하다가 20분 뒤에 돌아와 보니, 2분째부터 승인을 기다리고 있었습니다. Aubergine은 어느 터미널이 작업 중이고, 어느 것이 여러분을 기다리고, 어느 것이 끝났는지 한 페이지에서 보여 줍니다.

흔히 쓰는 방법

Claude Code는 멈출 때(Stop)나 알림을 보낼 때(Notification) 같은 순간에 훅, 즉 여러분이 정한 명령을 실행합니다. 흔한 해결책은 Claude Code 설정에 소리를 내거나 데스크톱 알림을 띄우는 훅을 넣는 것입니다. 잘 동작하며, 스크립트는 여러분이 직접 쓰고 관리합니다.

Aubergine이 하는 일

Aubergine에서 Claude Code를 시작하세요. 터미널 목록 맨 위의 New terminal ▾ → Claude Code를 누르거나 C를 누릅니다. Aubergine은 자체 데이터 폴더에 만든 설정 파일을 명령줄에 지정해 claude를 시작합니다. 여러분의 Claude Code 설정은 건드리지 않습니다. 그 파일의 훅이 에이전트가 하는 일을 페이지에 알립니다.

  • 프롬프트를 보내면 터미널에 working이 표시되고, 프롬프트가 노트의 로그에 추가됩니다.
  • 에이전트가 여러분을 필요로 하면(권한 질문, 또는 입력을 기다리며 유휴 상태일 때) 테두리 선이 대기 색으로 바뀌고, 제목과 목록의 행에 waiting for you가 표시됩니다.
  • 멈추면 터미널에 finished가 표시됩니다.

페이지 오른쪽 위의 For you 옆의 숫자는 모든 프로젝트에 걸쳐 여러분을 기다리는 모든 것입니다. 질문이 있는 터미널, 승인할 실행, 읽을 초안, 제안된 작업. 누르면 Runs가 열리고, 그 Waiting for you 열이 바로 그 목록입니다. 캔버스 탭에는 그 캔버스에서 기다리는 터미널 수가 표시됩니다.

다음으로 기다리는 터미널. 키보드를 가진 터미널이 없을 때 W는 여러분을 기다리는 다음 터미널로 이동합니다. macOS에서는 ⌃⌘J가 터미널 안에서도 같은 일을 합니다. 다른 환경에서는 팔레트에 있습니다.

열린 페이지의 알림. Settings → Notifications에 Notify me on the desktop when a terminal starts waiting(터미널이 기다리기 시작하면 데스크톱으로 알림)이 있습니다. 켜 두면 터미널이 기다리기 시작하거나 에이전트가 끝났을 때, 여러분이 그 터미널을 보고 있지 않다면 페이지가 브라우저 알림을 띄웁니다. 브라우저는 한 번 권한을 묻습니다.

규칙. Runs의 Rules 탭에서, 작업이 끝났을 때, 작업이 실패했을 때, 작업에 여러분이 필요할 때, 여러분에게 무언가를 요청할 때, 일정이 실행되었거나 실행되지 못했을 때 Notify me(알림) 규칙을 만들 수 있습니다. 무슨 일이 있었는지 한 문장으로 알려 주는, 열린 페이지의 알림입니다.

다른 에이전트, 그리고 직접 입력한 claude

Aubergine은 터미널 출력을 읽어 추측하지 않습니다. 다른 에이전트나 어떤 프로그램이든 자기 터미널에서 aubergine attention waiting "what it needs", aubergine attention working, aubergine attention done으로 같은 것을 스스로 알립니다. aubergine guide --snippet은 에이전트가 대화를 시작할 때 읽는 파일에 넣을 다섯 줄을 출력합니다. 그 줄은 이 명령들을 설명하는 aubergine guide를 실행하라고 에이전트에게 알려 줍니다.

일반 터미널에서 claude를 입력해 시작한 Claude Code는 Aubergine에게 프로그램을 실행 중인 바쁜 셸일 뿐이라 waiting for you가 표시되지 않습니다. 대신 메뉴에서 시작하거나, aubergine hooks print가 출력하는 훅을 여러분의 설정에 직접 추가하세요. 그 훅은 Aubergine 터미널 밖에서는 아무 일도 하지 않습니다.

하지 않는 일

  • 자체 소리가 없습니다. Aubergine은 소리를 내지 않습니다. 알림은 브라우저나 시스템이 알림에 소리를 내도록 되어 있을 때만 소리가 납니다.
  • 열린 페이지가 없으면 아무것도 오지 않습니다. 알림은 브라우저에 열려 있는 Aubergine 페이지에서 옵니다. 서버가 스스로 보내는 알림은 없습니다. 페이지를 모두 닫아도 터미널에는 여전히 waiting for you가 표시되고, 페이지를 열면 숫자가 그대로 있습니다.
  • 휴대폰 푸시는 없습니다. 앱도 푸시 서비스도 없습니다. 휴대폰 브라우저를 페어링해 같은 페이지를 열 수는 있습니다. 휴대폰에서 에이전트 확인하기를 보세요. 실제 휴대폰에서는 시도하지 않았습니다.
  • 확인한 것. 브라우저 테스트는 브라우저 자체 알림의 대역을 상대로 알림을 확인합니다. 실제 알림이 어떻게 보이는지, 그리고 아예 보이는지는 브라우저와 시스템의 알림 설정에 달려 있습니다.

질문

Claude Code가 끝나면 알림을 받으려면 어떻게 하나요?

Aubergine에서 Claude Code를 시작한 뒤 Settings → Notifications에서 Notify me on the desktop when a terminal starts waiting을 켜세요. 그러면 터미널이 여러분을 기다리기 시작하거나 에이전트가 끝났을 때 열린 페이지가 브라우저 알림을 띄웁니다. 알림이 없어도 터미널에는 finished가 표시됩니다.

Claude Code가 입력을 필요로 할 때 소리를 낼 수 있나요?

Aubergine은 소리를 내지 않습니다. 브라우저나 시스템이 소리를 내도록 되어 있으면 알림에 소리가 납니다. Claude Code 설정에 여러분이 직접 넣은 훅은 소리를 낼 수 있습니다. Aubergine은 그 설정에 절대 쓰지 않습니다.

Claude Code 세션을 여러 개 실행할 때 어느 것이 기다리는지 어떻게 보나요?

Aubergine에서는 기다리는 터미널의 테두리 선과 상태가 대기 색으로 표시되고, 목록의 행에 waiting for you가 나오며, For you 옆의 숫자가 기다리는 것의 수를 알려 줍니다. W는 다음 것으로 이동합니다.

브라우저가 닫혀 있어도 알림을 받나요?

아니요. 알림은 열린 Aubergine 페이지에서 옵니다. 상태는 유지되므로, 페이지를 다시 열면 기다리는 터미널이 표시되어 있습니다.

Claude Code 말고 다른 에이전트에서도 동작하나요?

저절로는 아닙니다. 훅은 Claude Code에 맞춰 만들어졌습니다. 다른 에이전트도 자신의 지침에서 그렇게 하라고 하면 aubergine attention waiting, working, done으로 같은 것을 보고할 수 있습니다. aubergine guide --snippet이 그 지침에 넣을 줄을 출력합니다.

관련: Aubergine의 Claude Code · Claude Code 대화 재개하기 · 터미널이 너무 많을 때

Aubergine은 Anthropic과 제휴 관계가 없습니다. Claude와 Claude Code는 Anthropic의 상표입니다.

tmux 3.2 이상과 Node.js 22 이상이 설치된 macOS가 필요합니다. brew install tmux node로 둘 다 설치할 수 있습니다.

npm install -g @meatgarden/aubergine
