자주 묻는 질문

짧은 답변입니다. 더 자세한 내용은 가이드에 있습니다.

Aubergine은 무엇인가요?

터미널 세션을 올려 두는, 브라우저 기반의 로컬 캔버스입니다. 각 터미널은 배치하고 사용할 수 있는 노드이므로, 여러 코딩 에이전트를 한꺼번에 실행하면서 어느 것이 여러분을 기다리는지 볼 수 있습니다.

Aubergine은 무료 오픈 소스인가요?

네. 무료이며 소스는 GitHub에 있습니다.

Aubergine을 실행하려면 무엇이 필요한가요?

tmux 3.2 이상과 Node.js 22 이상이 설치된 macOS입니다. 설치 프로그램에는 pnpm도 필요합니다. Linux에서는 컨테이너 안에서만 실행해 봤습니다. Windows에서는 WSL 2 안에서만 실행되며, 이것도 아직 시도해 보지 않았습니다. Windows 가이드를 보세요.

어떤 코딩 에이전트와도 동작하나요?

Aubergine은 평범한 터미널을 실행하므로 어떤 명령줄 에이전트든 그 안에서 실행할 수 있습니다. 에이전트가 기다리는 것을 알아보는 것처럼 Aubergine이 에이전트를 위해 스스로 해 주는 일은 Claude Code에 맞춰 만들어져 있습니다. Codex를 비롯한 다른 에이전트는 aubergine 명령과 로컬 API로 상태를 보고할 수 있고, 토큰이 허용하는 것만 나열하는 MCP 서버를 쓸 수 있습니다.

Aubergine이 제 터미널이나 코드를 어딘가로 보내나요?

아니요. 모든 것이 여러분의 컴퓨터에서 실행됩니다. 서버는 127.0.0.1에서만 수신합니다.

Aubergine이 AI 모델을 호출하나요?

아니요. 호출하는 것은 여러분의 에이전트입니다. Aubergine은 에이전트의 터미널을 실행하고 상황을 추적할 뿐이며, 어떤 모델의 키도 보관하지 않습니다.

브라우저를 닫으면 터미널은 어떻게 되나요?

계속 실행됩니다. 각 세션은 브라우저와 Aubergine 서버보다 오래 사는 tmux 세션입니다.

어느 에이전트가 저를 기다리는지 어떻게 알 수 있나요?

각 터미널은 작업 중인지, 유휴 상태인지, 기다리는지 표시합니다. 페이지 맨 위 For you 옆의 숫자와 For you 목록에 여러분이 필요한 모든 것이 모입니다.

두 에이전트가 같은 파일을 편집하지 않게 하려면 어떻게 하나요?

각 터미널을 자체 작업 사본에서 시작하세요. 자체 브랜치에 있는 자체 체크아웃입니다. Aubergine은 대신 병합하거나 푸시하지 않습니다.

에이전트에게 따라야 할 단계 목록을 줄 수 있나요?

네. 워크플로는 순서 있는 단계 목록이며, 에이전트가 어디에 있는지 보여 주는 띠가 있습니다. 단계는 여러분이 승인하거나 되돌려 보낼 때까지 기다릴 수 있습니다.

에이전트끼리 대화할 수 있나요?

네, 한도 안에서. 터미널 간 메시지에는 보낸 쪽 이름, 일시 정지, 차단이 있으며, 캔버스마다 기본값은 닫혀 있습니다.

API가 있나요?

네. 범위가 지정된 토큰을 쓰는 로컬 HTTP API, 타입이 있는 클라이언트, 그리고 자격 증명이 쓸 수 있는 도구만 나열하는 MCP 서버가 있습니다.

터미널 하나만 따로 열 수 있나요?

네. 터미널 제목의 Tab ↗를 누르면 별도의 브라우저 탭에서 열립니다. 사본이 아니라 같은 터미널이며, 요청하면 세부 정보와 노트가 옆에 열립니다. 탭을 닫아도 아무것도 끝나지 않습니다.

터미널에 티켓이나 담당자를 함께 기록할 수 있나요?

네. 터미널의 세부 정보에는 레이블과 값의 쌍인 필드가 있습니다. 그 안의 에이전트는 aubergine field set으로 자신의 필드를 설정할 수 있으며, 여러분이 같은 레이블을 설정했다면 여러분의 값이 유지됩니다.

Aubergine이 여러 사람이나 클라우드의 에이전트를 지원할 예정인가요?

둘 다 계획 중이며 어느 것도 아직 만들어지지 않았습니다. 로드맵을 보세요. 현재는 모든 것이 컴퓨터 한 대에서 실행됩니다.

설치 프로그램은 제 컴퓨터에서 무엇을 바꾸나요?

두 가지입니다. 설치 폴더(~/.aubergine)와 aubergine이라는 링크 하나. sudo를 쓰지 않고, 셸 시작 파일을 편집하지 않으며, Node.js, pnpm, tmux를 설치하지 않습니다.

5분이면 시작합니다

tmux 3.2 이상과 Node.js 22 이상이 설치된 macOS가 필요합니다. brew install tmux node로 둘 다 설치할 수 있습니다.

npm install -g @meatgarden/aubergine
