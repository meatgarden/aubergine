Aubergine 앱 자체는 영어로 되어 있습니다. 버튼, 메뉴, 그림은 모두 영어판 그대로입니다.

이 페이지는 영어 원문을 기계 번역한 것입니다. 수정 제안 보내기.

  3. 대기열과 일정

대기열, “For you”, 일정

서로를 채워 주는 두 목록입니다. 대기열에는 에이전트를 위한 일이, For you에는 사람을 기다리는 모든 것이 있습니다. 일정은 정해진 시각에 대기열에 작업을 추가합니다.

대기열

페이지 맨 위의 Runs를 열고(또는 Q를 누르고) Add task를 클릭하세요. 작업에는 제목, 할 일, 그리고 선택적으로 폴더, 워크플로, 누가 가져갈 수 있는지가 있습니다. 기본적으로 에이전트가 한가한 터미널이면 어디든 가져갈 수 있습니다. 터미널 하나를 지정하거나, 그 작업을 위해 새 에이전트 터미널을 시작하게 할 수도 있으며, 폴더가 저장소 안에 있으면 자체 작업 사본에서 시작됩니다.

  • Start next는 지금 누군가 가져갈 수 있는 첫 작업을 시작합니다. 일반 셸에는 작업이 주어지지 않습니다.
  • At most N at once(동시에 최대 N개)는 바꾸지 않으면 3입니다. Hold는 새로 시작하는 것을 멈추고, 실행 중인 것은 건드리지 않습니다.
  • Start by itself는 여러분이 켜기 전까지 꺼져 있습니다. 타이머로 확인하는 것은 없습니다.
  • 순서는 여러분이 정합니다. 작업을 끌거나 화살표 키를 쓰세요.
  • 작업은 자신의 실행을 따라갑니다. 실행이 승인을 기다리는 동안에는 needs you, 끝나면 done, 멈추면 한 문장의 이유와 함께 failed입니다. 아무것도 저절로 다시 시도되지 않습니다.

For you

질문이 있는 터미널, 승인할 실행이나 막힌 실행, 읽을 초안과 설치 항목, 대기열에 제안된 작업, 완료되거나 실패한 작업, 에이전트가 제출한 목록, 그리고 터미널이 사라진 작업 사본. 맨 위 For you 옆의 숫자와 “next waiting”은 같은 목록입니다. 대부분은 적어 넣는 것이 아니라 모이는 것입니다. 해당 일이 끝나면 항목도 사라집니다.

지금 하면 안 되는 일을 발견한 에이전트는 작업을 제안할 수 있고, 사람이 필요한 에이전트는 여러분에게 요청할 수 있습니다.

aubergine task add "Add a test for the retry" --details "it should fail without the fix"
aubergine ask "the staging key expires this week: rotate it, or say who can"

둘 다 여러분의 목록에 올라옵니다. 제안은 여러분이 수락하기 전까지 아무것도 시작하지 않습니다.

일정

일정은 하루 중 시각, 요일, 실행할 것, 실행할 곳으로 이루어집니다. 시각이 되면 대기열에 작업 하나를 추가하고, 대기열이 그것을 시작합니다. Runs 페이지의 Schedules, 또는 aubergine schedule에서 다룹니다. 시각은 이 컴퓨터의 시계를 따르며, 표현식은 없고 하루에 한 번보다 자주 실행되는 것도 없습니다.

aubergine schedule add "My morning list" --at 08:30 --days weekdays \
  --element "Morning list" --new Main
aubergine schedule run "My morning list"

aubergine schedule run은 일정을 지금 시험해 봅니다.

계획대로 되지 않을 때

  • 컴퓨터가 깨어 있고 Aubergine이 실행 중이어야 합니다. 잠든 동안 지나간 시각은, 지난 지 6시간이 안 되었다면 돌아왔을 때 늦었다는 표시와 함께 한 번 실행됩니다. 그렇지 않으면 missed(놓침)로 표시됩니다.
  • 일정의 이전 작업이 아직 기다리거나 진행 중이면 다른 작업을 추가하지 않고, 건너뛰었다고 알립니다.
  • 지정한 대상(터미널, 단계, 캔버스)이 사라졌다면 실행되지 않으며, 여러분의 목록에 항목 하나로 그렇게 알립니다.

규칙

Rules에서 “작업이 완료되거나 실패하거나 내가 필요할 때, 또는 일정이 실행되거나 놓쳤을 때, 나에게 알리거나 저장된 단계를 실행하라”라고 정할 수 있습니다. 규칙은 여러분만 쓸 수 있습니다. 어떤 프로그램이나 에이전트도 규칙을 추가하거나 바꿀 수 없으며, 규칙이 스스로를 발동시킬 수도 없습니다.

Aubergine은 모델을 호출하지 않으며 어떤 앱의 자격 증명도 보관하지 않습니다. 작업이나 일정은 실행을 시작할 뿐이며, 일은 그것을 가져간 에이전트가 자신의 도구로 합니다.

관련: 작업 사본 · 여러 코딩 에이전트를 한꺼번에 실행하기

5분이면 시작합니다

tmux 3.2 이상과 Node.js 22 이상이 설치된 macOS가 필요합니다. brew install tmux node로 둘 다 설치할 수 있습니다.

npm install -g @meatgarden/aubergine
