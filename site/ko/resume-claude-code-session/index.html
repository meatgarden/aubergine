재시작 후 Claude Code 대화 재개하기

컴퓨터가 재시작되었거나 터미널을 닫아서 Claude Code의 대화가 사라진 것처럼 보입니다. 대화는 Claude Code가 가지고 있습니다. Aubergine은 각 터미널이 어느 대화에 있었는지 기억하고, 버튼 하나로 되돌려 줍니다.

흔히 쓰는 방법

대화가 있던 폴더의 터미널에서 claude --continue는 그곳의 가장 최근 대화를 이어 가고, claude --resume은 목록에서 하나를 고르게 하거나 대화 ID를 받습니다. 문제는 폴더와 선택입니다. 한 폴더에 에이전트가 여러 개 있으면 가장 최근 대화가 늘 원하던 대화는 아닙니다.

Aubergine이 하는 일

터미널이 자신의 대화를 기억합니다. Claude Code를 Aubergine에서 시작했다면(New terminal ▾ → Claude Code, 또는 C) 그 훅이 어느 대화에 있는지 Aubergine에 알리고, Aubergine은 그 ID를 터미널과 함께 보관합니다.

셸이 프롬프트로 돌아오면 터미널 제목 표시줄에 Resume agent(에이전트 재개)가 나타납니다. 에이전트를 종료했거나, 컴퓨터가 재시작되어 터미널이 마지막 폴더의 새 셸로 돌아온 경우입니다. --resume과 그 ID를 붙여, 설정의 실행 명령(agents.claudeCommand, 기본값 claude)으로 Claude Code를 다시 시작합니다.

워크플로 실행에 속한 터미널이라면 Resume agent가 그 실행에 대해서도 다시 알려 주므로, 에이전트는 실행이 멈춰 있는 단계부터 이어 갑니다.

Past conversations…(지난 대화)는 팔레트(⌘K)에, “Past conversations in this folder…”는 터미널 세부 정보에 있으며, 한 폴더의 이전 Claude Code 대화를 나열합니다. 이름이나 처음 한 말, 마지막으로 활동한 때, 몇 번 주고받았는지, 지금 캔버스의 터미널이 그 대화에 있는지. Read는 읽기 전용으로 보여 줍니다. Open on the canvas는 그 폴더에서 그 대화를 재개한 새 터미널을 시작하고, Open a copy는 대화의 갈래를 시작하며 원본은 그대로 둡니다. 이미 그 대화에 있는 터미널이 있으면 먼저 묻습니다.

검색. 팔레트에 @ 다음에 단어 몇 개를 입력하면 캔버스에 있는 터미널들의 폴더에서 지난 대화를 검색합니다. 요청할 때 한도 안에서 기록을 읽고, 중간에 잘렸으면 그렇다고 알려 줍니다. 명령줄에서는 aubergine history가 목록을 보여 주고 aubergine history open <id>가 하나를 엽니다.

어디까지 했는지. 터미널의 노트에는 요약과 로그가 있고, 여러분이 보내는 프롬프트는 하나하나 로그에 추가됩니다. 세부 정보의 Ask its agent for a recap(에이전트에게 요약 요청)을 누르면 에이전트가 aubergine recap --write로 지금 상황을 쓰고, 그 요약은 터미널과 함께 남습니다. 30분 넘게 자리를 비웠다가 돌아오면 While you were away(자리를 비운 동안)가 그사이 바뀐 것을 나열합니다.

Aubergine 밖의 터미널에 있는 대화

터미널 앱의 탭에서 에이전트를 종료한 다음, 같은 폴더에서 aubergine here --claude를 실행하세요. 캔버스의 새 터미널이 --continue로 Claude Code를 시작하고, 이제 상태가 표시됩니다. aubergine move는 Claude Code 탭을 나열하고 각 대화의 사본을 캔버스에 시작합니다. --stop을 붙이면 여러분이 확인한 뒤 유휴 상태의 에이전트에게 먼저 종료를 요청합니다.

하지 않는 일

  • Claude Code 자체의 기록을 읽으며, 그 형식은 Aubergine의 것이 아닙니다. Claude Code는 그 파일 형식을 내부용이라고 하며, 버전마다 바뀝니다. 재개는 Claude Code 자체의 --resume에 ID를 넘겨 합니다. 이름, 횟수, 대화 내용은 Aubergine이 파일을 읽은 결과이므로, Claude Code를 업데이트한 뒤에는 빠지거나 줄어들 수 있습니다. 읽을 수 없는 기록은 빈 대화로 보여 주지 않고 읽을 수 없다고 알립니다.
  • 아무것도 복사하거나 보관하지 않습니다. 목록, 대화 내용, 검색은 요청할 때 읽고 닫으면 버립니다. Aubergine은 대화를 바꾸거나, 이름을 바꾸거나, 지우지 않으며, 어떤 에이전트나 토큰도 Aubergine을 통해 대화를 읽을 수 없습니다.
  • 하던 작업을 다시 하지 않습니다. 에이전트가 멈출 때 하던 일은 여러분이 요청할 때까지 다시 시작되지 않습니다.
  • 다른 에이전트에는 Resume agent가 없습니다. Aubergine은 다른 에이전트의 대화를 모르고, 지난 대화도 나열하지 않습니다. 같은 터미널에서 그 에이전트 자체의 재개 방법으로 다시 시작하고, 노트를 읽어 어디까지 했는지 알려 주세요.
  • 직접 입력해 시작한 claude는 기억되지 않습니다. 단, aubergine hooks print가 출력하는 훅을 여러분의 Claude Code 설정에 추가했다면 기억됩니다.
  • 확인한 것. 대화 기록 읽기는 지어낸 기록으로 테스트합니다. 모든 버전의 Claude Code로 확인하지는 않았습니다.

질문

터미널을 닫은 뒤 Claude Code 세션을 재개하려면 어떻게 하나요?

같은 폴더에서 claude --continue는 가장 최근 대화를 이어 가고, claude --resume은 고르게 해 줍니다. Aubergine에서는 브라우저를 닫아도 아무것도 끝나지 않으며, 에이전트를 종료한 터미널은 제목 표시줄에 Resume agent를 보여 줍니다.

재부팅 후 Claude Code 대화를 재개하려면 어떻게 하나요?

재시작 후 Aubergine의 각 터미널은 마지막 폴더의 새 셸로 돌아옵니다. Claude Code를 Aubergine에서 시작했다면, 제목 표시줄의 Resume agent가 그 터미널이 있던 대화에서 Claude Code를 다시 시작합니다.

예전 Claude Code 대화를 어떻게 찾나요?

팔레트의 Past conversations…가 한 폴더의 대화를 읽기 전용 대화 내용과 함께 나열하고, 팔레트에 @와 단어 몇 개를 입력하면 검색됩니다. Claude Code가 아직 보관하고 있는 것만 나열됩니다.

claude --continue와 claude --resume은 무엇이 다른가요?

--continue는 그 폴더의 가장 최근 대화를 이어 가고, --resume은 여러분이 고른 대화나 ID를 받습니다. Resume agent는 터미널이 기억한 ID로 --resume을 쓰므로, 어느 대화가 가장 최근이었는지와 상관없습니다.

두 터미널이 같은 Claude Code 대화를 이어 갈 수 있나요?

Aubergine은 묻지 않고 한 대화를 두 번 열지 않습니다. 한 대화에 에이전트가 둘이면 서로의 메시지를 잃습니다. 이미 그 대화에 있는 터미널, 또는 대화를 갈래로 나누는 사본을 선택지로 제시합니다.
