WSL로 Windows에 Aubergine 설치하기

Aubergine은 Windows 자체에서는 실행되지 않습니다. Windows가 제공하는 Linux인 WSL 2 안에서 실행되고, Windows 브라우저에서 사용합니다.

시도한 것. Linux 단계는 2026년 11월 25일에 WSL이 아닌 컨테이너 안의 Ubuntu 24.04.5(x86_64)에서, npm의 Aubergine 0.2.2로 실행했습니다. 터미널 라이브러리를 컴파일하고, 시작하고, 브라우저를 로그인시키고, 터미널과 데모를 실행했습니다. Node.js 22가 이미 설치되어 있어서 nvm으로 Node.js를 설치하는 단계는 거기서 실행하지 않았습니다. 이 페이지의 어떤 것도 아직 Windows에서 실행하지 않았습니다. 시도해 보셨다면 어땠는지 알려 주세요.

필요한 것

Windows 11, 또는 Windows 10 버전 2004(빌드 19041) 이상. 여기서는 명령 하나로 WSL 2를 설치할 수 있습니다. 자세한 내용은 Microsoft의 WSL 설치 페이지에 있습니다.

설치하고 시작하기

  1. WSL을 설치합니다. PowerShell을 관리자 권한으로 열고 이것을 실행한 뒤, 끝나면 Windows를 다시 시작합니다. Ubuntu가 포함된 WSL 2가 설치됩니다.

    wsl --install

    다시 시작한 뒤 시작 메뉴에서 Ubuntu를 열고 사용자 이름과 비밀번호를 정합니다. 아래 명령은 모두 그곳, Ubuntu 안에서 입력합니다.

  2. Aubergine에 필요한 것을 설치합니다: tmux, zsh, Git, 그리고 터미널 라이브러리를 컴파일하는 도구입니다. 이 라이브러리는 Linux용으로 미리 만들어진 것이 없습니다.

    sudo apt update

    sudo apt install -y tmux zsh git build-essential python3

    Node.js 22를 설치합니다. Ubuntu 자체 패키지는 버전 18로, 너무 오래되었습니다. 잘 알려진 방법 하나는 nvm입니다. nvm을 설치하고, 새 Ubuntu 창을 연 다음 Node.js 22를 설치합니다.

    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash

    nvm install 22

    이제 node -v가 v22 이상을 보여 줘야 합니다.

  3. npm에서 Aubergine을 설치합니다. 설치하면서 터미널 라이브러리를 컴파일합니다. 시도했을 때 설치 전체에 13초가 걸렸습니다.

    npm install -g @meatgarden/aubergine

  4. 시작하고, 그 창은 열어 둡니다.

    aubergine start

    브라우저를 로그인시킵니다. 두 번째 Ubuntu 창에서 로그인 주소를 출력한 뒤 Windows 브라우저에서 엽니다. 그 브라우저가 로그인되므로 비밀번호처럼 다루세요.

    aubergine open --print

    그다음부터는 그 브라우저에서 http://127.0.0.1:4600만으로 열립니다. 빈 캔버스에서는 Show me around로 둘러보기가 시작됩니다.

알아 두면 좋은 것

  • 프로젝트는 Ubuntu 안에 두세요. Ubuntu의 홈 폴더에 두고 /mnt/c 아래에는 두지 마세요. 그곳의 Windows 파일은 더 느린 다리를 거쳐 접근합니다.
  • 에이전트는 Ubuntu 안에 설치하세요. Claude Code든 Codex든 다른 것이든, 다른 Linux에서와 같습니다. Windows에 설치한 에이전트는 Aubergine의 터미널에 없습니다.
  • 터미널은 WSL이 실행되는 동안 살아 있습니다. 브라우저를 닫아도 아무것도 끝나지 않고, aubergine start 창에서 Ctrl+C를 누르면 서버만 멈춥니다. Windows가 다시 시작되거나 wsl --shutdown을 실행해 WSL이 멈추면 터미널이 끝나고, 다음 aubergine start가 마지막 폴더에서 새 셸을 엽니다. Mac을 다시 시작한 뒤와 같습니다.
  • bash와 zsh. Ubuntu의 셸은 bash이고, 터미널은 그 안에서 잘 작동합니다. 터미널의 명령 상태(실행 중, 실패한 명령의 종료 코드)는 zsh에서만 나옵니다. 시도했을 때 zsh 터미널은 실패한 명령 뒤에 exit 3을 보여 줬습니다. 이를 쓰려면 Ubuntu에서 zsh를 셸로 정하세요.
  • 없는 것: 로그인 시 시작은 macOS에서만 작동하고(aubergine service install이 그렇게 알려 줍니다), Open on desktop에는 Windows 터미널 앱을 위한 설정이 없습니다. 시도했을 때 aubergine open은 열 브라우저를 찾지 못했습니다. aubergine open --print는 언제나 작동합니다.
  • Windows의 단축키는 브라우저 문서를 보고 고른 것이며 측정하지 않았습니다. docs/keys.md를 보세요. 팔레트는 언제나 작동합니다.

문제가 생기면

먼저 Ubuntu에서 aubergine doctor를 실행하세요. Node.js, tmux, Git과 서버를 확인합니다.

보이는 것해야 할 일
Aubergine 설치가 node-pty를 컴파일하다 실패함빌드 도구가 없습니다. 2단계의 apt 줄을 실행한 뒤 Aubergine을 다시 설치하세요.
tmux가 없거나 너무 오래되었다는 페이지Ubuntu 24.04의 tmux는 3.4로 충분히 새롭습니다. sudo apt install -y tmux를 실행하고 서버를 다시 시작하세요.
node -v가 v22보다 오래된 버전을 보여 줌2단계처럼 Node.js 22를 설치하고, 새 Ubuntu 창을 연 뒤 Aubergine을 다시 설치하세요.
Windows 브라우저에서 주소가 열리지 않음Ubuntu에서 aubergine start가 아직 실행 중인지 확인하세요. 그다음 Microsoft의 WSL 네트워킹 페이지를 보세요. 이것은 Aubergine으로 시도해 보지 않았습니다.
