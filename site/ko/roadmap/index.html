Aubergine 앱 자체는 영어로 되어 있습니다. 버튼, 메뉴, 그림은 모두 영어판 그대로입니다.

이 페이지는 영어 원문을 기계 번역한 것입니다. 수정 제안 보내기.

계획 중, 아직 만들어지지 않음

로드맵

이 중 어느 것도 아직 존재하지 않습니다. 우리가 가고 싶은 방향이며, 순서는 바뀔 수 있습니다. 지금 만들어진 것은 가이드를 보세요.

팀과 연결

함께 일하는 사람들, 그리고 이미 쓰는 도구에서 닿는 에이전트.

  • 멀티플레이어

    다른 사람들과 그들의 에이전트와 캔버스를 공유합니다. 누가 어디서 일하는지 보고, 기다리는 에이전트를 팀원에게 넘기고, 함께 답합니다.

  • 채팅 인터페이스

    팀 채팅 앱에서 에이전트에게 요청하고 질문에 답합니다. 브라우저에서와 같은 신원과 설정으로.

  • 티켓과 풀 리퀘스트

    이슈를 대기열의 작업으로 바꾸고, 작업 사본에서 풀 리퀘스트를 열고, 결과를 티켓에 다시 보고합니다.

  • 감시, 웹훅, 분류

    무언가 일어나면 작업을 시작합니다. 실패한 CI 작업, 알림, 감시 중인 변경, 다른 서비스의 호출. 무엇이 작업이 될지는 규칙이 정합니다.

  • 공유 스킬과 마켓플레이스

    권한 부여로 에이전트의 스킬을 공유하고, 승인을 거쳐 팀 전체로 넓히고, Git에서 가져오고, 공개 카탈로그에서 검토된 항목을 찾습니다.

  • 사람과 방을 위한 기억

    에이전트가 배운 것을 사람마다, 공유된 방마다 서로 분리해 보관합니다.

또한: 모델, 공유, 엄격도에 대한 관리자 통제 · 자체 호스팅 팀 서버 · 팀을 위한 로그인(SSO와 MFA) · 사람, 토큰, 에이전트별 사용량 한도 · 터미널을 공유하지 않고 공유하는 읽기 전용 보고서 · “For you” 목록의 휴대폰 화면 · 회사 도구로 가는 검토된 커넥터 · 더 많은 채팅 앱 · 정해진 사람들에게 게시하는 작은 내부 웹 앱.

클라우드

노트북이 깨어 있지 않아도 되는 에이전트.

  • 클라우드의 샌드박스 에이전트

    격리된 클라우드 샌드박스에서 에이전트를 실행하고, 로컬 에이전트와 같은 캔버스에서 지켜봅니다. 샌드박스는 유휴 시 잠들고, 필요할 때 깨어나며, 실행 사이에 저장소를 유지합니다.

  • 에이전트 풀

    작업마다 터미널을 지정하는 대신, 일을 설명하면 에이전트 풀이 가져갑니다.

  • 미리 만든 환경

    의존성, 도구, 스킬, 파일, 변수를 한 번 저장해 두고, 새 터미널이나 클라우드 에이전트를 그것으로 시작합니다.

  • 길고 여러 단계로 된 작업

    몇 시간이나 며칠에 걸쳐 단계별로 실행되는 작업. 단계마다 확인이 있고, 진행 상황은 재시작을 견딥니다.

  • 명령 하나로 클라우드 배포

    팀이 공유하는 Aubergine을 명령 하나로 여러분의 클라우드 계정에 올립니다.

  • 볼 수 있는 작업

    클라우드 에이전트가 만든 것의 스크린샷이나 짧은 녹화를 여러분의 “For you” 목록으로 돌려줍니다.

또한: 다른 기기의 에이전트를 위한 HTTP 기반 MCP · 테스트된 Linux 지원 · zsh 외의 셸 통합.

통제

에이전트가 얼마나 할 수 있는지, 그리고 무엇을 했는지의 기록.

  • 승인 모드

    에이전트가 혼자 얼마나 할 수 있는지 고릅니다. 모든 행동을 승인, 위험한 것만 승인, 또는 승인 없음.

  • 명령 정책과 검사

    승인이 필요하거나 항상 거부되는 명령에 대한 규칙, 그리고 에이전트가 읽기 전에 외부 내용을 선택적으로 검사하는 기능.

  • 저장소별 위험 수준

    중요한 곳에서는 더 엄격하게, 그렇지 않은 곳에서는 더 느슨하게.

  • 전체 감사 기록

    오늘 기록되는 토큰 호출을 넘어, 프로젝트별로 누가 또는 무엇이 무엇을 했는지의 기록.

  • 에이전트의 작업 되돌리기

    작업 사본을 작업 이전으로 되돌리거나, 그 브랜치를 한 번에 버립니다.

  • 관리자 통제

    어떤 모델을 쓸 수 있는지, 공유가 어떻게 동작하는지에 대한 팀 전체 설정.

또한: 터미널, 작업, 일정별 모델 선택.

품질

작업을 완료라고 부르기 전에 일어나는 확인.

  • 품질 관문

    리뷰, 테스트, 보안 검사가 통과를 보고하기 전에는 실행이 끝날 수 없습니다.

  • 풀 리퀘스트 리뷰

    에이전트가 풀 리퀘스트를 리뷰하고 여러분의 “For you” 목록에 보고합니다.

  • 브라우저 기반 테스트

    에이전트가 브라우저를 조작해 변경을 테스트하고 결과를 돌려줍니다.

  • 만들기 전에 계획

    에이전트가 계획을 제안하고, 파일을 건드리기 전에 여러분의 승인을 기다립니다.

  • 작업 레시피

    테스트 생성, 리뷰, 의존성과 비밀 검사, 문서 최신 유지를 위한 미리 만든 워크플로.

  • 성과 지표

    프로젝트별로 작업에서 완료까지의 시간, 에이전트가 여러분을 기다린 빈도, 누가 시작했는지에 따른 사용량.

또한: 에이전트가 조사하고 사후 분석 초안을 쓰는 장애 보고서.

어디서나

Aubergine에 닿고 그 위에 무언가를 만드는 더 많은 방법.

  • 공개 SDK

    설치 가능한 패키지로서의 타입 있는 클라이언트, 그다음 Python 같은 다른 언어용 클라이언트.

  • 에디터 확장

    VS Code와 비슷한 에디터 안에서, 에디터를 떠나지 않고 터미널과 “For you” 목록을 보여 줍니다.

  • 데스크톱 앱

    브라우저 탭 대신, 메뉴 막대 아이콘이 있는 패키지 앱.

  • Windows 지원

    Windows 자체에서 Aubergine을 실행합니다. 지금은 Windows 가이드에 적힌 대로 WSL 2 안에서만 실행되며, Windows에서 이를 시도해 본 사람은 아직 없습니다.

내 방식대로

오늘의 테마, 색, 키, 템플릿, 내 스타일시트를 넘어, 페이지를 더 여러분의 방식대로.

  • 플러그인

    내 코드를 완전한 제어 아래 페이지에 불러옵니다. 이름 붙은 자리를 통해서도, 그 너머로도. 다른 사람의 코드를 위한 격리 모드는 나중에 생길 수 있습니다.

계획된 작업은 방향이지 약속이 아닙니다. 출시된 것은 저장소에서 볼 수 있습니다.

5분이면 시작합니다

tmux 3.2 이상과 Node.js 22 이상이 설치된 macOS가 필요합니다. brew install tmux node로 둘 다 설치할 수 있습니다.

npm install -g @meatgarden/aubergine
