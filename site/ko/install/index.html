Aubergine 앱 자체는 영어로 되어 있습니다. 버튼, 메뉴, 그림은 모두 영어판 그대로입니다.

이 페이지는 영어 원문을 기계 번역한 것입니다. 수정 제안 보내기.

  1. Aubergine
  2. 설치

Aubergine 설치 방법

명령 하나로 설치하고, 하나로 시작합니다. 둘러보기를 포함해 5분 정도 걸립니다.

요구 사항

  • macOS. Linux에서는 컨테이너 안에서만 실행해 봤습니다. Ubuntu 24.04에서 npm 패키지를, Debian에서 컨테이너 이미지를 실행했습니다. Windows 자체는 지원하지 않습니다. Aubergine은 WSL 2 안에서 실행할 수 있지만 아직 시도해 보지 않았습니다. WSL로 Windows에 설치하기를 보세요.
  • tmux 3.2 이상과 Node.js 22 이상. 설치 프로그램에는 pnpm도 필요합니다.

Homebrew가 있으면 한 줄로 둘 다 설치합니다(설치 프로그램을 쓰려면 pnpm을 추가하세요).

brew install tmux node

설치하고 시작하기

  1. npm에서 Aubergine 설치(tmux와 Node.js만 필요):

    npm install -g @meatgarden/aubergine

    또는 pnpm도 필요하고 소스에서 빌드하는 설치 프로그램으로:

    curl -fsSL https://raw.githubusercontent.com/thirstyeggplant/aubergine/main/install.sh | sh

  2. 시작하고, 로그인된 상태로 브라우저를 엽니다.

    aubergine start --open

  3. 둘러보기. 빈 캔버스 가운데의 Show me around를 클릭하세요. 대역 에이전트 몇 개가 있는 “Demo”라는 캔버스를 만들고 여덟 개의 짧은 단계로 안내합니다. 데모의 어떤 것도 진짜가 아니며, aubergine demo --remove로 없앨 수 있습니다.

스크립트를 먼저 읽어 보고 싶으신가요? 내려받아 읽은 뒤 sh install.sh --dry-run을 실행하면 아무것도 바꾸지 않고 무엇을 할지 볼 수 있습니다.

설치 프로그램이 바꾸는 것

두 가지뿐입니다. 설치 폴더(~/.aubergine 또는 AUBERGINE_HOME)와 aubergine이라는 링크 하나이며, 이 링크는 쓰기 권한이 있는 PATH상의 폴더에 놓입니다. 먼저 모든 것을 확인하고, 빠진 것이 있으면 아무것도 바꾸지 않습니다.

하지 않는 일: sudo 사용, 셸 시작 파일 편집, Node.js·pnpm·tmux 설치, 데이터 폴더 건드리기.

문제가 생기면

먼저 aubergine doctor를 실행하세요. 흔한 원인을 확인해 줍니다.

보이는 것해야 할 일
“This browser is not signed in yet”그 브라우저에서 로그인 링크를 한 번 여세요. aubergine open --print가 링크를 다시 출력합니다.
tmux가 없거나 너무 오래되었다는 페이지tmux를 설치하거나 업그레이드한 뒤(brew install tmux) 서버를 다시 시작하세요.
포트가 사용 중이라 서버가 시작되지 않음다른 포트를 사용하세요: AUBERGINE_PORT=4700 aubergine start.
aubergine: command not found링크가 PATH에 없습니다. 설치 프로그램이 셸 시작 파일에 추가할 한 줄을 출력합니다.
터미널에 상태 배지가 표시되지 않음상태 표시에는 zsh가 필요하며, 업데이트 전에 만든 세션은 이전 셸을 그대로 씁니다. 그 세션을 치워 두고 새로 시작하세요.

중지, 업데이트, 제거

  • Ctrl+C로 서버를 중지합니다. 터미널은 계속 실행되며, 서버를 다시 시작하고 페이지를 새로 고치면 돌아옵니다.
  • 업데이트: npm으로 설치했다면 npm install -g @meatgarden/aubergine@latest, 설치 프로그램을 썼다면 aubergine update를 실행합니다. 그다음 서버를 다시 시작하세요.
  • 제거: aubergine uninstall을 실행합니다. 링크를 지우고, 확인을 받은 뒤 설치 프로그램이 만든 사본을 지웁니다. 데이터를 지우거나 터미널을 끝내는 일은 결코 없습니다.
  • 로그인 시 시작: aubergine service install을 실행해 두면, 브라우저만 열면 됩니다.

다음

여러 코딩 에이전트를 한꺼번에 실행하는 방법이나 가이드를 읽어 보세요. 전체 참조 문서는 README에 있습니다.

npm install -g @meatgarden/aubergine
