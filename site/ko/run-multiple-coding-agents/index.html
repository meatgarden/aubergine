여러 코딩 에이전트를 한꺼번에 실행하는 방법

에이전트 두 개는 쉽습니다. 다섯 개면 혼돈입니다. 어느 것이 막혔는지, 어느 것이 여러분을 기다리는지, 어느 것이 그 파일을 바꿨는지? Aubergine은 바로 그 순간을 위해 만들어졌습니다. 여러분의 컴퓨터에서 실행됩니다.

1. 각 에이전트에게 하나의 캔버스 위 터미널을 주세요

터미널 목록 맨 위의 New terminal을 클릭하고(또는 N을 누르고) 그 안에서 에이전트를 시작하세요. 터미널은 제목 표시줄로 끌어 옮기고, 크기를 바꾸고, 프레임으로 묶을 수 있습니다. 관련된 작업은 하나의 캔버스에, 별개의 작업은 별도의 캔버스(탭)나 프로젝트에 둡니다. 프로젝트마다 자체 터미널, 대기열, 일정이 있습니다.

모든 터미널은 tmux 세션 안의 실제 셸입니다. 브라우저를 닫거나 Aubergine을 멈춰도 에이전트는 계속 실행됩니다.

2. 어느 에이전트가 여러분을 필요로 하는지 보세요

각 터미널은 작업 중인지, 유휴 상태인지, 여러분을 기다리는지 표시합니다. 이 상태는 화면을 읽어서가 아니라 셸의 훅과 에이전트 자신에게서 옵니다. 맨 위 For you 옆의 숫자와 W 키가 다음으로 기다리는 터미널로 바로 데려갑니다.

For you라는 목록 하나에 사람을 기다리는 모든 것이 모입니다. 질문, 승인할 실행, 확인할 완료된 작업, 이유가 적힌 실패한 작업.

3. 대기열에서 일을 나눠 주세요

작업을 한 번 적어 대기열에 넣으세요. 여러분이 지시하면 한가한 에이전트가 가져가며, 동시에 실행되는 수에는 한도가 있습니다. 반복되는 일에는 일정을 정하세요. 에이전트는 작업을 제안하고 질문할 수 있지만, 여러분이 수락하기 전에는 아무것도 시작되지 않습니다.

4. 각 에이전트의 변경을 떼어 놓으세요

한 폴더의 두 에이전트는 같은 파일을 편집합니다. 각각을 자체 작업 사본에서 시작하세요. 자체 브랜치에 있는 별도의 체크아웃이므로 각 에이전트의 작업을 따로 읽을 수 있습니다. Aubergine은 대신 병합하거나 푸시하거나 리베이스하지 않습니다.

5. 에이전트에게 단계를 주고, 관문에서 결정하세요

워크플로는 에이전트가 따르는 순서 있는 단계 목록이며, 현재 위치를 보여 주는 띠가 있습니다. 단계는 여러분이 승인하거나 되돌려 보낼 때까지 기다릴 수 있습니다. 진행 중인 모든 실행은 하나의 보드에 나타납니다.

하지 않는 일

  • 모델을 호출하거나 대신 골라 주지 않습니다. 에이전트는 여러분의 것입니다.
  • 여러분이 할 수 있는 일을 에이전트가 하지 못하게 막지 않습니다. 에이전트는 여러분으로서 실행됩니다. 무엇이 보호되고 무엇이 보호되지 않는지는 보안을 참고하세요.
  • 현재는 컴퓨터 한 대에서 실행됩니다. 다른 사람과 캔버스를 공유하는 것과 클라우드에서 에이전트를 실행하는 것은 로드맵에 있으며, 아직 만들어지지 않았습니다.

5분이면 시작합니다

tmux 3.2 이상과 Node.js 22 이상이 설치된 macOS가 필요합니다. brew install tmux node로 둘 다 설치할 수 있습니다.

npm install -g @meatgarden/aubergine
