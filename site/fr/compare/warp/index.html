Aubergine vs Warp

Warp est une app de terminal complète, avec un agent à lui, des offres et un cloud, qui fait aussi tourner d’autres agents en ligne de commande dans des onglets et des volets. Aubergine est plus étroite : elle n’appelle aucun modèle et ne remplace aucune app de terminal. Elle fait tourner les agents que vous utilisez déjà côte à côte dans une page du navigateur, et les garde en marche.

D’où cela vient. Ce qui est dit ici de Warp vient de sa documentation et de sa page de tarifs, lues le 26 novembre 2026, et porte seulement sur le fait de faire tourner plusieurs agents de code ; Warp fait bien d’autres choses. Nous n’avons pas fait tourner Warp pour cela. Si quelque chose est faux ou dépassé, dites-le-nous.

Lequel choisir

Choisissez Warp si vous voulez une seule app de terminal pour tout, aussi sous Windows et Linux, avec son propre agent intégré et des agents dans le cloud que vous pouvez planifier.

Choisissez Aubergine si vous avez déjà un terminal et des agents qui vous plaisent, et ne voulez que ce qui manque entre eux : tous en vue, maintenus en marche, sans compte et sans modèle à elle.

Ce qu’est Warp

D’après sa propre description, un environnement de développement agentique : un terminal de bureau pour macOS, Windows et Linux dont le client est open source sous AGPL-3.0. Il a son propre Warp Agent, qui appelle des modèles par Warp ou avec vos propres clés, et il fait tourner d’autres agents en ligne de commande comme Claude Code, Codex et Gemini CLI dans des onglets et des volets, avec un panneau de tous les agents actifs, des notifications, un panneau de revue de code, et des agents dans le cloud qui tournent selon une planification.

Ce qui les distingue

Un modèle à lui, ou aucun. Warp a son propre agent, avec des offres qui en paient l’usage et la possibilité d’apporter vos propres clés. Aubergine n’appelle aucun modèle et ne détient aucune clé : les agents dans ses terminaux sont ceux que vous avez installés et auxquels vous vous êtes connecté vous-même.

Ce que la fermeture arrête. Warp documente qu’il restaure les fenêtres, les onglets, les volets et la sortie récente ; nous n’avons rien trouvé disant qu’un programme en cours est gardé. Dans Aubergine, chaque terminal est une session tmux, donc un agent continue quand le navigateur ou Aubergine elle-même s’arrête.

D’où vos agents sont accessibles. Warp publie une session en cours dans son cloud pour que vous la pilotiez depuis un téléphone ou un navigateur. Aubergine n’a pas de cloud : un autre appareil est un navigateur que vous appairez avec un code, par un proxy que vous faites tourner sur votre propre machine, essayé une fois sur un Mac.

Ce que Warp a et qu’Aubergine n’a pas

  • Windows et Linux comme plateformes documentées, en app de bureau. Aubergine est faite pour macOS.
  • Un agent à lui, et des agents dans le cloud qui démarrent selon une planification ou depuis un autre service comme Slack, Linear ou GitHub. Aubergine ne lance rien depuis l’extérieur et n’accède à aucun réseau pour une planification.
  • Tout ce qu’est par ailleurs une app de terminal : son éditeur de commandes, des blocs de sortie, et des notifications pour plus d’un agent. Aubergine voit qu’un agent attend grâce à des hooks faits pour Claude Code.

Questions

Aubergine est-elle une alternative à Warp ?

Seulement pour une chose que fait Warp : faire tourner plusieurs agents de code en ligne de commande et voir lequel a besoin de vous. Aubergine n’est pas une app de terminal et n’a pas d’agent à elle. Vous pouvez garder Warp, ou n’importe quel terminal, et utiliser Aubergine pour les agents.

Ai-je besoin d’un compte ou d’une offre payante ?

La documentation de Warp dit que la connexion est facultative pour le terminal, et sa page de tarifs liste une offre gratuite et des offres payantes. Aubergine n’a ni compte ni offres.

Warp est-il open source ?

Sa documentation dit que le client de Warp est open source sous AGPL-3.0. Aubergine est sous licence MIT.

Puis-je utiliser Warp et Aubergine ensemble ?

Oui, comme avec n’importe quelle app de terminal. Les terminaux d’Aubergine sont des sessions tmux, et aubergine attach <name> en affiche un dans une fenêtre de l’app de terminal depuis laquelle vous la lancez. Nous n’avons pas essayé cela dans Warp.

Aubergine n’est pas affiliée à Warp. Warp est une marque de Denver Technologies, Inc., qui exerce sous le nom de Warp.

Opérationnel en cinq minutes

Il vous faut macOS avec tmux 3.2 ou plus récent et Node.js 22 ou plus récent. brew install tmux node installe les deux.

npm install -g @meatgarden/aubergine
