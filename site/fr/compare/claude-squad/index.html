Aubergine vs Claude Squad

Les deux reposent sur la même base : chaque agent dans une session tmux, chacun dans son propre worktree Git, tous deux gratuits et open source. Claude Squad est un programme dans votre terminal. Aubergine est une page dans votre navigateur où les terminaux se tiennent côte à côte.

D’où cela vient. Ce qui est dit ici de Claude Squad vient de son dépôt et son README, lus le 26 novembre 2026. Nous n’avons pas fait tourner Claude Squad. Si quelque chose est faux ou dépassé, dites-le-nous.

Lequel choisir

Choisissez Claude Squad si vous vivez dans un terminal et y voulez un seul petit programme qui lance des agents dans des worktrees et pousse leurs branches, et rien de plus.

Choisissez Aubergine si vous voulez voir plusieurs agents travailler à la fois, savoir lequel vous attend, et avoir autour d’eux une file d’attente, des planifications et une API.

Ce qu’est Claude Squad

D’après sa propre description, une app de terminal qui gère plusieurs agents locaux, Claude Code, Codex, Gemini et d’autres, dans des espaces de travail séparés. Vous le lancez avec cs : une liste de sessions avec un aperçu et un onglet de diff, dans une seule fenêtre de terminal. Chaque session est une session tmux dans un worktree Git sur sa propre branche. Il demande tmux et gh, et est sous licence AGPL-3.0.

Ce qui les distingue

Un à la fois, ou tous à la fois. Claude Squad montre une liste et un aperçu de la session choisie. Aubergine dessine chaque terminal en direct sur un canevas, donc cinq agents sont cinq terminaux en vue, et une seule liste dit l’état de chacun en toutes lettres.

Qui attend. Nous n’avons rien trouvé dans le README de Claude Squad sur le fait d’être prévenu qu’un agent attend ou a fini. Aubergine marque en couleur un terminal qui attend, compte en haut ce qui attend, va au suivant avec une touche, et peut envoyer une notification depuis la page ouverte.

Ce qu’il y a autour des agents. Aubergine a une file d’attente de tâches avec une limite, des planifications, des workflows avec des étapes qu’une personne approuve, des notes et des champs sur chaque terminal, une API HTTP et un serveur MCP. Claude Squad s’en tient aux sessions et à leurs branches.

Ce que Claude Squad a et qu’Aubergine n’a pas

  • Il tourne dans le terminal que vous avez déjà ouvert, sans serveur ni navigateur. Il fonctionne par SSH comme n’importe quel programme de terminal ; Aubergine, depuis ailleurs, demande un tunnel ou un proxy.
  • Il fait le commit et le push d’une branche pour vous, et met une session en pause en faisant un commit de son travail. Aubergine ne fait jamais de commit ni de push.
  • Un mode expérimental qui accepte de lui-même les demandes d’un agent. Aubergine ne répond jamais à un agent à votre place.

Questions

Aubergine est-elle une alternative à Claude Squad ?

Oui, pour le même travail fait autrement. Les deux font tourner chaque agent dans une session tmux et peuvent donner à chacun un worktree Git sur sa propre branche. Claude Squad le fait depuis un programme dans votre terminal ; Aubergine depuis une page de votre navigateur, avec chaque terminal en vue.

Les deux utilisent-ils tmux ?

Oui. Claude Squad indique tmux comme prérequis et crée une session tmux pour chaque agent. Aubergine demande tmux 3.2 ou plus récent et le fait tourner sur un socket à elle avec sa propre configuration, donc votre propre tmux n’est pas touché.

Claude Squad fonctionne-t-il avec d’autres agents que Claude Code ?

Son README dit que le programme par défaut est claude et qu’un autre, comme Codex, Gemini ou Aider, se nomme avec -p. Aubergine fait tourner n’importe quel programme en ligne de commande dans un terminal ; ce qu’elle fait d’elle-même pour un agent est fait pour Claude Code.

Quelle licence a chacun ?

Claude Squad est sous AGPL-3.0, Aubergine sous licence MIT. Les deux sont gratuits.

Aubergine n’est affiliée ni à Claude Squad ni à Anthropic. Claude Squad est le nom du projet smtg-ai ; Claude est une marque d’Anthropic.

Opérationnel en cinq minutes

Il vous faut macOS avec tmux 3.2 ou plus récent et Node.js 22 ou plus récent. brew install tmux node installe les deux.

npm install -g @meatgarden/aubergine
