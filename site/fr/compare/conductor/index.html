Aubergine vs Conductor

Les deux font tourner plusieurs agents de code à la fois, chacun dans son propre worktree Git. Conductor est une app Mac avec des chats, un visualiseur de diffs et un cloud. Aubergine est un serveur gratuit et open source sur votre propre ordinateur, qui montre des terminaux ordinaires côte à côte dans une page du navigateur.

D’où cela vient. Ce qui est dit ici de Conductor vient de sa documentation et de son journal des modifications, lus le 26 novembre 2026. Nous n’avons pas fait tourner Conductor. Si quelque chose est faux ou dépassé, dites-le-nous.

Où en est Conductor. Le 4 novembre 2026, son journal des modifications disait que Conductor rejoignait Meta et allait s’arrêter progressivement ; le 13 novembre, il disait que Conductor ne fermait pas. Des parties de son site portaient encore le premier message quand ceci a été écrit. Lisez son journal des modifications pour savoir où il en est aujourd’hui.

Lequel choisir

Choisissez Conductor si vous voulez une app Mac qui mène une tâche d’un prompt jusqu’à une pull request fusionnée, avec un cloud pour le travail qui continue quand votre Mac est éteint.

Choisissez Aubergine si vous voulez vos agents comme de simples terminaux que vous voyez tous à la fois, qui continuent dans tmux quand la fenêtre se ferme, sans rien où se connecter et avec le code source ouvert.

Ce qu’est Conductor

D’après sa propre description, une app Mac qui fait tourner de nombreux agents de code en parallèle sur votre base de code. Chaque travail est un espace de travail : un worktree Git sur une branche, avec des onglets de chat, de terminal et de navigateur. Il fait tourner Claude Code, Codex, Cursor et OpenCode avec les connexions déjà présentes sur votre Mac, et a un visualiseur de diffs, des pull requests, une app iOS et un cloud payant où les agents tournent dans des bacs à sable.

Ce qui les distingue

Des terminaux, pas des chats. Conductor montre un agent comme un chat dans un espace de travail, avec un mode terminal à côté. Aubergine montre le terminal même de l’agent, tel qu’il tourne dans n’importe quelle app de terminal, et en dispose beaucoup sur un canevas que vous déplacez et zoomez.

Ce que la fermeture arrête. La documentation de Conductor dit que les sessions locales s’arrêtent quand vous fermez l’app ou éteignez le Mac, et que les sessions dans le cloud continuent. Dans Aubergine, chaque terminal est une session tmux : fermer le navigateur ou arrêter Aubergine n’arrête rien. Un redémarrage de l’ordinateur, si, dans les deux cas.

Rien hors de votre ordinateur. Conductor documente un compte, un cloud, un relais pour son app mobile et des statistiques d’utilisation. Aubergine n’a ni compte ni service à elle : le serveur écoute sur 127.0.0.1, et l’usage depuis un autre appareil passe par un proxy que vous faites tourner.

Ce que Conductor a et qu’Aubergine n’a pas

  • Un visualiseur de diffs où vous commentez des lignes et renvoyez les commentaires à l’agent, puis les pull requests, les vérifications et la fusion. Aubergine montre ce qui a changé dans une copie de travail et ne fait jamais de commit, de push ni de fusion.
  • Un cloud où les agents continuent quand votre Mac est éteint, et des routines qui y tournent selon une planification. Les planifications d’Aubergine se déclenchent sur votre ordinateur, tant qu’il est allumé.
  • Une app iOS et des sons de fin. Aubergine n’a pas d’app et ne joue aucun son.

Questions

Aubergine est-elle une alternative à Conductor ?

Pour faire tourner plusieurs agents en ligne de commande sur votre propre ordinateur, oui : chaque agent a un terminal sur un canevas et, quand vous le demandez, son propre worktree Git. Ce n’est pas un remplacement à l’identique : Aubergine n’a pas de vue de chat, pas de pull requests ni de fusion, pas de cloud et pas d’app mobile.

Conductor est-il open source ?

Non : ses conditions le disent propriétaire, et nous n’avons trouvé aucun dépôt public. Sa documentation dit que l’app locale est gratuite et que les espaces de travail dans le cloud demandent une offre payante. Aubergine est sous licence MIT et n’a pas d’offre payante.

Conductor tourne-t-il sous Linux ou Windows ?

Sa documentation dit qu’il n’est pas encore disponible pour Windows ni Linux. Aubergine est faite pour macOS, n’a été lancée sous Linux que dans des conteneurs, et sous Windows ne tourne que dans WSL 2, ce qui n’a pas été essayé.

Puis-je utiliser Conductor et Aubergine ensemble ?

Rien ne l’empêche : les deux travaillent dans des worktrees Git du même dépôt, chacun créant les siens. Nous n’avons pas fait tourner les deux côte à côte.

Aubergine n’est pas affiliée à Conductor ni à ses créateurs. Conductor est le nom de leur produit : ses conditions nomment Melty Labs, Inc., et son site dit Conductor from Meta.

Opérationnel en cinq minutes

Il vous faut macOS avec tmux 3.2 ou plus récent et Node.js 22 ou plus récent. brew install tmux node installe les deux.

npm install -g @meatgarden/aubergine
