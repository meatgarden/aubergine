Reprendre une conversation Claude Code après un redémarrage

L’ordinateur a redémarré, ou vous avez fermé le terminal, et la conversation de Claude Code semble perdue. Claude Code la garde. Aubergine se souvient de la conversation où était chaque terminal et la ramène d’un seul bouton.

Ce que l’on fait d’habitude

Dans un terminal, dans le dossier où était la conversation : claude --continue poursuit la conversation la plus récente de ce dossier, et claude --resume vous en fait choisir une dans une liste, ou prend l’ID d’une conversation. Le piège, c’est le dossier et le choix : avec plusieurs agents dans un même dossier, la plus récente n’est pas toujours celle que vous vouliez.

Ce que fait Aubergine

Un terminal se souvient de sa conversation. Quand Claude Code a été lancé depuis Aubergine (New terminal ▾ → Claude Code, ou C), ses hooks indiquent à Aubergine dans quelle conversation il est, et Aubergine garde cet ID avec le terminal.

Resume agent (reprendre l’agent) est proposé dans la barre de titre du terminal dès que son shell est revenu à l’invite : vous avez quitté l’agent, ou l’ordinateur a redémarré et le terminal est revenu sous la forme d’un nouveau shell dans son dernier dossier. Il relance Claude Code avec --resume et cet ID, avec la commande de lancement de vos réglages (agents.claudeCommand, claude par défaut).

Sur une exécution d’un workflow, Resume agent informe aussi de nouveau l’agent de l’exécution, pour qu’il reprenne à l’étape où elle en est.

Past conversations… (conversations passées) dans la palette (⌘K), ou « Past conversations in this folder… » dans les détails d’un terminal, liste les conversations précédentes de Claude Code dans un dossier : le nom ou la première chose que vous avez dite, quand elle a été active pour la dernière fois, combien de fois vous avez parlé, et si un terminal d’un canevas y est en ce moment. Read (lire) l’affiche, en lecture seule. Open on the canvas (ouvrir sur le canevas) lance un nouveau terminal dans ce dossier qui reprend cette conversation, et Open a copy (ouvrir une copie) en lance une branche et laisse l’originale telle quelle. Si un terminal est déjà sur cette conversation, on vous demande d’abord.

La recherche. Tapez @ et quelques mots dans la palette pour chercher dans les conversations passées des dossiers des terminaux de vos canevas. Elle lit les fichiers quand vous le demandez, dans certaines limites, et dit quand elle a été écourtée. En ligne de commande, aubergine history les liste et aubergine history open <id> en ouvre une.

Où elle en était. La note du terminal garde son résumé et un journal, et chaque prompt que vous envoyez est ajouté au journal. Ask its agent for a recap (demander un récapitulatif à son agent), dans ses détails, fait écrire à l’agent où il en est avec aubergine recap --write, gardé avec le terminal. Quand vous revenez après plus de 30 minutes, While you were away (pendant votre absence) liste ce qui a changé entre-temps.

Une conversation dans un terminal hors d’Aubergine

Dans un onglet de votre application de terminal, quittez l’agent, puis lancez aubergine here --claude dans le même dossier : un nouveau terminal sur le canevas lance Claude Code avec --continue, désormais avec son état affiché. aubergine move liste vos onglets Claude Code et lance une copie de chaque conversation sur le canevas ; avec --stop, il demande d’abord à un agent inactif de quitter, après votre confirmation.

Ce qu’il ne fait pas

  • Il lit les fichiers propres à Claude Code, dans un format qui n’est pas celui d’Aubergine. Claude Code dit que le format de ces fichiers est interne, et il change d’une version à l’autre. La reprise utilise le --resume de Claude Code lui-même avec l’ID ; les noms, les décomptes et les transcriptions sont la lecture qu’Aubergine fait des fichiers, et peuvent manquer ou être plus pauvres après une mise à jour de Claude Code. Un fichier qu’il ne sait pas lire est signalé comme tel, pas affiché comme une conversation vide.
  • Rien n’est copié ni gardé. Une liste, une transcription ou une recherche est lue quand vous la demandez et oubliée quand vous la fermez. Aubergine ne modifie, ne renomme ni ne supprime jamais une conversation, et aucun agent ni aucun jeton ne peut lire de conversations par son intermédiaire.
  • Le travail en cours n’est pas refait. Ce que faisait l’agent au moment où il s’est arrêté n’est pas relancé tant que vous ne le lui demandez pas.
  • Pas de Resume agent pour un autre agent. Aubergine ne connaît pas la conversation d’un autre agent, et ne liste pas de conversations passées pour lui. Relancez-le dans le même terminal avec la façon de reprendre propre à cet agent, et lisez la note pour lui dire où il en était.
  • Un claude que vous avez tapé vous-même n’est pas retenu, sauf si vous avez ajouté à vos propres réglages de Claude Code les hooks qu’affiche aubergine hooks print.
  • Ce qui a été vérifié. La lecture des fichiers de conversation est testée sur des fichiers inventés. Elle n’a pas été vérifiée avec toutes les versions de Claude Code.

Questions

Comment reprendre une session Claude Code après avoir fermé le terminal ?

Dans le même dossier, claude --continue prend la conversation la plus récente et claude --resume vous laisse choisir. Dans Aubergine, fermer le navigateur n’arrête rien, et un terminal dont vous avez quitté l’agent propose Resume agent dans sa barre de titre.

Comment reprendre une conversation Claude Code après un redémarrage ?

Après un redémarrage, chaque terminal Aubergine revient sous la forme d’un nouveau shell dans son dernier dossier. Là où Claude Code a été lancé depuis Aubergine, Resume agent dans la barre de titre le relance dans la conversation où était ce terminal.

Comment retrouver une ancienne conversation Claude Code ?

Past conversations… dans la palette les liste pour un dossier, avec une transcription en lecture seule ; @ et quelques mots dans la palette y cherchent. Seul ce que Claude Code garde encore est listé.

Quelle est la différence entre claude --continue et claude --resume ?

--continue poursuit la conversation la plus récente du dossier ; --resume prend celle que vous choisissez, ou un ID. Resume agent utilise --resume avec l’ID dont le terminal s’est souvenu : il ne dépend donc pas de la conversation la plus récente.

Deux terminaux peuvent-ils poursuivre la même conversation Claude Code ?

Aubergine n’en ouvre pas une deux fois sans demander : deux agents dans une même conversation perdent les messages l’un de l’autre. On vous propose le terminal qui y est déjà, ou une copie, qui crée une branche de la conversation.

Opérationnel en cinq minutes

Il vous faut macOS avec tmux 3.2 ou plus récent et Node.js 22 ou plus récent. brew install tmux node installe les deux.

npm install -g @meatgarden/aubergine
