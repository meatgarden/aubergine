Codex et ChatGPT

Codex est l’agent de code en ligne de commande d’OpenAI. Vous l’installez et vous vous y connectez vous-même ; dans Aubergine, il tourne dans un terminal comme n’importe quel autre programme.

Pas encore essayé

Personne n’a encore fait tourner un vrai Codex dans Aubergine. Ce que dit cette page, c’est ce qu’Aubergine fait pour n’importe quel programme dans un terminal et pour les commandes aubergine, ce qui est construit et testé ; le comportement de Codex lui-même n’y a pas été observé. Si vous l’essayez, dites-nous comment ça s’est passé.

Le lancer

Ouvrez un terminal avec New terminal, ou N, et lancez-y Codex comme dans n’importe quel terminal. Aubergine n’appelle aucun modèle et ne détient aucune clé : ce dont Codex a besoin, vous le lui avez donné en vous y connectant.

Ce qui fonctionne aujourd’hui

Tout ce qu’Aubergine fait pour n’importe quel terminal :

  • Côte à côte

    Autant de terminaux que vous voulez sur un seul canevas, et des canevas en onglets.

  • État des commandes

    Avec zsh, le titre d’un terminal indique qu’une commande tourne, et laquelle.

  • Couleurs, notes et champs

    Donnez une couleur à son terminal, tenez une note avec un résumé et un journal, et des champs comme un ticket ou un responsable.

  • Mettre de côté

    × met le terminal de côté : il quitte le canevas et continue de tourner, et Parked le ramène.

  • Un terminal à part

    Ouvrez le terminal dans un onglet du navigateur à lui seul, avec ses détails et sa note à côté.

  • Une copie de travail

    Shell in a folder or a working copy…, ou aubergine new --copy, lance le terminal dans sa propre extraction sur sa propre branche, pour que deux agents ne modifient jamais les mêmes fichiers.

  • Recherche dans la sortie

    ⌘K cherche dans ce que chaque terminal a affiché, et ouvre le terminal remonté jusqu’à la correspondance.

Ce qu’il peut dire avec les commandes

Chaque terminal Aubergine a la commande aubergine et un identifiant propre à ce seul terminal. N’importe quel programme qui s’y trouve, Codex compris, peut s’en servir :

  • aubergine attention waiting "…"

    Marque le terminal comme en attente de vous, avec ce dont il a besoin ; aubergine attention working et aubergine attention done disent le reste.

  • aubergine note "…"

    Ajoute une ligne au journal de la note du terminal.

  • aubergine describe

    Nomme le terminal d’après le travail et tient son résumé ; aubergine link add et aubergine field set ajoutent les liens et les champs du travail. Ce que vous avez écrit vous-même l’emporte.

  • aubergine workflow status

    Lit l’étape en cours d’un workflow ; aubergine workflow done la signale comme terminée et affiche la suivante.

  • aubergine task add

    Propose une tâche pour la file d’attente, et aubergine ask vous demande quelque chose que seule une personne peut faire. Les deux attendent dans votre liste.

Comment le lui dire

Codex ne connaît pas Aubergine tant qu’on ne le lui a pas dit. Ceci affiche cinq lignes à coller dans les instructions que votre agent lit au début de chaque conversation d’un projet ; sa propre documentation dit où les mettre :

aubergine guide --snippet

Ces lignes lui disent d’exécuter aubergine guide une fois lorsqu’il est dans un terminal Aubergine, et le guide dit le reste. Aubergine affiche les lignes et ne les écrit jamais dans aucun fichier.

Si votre agent peut lancer un serveur MCP, aubergine mcp offre la même chose sous forme d’outils ; dans un terminal Aubergine, il n’a besoin ni d’adresse ni de jeton pour le travail propre au terminal.

Construit uniquement pour Claude Code aujourd’hui

Ce qu’Aubergine fait d’elle-même pour un agent est conçu pour Claude Code. Pour Codex, aujourd’hui :

  • Il n’est pas dans le menu New terminal : vous le lancez vous-même dans un terminal.
  • Aubergine ne le voit pas comme un agent : il n’est pas marqué en attente ou terminé de lui-même, seulement quand il exécute aubergine attention.
  • Rien n’est tapé pour lui : un workflow lancé sur son terminal ne tape rien et affiche la ligne à lui donner vous-même, et un récapitulatif ou un message ne lui est pas annoncé.
  • La file d’attente ne lui donne aucune tâche : une tâche ne va qu’à un terminal où un agent est vu et libre.
  • Il n’y a ni Resume agent, ni liste des anciennes conversations, ni liste de sa configuration, ni boîte de dialogue pour les outils d’Aubergine.
  • aubergine move et aubergine here --claude ne ramènent que Claude Code.
  • On ne lui rappelle pas de nommer son terminal ni de tenir un résumé.

Tout est sur la page Claude Code.

ChatGPT dans un navigateur

ChatGPT dans un onglet du navigateur est une page web, pas un programme dans un terminal ; il ne tourne donc pas sur le canevas.

Aubergine n’est pas affiliée à OpenAI. Codex et ChatGPT sont des marques d’OpenAI.

Opérationnel en cinq minutes

Il vous faut macOS avec tmux 3.2 ou plus récent et Node.js 22 ou plus récent. brew install tmux node installe les deux.

npm install -g @meatgarden/aubergine
