Comment installer Aubergine

Une commande l’installe, une autre la lance. Environ cinq minutes, visite comprise.

Prérequis

  • macOS. Sous Linux, il n’a été lancé que dans des conteneurs : le paquet npm sous Ubuntu 24.04 et l’image de conteneur sous Debian. Windows lui-même n’est pas pris en charge ; Aubergine peut tourner dans WSL 2, ce qui n’a pas encore été essayé : voir Installer sous Windows avec WSL.
  • tmux 3.2 ou plus récent et Node.js 22 ou plus récent. Le script d’installation a aussi besoin de pnpm.

Avec Homebrew, une ligne installe les deux (ajoutez pnpm pour le script d’installation) :

brew install tmux node

Installer et lancer

  1. Installez Aubergine depuis npm (il ne faut que tmux et Node.js) :

    npm install -g @meatgarden/aubergine

    Ou avec le script d’installation, qui a aussi besoin de pnpm et compile depuis le code source :

    curl -fsSL https://raw.githubusercontent.com/thirstyeggplant/aubergine/main/install.sh | sh

  2. Lancez-la et ouvrez votre navigateur, déjà connecté.

    aubergine start --open

  3. Suivez la visite. Cliquez sur Show me around au milieu du canevas vide. Cela crée un canevas nommé « Demo » avec quelques agents factices et vous guide en huit courtes étapes. Rien dans la démo n’est réel, et aubergine demo --remove la retire.

Vous préférez lire le script d’abord ? Téléchargez-le, lisez-le, et exécutez sh install.sh --dry-run pour voir ce qu’il ferait sans rien modifier.

Ce que modifie le script d’installation

Deux choses seulement : le dossier d’installation (~/.aubergine, ou AUBERGINE_HOME) et un lien nommé aubergine dans un dossier de votre PATH où vous pouvez écrire. Il vérifie tout d’abord et ne modifie rien s’il manque quelque chose.

Il n’utilise pas sudo, ne modifie pas les fichiers de démarrage de votre shell, n’installe ni Node.js, ni pnpm, ni tmux, et ne touche pas à votre dossier de données.

Si quelque chose ne va pas

Exécutez d’abord aubergine doctor. Il vérifie les causes habituelles.

Ce que vous voyezQue faire
« This browser is not signed in yet »Ouvrez une fois le lien de connexion dans ce navigateur. aubergine open --print l’affiche de nouveau.
Une page disant que tmux manque ou est trop ancienInstallez ou mettez à jour tmux (brew install tmux), puis redémarrez le serveur.
Le serveur ne démarre pas parce que le port est prisUtilisez un autre port : AUBERGINE_PORT=4700 aubergine start.
aubergine: command not foundLe lien n’est pas dans votre PATH. Le script d’installation affiche la ligne à ajouter au fichier de démarrage de votre shell.
Un terminal n’affiche aucun badge d’étatL’état demande zsh, et une session créée avant une mise à jour garde son ancien shell. Mettez-la de côté et lancez-en une nouvelle.

Arrêter, mettre à jour, désinstaller

  • Arrêtez le serveur avec Ctrl+C. Vos terminaux continuent de tourner ; relancez le serveur et rechargez la page pour les retrouver.
  • Mettez à jour, si vous avez installé avec npm, avec npm install -g @meatgarden/aubergine@latest ; si vous avez utilisé le script d’installation, avec aubergine update. Puis redémarrez le serveur.
  • Désinstallez avec aubergine uninstall. Cela retire le lien et, après vous l’avoir demandé, la copie créée par le script d’installation. Vos données ne sont jamais supprimées et vos terminaux jamais fermés.
  • Lancez-la à l’ouverture de session avec aubergine service install, pour n’avoir plus qu’à ouvrir le navigateur.

Ensuite

Lisez comment faire tourner plusieurs agents de code à la fois, ou les guides. La référence complète est dans le README.
