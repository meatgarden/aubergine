Guides

Des guides courts et pratiques. La référence complète est le README.

  • Installer Aubergine

    Prérequis, le script d’installation en une ligne, ce qu’il modifie, et solutions aux problèmes courants.

  • Installer sous Windows avec WSL

    Faites tourner Aubergine dans WSL 2 et utilisez-le depuis votre navigateur Windows. Les étapes Linux ont été lancées ; rien n’a encore été essayé sous Windows.

  • Faire tourner plusieurs agents de code à la fois

    Le canevas, le compteur d’attente, la file d’attente, les copies de travail et les workflows en une visite.

  • Claude Code dans Aubergine

    Ce qu’Aubergine fait d’elle-même pour Claude Code, et où se trouve chaque chose.

  • Codex et ChatGPT

    Codex dans un terminal comme n’importe quel programme, ce qu’il peut signaler, et ce qui est construit uniquement pour Claude Code.

  • Copies de travail

    Donnez à chaque agent sa propre extraction et sa propre branche, pour que deux agents ne modifient jamais les mêmes fichiers.

  • Garder vos terminaux après un redémarrage

    Ce que gardent la fermeture du navigateur, un redémarrage d’Aubergine et un redémarrage de l’ordinateur, et comment reprendre là où vous en étiez.

  • Garder un processus en marche après avoir fermé le terminal

    Fermez l’onglet, la fenêtre ou le navigateur, et rien ne s’arrête : ce que donne tmux, sans apprendre tmux.

  • tmux sans apprendre tmux

    Des shells qui survivent à la fenêtre, sans touche de préfixe ni configuration, et votre propre tmux laissé tel quel.

  • Savoir quand Claude Code a fini ou vous attend

    Les états working, waiting for you et finished sur chaque terminal, le compteur For you, la touche du prochain qui attend et les notifications de la page ouverte.

  • Reprendre une conversation Claude Code

    Resume agent sur le terminal où elle tournait, les conversations passées d’un dossier, et ce qui vous dit où elle en était.

  • Trouver le bon terminal quand vous en avez trop

    Un canevas, une liste de tous les terminaux avec leur état en toutes lettres, des filtres, des étiquettes et la recherche dans ce que les terminaux ont affiché.

  • Surveiller vos agents depuis votre téléphone

    Accéder à Aubergine depuis un autre appareil, chacun appairé avec un code. Lancé une fois sur un Mac ; pas essayé sur un vrai téléphone.

  • La file d’attente, For you et les planifications

    Distribuez le travail une fois, voyez tout ce qui vous attend, et lancez des tâches à heure fixe.

  • Aubergine comparée à d’autres outils

    Conductor, Claude Squad, Vibe Kanban, cmux, Warp et Paradev à côté d’Aubergine, d’après ce que chacun documente sur lui-même.

  • Sécurité et confidentialité

    Ce qui est protégé, et ce qui ne l’est pas.

  • FAQ

    Des réponses courtes aux questions courantes.

Opérationnel en cinq minutes

Il vous faut macOS avec tmux 3.2 ou plus récent et Node.js 22 ou plus récent. brew install tmux node installe les deux.

npm install -g @meatgarden/aubergine
