Savoir quand Claude Code a fini ou vous attend

Vous confiez une tâche à Claude Code, passez à autre chose, et revenez vingt minutes plus tard pour découvrir qu’il attend un oui depuis la deuxième minute. Aubergine montre, sur une seule page, quel terminal travaille, lequel vous attend et lequel a fini.

Ce que l’on fait d’habitude

Claude Code exécute des hooks, des commandes à vous, à certains moments, par exemple quand il s’arrête (Stop) ou envoie une notification (Notification). La réponse habituelle est un hook dans vos réglages de Claude Code qui joue un son ou affiche une notification sur le bureau. Ça marche, et ces scripts sont à écrire et à entretenir vous-même.

Ce que fait Aubergine

Lancez Claude Code depuis Aubergine : New terminal ▾ → Claude Code en haut de la liste des terminaux, ou C. Aubergine lance claude avec un fichier de réglages qu’il génère dans son propre dossier de données et qu’il nomme sur la ligne de commande. Votre propre configuration de Claude Code n’est pas touchée. Les hooks de ce fichier indiquent à la page ce que fait l’agent :

  • quand vous envoyez un prompt, le terminal affiche working (au travail), et le prompt est ajouté au journal de sa note ;
  • quand l’agent a besoin de vous (une question d’autorisation, ou il attend une saisie), son contour prend la couleur de l’attente, et son titre et sa ligne dans la liste indiquent waiting for you (vous attend) ;
  • quand il s’arrête, le terminal affiche finished (fini).

Le compteur à côté de For you, en haut à droite de la page, compte tout ce qui vous attend, sur tous les projets : les terminaux qui posent une question, mais aussi les exécutions à approuver, les brouillons à lire et les tâches proposées. Cliquer dessus ouvre Runs, dont la colonne Waiting for you est cette liste. L’onglet d’un canevas indique combien de ses terminaux attendent.

Le prochain qui attend. W va au prochain terminal qui vous attend tant qu’aucun terminal n’a le clavier ; sous macOS, ⌃⌘J le fait aussi depuis un terminal. Ailleurs, c’est dans la palette.

Des notifications de la page ouverte. Settings → Notifications contient Notify me on the desktop when a terminal starts waiting (me prévenir sur le bureau quand un terminal se met à attendre). Une fois cette option activée, la page affiche une notification de votre navigateur quand un terminal se met à attendre ou que son agent a fini, sauf si vous regardez ce terminal. Le navigateur vous demande l’autorisation une fois.

Les règles. Dans l’onglet Rules de Runs, une règle peut, avec Notify me (me prévenir), vous avertir quand une tâche est terminée, qu’une tâche a échoué, qu’une tâche a besoin de vous, que l’on vous demande quelque chose, ou qu’une planification s’est déclenchée ou n’a pas pu s’exécuter : une notification de la page ouverte, avec une phrase sur ce qui s’est passé.

Les autres agents, et un claude tapé à la main

Aubergine ne lit pas la sortie d’un terminal pour deviner. Tout autre agent, ou tout programme, dit la même chose de lui-même avec aubergine attention waiting "what it needs", aubergine attention working et aubergine attention done dans son terminal. aubergine guide --snippet affiche cinq lignes pour le fichier que votre agent lit au début d’une conversation ; elles lui disent de lancer aubergine guide, qui explique ces commandes.

Un Claude Code que vous avez lancé en tapant claude dans un terminal ordinaire n’est, pour Aubergine, qu’un shell occupé par un programme : pas de waiting for you. Lancez-le plutôt depuis le menu, ou ajoutez à la main à vos propres réglages les hooks qu’affiche aubergine hooks print ; ils ne font rien en dehors d’un terminal Aubergine.

Ce qu’il ne fait pas

  • Aucun son à lui. Aubergine n’en joue aucun. Une notification ne fait du bruit que si votre navigateur ou votre système en fait pour les notifications.
  • Rien tant qu’aucune page n’est ouverte. Les notifications viennent d’une page Aubergine ouverte dans votre navigateur ; le serveur n’en envoie aucune de lui-même. Toutes les pages fermées, le terminal indique toujours waiting for you, et le compteur est là quand vous ouvrez la page.
  • Pas de notification push sur un téléphone. Il n’y a ni application ni service de push. Le navigateur d’un téléphone peut être appairé pour ouvrir la même page ; voir Surveiller vos agents depuis votre téléphone, ce qui n’a pas été essayé sur un vrai téléphone.
  • Ce qui a été vérifié. Les tests dans le navigateur vérifient les notifications auprès d’un substitut de celles du navigateur. L’aspect d’une vraie notification, et si elle s’affiche seulement, dépendent de votre navigateur et des réglages de votre système à ce sujet.

Questions

Comment recevoir une notification quand Claude Code a fini ?

Lancez Claude Code depuis Aubergine, puis activez Notify me on the desktop when a terminal starts waiting sous Settings → Notifications. La page ouverte affiche alors une notification du navigateur quand un terminal se met à vous attendre ou que son agent a fini. Sans notification, le terminal indique finished.

Claude Code peut-il jouer un son quand il a besoin d’une saisie ?

Aubergine ne joue aucun son. Une notification sonne si votre navigateur ou votre système la fait sonner. Un hook à vous dans vos réglages de Claude Code peut en jouer un ; Aubergine n’écrit jamais dans ces réglages.

Comment voir quelle session Claude Code attend quand j’en fais tourner plusieurs ?

Dans Aubergine, le contour et l’état du terminal qui attend sont dans la couleur de l’attente, sa ligne dans la liste indique waiting for you, et le compteur à côté de For you dit combien de choses attendent. W va au suivant.

Suis-je prévenu quand le navigateur est fermé ?

Non. Les notifications viennent d’une page Aubergine ouverte. L’état est gardé : les terminaux qui attendent sont marqués quand vous rouvrez la page.

Est-ce que ça marche avec d’autres agents que Claude Code ?

Pas de lui-même : les hooks sont faits pour Claude Code. Tout autre agent peut signaler la même chose avec aubergine attention waiting, working et done quand ses propres instructions le lui disent ; aubergine guide --snippet affiche les lignes à mettre dans ces instructions.

Opérationnel en cinq minutes

Il vous faut macOS avec tmux 3.2 ou plus récent et Node.js 22 ou plus récent. brew install tmux node installe les deux.

npm install -g @meatgarden/aubergine
