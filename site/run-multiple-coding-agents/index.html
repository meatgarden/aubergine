How to run several coding agents at once

Two agents are easy. Five are chaos: which one is stuck, which is waiting on you, which changed that file? Aubergine is built for that moment. It runs on your own computer.

1. Give each agent a terminal on one canvas

Click + New terminal (or press N) and start an agent in it. Drag terminals by their title bars, resize them, and group them in frames. Related work goes on one canvas; separate pieces of work go in separate canvases (tabs) or projects, each with its own terminals, queue and schedules.

Every terminal is a real shell in a tmux session. Close the browser, or stop Aubergine, and your agents keep running.

2. See which agent needs you

Each terminal shows whether it is busy, idle or waiting for you. That status comes from hooks in your shell and from the agents themselves, not from reading the screen. The count at the top of the canvas and the W key take you straight to the next one that is waiting.

One list, For you, gathers everything that waits on a person: questions, runs to approve, finished tasks to look at, and failed ones with the reason.

3. Hand out work from a queue

Write a task once and put it in the queue. A free agent takes it when you say so, with a limit on how many run at once. For work that repeats, set a schedule. Agents can propose tasks and ask you questions, but nothing starts until you accept.

4. Keep each agent's changes apart

Two agents in one folder edit the same files. Start each in its own working copy: a separate checkout on its own branch, so you can read each agent's work apart. Aubergine never merges, pushes or rebases for you.

5. Give agents steps, and decide at the gates

A workflow is an ordered list of steps an agent follows, with a strip showing where it is. A step can wait for you to approve or send back. Every live run appears on one board.

What it does not do

  • It does not call a model or pick one for you. The agents are yours.
  • It does not keep an agent from doing something you could do. Agents run as you. See security for what is and is not protected.
  • It runs on one computer today. Sharing a canvas with other people and running agents in the cloud are on the roadmap, and are not built.
