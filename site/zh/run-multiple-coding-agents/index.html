如何同时运行多个编程智能体

两个智能体很简单。五个就是一团乱：哪个卡住了，哪个在等你，哪个改了那个文件？Aubergine 正是为这种时刻而做的。它运行在你自己的电脑上。

1. 在一张画布上给每个智能体一个终端

点击终端列表顶部的 New terminal（新建终端）或按 N，在其中启动一个智能体。拖动终端的标题栏来移动，调整大小，并用框把它们归组。相关的工作放在一张画布上；彼此独立的工作放在不同的画布（标签页）或项目中，每个项目都有自己的终端、队列和定时计划。

每个终端都是 tmux 会话中真正的 shell。关掉浏览器或停止 Aubergine，你的智能体仍会继续运行。

2. 看清哪个智能体需要你

每个终端都会显示它是忙碌、空闲还是在等你。这个状态来自你 shell 中的钩子和智能体本身，而不是读取屏幕内容。顶部 For you 旁边的数字和 W 键会直接带你去下一个在等待的终端。

一个列表 For you 汇集所有在等人处理的事：问题、待审批的运行、需要查看的已完成任务，以及带有原因的失败任务。

3. 从队列分派工作

任务写一次，放进队列。在你发话时，空闲的智能体会接手，并且同时运行的数量有上限。对于重复的工作，设置一个定时计划。智能体可以提议任务、向你提问，但在你接受之前什么都不会开始。

4. 把每个智能体的改动分开

在同一个文件夹里的两个智能体会编辑同一批文件。让每个智能体在自己的工作副本中启动：在自己分支上的独立检出，这样你就能分开阅读每个智能体的工作。Aubergine 从不替你合并、推送或变基。

5. 给智能体步骤，在关卡处做决定

工作流是智能体依次遵循的一系列步骤，并有一条进度条显示它走到了哪里。某个步骤可以等你批准或退回。所有正在进行的运行都显示在一块看板上。

它不做什么

  • 它不调用模型，也不替你选模型。智能体是你的。
  • 它不会阻止智能体做你能做的事。智能体以你的身份运行。哪些受保护、哪些不受保护，见安全。
  • 目前它在一台电脑上运行。与他人共享画布、在云端运行智能体都在路线图上，尚未构建。

五分钟上手

你需要 macOS，以及 tmux 3.2 或更高版本和 Node.js 22 或更高版本。brew install tmux node 可以一次装好两者。

npm install -g @meatgarden/aubergine
