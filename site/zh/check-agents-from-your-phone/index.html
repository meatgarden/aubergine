用手机查看你的智能体

你让三个智能体干着活就出门了。其中有没有哪个在等你说一声“是”？设置好之后，就可以在手机浏览器里打开 Aubergine：同样的页面、同样的终端，每台设备用一次性代码配对。

试过什么，没试过什么。从另一台设备使用在 2026 年 11 月 22 日运行过一次：在一台 Mac 上使用 docker/ 中的容器配置，前面是 https://aubergine.localhost 下的 Caddy，用同一台 Mac 上的 Chromium，它用代码完成了配对，在终端里输入了内容，并在其设备被吊销时被登出。没试过：真正的手机、用手机扫描二维码、带公开证书的真实域名、私有网络、云服务器、两台独立的机器。页面没有针对手机的宽度排版。其余内容来自代码及其测试。请把这当作可以一试的东西，而不是承诺。

通常的做法

在手机上用 SSH 应用登录电脑，再 tmux attach 到某个智能体运行的会话。或者用隧道，或者用私有网络让手机能连到电脑。两种都可行；但这样查看几个智能体，就得在小键盘上轮流连接每一个。

Aubergine 做什么

默认关闭，并且始终只绑定在这台电脑上。服务器只监听 127.0.0.1，这一点不会改变。由同一台电脑上的某个程序以一个域名为它提供 HTTPS，比如私有网络自带的 HTTPS 服务，或者 Caddy 这样的 Web 服务器。Aubergine 自己从不处理 HTTPS。

地址由你写在设置里。它写在 access.addresses 下，位于 config.json 中，在服务器启动时读取；任何页面或程序都不能修改它。aubergine doctor 会列出这些地址，以及其中任何一个有什么问题。

每台设备用一次性代码配对。在电脑上运行 aubergine device add --name "Phone"，或在已登录的浏览器中使用 Settings → Devices → Add a device，会显示一个代码，并为每个地址显示一个二维码，内容是带着代码的链接。扫描它、打开链接，或在手机的登录页面输入代码。代码只能用一次，有效期三分钟。

设备可以被吊销。aubergine device revoke "Phone"，或 Settings → Devices 下的 Revoke…（吊销），会立即将其登出，并关闭它打开的一切。90 天未使用的设备会停止工作。

已配对的设备就是完整的所有者。你在电脑前能做的一切它都能做：每个终端都能用，也就是以你的身份在那台电脑上使用 shell。只配对你愿意把键盘交给它的浏览器。作用于电脑自身桌面的功能，即 Open on desktop，在那里的页面上不会出现，请求也会被拒绝。

你会看到什么

和在电脑前一样的页面：画布和其中的终端、For you 旁边的数字和等待清单，以及在 /t/<terminal> 单独打开的终端，带着它的详情和笔记。它没有针对手机排版；用起来和在窄窗口中一样。

三种设置方式（SSH 隧道、私有网络、你自己的域名加代理）、配对，以及出问题时怎么办，都在 Using Aubergine from elsewhere 中。SSH 隧道完全不需要设置，但在手机上用起来不方便。

它不做什么

  • 没有应用，也没有推送。它是手机浏览器里的一个页面，打开期间保持最新。页面关掉的手机不会收到任何东西。
  • 睡眠中的笔记本不会响应。服务器在笔记本上时，手机只能在笔记本醒着时连到它。另一个选择是一台一直开着的机器。
  • 不为任何人都能打开的地址提供保护。没有代码谁也进不来，代码也很难猜中，但陌生人猜的可是一个 shell。请在它前面放一个私有网络或你所在组织自己的登录，并且永远不要使用把机器公开到整个互联网的私有网络模式。
  • 没有手机版排版。页面用起来和在窄窗口中一样。这样可以阅读终端、回答问题；排列画布则适合在更大的屏幕上做。

常见问题

能用手机查看我的编程智能体吗？

一旦能通过 HTTPS 访问 Aubergine，并且手机浏览器已配对，手机就会显示同样的页面：哪个终端在等待、等待清单，以及每个终端。这在同一台 Mac 上的浏览器中运行过，还没有在真正的手机上运行。

如何把手机和 Aubergine 配对？

在电脑上运行 aubergine device add --name "Phone"，或使用 Settings → Devices → Add a device。在三分钟内扫描二维码、打开链接，或在手机的登录页面输入代码。

手机丢了怎么办？

在电脑上吊销它：aubergine device revoke "Phone"，或 Settings → Devices 下的 Revoke…。它会被立即登出，它打开的一切都会被关闭。

把 Aubergine 放到互联网上安全吗？

任何人都能打开的地址，会把登录页摆在所有人面前，而已配对的设备拥有你电脑上的 shell。最好用私有网络，或在地址前面放你所在组织自己的登录。

笔记本睡眠时还能用吗？

不能。睡眠中的笔记本不会响应任何请求，它的终端会暂停到醒来为止。要随时连到智能体，服务器必须运行在一台一直醒着的机器上。

五分钟上手

你需要 macOS，以及 tmux 3.2 或更高版本和 Node.js 22 或更高版本。brew install tmux node 可以一次装好两者。

npm install -g @meatgarden/aubergine
