如何安装 Aubergine

一条命令安装，一条命令启动。包括导览在内大约五分钟。

系统要求

  • macOS。在 Linux 上只在容器里运行过：在 Ubuntu 24.04 上运行了 npm 包，在 Debian 上运行了容器镜像。不支持 Windows 本身；Aubergine 可以在 WSL 2 里运行，但这还没有试过：见在 Windows 上用 WSL 安装。
  • tmux 3.2 或更高版本，以及 Node.js 22 或更高版本。安装脚本还需要 pnpm。

用 Homebrew，一行就能装好两者（使用安装脚本的话再加上 pnpm）：

brew install tmux node

安装并启动

  1. 从 npm 安装 Aubergine（只需要 tmux 和 Node.js）：

    npm install -g @meatgarden/aubergine

    或者使用安装脚本，它还需要 pnpm，并从源码构建：

    curl -fsSL https://raw.githubusercontent.com/thirstyeggplant/aubergine/main/install.sh | sh

  2. 启动它，并打开已登录的浏览器。

    aubergine start --open

  3. 走一遍导览。点击空画布中间的 Show me around（带我看看）。它会创建一张名为“Demo”的画布，其中有几个替身智能体，并用八个简短步骤带你走一遍。演示中的一切都不是真的，aubergine demo --remove 会把它移除。

想先读一读脚本？下载它，读一遍，然后运行 sh install.sh --dry-run，看看它会做什么，而不改动任何东西。

安装脚本会改动什么

只有两样：安装文件夹（~/.aubergine，或 AUBERGINE_HOME），以及一个名为 aubergine 的链接，放在你 PATH 中一个你有写权限的文件夹里。它会先检查一切，缺了什么就什么都不改。

它不会使用 sudo、编辑你的 shell 启动文件、安装 Node.js、pnpm 或 tmux，也不会碰你的数据文件夹。

如果出了问题

先运行 aubergine doctor。它会检查常见原因。

你看到的情况怎么做
“This browser is not signed in yet”在那个浏览器中打开一次登录链接。aubergine open --print 会再次打印它。
页面提示 tmux 缺失或版本太旧安装或升级 tmux（brew install tmux），然后重启服务器。
端口被占用，服务器无法启动换一个端口：AUBERGINE_PORT=4700 aubergine start。
aubergine: command not found链接不在你的 PATH 中。安装脚本会打印需要加进 shell 启动文件的那一行。
终端没有显示状态标记状态需要 zsh，而更新之前创建的会话会保留旧的 shell。把它停放起来，再启动一个新的。

停止、更新、卸载

  • 按 Ctrl+C 停止服务器。你的终端会继续运行；再次启动服务器并刷新页面即可找回它们。
  • 更新：如果用 npm 安装，运行 npm install -g @meatgarden/aubergine@latest；如果用安装脚本，运行 aubergine update。然后重启服务器。
  • 卸载：运行 aubergine uninstall。它会移除链接，并在询问后移除安装脚本创建的副本。它从不删除你的数据，也从不结束你的终端。
  • 登录时启动：运行 aubergine service install，以后只需打开浏览器。
