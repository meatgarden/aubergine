终端太多时找到要找的那个

二十个标签页，大多叫 zsh，其中三个在运行智能体，其中一个在等你。Aubergine 把每个终端放到画布上，并放进一个写明各自在做什么的列表，让你按终端是什么来找它，而不是按你把它放在了哪里。

通常的做法

给标签页或窗口命名（大多数终端应用都可以），把窗口拆成窗格，使用命名的 tmux 会话和窗口，或者让平铺式窗口管理器来摆放。这些能帮你摆放终端；但要找出需要你的那个，还是得一个个去看。

Aubergine 做什么

一张画布。终端并排摆开，每个都是实时的。拖动标题移动，拖动边缘调整大小，双击标题重命名。标题里的圆点可以给它上色；框（New terminal ▾ → Frame，或按 G）把终端归到一个标签下，并让它们一起移动。

画布和项目。可以有多张画布，显示为标签页、一个列表或左侧的一列，每张都有自己的地址。项目拥有自己的画布、终端、队列和等待清单；左上角的切换器用于在项目之间切换。

所有终端的一个列表。侧边栏的 Terminals 列出每个终端，用文字写出状态（working、waiting for you、finished、失败的命令），以及它所在运行的步骤和最后活跃的时间，范围可以是这张画布或所有画布。顶部的输入框可以按名称、文件夹、命令、笔记或标签查找终端。

Filter（筛选）里有各种筛选条件（waiting for me、busy、unread、has an agent、parked、tags），以及列表的排列方式：按画布分组，或者一个平铺的列表，按画布顺序、最近更新、最近输入或名称排序。

画布上方的 Go to… 或 ⌘K 就是命令面板：输入名称、文件夹、命令或笔记的一部分。它的 Terminal output 部分会搜索终端输出过的内容（tmux 为每个终端保留的最后 50,000 行），选中一个结果会打开那个终端并回滚到那里。

小地图（按钮在 Go to… 旁边）以缩小的方式显示整张画布，并可以拖动它。Fit（F）一次显示全部。

终端是做什么用的。每个终端旁边都有一份笔记（摘要和日志），详情中有标签、链接，以及像 Ticket: DEMO-12 这样的字段。智能体可以用 aubergine 命令写下自己终端的名称、摘要和字段。

单独一个终端。标题里的 Tab ↗ 会在它专属的浏览器标签页中打开它，地址是 /t/<terminal>，详情和笔记一点即开。

Tab 和 Shift+Tab 按列表显示的顺序逐个走过终端，W 跳到下一个在等你的终端。

它不做什么

  • 它不会替你排列。终端待在你放的地方（新终端会放进视图中部附近的空位），并保留你或它的智能体给它起的名字。
  • 它不承诺数量。只有你正在看的画布会保持实时终端：缩得很小时终端显示的是屏幕的图片，在屏幕外时对页面没有任何开销。每个终端仍然是你电脑上的一个 shell。列表在单元测试中用 1,000 个终端测试过（列出、筛选，只绘制一屏的内容），还有一个脚本会在三张画布上放 90 个终端，供人工判断。两者都不是对你电脑的承诺。
  • 不显示你终端应用的标签页。Open elsewhere（O）会列出在那里打开的终端，并一次一个地把它们搬过来，成为同一文件夹中的新终端。标签页里正在运行的程序留在那个标签页里。

常见问题

如何整理大量终端窗口？

在 Aubergine 中：每项工作一张画布，终端带着名称和颜色并排摆放，相关的用框框起来，再用一个列表看全部终端，以及每个在做什么。

如何找出哪个终端在运行某条命令？

列表上方的输入框会匹配终端的名称、文件夹、命令、笔记和标签，命令面板（⌘K）在所有画布上做同样的事。终端的标题会显示它在运行什么。

能搜索所有终端的输出吗？

能，限于仍在运行的终端：命令面板的 Terminal output 部分会在你搜索时读取每个终端的历史，包括停放的终端，最远到 tmux 保留的范围（50,000 行）。不建立索引，也不做记录。

Aubergine 能处理多少个终端？

没有固定的上限。列表用 1,000 个终端测试过，也人工看过三张各有 90 个终端的画布；每个终端仍然是一个 shell，所以取决于你的电脑能跑多少。

能给终端命名和上色吗？

能。双击终端的标题来重命名，用标题里的圆点从十三种颜色中选一种，或用你自己的颜色。画布也有名称和颜色。

五分钟上手

你需要 macOS，以及 tmux 3.2 或更高版本和 Node.js 22 或更高版本。brew install tmux node 可以一次装好两者。

npm install -g @meatgarden/aubergine
