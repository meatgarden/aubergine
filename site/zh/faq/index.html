常见问题

简短的回答。指南讲得更深入。

Aubergine 是什么？

一个在本地运行、基于浏览器的终端会话画布。每个终端都是一个可以排列和使用的节点，所以你可以同时运行多个编程智能体，并看清哪一个在等你。

Aubergine 免费开源吗？

是的。它是免费的，源码在 GitHub 上。

运行 Aubergine 需要什么？

装有 tmux 3.2 或更新版本以及 Node.js 22 或更新版本的 macOS；安装脚本还需要 pnpm。在 Linux 上只在容器里运行过。在 Windows 上只能在 WSL 2 里运行，而这还没有试过：见Windows 指南。

它适用于任何编程智能体吗？

Aubergine 运行的是普通终端，所以任何命令行智能体都能在其中运行。Aubergine 为智能体自动做的事，比如看到它在等待，是为 Claude Code 构建的；其他任何智能体，包括 Codex，都可以通过 aubergine 命令和本地 API 报告自己的状态，还可以使用一个只列出其令牌所允许内容的 MCP 服务器。

Aubergine 会把我的终端或代码发送到别处吗？

不会。一切都在你自己的电脑上运行。服务器只监听 127.0.0.1。

Aubergine 会调用 AI 模型吗？

不会。调用模型的是你的智能体。Aubergine 只运行它们的终端并跟踪它们，不持有任何模型的密钥。

关掉浏览器后，我的终端会怎样？

它们会继续运行。每个会话都是一个 tmux 会话，比浏览器和 Aubergine 服务器都活得更久。

我怎么知道哪个智能体在等我？

每个终端都会显示它是忙碌、空闲还是在等待。页面顶部 For you 旁边的数字和 For you 列表汇集了所有需要你的事。

如何避免两个智能体编辑同一批文件？

让每个终端在自己的工作副本中启动：独立的检出，位于自己的分支上。Aubergine 从不替你合并或推送。

我能给智能体一份要遵循的步骤清单吗？

可以。工作流就是一系列有序的步骤，并有一条进度条显示智能体走到了哪里。某个步骤可以等你批准或退回。

智能体之间能对话吗？

能，在限制范围内。终端之间的消息带有署名的发送者、暂停和屏蔽，每张画布默认关闭。

有 API 吗？

有。带有限定权限令牌的本地 HTTP API、一个有类型的客户端，以及一个只列出凭据可用工具的 MCP 服务器。

我能单独打开一个终端吗？

可以。终端标题中的 Tab ↗ 会在单独的浏览器标签页中打开它，是同一个终端，不是副本，需要时旁边会显示它的详情和笔记。关闭标签页不会结束任何东西。

我能给终端记上工单或负责人吗？

可以。终端在详情中有字段，也就是标签和值的配对。其中的智能体可以用 aubergine field set 设置自己的字段；如果你设置了同一个标签，保留的是你的。

Aubergine 会支持多人或云端智能体吗？

两者都在计划中，目前都还没有构建。见路线图。今天一切都在一台电脑上运行。

安装脚本会在我的电脑上改动什么？

两样：安装文件夹（~/.aubergine），以及一个名为 aubergine 的链接。它从不使用 sudo，从不编辑你的 shell 启动文件，也从不安装 Node.js、pnpm 或 tmux。

五分钟上手

你需要 macOS，以及 tmux 3.2 或更高版本和 Node.js 22 或更高版本。brew install tmux node 可以一次装好两者。

npm install -g @meatgarden/aubergine
