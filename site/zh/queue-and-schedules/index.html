队列、“For you”与定时计划

两个相互衔接的列表：队列存放给智能体的工作，For you 存放所有在等人处理的事。定时计划在设定的时间把任务加入队列。

队列

打开页面顶部的 Runs（或按 Q），点击 Add task（添加任务）。任务有标题、要做什么，以及可选的文件夹、工作流和谁可以接手。默认情况下，任何有空闲智能体的终端都可以接手；你也可以指定一个终端，或为它启动一个新的智能体终端，当文件夹位于仓库中时，这个终端会在自己的工作副本中运行。

  • Start next 会启动第一个现在有人能接手的任务。普通 shell 永远不会被分到任务。
  • At most N at once（同时最多 N 个），除非你修改，否则为三个。Hold 会停止新的启动，不影响正在运行的任何东西。
  • Start by itself 在你打开之前一直是关闭的。没有任何东西靠定时器检查。
  • 顺序由你决定：拖动任务，或使用方向键。
  • 任务跟随它的运行：运行等待审批时为 needs you，完成时为 done，停下时为 failed 并附一句原因。不会自动重试任何东西。

For you

有问题的终端、待审批或受阻的运行、待读的草稿和待安装项、提议加入队列的任务、已完成和失败的任务、智能体交上来的清单，以及终端已不在的工作副本。顶部 For you 旁边的数字和“next waiting”是同一个列表。其中大部分是汇集来的，不是写进去的：事情本身处理完了，条目就会消失。

发现现在不该做的工作的智能体可以提议一个任务，需要人的智能体可以向你提出请求：

aubergine task add "Add a test for the retry" --details "it should fail without the fix"
aubergine ask "the staging key expires this week: rotate it, or say who can"

两者都会出现在你的列表上。提议在你接受之前不会启动任何东西。

定时计划

定时计划就是一天中的某个时间、一周中的某几天、要运行的东西和运行的地方。时间一到，它向队列添加一个任务，由队列启动。在 Runs 页面的 Schedules 下设置，或使用 aubergine schedule。时间以这台电脑的时钟为准；没有表达式，频率最多一天一次。

aubergine schedule add "My morning list" --at 08:30 --days weekdays \
  --element "Morning list" --new Main
aubergine schedule run "My morning list"

aubergine schedule run 会立即试运行一个定时计划。

事情没有按计划进行时

  • 电脑必须醒着，并且 Aubergine 在运行。电脑睡眠期间错过的时间，如果不超过六小时，会在恢复时运行一次，并标为迟到。否则标为 missed（已错过）。
  • 当定时计划的上一个任务仍在等待或正在执行时，它不会再添加新任务，并注明已跳过。
  • 如果它指定的东西（终端、步骤、画布）已经不在，它不会运行，并在你的列表上用一个条目说明。

规则

在 Rules 下，你可以设定“当任务完成、失败或需要我时，或者定时计划触发或被错过时，就通知我或运行一个已保存的步骤”。规则只能由你来写：任何程序和智能体都不能添加或修改规则，规则也不能触发自己。

Aubergine 不调用模型，也不持有任何应用的凭据。任务或定时计划只会启动一次运行；接手的智能体用它自己的工具完成工作。

五分钟上手

你需要 macOS，以及 tmux 3.2 或更高版本和 Node.js 22 或更高版本。brew install tmux node 可以一次装好两者。

npm install -g @meatgarden/aubergine
