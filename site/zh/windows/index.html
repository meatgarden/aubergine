在 Windows 上用 WSL 安装 Aubergine

Aubergine 不能在 Windows 本身上运行。它在 WSL 2（Windows 提供的 Linux）里运行，你在 Windows 的浏览器中使用它。

试过什么。Linux 部分的步骤于 2026 年 11 月 25 日在容器中的 Ubuntu 24.04.5（x86_64）上运行，而不是在 WSL 中，使用的是 npm 上的 Aubergine 0.2.2：它编译了终端库、启动、让一个浏览器登录，并运行了一个终端和演示。用 nvm 安装 Node.js 那一步没有在那里运行，因为 Node.js 22 已经装好了。本页的内容还没有在 Windows 上运行过。如果你试了，请告诉我们结果。

你需要什么

Windows 11，或 Windows 10 版本 2004（内部版本 19041）或更新版本，在这些系统上用一条命令就能装好 WSL 2。详情见 Microsoft 的安装 WSL 页面。

安装并启动

  1. 安装 WSL。以管理员身份打开 PowerShell，运行下面这条命令，完成后重启 Windows。它会安装带 Ubuntu 的 WSL 2。

    wsl --install

    重启后，从开始菜单打开 Ubuntu，为它设置用户名和密码。下面的命令都在那里，也就是在 Ubuntu 中输入。

  2. 安装 Aubergine 需要的东西：tmux、zsh 和 Git，以及编译其终端库的工具，因为这个库没有为 Linux 准备现成的版本。

    sudo apt update

    sudo apt install -y tmux zsh git build-essential python3

    安装 Node.js 22。Ubuntu 自带的软件包是 18 版，太旧了。一个常见的办法是 nvm：先安装它，再打开一个新的 Ubuntu 窗口，然后安装 Node.js 22。

    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash

    nvm install 22

    现在 node -v 应该显示 v22 或更新版本。

  3. 从 npm 安装 Aubergine。它在安装时编译自己的终端库；试的时候整个安装用了 13 秒。

    npm install -g @meatgarden/aubergine

  4. 启动它，并让那个窗口保持打开：

    aubergine start

    让浏览器登录。在第二个 Ubuntu 窗口中显示登录地址，然后在 Windows 的浏览器中打开它。它会让那个浏览器登录，所以要像对待密码一样对待它。

    aubergine open --print

    之后，在那个浏览器中直接打开 http://127.0.0.1:4600 就行。在空画布上，Show me around 会开始导览。

值得知道

  • 把项目放在 Ubuntu 里，放在它的主文件夹中，而不是 /mnt/c 下面；那里的 Windows 文件要经过一座更慢的桥才能访问。
  • 把智能体装在 Ubuntu 里，无论是 Claude Code、Codex 还是别的，和在任何 Linux 上一样。装在 Windows 中的智能体不在 Aubergine 的终端里。
  • 终端在 WSL 运行期间一直存在。关闭浏览器不会结束任何东西，在 aubergine start 的窗口按 Ctrl+C 只会停止服务器。当 WSL 停止时（Windows 重启或执行 wsl --shutdown 之后），终端会结束，下一次 aubergine start 会在它们最后所在的文件夹中打开新的 shell，就像 Mac 重启之后一样。
  • bash 还是 zsh。Ubuntu 的 shell 是 bash，终端在其中可以正常使用。终端上的命令状态（忙碌、失败命令的退出码）只来自 zsh：试的时候，一个 zsh 终端在命令失败后显示了 exit 3。要有这些，请在 Ubuntu 中把 zsh 设为你的 shell。
  • 没有的东西：登录时启动只适用于 macOS（aubergine service install 会这样说明），Open on desktop 也没有针对 Windows 终端应用的设置。试的时候 aubergine open 找不到可以打开的浏览器；aubergine open --print 总是可用。
  • Windows 上的快捷键是根据浏览器的文档选的，没有实测过：见 docs/keys.md。命令面板总是可用。

如果出了问题

先在 Ubuntu 中运行 aubergine doctor。它会检查 Node.js、tmux、Git 和服务器。

你看到的情况怎么做
安装 Aubergine 时在编译 node-pty 处失败缺少构建工具。运行第 2 步中的 apt 命令，然后重新安装 Aubergine。
页面提示 tmux 缺失或版本太旧Ubuntu 24.04 的 tmux 是 3.4，足够新：运行 sudo apt install -y tmux，然后重新启动服务器。
node -v 显示的版本低于 v22按第 2 步安装 Node.js 22，打开一个新的 Ubuntu 窗口，然后重新安装 Aubergine。
地址在 Windows 的浏览器中打不开检查 aubergine start 是否仍在 Ubuntu 中运行。然后看 Microsoft 的WSL 网络页面；这一点还没有用 Aubergine 试过。

下一步

停止、更新和卸载与安装页面上的一样，其他一切都在 README 中。

npm install -g @meatgarden/aubergine
