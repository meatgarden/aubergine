关闭终端后让进程继续运行

你启动了一次构建、一个服务器或一个编程智能体，而关掉窗口就会结束它。在 Aubergine 里，关掉窗口不会结束任何东西：每个终端都独立于浏览器运行，你回来时它输出过的内容都还在。

通常的做法

关闭终端窗口会结束其中的 shell，以及这个 shell 启动的东西。绕开这一点的标准办法有：

  • nohup 启动的命令会忽略终端关闭时发出的挂断信号。它的输出会写进一个文件（除非你指定别处，否则是 nohup.out）。
  • disown（bash 和 zsh 中）会放开一个已经启动的作业，这样 shell 就不会把挂断信号传给它。之后你就无法在终端里回到它了。
  • screen 和 tmux 在它们自己的服务器里运行 shell。你可以分离、关掉窗口，之后再重新连接到同一个 shell，输出也都在。它们是可靠的答案，但要用它们就得学它们的按键和命令。

Aubergine 就建立在最后这一种之上。它替你运行 tmux，所以你不用学按键就能得到它的答案。

Aubergine 做什么

Aubergine 中的每个终端都是一个 shell，位于它自己的 tmux 会话中，在 Aubergine 专用的 tmux 套接字上。tmux 独立于浏览器和 Aubergine 的服务器运行，所以：

  • 关掉标签页、窗口或整个浏览器，什么都不会结束。重新打开页面（aubergine open 会以登录状态打开），每个终端都会按 tmux 中的当前状态绘制，期间输出的内容都在它的回滚记录里。
  • 停止 Aubergine 也不会结束任何东西。在运行 aubergine start 的地方按 Ctrl+C、服务器崩溃或更新，停止的都只是服务器。再启动它并重新加载页面即可。
  • 在画布上关闭终端会把它停放起来。标题里的 × 把它从画布上拿走，它的 shell 继续运行。画布上方工具栏中的 Parked（已停放）列出停放的终端，Restore（恢复）可以把一个拿回来。
  • 彻底结束一个 shell 之前会先问你。停放列表中的 End（结束）只有在你确认之后才会结束终端。
  • 关掉它的其他视图也不会结束任何东西。终端标题中的 Tab ↗ 会在一个浏览器标签页中单独打开它，aubergine attach <name> 会在你的终端应用窗口中显示它。它们都是同一个终端，不是副本；关掉那个标签页或窗口，它照样运行。

shell 运行期间，tmux 会保留它最后输出的 50,000 行。在占着键盘的终端里，滚轮可以往回翻看这些内容，命令面板（⌘K）可以搜索它们。

它不做什么

  • 它撑不过电脑重启。重启、电脑崩溃或需要重启的更新，会结束所有 shell 以及其中运行的东西。Aubergine 会把它们周围的一切带回来，每个终端都成为位于最后所在文件夹的新 shell，但不会自行重新启动任何东西。参见重启之后保留你的终端。
  • 它不会让电脑保持唤醒。笔记本睡眠时，程序会暂停，这里的终端也不例外；醒来后它们会继续。
  • 它不是服务管理器。必须在重启后自己恢复的任务，应当交给你系统的服务。
  • 它无法接管已经在别处运行的程序。没有任何工具能把正在运行的程序搬进另一个终端。在终端应用的标签页里运行 aubergine here，会在画布上为那个文件夹创建一个终端；标签页里正在运行的程序留在原处，需要在新终端中重新启动。

通过 SSH 在另一台机器上

Aubergine 运行在你自己的电脑上：它的服务器监听 127.0.0.1，它的终端是那台电脑上的 shell。如果你想保住的是一台通过 SSH 连接的远程服务器上的进程，答案仍然是在那台服务器上用 tmux 或 screen。

Aubergine 本身也可以运行在另一台机器上，并通过 SSH 隧道、私有网络，或一个域名加代理从你的浏览器使用：步骤见 Using Aubergine from elsewhere。使用 SSH 隧道时，关掉运行 aubergine start 的 SSH 窗口会停止服务器，而终端会继续运行。Linux 只在容器中运行过，从未在云服务器上运行。

常见问题

关闭浏览器会停止我的终端吗？

不会。每个终端都是 tmux 中的一个 shell，独立于浏览器运行。关掉标签页、窗口或浏览器，再重新打开页面，每个终端都是当前的样子，仍在运行，期间输出的内容也都在。

SSH 断开后如何让进程继续运行？

在远程机器上，把它放在 tmux 或 screen 里启动，或者用 nohup。Aubergine 只保留它所运行的那台电脑上的终端。它也可以运行在远程机器上，通过 SSH 隧道或代理来用，但这只在容器中运行过，从未在云服务器上运行。

该用 nohup 还是 tmux？

nohup 适合输出可以写进文件的单条命令。tmux 适合你想回去继续输入的 shell。Aubergine 给每个终端的都是后者，放在浏览器页面里，不用 tmux 的按键。

关闭终端后还能看到输出吗？

能，只要 shell 还在运行：tmux 为每个终端保留最后 50,000 行，你回来时页面会显示它们。Aubergine 自己不记录任何东西，所以电脑重启后那些输出就没了。

重启之后它还会继续运行吗？

不会。电脑重启会结束所有程序。Aubergine 会把每个终端带回来，成为位于最后所在文件夹的新 shell，保留位置、名称和笔记，但不会重新运行任何东西。
