Aubergine vs Warp

Warp 是一个完整的终端应用，有自己的智能体、套餐和云，也能在标签页和窗格中运行其他命令行智能体。Aubergine 的范围更窄：它不调用模型，也不取代任何终端应用。它在浏览器页面里把你已经在用的智能体并排运行，并让它们保持运行。

信息来源。这里关于 Warp 的内容来自它的文档和它的定价页面，阅读时间为 2026 年 11 月 26 日，并且只涉及运行多个编程智能体这一点；Warp 还能做很多别的事。我们没有为此运行过 Warp。如果有错误或已过时，请告诉我们。

选哪个

选 Warp：如果你想要一个包揽一切的终端应用，在 Windows 和 Linux 上也能用，内置自己的智能体，还有可以安排计划的云端智能体。

选 Aubergine：如果你已经有喜欢的终端和智能体，只想补上它们之间缺的东西：全部尽收眼底，保持运行，没有账号，自己也没有模型。

Warp 是什么

按它自己的描述，是一个智能体式开发环境：一个支持 macOS、Windows 和 Linux 的桌面终端，客户端在 AGPL-3.0 下开源。它有自己的 Warp Agent，通过 Warp 或用你自己的密钥调用模型；它还能在标签页和窗格中运行其他命令行智能体，例如 Claude Code、Codex 和 Gemini CLI，并有一个列出所有活动智能体的面板、通知、一个代码审阅面板，以及按计划运行的云端智能体。

不同之处

自带模型，还是没有模型。Warp 有自己的智能体，用套餐为其使用付费，也可以选择用你自己的密钥。Aubergine 不调用模型，也不持有密钥：它终端里的智能体就是你自己安装并登录的那些。

关掉它会结束什么。Warp 的文档说它会恢复窗口、标签页、窗格和最近的输出；我们没有找到说明正在运行的程序会被保留的内容。在 Aubergine 中，每个终端都是一个 tmux 会话，所以浏览器或 Aubergine 本身停下时，智能体仍会继续。

从哪里能访问你的智能体。Warp 会把正在运行的会话发布到它的云，让你可以从手机或浏览器操控它。Aubergine 没有云：另一台设备是一个用代码配对的浏览器，经过你在自己机器上运行的代理，只在一台 Mac 上试过一次。

Warp 有而 Aubergine 没有的

  • 文档列出的平台包括 Windows 和 Linux，且是桌面应用。Aubergine 为 macOS 构建。
  • 一个自己的智能体，以及按计划或由其他服务（例如 Slack、Linear 或 GitHub）启动的云端智能体。Aubergine 不从外部启动任何东西，也不会为定时计划访问网络。
  • 终端应用所具备的其他一切：它的命令编辑器、输出块，以及面向不止一种智能体的通知。Aubergine 通过为 Claude Code 构建的钩子看出智能体在等待。

常见问题

Aubergine 是 Warp 的替代品吗？

只针对 Warp 所做的一件事：运行多个命令行编程智能体并看清哪一个需要你。Aubergine 不是终端应用，也没有自己的智能体。你可以继续用 Warp 或任何终端，并用 Aubergine 来管理智能体。

我需要账号或付费套餐吗？

Warp 的文档说使用终端时登录是可选的，它的定价页面列出了一个免费套餐和若干付费套餐。Aubergine 没有账号，也没有套餐。

Warp 是开源的吗？

它的文档说 Warp 的客户端在 AGPL-3.0 下开源。Aubergine 采用 MIT 许可证。

可以同时使用 Warp 和 Aubergine 吗？

可以，和任何终端应用一样。Aubergine 的终端是 tmux 会话，aubergine attach <name> 会在你运行它的那个终端应用窗口中显示其中一个。我们没有在 Warp 中试过。

Aubergine 与 Warp 没有任何关联。Warp 是 Denver Technologies, Inc. 的商标，该公司以 Warp 的名义经营。

五分钟上手

你需要 macOS，以及 tmux 3.2 或更高版本和 Node.js 22 或更高版本。brew install tmux node 可以一次装好两者。

npm install -g @meatgarden/aubergine
