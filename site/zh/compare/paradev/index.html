Aubergine vs Paradev（原名 Superset）

Paradev 是一款桌面应用，2026 年 10 月之前叫 Superset。和 Aubergine 一样，它采用 MIT 许可证，能运行任何命令行智能体，并在 Git worktree 中工作。它是一个带套餐、手机应用和云的应用；Aubergine 是你自己电脑上的一个服务器加上你浏览器里的一个页面，这些都没有。

信息来源。这里关于 Paradev 的内容来自它的文档、它的更新日志和它的仓库，阅读时间为 2026 年 11 月 26 日。我们没有运行过 Paradev。如果有错误或已过时，请告诉我们。

关于名称。它 2026 年 10 月 25 日的更新日志说 Superset 现在改名为 Paradev，账号、工作区、设置和 superset 命令都会沿用。它不是数据工具 Apache Superset。

选哪个

选 Paradev：如果你想要一个桌面应用，为每个任务创建 worktree，并带它走完差异、检查和合并，付费后还有手机应用和云。

选 Aubergine：如果你想让所有部分都在你自己的电脑上免费可用、不需要账号：并排的终端、队列、定时计划，以及从另一台设备使用。

Paradev 是什么

按它自己的描述，是面向 Claude Code、Codex 及任何编程智能体的开源工作区：一个桌面应用，而不是终端应用，智能体在其中以聊天形式或在终端里运行。每个任务都有自己的 worktree、分支和终端；一个侧边栏按项目显示所有会话。它有一个带拉取请求检查和合并功能的差异查看器、一个命令、一个 SDK 和一个 MCP 服务器，付费套餐中还有手机应用、远程访问、云端工作区和自动化。

不同之处

什么是免费的。Paradev 列出一个面向个人的免费套餐，包括本地工作区、应用和命令；自动化、手机应用和远程访问在付费套餐中。Aubergine 没有套餐：它的队列、定时计划和从另一台设备使用，全都在这一个采用 MIT 许可证的程序里，不需要账号。

侧边栏还是画布。Paradev 在带标签页和窗格的侧边栏中显示会话。Aubergine 把终端摆在一张可以平移和缩放的画布上，所以许多终端同时实时可见，旁边还有一份列出全部终端的列表。

终端怎样比窗口活得更久。两者在窗口关闭时都能让智能体继续运行：Paradev 靠它自己的后台守护进程，它的文档说当你完全退出 Paradev 时，所有终端都会结束；Aubergine 靠 tmux，即使 Aubergine 本身停止，tmux 也会继续。两者在电脑重启时都会结束它们。

Paradev 有而 Aubergine 没有的

  • 一个差异查看器，你可以在其中评论和编辑智能体的改动、查看拉取请求的检查并合并。Aubergine 显示改了什么，但从不提交、推送或合并。
  • 一个桌面应用、iOS 和 Android 应用、云端工作区，以及在智能体需要你时的提示音和程序坞徽标。Aubergine 是一个浏览器页面，不播放声音。
  • 由审阅请求、Slack 消息、issue 或 webhook 触发的自动化，以及它安装的钩子，让许多智能体能报告自己的状态。Aubergine 不从外部启动任何东西，并且只对 Claude Code 才能自己看出智能体在等待。

常见问题

Aubergine 是 Paradev（Superset）的替代品吗？

如果是在本地运行多个命令行智能体、每个都在自己的 Git worktree 中，是的，而且所有功能都免费。但它不是一对一的替代：Aubergine 没有桌面或手机应用，没有差异评论，没有拉取请求或合并，也没有云。

Superset 和 Paradev 是同一个东西吗？

是的。它 2026 年 10 月 25 日的更新日志说 Superset 现在改名为 Paradev，它的 README 说命令仍然是 superset。两者都与 Apache Superset 无关。

两者都开源吗？

两者都采用 MIT 许可证。Paradev 还为其手机应用、远程访问、云和自动化出售套餐；Aubergine 什么都不卖。

Paradev 能在 Linux 或 Windows 上运行吗？

它的文档说支持 macOS，另有一个实验性的 Linux 版本，Windows 版本尚未推出。Aubergine 为 macOS 构建，在 Linux 上只在容器里运行过，在 Windows 上只能在 WSL 2 里运行，而这还没有试过。

Aubergine 与 Paradev 及其开发者 Superset Inc. 没有任何关联。Paradev 和 Superset 是他们的名称；他们和 Aubergine 都与 Apache Superset 无关。

五分钟上手

你需要 macOS，以及 tmux 3.2 或更高版本和 Node.js 22 或更高版本。brew install tmux node 可以一次装好两者。

npm install -g @meatgarden/aubergine
