Aubergine vs Conductor

两者都能同时运行多个编程智能体，每个都在自己的 Git worktree 里。Conductor 是一个 Mac 应用，有聊天、差异查看器和云。Aubergine 是你自己电脑上一个免费开源的服务器，在浏览器页面里把普通终端并排显示。

信息来源。这里关于 Conductor 的内容来自它的文档和它的更新日志，阅读时间为 2026 年 11 月 26 日。我们没有运行过 Conductor。如果有错误或已过时，请告诉我们。

Conductor 的现状。2026 年 11 月 4 日，它的更新日志说 Conductor 将加入 Meta 并逐步停止运营；11 月 13 日又说 Conductor 不会关闭。撰写本文时，它网站的部分页面仍显示第一条消息。它现在的情况请看它的更新日志。

选哪个

选 Conductor：如果你想要一个 Mac 应用，把任务从一条提示词一直带到已合并的拉取请求，并有一个云，让工作在你的 Mac 关机时继续。

选 Aubergine：如果你想把智能体当作普通终端，一眼看到全部，窗口关掉后仍在 tmux 里继续运行，不用登录任何东西，而且源码开放。

Conductor 是什么

按它自己的描述，是一个在你的代码库上并行运行多个编程智能体的 Mac 应用。每项工作是一个工作区：一个位于某个分支上的 Git worktree，带有聊天、终端和浏览器标签页。它用你 Mac 上已有的登录来运行 Claude Code、Codex、Cursor 和 OpenCode，并有差异查看器、拉取请求、一个 iOS 应用，以及一个付费的云，智能体在那里的沙箱中运行。

不同之处

终端，而不是聊天。Conductor 把智能体显示为工作区里的一个聊天，旁边有终端模式。Aubergine 显示智能体自己的终端，和它在任何终端应用里运行时一样，并把许多终端摆在一张可以平移和缩放的画布上。

关掉它会结束什么。Conductor 的文档说，关掉应用或关闭 Mac 时本地会话会结束，而云端会话会继续。在 Aubergine 中，每个终端都是一个 tmux 会话：关掉浏览器或停止 Aubergine 不会结束任何东西。两者在电脑重启时都会结束。

不依赖你电脑之外的任何东西。Conductor 的文档提到账号、云、供其手机应用使用的中继，以及使用情况分析。Aubergine 没有账号，也没有自己的服务：服务器监听 127.0.0.1，从另一台设备使用需要经过你自己运行的代理。

Conductor 有而 Aubergine 没有的

  • 一个差异查看器，你可以在里面对某些行发表评论并把评论发回给智能体，然后是拉取请求、检查和合并。Aubergine 显示工作副本中改了什么，但从不提交、推送或合并。
  • 一个云，智能体在你的 Mac 关机时也能在那里继续运行，还有在那里按计划运行的例行任务。Aubergine 的定时计划在你的电脑上触发，并且只在它开着时。
  • 一个 iOS 应用和完成提示音。Aubergine 没有应用，也不播放声音。

常见问题

Aubergine 是 Conductor 的替代品吗？

如果是在你自己的电脑上运行多个命令行智能体，是的：每个智能体在画布上有一个终端，在你需要时还有自己的 Git worktree。但它不是一对一的替代：Aubergine 没有聊天视图，没有拉取请求或合并，没有云，也没有手机应用。

Conductor 是开源的吗？

不是：它的条款称它为专有软件，我们也没有找到公开的仓库。它的文档说本地应用可以免费使用，云端工作区需要付费套餐。Aubergine 采用 MIT 许可证，没有付费套餐。

Conductor 能在 Linux 或 Windows 上运行吗？

它的文档说目前还不支持 Windows 和 Linux。Aubergine 为 macOS 构建，在 Linux 上只在容器里运行过，在 Windows 上只能在 WSL 2 里运行，而这还没有试过。

可以同时使用 Conductor 和 Aubergine 吗？

没有什么阻止你这样做：两者都在同一个仓库的 Git worktree 中工作，各自创建自己的。我们没有把两者放在一起运行过。

Aubergine 与 Conductor 及其开发者没有任何关联。Conductor 是他们产品的名称：它的条款写的是 Melty Labs, Inc.，它的网站写的是 Conductor from Meta。

五分钟上手

你需要 macOS，以及 tmux 3.2 或更高版本和 Node.js 22 或更高版本。brew install tmux node 可以一次装好两者。

npm install -g @meatgarden/aubergine
