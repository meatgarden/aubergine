运行多个编程智能体的工具对比

七个工具，面对同一个场景：不止一个编程智能体在工作，而你在中间。这里把 Aubergine 与 Conductor、Claude Squad、Vibe Kanban、cmux、Warp 和 Paradev 并列对比，每个工具各有一页。

这些页面是怎么写的。这些页面对其他工具的描述，来自该工具自己的网站、文档和仓库，阅读时间为 2026 年 11 月 26 日，每一页都附有链接。我们没有运行过其他工具。它们的文档没有提到的地方，页面只说没有找到相关内容，而不是说该工具做不到。这些工具变化很快：如果这里有错误或已过时，请告诉我们，我们会更正。

每个工具一页

每一页都有两者的完整对比表、它们的不同之处，以及对方有而 Aubergine 没有的东西。

  • Aubergine vs Conductor

    选 Conductor：如果你想要一个 Mac 应用，把任务从一条提示词一直带到已合并的拉取请求，并有一个云，让工作在你的 Mac 关机时继续。

  • Aubergine vs Claude Squad

    选 Claude Squad：如果你整天待在终端里，想在那里有一个小程序，在 worktree 中启动智能体并推送它们的分支，别的都不需要。

  • Aubergine vs Vibe Kanban

    选 Vibe Kanban：如果你习惯用 issue 思考：在看板上规划，把每张卡片交给一个智能体，带评论审阅它的差异，然后合并。

  • Aubergine vs cmux

    选 cmux：如果你想要一个快速的原生 Mac 终端应用，带窗格、应用内浏览器和 macOS 通知，并在它之上用脚本搭建你自己的工作方式。

  • Aubergine vs Warp

    选 Warp：如果你想要一个包揽一切的终端应用，在 Windows 和 Linux 上也能用，内置自己的智能体，还有可以安排计划的云端智能体。

  • Aubergine vs Paradev（原名 Superset）

    选 Paradev：如果你想要一个桌面应用，为每个任务创建 worktree，并带它走完差异、检查和合并，付费后还有手机应用和云。

Aubergine 围绕什么构建

  • 普通的终端。智能体在 Aubergine 里的运行方式，和在任何终端应用里一样。上面没有聊天视图，你和它打印的内容之间没有任何隔层。
  • 全部尽收眼底。终端并排摆在一张可以平移和缩放的画布上，还有一份列表，列出所有终端并用文字写出各自的状态。见找到正确的终端。
  • 关掉窗口不会结束任何东西。每个终端都是一个 tmux 会话，所以浏览器和 Aubergine 本身都可以停下，而你的智能体继续运行。见重启会保留什么。
  • 只在你的电脑上。没有账号，没有云，没有付费套餐，自己也没有模型；服务器监听 127.0.0.1。见安全。
  • 由人来决定。智能体提出的东西等你审阅，工作流中的审批只能由你来做，而一份列表 For you 汇集了所有在等你的事。见队列。

Aubergine 没有的东西

  • 没有桌面应用，也没有手机应用。它是你浏览器里的一个页面。另一台设备可以通过你自己运行的代理来配对；这只在一台 Mac 上运行过一次，从未在真正的手机上试过。
  • 没有拉取请求，也不做合并。它会逐个文件显示工作副本中改了什么，但从不提交、推送、变基或合并。
  • 没有云。智能体运行在 Aubergine 所在的电脑上，定时计划只在电脑开着时触发。
  • 没有声音，也没有推送。通知来自你浏览器里打开的 Aubergine 页面。
  • 为 macOS 构建。在 Linux 上只在容器里运行过；在 Windows 上只能在 WSL 2 里运行，而这还没有试过。
  • 主要为 Claude Code。任何命令行智能体都能在终端里运行，但 Aubergine 自己为智能体做的事（看出它在等待、恢复对话）是为 Claude Code 构建的；其他智能体通过 aubergine 命令来报告。

常见问题

同时运行多个 Claude Code 智能体，最好的工具是什么？

取决于你想在智能体周围有什么。想要一个带差异、拉取请求和合并的 Mac 应用：Conductor 或 Paradev。想要在你已经在用的终端里运行的程序：Claude Squad。想要一块 issue 看板：Vibe Kanban。想要原生 Mac 终端：cmux。想要一个自带智能体和云端智能体的终端：Warp。想要在浏览器页面里并排摆放普通终端、由 tmux 保持运行、不需要账号：Aubergine。

这些工具中哪些是开源的？

截至 2026 年 11 月 26 日的阅读：Aubergine（MIT）、Paradev（MIT）、Vibe Kanban（Apache-2.0）、Claude Squad（AGPL-3.0）、cmux 应用（GPL-3.0-or-later）和 Warp 客户端（AGPL-3.0）。Conductor 的条款称它为专有软件。

这些工具中哪些能在 Linux 或 Windows 上运行？

按它们自己的文档：Warp 支持 macOS、Windows 和 Linux；Vibe Kanban 三者都支持；Claude Squad 支持 macOS 和 Linux，在 Windows 上通过 WSL 使用 tmux；Paradev 支持 macOS，另有一个实验性的 Linux 版本；Conductor 和 cmux 只支持 macOS。Aubergine 为 macOS 构建，在 Linux 上只在容器里运行过，在 Windows 上只能在 WSL 2 里运行，尚未试过。

关掉应用后，哪些工具能让智能体继续运行？

Aubergine 和 Claude Squad 都把每个智能体放在一个 tmux 会话里运行。Paradev 的文档说明有一个后台守护进程，在窗口关闭时保留终端。cmux 只在需要手动开启的 tmux 模式下保留运行中的进程。Conductor 说本地会话随应用一起结束。Warp 恢复的是窗口和最近的输出，而不是正在运行的程序。Conductor、cmux、Warp 和 Paradev 还各自有一个云，智能体可以在那里继续运行。没有一个工具（包括 Aubergine）能让本地智能体在电脑重启后继续运行。

五分钟上手

你需要 macOS，以及 tmux 3.2 或更高版本和 Node.js 22 或更高版本。brew install tmux node 可以一次装好两者。

npm install -g @meatgarden/aubergine
