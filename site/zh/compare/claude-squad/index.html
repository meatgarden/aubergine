Aubergine vs Claude Squad

两者的基础相同：每个智能体在一个 tmux 会话里，每个都有自己的 Git worktree，都免费开源。Claude Squad 是你终端里的一个程序。Aubergine 是你浏览器里的一个页面，终端在那里并排摆开。

信息来源。这里关于 Claude Squad 的内容来自它的仓库和 README，阅读时间为 2026 年 11 月 26 日。我们没有运行过 Claude Squad。如果有错误或已过时，请告诉我们。

选哪个

选 Claude Squad：如果你整天待在终端里，想在那里有一个小程序，在 worktree 中启动智能体并推送它们的分支，别的都不需要。

选 Aubergine：如果你想同时看到多个智能体在工作，知道哪一个在等你，并在它们周围有队列、定时计划和 API。

Claude Squad 是什么

按它自己的描述，是一个终端应用，在彼此分开的工作区中管理多个 Claude Code、Codex、Gemini 及其他本地智能体。你用 cs 启动它：在一个终端窗口里有一份会话列表，带预览和一个差异标签页。每个会话是一个 tmux 会话，位于独立分支上的 Git worktree 中。它需要 tmux 和 gh，采用 AGPL-3.0 许可证。

不同之处

一次一个，还是全部一起。Claude Squad 显示一份列表和你选中会话的预览。Aubergine 在画布上实时绘制每个终端，所以五个智能体就是眼前的五个终端，一份列表用文字写出每个的状态。

谁在等。我们在 Claude Squad 的 README 中没有找到关于提示智能体在等待或已完成的内容。Aubergine 用颜色标出在等待的终端，在顶部统计等待的数量，按一个键就能跳到下一个，并能从打开的页面发出通知。

智能体周围有什么。Aubergine 有带上限的任务队列、定时计划、带有由人审批步骤的工作流、每个终端上的笔记和字段、HTTP API 和 MCP 服务器。Claude Squad 只管会话和它们的分支。

Claude Squad 有而 Aubergine 没有的

  • 它在你已经打开的终端里运行，不需要服务器，也不需要浏览器。它像任何终端程序一样能通过 SSH 使用；从别处使用 Aubergine 则需要隧道或代理。
  • 它会替你提交并推送分支，并通过提交会话的工作来暂停会话。Aubergine 从不提交或推送。
  • 一个实验性模式，会自动接受智能体的提示。Aubergine 从不替你回答智能体。

常见问题

Aubergine 是 Claude Squad 的替代品吗？

是的，用另一种方式做同一件事。两者都把每个智能体放在一个 tmux 会话里运行，并能为每个提供一个位于独立分支上的 Git worktree。Claude Squad 通过你终端里的一个程序来做；Aubergine 通过你浏览器里的一个页面来做，所有终端尽收眼底。

两者都用 tmux 吗？

是的。Claude Squad 把 tmux 列为前提条件，并为每个智能体创建一个 tmux 会话。Aubergine 需要 tmux 3.2 或更高版本，并在它自己的套接字上用它自己的配置运行 tmux，所以你自己的 tmux 不受影响。

Claude Squad 能和 Claude Code 以外的智能体一起用吗？

它的 README 说默认程序是 claude，其他程序（例如 Codex、Gemini 或 Aider）用 -p 指定。Aubergine 能在终端里运行任何命令行程序；它自己为智能体做的事是为 Claude Code 构建的。

两者各采用什么许可证？

Claude Squad 采用 AGPL-3.0，Aubergine 采用 MIT 许可证。两者都免费。

Aubergine 与 Claude Squad 及 Anthropic 没有任何关联。Claude Squad 是 smtg-ai 项目的名称；Claude 是 Anthropic 的商标。

五分钟上手

你需要 macOS，以及 tmux 3.2 或更高版本和 Node.js 22 或更高版本。brew install tmux node 可以一次装好两者。

npm install -g @meatgarden/aubergine
