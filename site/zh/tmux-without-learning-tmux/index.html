不学 tmux 也能用 tmux

tmux 能在窗口关闭后让你的 shell 继续运行。代价是要学前缀键、复制模式和配置文件。Aubergine 替你运行 tmux，你在浏览器页面里像用任何终端一样使用每个终端。

适合谁

适合想要 tmux 带来的东西——关掉窗口后依然存在的 shell——却不想学它的按键和配置的人。如果你已经离不开 tmux，就继续用：Aubergine 不会碰你的 tmux。

通常的做法

学 tmux：每条命令前按前缀键（除非你改过，否则是 Ctrl+B），用 tmux attach 回去，再在 ~/.tmux.conf 里写几行来支持鼠标和剪贴板。或者用 screen，一个同类的更老的工具。下面是各种日常操作在默认的 tmux 中和在 Aubergine 中的做法：

要做的事在 tmux 中在 Aubergine 中
让 shell 继续运行并离开Ctrl+B 然后 d 分离关掉标签页
回到它tmux attach打开页面
往回滚动复制模式，Ctrl+B 然后 [滚轮
复制在复制模式中选择用鼠标选择
粘贴Ctrl+B 然后 ]⌘V 或 Ctrl+Shift+V
同时看多个 shell窗口和窗格在画布上并排摆放终端
给它命名Ctrl+B 然后 ,双击它的标题

Aubergine 做什么

自己的套接字和自己的配置。Aubergine 在它自己的、名为 aubergine 的套接字上启动 tmux，用的是它自己的配置文件而不是你的：没有状态栏，没有前缀键，开启鼠标，50,000 行历史。每个终端是一个 tmux 会话，里面是一个 shell，也就是你的登录 shell。你自己的 tmux、它的会话和你的 ~/.tmux.conf 都不会被改动。

在占着键盘的终端里，滚轮会往回滚动；在画布的其他地方，滚轮用于缩放。

用鼠标选中，松开时就复制到你的剪贴板：tmux 用 OSC 52（终端用于剪贴板的转义序列）把选中的内容交给页面，由页面放进剪贴板。用 ⌘V 粘贴（macOS 之外用 Ctrl+Shift+V）。多行粘贴会加上括号粘贴标记，所以 shell 不会逐行执行它。

拖动来调整大小：在画布上拖动终端的边缘，shell 就会得到新的尺寸。同时在两处打开的终端只有一个尺寸，由你最后输入的那个视图决定。

底层仍然是 tmux。aubergine attach <name> 会在你的终端应用窗口中显示一个终端，终端菜单中的 Open on desktop（在桌面上打开）会替你做这件事（macOS 上用 Terminal 或 iTerm；Linux 上用你设置的命令行）。服务器停止时，tmux -L aubergine ls 和 tmux -L aubergine attach -t <id> 依然能连到每个 shell。

你需要什么

tmux 3.2 或更高版本，由你自己安装：macOS 上用 brew install tmux，Linux 上用系统的软件包。Aubergine 不会安装它，缺少或版本太旧时会显示一个页面说明。使用 zsh 时，终端标题会显示正在运行的命令以及上一条命令的结束情况；其他 shell 也能运行，只是没有这些。

它不是什么

  • 不是远程服务器上的 tmux。Aubergine 的 tmux 运行在它的服务器所在的电脑上。对于你通过 SSH 连接的机器上的 shell，那台机器上的 tmux 仍然是该用的工具。Aubergine 本身可以运行在另一台机器上（Using Aubergine from elsewhere）；这只在容器中运行过。
  • 不显示你自己的 tmux 会话。画布上只有 Aubergine 的终端。aubergine scan 列出这台电脑上 Aubergine 之外打开的交互式 shell，aubergine import 或 aubergine here 会在画布上为其中一个创建同一文件夹中的新终端；旧终端里正在运行的程序留在原处。aubergine shell-hook print 为你的 .zshrc 提供的那几行在 tmux 里不起作用。
  • 没有 tmux 按键，也没有窗格。没有前缀键，你自己的 tmux 键绑定也不适用。终端占着键盘时，每个按键都交给其中的程序，只有少数几个组合键例外，它们是特意挑选的，任何 shell、编辑器或 tmux 都用不到。
  • 不能直接在 Windows 上运行。它需要 tmux 和 Unix shell；在 Windows 上它运行在 WSL 2 里。参见使用 WSL 的 Windows。

常见问题

不学快捷键能用 tmux 吗？

能。Aubergine 运行的 tmux 没有前缀键，也没有状态栏，所以你永远不用输入 tmux 命令：关掉标签页就是离开，打开页面就是回来，用滚轮滚动，选中即复制。

Aubergine 会修改我的 tmux 配置吗？

不会。它在自己的套接字 aubergine 上用自己的配置文件运行 tmux。你的 tmux 服务器、它的会话和你的 ~/.tmux.conf 都保持原样。

如何在 Aubergine 的终端里滚动和复制？

点击终端把键盘交给它，然后用滚轮往回滚动。用鼠标选中文字：松开时它就在你的剪贴板里了。用 ⌘V 粘贴，macOS 之外用 Ctrl+Shift+V。

能从我自己的终端应用连接到 Aubergine 的终端吗？

能：aubergine attach <name>，或终端菜单中的 Open on desktop。两处是同一个终端；在一处输入的内容会显示在另一处。

Aubergine 能取代我 SSH 登录的服务器上的 tmux 吗？

不能直接取代：它的终端在它的服务器所在的机器上。它可以运行在服务器上，再通过 SSH 隧道或代理从你的浏览器使用，但这只在容器中运行过，从未在云服务器上运行。

五分钟上手

你需要 macOS，以及 tmux 3.2 或更高版本和 Node.js 22 或更高版本。brew install tmux node 可以一次装好两者。

npm install -g @meatgarden/aubergine
