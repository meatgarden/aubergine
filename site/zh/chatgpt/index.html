Codex 与 ChatGPT

Codex 是 OpenAI 的命令行编程智能体。它由你自己安装和登录；在 Aubergine 中，它像其他任何程序一样在终端里运行。

尚未试过

还没有人在 Aubergine 中运行过真正的 Codex。本页所说的是 Aubergine 为终端中的任何程序以及为 aubergine 命令所做的事，这部分已构建并经过测试；Codex 本身在其中表现如何还没有人看到过。如果你试了，告诉我们结果。

启动它

用 New terminal（新建终端）或 N 打开一个终端，然后像在任何终端里一样启动 Codex。Aubergine 不调用模型，也不持有密钥：Codex 需要的东西，你在登录时已经给了它。

今天能用的

Aubergine 为任何终端所做的一切：

  • 并排摆放

    一张画布上想放多少终端就放多少，画布以标签页的形式呈现。

  • 命令状态

    使用 zsh 时，终端标题会显示有命令正在运行，以及是哪条命令。

  • 颜色、笔记和字段

    给它的终端设一个颜色，保留一份带摘要和日志的笔记，以及工单或负责人之类的字段。

  • 停放

    × 会停放终端：它离开画布但继续运行，Parked 可以把它拿回来。

  • 单独打开一个终端

    在单独的浏览器标签页中打开终端，旁边是它的详情和笔记。

  • 工作副本

    Shell in a folder or a working copy… 或 aubergine new --copy 会在独立检出、独立分支中启动终端，两个智能体永远不会编辑同一批文件。

  • 搜索输出

    ⌘K 搜索所有终端打印过的内容，并打开该终端，滚动到匹配处。

它能通过命令告诉你什么

每个 Aubergine 终端都有 aubergine 命令和一个仅属于该终端的凭据。其中的任何程序，包括 Codex，都可以使用它们：

  • aubergine attention waiting "…"

    把终端标为 waiting for you（在等你），并附上它需要什么；aubergine attention working 和 aubergine attention done 表示其余状态。

  • aubergine note "…"

    向终端的笔记日志添加一行。

  • aubergine describe

    按工作内容给终端命名并保持摘要；aubergine link add 和 aubergine field set 添加这项工作的链接和字段。你自己写的内容优先。

  • aubergine workflow status

    读取工作流的当前步骤；aubergine workflow done 报告完成并打印下一步。

  • aubergine task add

    向队列提议一个任务，aubergine ask 请你做一件只有人能做的事。两者都会在你的列表上等待。

怎样告诉它

在被告知之前，Codex 不知道 Aubergine 的存在。下面这条命令会打印五行，粘贴到你的智能体在项目中每次对话开始时读取的指令里；放在哪里，请看它自己的文档：

aubergine guide --snippet

这几行告诉它：在 Aubergine 终端中时运行一次 aubergine guide，其余的由指南说明。Aubergine 只打印这几行，从不把它们写进任何文件。

如果你的智能体能启动 MCP 服务器，aubergine mcp 会以工具的形式提供同样的功能；在 Aubergine 终端内，处理该终端自己的工作不需要地址，也不需要令牌。

目前只为 Claude Code 构建的部分

Aubergine 为智能体自动做的事是为 Claude Code 构建的。对于 Codex，目前：

  • 它不在 New terminal 菜单中：你需要自己在终端里启动它。
  • Aubergine 不会把它视为智能体：它不会自动被标为等待或已完成，只有在它运行 aubergine attention 时才会。
  • 不会替它输入任何内容：在它的终端上启动的工作流不会输入任何东西，而是显示一行让你自己交给它；回顾或消息也不会通知它。
  • 队列不会给它任务：任务只交给能看到智能体且它空闲的终端。
  • 没有 Resume agent，没有过去对话的列表，没有配置清单，也没有 Aubergine 工具的对话框。
  • aubergine move 和 aubergine here --claude 只能搬来 Claude Code。
  • 它不会被提醒给终端命名或保持摘要。

全部内容见 Claude Code 页面。

浏览器中的 ChatGPT

浏览器标签页中的 ChatGPT 是一个网页，不是终端里的程序，所以不能在画布上运行。

Aubergine 与 OpenAI 没有关联。Codex 和 ChatGPT 是 OpenAI 的商标。

五分钟上手

你需要 macOS，以及 tmux 3.2 或更高版本和 Node.js 22 或更高版本。brew install tmux node 可以一次装好两者。

npm install -g @meatgarden/aubergine
