知道 Claude Code 何时完成或在等你

你给 Claude Code 布置了一个任务，转头去忙别的，二十分钟后回来，才发现它从第二分钟起就在等你说一声“是”。Aubergine 在一个页面上显示哪个终端在工作、哪个在等你、哪个已经完成。

通常的做法

Claude Code 会在某些时刻运行钩子，也就是你自己的命令，比如它停下时（Stop）或发送通知时（Notification）。通常的答案是在你的 Claude Code 设置里写一个播放声音或显示桌面通知的钩子。这样可行，只是脚本要你自己写、自己维护。

Aubergine 做什么

从 Aubergine 启动 Claude Code：终端列表顶部的 New terminal ▾ → Claude Code，或按 C。Aubergine 会用它在自己数据文件夹中生成、并在命令行中指定的一个设置文件来启动 claude。你自己的 Claude Code 配置不会被改动。那个文件里的钩子会告诉页面智能体在做什么：

  • 你发送提示词时，终端显示 working（工作中），提示词会加入它的笔记日志；
  • 智能体需要你时（权限询问，或空闲等待输入），它的边框变成等待的颜色，标题和列表中的行显示 waiting for you（在等你）；
  • 它停下时，终端显示 finished（已完成）。

页面右上角 For you 旁边的数字是所有项目中在等你的一切：有问题的终端，以及待审批的运行、待阅读的草稿和被提议的任务。点它会打开 Runs，其中的 Waiting for you 列就是这份清单。画布的标签页会显示其中有多少个终端在等待。

下一个在等待的。没有终端占用键盘时，W 会跳到下一个在等你的终端；在 macOS 上，⌃⌘J 在终端里也能做到。在其他系统上，它在命令面板中。

打开的页面发出的通知。Settings → Notifications 中有 Notify me on the desktop when a terminal starts waiting（终端开始等待时在桌面上通知我）。打开后，当终端开始等待或其智能体完成时，只要你没在看那个终端，页面就会显示一条浏览器通知。浏览器只会请求一次你的许可。

规则。在 Runs 的 Rules 标签页上，可以设一条规则，在任务完成、任务失败、任务需要你、有事要问你，或定时计划触发或无法运行时 Notify me（通知我）：由打开的页面发出通知，用一句话说明发生了什么。

其他智能体，以及你自己输入的 claude

Aubergine 不会读终端输出去猜测。任何其他智能体或程序，都可以在自己的终端里用 aubergine attention waiting "what it needs"、aubergine attention working 和 aubergine attention done 自己说出同样的状态。aubergine guide --snippet 会打印五行内容，放进你的智能体在对话开始时读取的文件；这几行让它运行 aubergine guide，由后者说明这些命令。

在普通终端里输入 claude 启动的 Claude Code，在 Aubergine 看来只是一个忙着运行程序的 shell：不会显示 waiting for you。请改为从菜单启动，或者把 aubergine hooks print 打印出的钩子手动加到你自己的设置中；它们在 Aubergine 终端之外不起任何作用。

它不做什么

  • 没有自己的声音。Aubergine 不播放任何声音。只有你的浏览器或系统为通知设置了声音时，通知才会响。
  • 没有打开的页面时什么都没有。通知来自你浏览器中打开的 Aubergine 页面；服务器自己不会发送任何通知。所有页面都关掉时，终端仍然显示 waiting for you，你打开页面时计数就在那里。
  • 不会推送到手机。没有应用，也没有推送服务。可以把手机的浏览器配对来打开同一个页面；见用手机查看你的智能体，不过还没有在真正的手机上试过。
  • 检查过什么。浏览器测试是拿浏览器自带通知的替身来检查通知的。真正的通知长什么样，甚至会不会显示，取决于你的浏览器以及系统中对它的设置。

常见问题

Claude Code 完成时如何收到通知？

从 Aubergine 启动 Claude Code，然后在 Settings → Notifications 中打开 Notify me on the desktop when a terminal starts waiting。之后，当终端开始等你或其智能体完成时，打开的页面会显示一条浏览器通知。没有通知时，终端也会显示 finished。

Claude Code 需要输入时能播放声音吗？

Aubergine 不播放声音。如果你的浏览器或系统让通知发声，通知就会响。在你的 Claude Code 设置里写一个你自己的钩子可以播放声音；Aubergine 从不写入那些设置。

同时运行多个时，如何看出哪个 Claude Code 会话在等待？

在 Aubergine 中，等待中的终端的边框和状态是等待的颜色，它在列表中的行显示 waiting for you，For you 旁边的数字说明有多少事在等待。W 跳到下一个。

浏览器关闭时会收到通知吗？

不会。通知来自打开的 Aubergine 页面。状态会被保存，所以你重新打开页面时，在等待的终端会被标出来。

它支持 Claude Code 以外的智能体吗？

不会自动支持：钩子是为 Claude Code 构建的。任何其他智能体，只要它自己的指令要求，都可以用 aubergine attention waiting、working 和 done 报告同样的状态；aubergine guide --snippet 会打印用于这些指令的几行。
