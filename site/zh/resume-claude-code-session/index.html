重启后恢复 Claude Code 对话

电脑重启了，或者你关掉了终端，Claude Code 的对话看起来没了。其实 Claude Code 保存着它。Aubergine 记得每个终端处于哪个对话，一个按钮就能把它找回来。

通常的做法

在终端中，进入对话所在的文件夹：claude --continue 接着那里最近的一次对话，claude --resume 让你从列表里选一个，或者接受一个对话 ID。麻烦在于文件夹和选择：一个文件夹里有好几个智能体时，最近的那次不一定是你想要的。

Aubergine 做什么

终端记得自己的对话。从 Aubergine 启动 Claude Code 时（New terminal ▾ → Claude Code，或按 C），它的钩子会告诉 Aubergine 它处于哪个对话，Aubergine 会把这个 ID 和终端一起保存。

一旦终端的 shell 回到提示符，标题栏就会提供 Resume agent（恢复智能体）：可能是你退出了智能体，也可能是电脑重启后终端作为位于最后所在文件夹的新 shell 回来了。它会带上 --resume 和那个 ID 再次启动 Claude Code，使用你设置中的启动命令（agents.claudeCommand，默认是 claude）。

在工作流的运行中，Resume agent 还会再次把这次运行告诉智能体，让它从运行所在的步骤继续。

Past conversations…（过去的对话，在命令面板 ⌘K 中），或终端详情中的“Past conversations in this folder…”，会列出某个文件夹里 Claude Code 以前的对话：名称或你说的第一句话、最后活跃的时间、你说了几次话，以及画布上现在是否有终端正处于这个对话。Read 以只读方式显示它。Open on the canvas 在那个文件夹中启动一个新终端并恢复这个对话，Open a copy 则开出它的一个分支，原件保持不变。如果已有终端处于这个对话，会先问你。

搜索。在命令面板中输入 @ 和一些词，可以搜索你画布上各终端所在文件夹里的过去对话。它在你要求时、在限定范围内读取记录，被截断时会说明。在命令行中，aubergine history 列出它们，aubergine history open <id> 打开其中一个。

它进行到哪里。终端的笔记保存着它的摘要和日志，你发送的每条提示词都会加入日志。详情中的 Ask its agent for a recap（请它的智能体写回顾）会让智能体用 aubergine recap --write 写下现状，并和终端一起保存。离开超过 30 分钟后回来，While you were away（你不在时）会列出这期间发生的变化。

Aubergine 之外的终端里的对话

在终端应用的标签页里退出智能体，然后在同一个文件夹中运行 aubergine here --claude：画布上的一个新终端会用 --continue 启动 Claude Code，这次会显示它的状态。aubergine move 会列出你的 Claude Code 标签页，并在画布上为每个对话启动一个副本；加上 --stop，它会在你确认后先请空闲的智能体退出。

它不做什么

  • 它读取的是 Claude Code 自己的记录，格式不属于 Aubergine。Claude Code 称这些文件的格式为内部格式，并且会随版本变化。恢复时用的是 Claude Code 自己的 --resume 加上 ID；名称、次数和对话记录是 Aubergine 对这些文件的解读，Claude Code 更新后可能缺失或变得不完整。读不了的记录会明确说读不了，不会显示成空对话。
  • 不复制，也不保留任何东西。列表、对话记录或搜索都是在你要求时读取，关闭时丢弃。Aubergine 从不修改、重命名或删除对话，任何智能体或令牌都无法通过它读取对话。
  • 进行中的工作不会重做。智能体停下时正在做的事，在你要求之前不会重新开始。
  • 其他智能体没有 Resume agent。Aubergine 不知道其他智能体的对话，也不会列出它们过去的对话。请在同一个终端里用那个智能体自己的恢复方式重新启动它，并读一读笔记，告诉它进行到哪里了。
  • 你自己输入的 claude 不会被记住，除非你把 aubergine hooks print 打印出的钩子加到了你自己的 Claude Code 设置中。
  • 检查过什么。对话记录的读取是拿虚构的记录测试的。没有对照 Claude Code 的每个版本检查过。

常见问题

关闭终端后如何恢复 Claude Code 会话？

在同一个文件夹中，claude --continue 接着最近的一次对话，claude --resume 让你来选。在 Aubergine 中，关掉浏览器不会结束任何东西；你退出了智能体的终端会在标题栏提供 Resume agent。

重启后如何恢复 Claude Code 对话？

重启后，每个 Aubergine 终端都会作为位于最后所在文件夹的新 shell 回来。如果 Claude Code 是从 Aubergine 启动的，标题栏中的 Resume agent 会在那个终端原来的对话中再次启动它。

如何找到以前的 Claude Code 对话？

命令面板中的 Past conversations… 按文件夹列出它们，并提供只读的对话记录；在命令面板中输入 @ 和一些词可以搜索它们。只会列出 Claude Code 仍然保存着的内容。

claude --continue 和 claude --resume 有什么区别？

--continue 接着文件夹中最近的一次对话；--resume 接受你选的那个，或一个 ID。Resume agent 用的是 --resume 加终端记住的 ID，所以不取决于哪个对话最近。

两个终端能接着同一个 Claude Code 对话吗？

Aubergine 不会不问就把一个对话打开两次：一个对话里有两个智能体，会丢失彼此的消息。你可以选择已经处于这个对话的终端，或者开一个副本，让对话分支。

npm install -g @meatgarden/aubergine
