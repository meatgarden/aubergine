O que o Aubergine faz pelo Claude Code

O Claude Code roda em um terminal do Aubergine como qualquer programa. Iniciado pelo Aubergine, ele também diz ao canvas o que está fazendo, e o Aubergine pode passar instruções a ele, retomá-lo e mostrar como ele está configurado. Isto é tudo, na ordem em que você encontra.

Você mesmo instala o Claude Code e faz login nele. O Aubergine não chama nenhum modelo e não guarda nenhuma chave: ele inicia o comando claude que você já tem.

  1. Inicie pelo menu

    New terminal ▾ → Claude Code, ou C enquanto nenhum terminal está com o teclado, inicia claude em um terminal novo com um arquivo de configurações que o Aubergine escreve na própria pasta de dados. A sua configuração do Claude Code não é tocada.

    O comando que ele inicia é agents.claudeCommand nas configurações, claude a menos que você mude; o Aubergine adiciona as próprias flags no final.

    Onde: o menu ao lado de New terminal, no topo da lista de terminais.

  2. Veja quando ele trabalha, espera e termina

    Os hooks desse arquivo de configurações dizem ao canvas o que o agente está fazendo. Quando você envia um prompt, ele é adicionado ao log de notas do terminal e o terminal mostra working (trabalhando). Quando o agente precisa de você, com uma pergunta de permissão ou porque está ocioso esperando uma entrada, a borda dele ganha a cor da espera e o título e a linha dele dizem waiting for you (esperando por você). Quando ele para, mostra finished (terminado).

    W vai para o próximo terminal que espera, e Notify liga as notificações na área de trabalho para os terminais que começam a esperar. Prompts podem conter segredos: "agents": { "logPrompts": false } em config.json os deixa fora do log de notas.

    Onde: o título do terminal, a linha dele na lista e o contador ao lado de For you, no topo.

  3. Um Claude Code que você mesmo iniciou

    Digitado à mão em um terminal comum, claude funciona como qualquer programa, mas o Aubergine só vê um shell ocupado rodando-o: nada de waiting for you, e nada é digitado para ele quando você inicia um fluxo de trabalho ali. Para mudar isso, imprima os hooks e adicione-os à mão às suas próprias configurações do Claude Code. Fora de um terminal do Aubergine eles não fazem nada.

    aubergine hooks print

  4. Ele se dá um nome e mantém um resumo

    Um agente que o Aubergine inicia é instruído, quando começa, a dar ao terminal o nome do trabalho e manter um resumo, com aubergine describe, aubergine link add e aubergine field set, e é lembrado uma vez quando para sem nome próprio ou sem resumo. O que você mesmo escreve prevalece; o que o agente diz sobre a mesma coisa espera ao lado com Use this (usar este). O lembrete pode ser desligado em Settings.

    Onde: os detalhes do terminal, com nome, resumo, campos e links.

  5. Fluxos de trabalho, tarefas, resumos e mensagens chegam até ele

    O Aubergine digita quatro frases fixas em um terminal, e só elas: que um fluxo de trabalho foi iniciado, que pediram ao agente para escrever algo, que você pediu um resumo e que há uma mensagem esperando. Cada uma nomeia um comando para o agente rodar. Uma frase só é digitada onde se vê que um agente está com o teclado: um que o Aubergine iniciou, ou um cujas configurações têm os hooks de aubergine hooks print.

    Da mesma forma, uma tarefa da fila só vai para um terminal onde um agente assim está na frente e livre, e Claude Code on a workflow… inicia um terminal novo cujo agente fica sabendo da execução no primeiro prompt.

    Onde: Run a workflow… no menu do título de um terminal, e Runs no topo da página.

  6. Resume agent

    O Aubergine lembra em qual conversa um terminal de agente estava. Quando o shell dele volta a um prompt, porque você saiu do agente ou o computador reiniciou, o terminal oferece Resume agent (retomar o agente), que inicia o agente de novo naquela conversa. Em um terminal que está em uma execução, ele também conta ao agente sobre a execução de novo.

    Onde: a barra de título do terminal.

  7. Conversas anteriores

    Past conversations… lista as conversas anteriores do agente em uma pasta: leia uma, abra-a no canvas ou abra uma cópia que deixa o original como está. Digite @ e algumas palavras na paleta para pesquisá-las; aubergine history as lista na linha de comando. Nada do que é lido é guardado, e nenhum token e nenhum agente pode ler conversas através do Aubergine.

    Ele lê os arquivos que o Claude Code mantém. O formato deles é interno do Claude Code e muda entre versões. Depois de uma atualização do agente, nomes e transcrições podem vir mais pobres, e um registro que o Aubergine não consegue ler é indicado como tal, nunca mostrado como vazio.

    Onde: a paleta (⌘K), e “Past conversations in this folder…” nos detalhes de um terminal.

  8. Como ele está configurado

    Uma lista do que os arquivos de configuração do agente dizem que ele recebeu: servidores MCP, plugins, hooks, skills, regras de permissão e arquivos de configurações, cada um com sua origem, e o que o Aubergine adicionou. Só nomes, nunca um valor ou um segredo. Ela diz como o agente está configurado, não o que o agente em execução carregou, e diz claramente o que não tem como saber, como os conectores que vêm com a sua conta.

    Onde: ⚙ on no terminal, “What is switched on for this agent…” na paleta, e os detalhes do terminal.

  9. As ferramentas do Aubergine para ele

    Claude Code with Aubergine tools… pergunta primeiro o que o agente pode fazer: None (nada); Its own work only (só o próprio trabalho), com a credencial do próprio terminal; ou More… (mais), escopos que você escolhe, para os quais é criado um token só para aquele terminal, revogado quando o terminal é encerrado de vez. As ferramentas são aubergine mcp, passado ao agente na linha de inicialização; a configuração dele não é escrita.

    Onde: o menu ao lado de New terminal.

  10. Traga um Claude Code que você já tem aberto

    Um agente em execução não pode ser movido, mas a conversa dele pode. Open elsewhere (abertos em outro lugar) lista as suas abas do Claude Code, com Fork to canvas (bifurcar para o canvas) e, para um agente ocioso, Stop and resume here (parar e retomar aqui), que pergunta antes. De um terminal, aubergine move faz o mesmo, e aubergine here --claude inicia o Claude Code no canvas continuando a última conversa daquela pasta.

    Onde: Open elsewhere na barra sobre o canvas, ou O.

  11. Em uma cópia de trabalho só dele

    aubergine here --copy --claude inicia o Claude Code no próprio checkout do repositório, no próprio branch, para que dois agentes nunca editem os mesmos arquivos. A caixa de diálogo de um terminal do Claude Code com ferramentas tem a mesma opção.

O que já foi testado

A demo que vem com o Aubergine usa agentes simulados, scripts curtos que rodam os mesmos comandos e hooks que um agente de verdade, não um Claude Code de verdade. Com um agente de verdade, ainda não foram testados uma aprovação, uma cópia de trabalho, uma tarefa da fila e um agendamento.

Outro agente pode dizer quase tudo isso pelos comandos aubergine: veja Codex e ChatGPT.

O Aubergine não é afiliado à Anthropic. Claude e Claude Code são marcas registradas da Anthropic.

Funcionando em cinco minutos

Você precisa de macOS com tmux 3.2 ou mais recente e Node.js 22 ou mais recente. brew install tmux node instala os dois.

npm install -g @meatgarden/aubergine
