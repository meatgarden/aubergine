Guias

Guias curtos e práticos. A referência completa é o README.

  • Instalar o Aubergine

    Requisitos, o instalador de uma linha, o que ele muda e soluções para problemas comuns.

  • Instalar no Windows com WSL

    Rode o Aubergine dentro do WSL 2 e use-o pelo navegador do Windows. Os passos de Linux foram executados; nada foi testado no Windows ainda.

  • Rodar vários agentes de programação ao mesmo tempo

    O canvas, o contador de espera, a fila, as cópias de trabalho e os fluxos de trabalho em um só tour.

  • Claude Code no Aubergine

    O que o Aubergine faz sozinho pelo Claude Code, e onde fica cada coisa.

  • Codex e ChatGPT

    O Codex em um terminal como qualquer programa, o que ele pode informar e o que é feito só para o Claude Code.

  • Cópias de trabalho

    Dê a cada agente seu próprio checkout e branch para que dois agentes nunca editem os mesmos arquivos.

  • Mantenha seus terminais depois de reiniciar

    O que fechar o navegador, reiniciar o Aubergine e reiniciar o computador mantêm, e como retomar de onde você parou.

  • Mantenha um processo rodando depois de fechar o terminal

    Feche a aba, a janela ou o navegador e nada termina: o que o tmux oferece, sem aprender tmux.

  • tmux sem aprender tmux

    Shells que sobrevivem à janela, sem tecla de prefixo e sem configuração, e o seu próprio tmux intocado.

  • Saiba quando o Claude Code terminou ou está esperando

    Trabalhando, esperando por você e terminado em todo terminal, o contador de For you, a tecla para o próximo que espera e notificações na página aberta.

  • Retome uma conversa do Claude Code

    Resume agent no terminal em que ele rodava, as conversas anteriores de uma pasta e o que mostra onde ele parou.

  • Ache o terminal certo quando você tem terminais demais

    Um canvas, uma única lista de todos os terminais com o estado em palavras, filtros, tags e busca no que os terminais imprimiram.

  • Personalize temas, cores, fontes e teclas

    Dez temas de cores, um tema para cada terminal, cores à mão, a fonte e o cursor do terminal, todas as teclas, e como outras ferramentas deixam você personalizar as delas.

  • Acompanhe seus agentes pelo celular

    Acessar o Aubergine de outro dispositivo, cada um pareado com um código. Executado uma vez em um Mac; não testado em um celular de verdade.

  • A fila, For you e os agendamentos

    Distribua o trabalho uma vez, veja tudo o que espera por você e rode tarefas em horários definidos.

  • O Aubergine comparado com outras ferramentas

    Conductor, Claude Squad, Vibe Kanban, cmux, Warp e Paradev ao lado do Aubergine, a partir do que cada um documenta sobre si mesmo.

  • Segurança e privacidade

    O que está protegido e o que não está.

  • Perguntas frequentes

    Respostas curtas para perguntas comuns.

Funcionando em cinco minutos

Você precisa de macOS com tmux 3.2 ou mais recente e Node.js 22 ou mais recente. brew install tmux node instala os dois.

npm install -g @meatgarden/aubergine
