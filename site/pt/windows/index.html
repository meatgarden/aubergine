Instalar o Aubergine no Windows com WSL

O Aubergine não roda no próprio Windows. Ele roda dentro do WSL 2, o Linux que o Windows oferece, e você o usa pelo navegador do Windows.

O que foi testado. Os passos de Linux foram executados em 25 de novembro de 2026 no Ubuntu 24.04.5 (x86_64) em um contêiner, não no WSL, com o Aubergine 0.2.2 do npm: ele compilou sua biblioteca de terminal, iniciou, fez login em um navegador e rodou um terminal e a demo. A instalação do Node.js com nvm não foi executada lá, pois o Node.js 22 já estava instalado. Nada nesta página foi executado no Windows ainda. Se você testar, conte para a gente como foi.

Do que você precisa

Windows 11, ou Windows 10 versão 2004 (build 19041) ou mais recente, em que o WSL 2 se instala com um único comando. A página da Microsoft sobre como instalar o WSL tem os detalhes.

Instalar e iniciar

  1. Instale o WSL. Abra o PowerShell como administrador, rode isto e reinicie o Windows quando terminar. Ele instala o WSL 2 com Ubuntu.

    wsl --install

    Depois de reiniciar, abra o Ubuntu pelo menu Iniciar e escolha um nome de usuário e uma senha para ele. Todos os comandos abaixo são digitados lá, no Ubuntu.

  2. Instale o que o Aubergine precisa: tmux, zsh e Git, e as ferramentas que compilam sua biblioteca de terminal, que não tem nada pronto para Linux.

    sudo apt update

    sudo apt install -y tmux zsh git build-essential python3

    Instale o Node.js 22. O pacote do próprio Ubuntu é a versão 18, antiga demais. Um jeito bem conhecido é o nvm: instale-o, abra uma nova janela do Ubuntu e então instale o Node.js 22.

    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash

    nvm install 22

    node -v agora deve mostrar v22 ou mais recente.

  3. Instale o Aubergine pelo npm. Ele compila sua biblioteca de terminal durante a instalação; no teste, a instalação inteira levou 13 segundos.

    npm install -g @meatgarden/aubergine

  4. Inicie-o e deixe essa janela aberta:

    aubergine start

    Faça login no navegador. Em uma segunda janela do Ubuntu, mostre o endereço de login e abra-o no seu navegador do Windows. Ele faz login nesse navegador, então trate-o como uma senha.

    aubergine open --print

    Depois disso, http://127.0.0.1:4600 funciona sozinho nesse navegador. Em um canvas vazio, Show me around inicia o tour.

Bom saber

  • Mantenha seus projetos no Ubuntu, na pasta pessoal dele, não em /mnt/c, onde os arquivos do Windows são acessados por uma ponte mais lenta.
  • Instale seus agentes dentro do Ubuntu, Claude Code, Codex ou qualquer outro, como em qualquer Linux. Um agente instalado no Windows não está nos terminais do Aubergine.
  • Os terminais vivem enquanto o WSL estiver rodando. Fechar o navegador não encerra nada, e Ctrl+C na janela do aubergine start para só o servidor. Quando o WSL para, porque o Windows reinicia ou depois de wsl --shutdown, os terminais terminam, e o próximo aubergine start abre shells novos nas últimas pastas deles, como depois de reiniciar um Mac.
  • bash ou zsh. O shell do Ubuntu é o bash, e os terminais funcionam nele. O status dos comandos em um terminal (ocupado, o código de saída de um comando que falhou) vem só do zsh: no teste, um terminal com zsh mostrou exit 3 depois de um comando que falhou. Faça do zsh o seu shell no Ubuntu para ter isso.
  • O que não existe lá: iniciar no login funciona só no macOS (aubergine service install avisa), e Open on desktop não tem configuração para um app de terminal do Windows. O aubergine open não encontrou um navegador para abrir no teste; aubergine open --print sempre funciona.
  • Os atalhos no Windows foram escolhidos pelo que os navegadores documentam e não foram medidos: veja docs/keys.md. A paleta sempre funciona.

Se algo der errado

Rode primeiro aubergine doctor no Ubuntu. Ele verifica Node.js, tmux, Git e o servidor.

O que você vêO que fazer
A instalação do Aubergine falha ao compilar o node-ptyFaltam as ferramentas de compilação. Rode as linhas de apt do passo 2 e instale o Aubergine de novo.
Uma página dizendo que o tmux está faltando ou é antigo demaisO tmux do Ubuntu 24.04 é a versão 3.4, recente o bastante: sudo apt install -y tmux e inicie o servidor de novo.
node -v mostra uma versão anterior à v22Instale o Node.js 22 como no passo 2, abra uma nova janela do Ubuntu e instale o Aubergine de novo.
O endereço não abre no navegador do WindowsVerifique se o aubergine start ainda está rodando no Ubuntu. Depois veja a página da Microsoft sobre rede no WSL; isso não foi testado com o Aubergine.
