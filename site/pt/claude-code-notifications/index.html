Saiba quando o Claude Code terminou ou está esperando por você

Você dá uma tarefa ao Claude Code, vai fazer outra coisa e volta vinte minutos depois para descobrir que ele está esperando um sim desde o minuto dois. O Aubergine mostra em uma só página qual terminal está trabalhando, qual está esperando por você e qual terminou.

O que as pessoas costumam fazer

O Claude Code roda hooks, comandos seus, em momentos como quando ele para (Stop) ou envia uma notificação (Notification). A resposta de sempre é um hook nas suas configurações do Claude Code que toca um som ou mostra uma notificação na área de trabalho. Funciona, e os scripts ficam por sua conta escrever e manter.

O que o Aubergine faz

Inicie o Claude Code pelo Aubergine: New terminal ▾ → Claude Code no topo da lista de terminais, ou C. O Aubergine inicia claude com um arquivo de configurações que ele gera na própria pasta de dados e indica na linha de comando. A sua configuração do Claude Code não é tocada. Os hooks desse arquivo dizem à página o que o agente está fazendo:

  • quando você envia um prompt, o terminal mostra working (trabalhando), e o prompt é adicionado ao registro da nota dele;
  • quando o agente precisa de você (uma pergunta de permissão, ou ele está ocioso esperando uma entrada), a borda dele ganha a cor da espera, e o título e a linha dele na lista dizem waiting for you (esperando por você);
  • quando ele para, o terminal mostra finished (terminado).

O contador ao lado de For you, no canto superior direito da página, é tudo o que espera por você, em todos os projetos: terminais com uma pergunta, e execuções para aprovar, rascunhos para ler e tarefas propostas. Clicar nele abre Runs (execuções), cuja coluna Waiting for you é essa lista. A aba de um canvas mostra quantos terminais dele estão esperando.

O próximo que espera. W vai para o próximo terminal que está esperando por você enquanto nenhum terminal está com o teclado; no macOS, ⌃⌘J faz isso também de dentro de um terminal. Nos outros sistemas, está na paleta.

Notificações da página aberta. Settings → Notifications tem Notify me on the desktop when a terminal starts waiting (me avisar na área de trabalho quando um terminal começar a esperar). Ligado, a página mostra uma notificação do seu navegador quando um terminal começa a esperar ou o agente dele terminou, a menos que você esteja olhando para esse terminal. O navegador pede sua permissão uma vez.

Regras. Na aba Rules (regras) de Runs, uma regra pode Notify me (me avisar) quando uma tarefa foi concluída, uma tarefa falhou, uma tarefa precisa de você, algo é pedido a você, ou um agendamento disparou ou não pôde rodar: uma notificação da página aberta, com uma frase sobre o que aconteceu.

Outros agentes, e um claude que você mesmo digitou

O Aubergine não lê a saída de um terminal para adivinhar. Qualquer outro agente, ou qualquer programa, diz o mesmo sozinho com aubergine attention waiting "what it needs", aubergine attention working e aubergine attention done no seu terminal. aubergine guide --snippet imprime cinco linhas para o arquivo que o seu agente lê no início de uma conversa; elas dizem a ele para rodar aubergine guide, que explica esses comandos.

Um Claude Code que você iniciou digitando claude em um terminal comum é, para o Aubergine, um shell ocupado com um programa: nada de waiting for you. Inicie-o pelo menu, ou adicione à mão, nas suas próprias configurações, os hooks que aubergine hooks print imprime; fora de um terminal do Aubergine eles não fazem nada.

O que ele não faz

  • Nenhum som próprio. O Aubergine não toca nenhum. Uma notificação faz som só se o seu navegador ou o seu sistema fazem isso com notificações.
  • Nada enquanto nenhuma página está aberta. As notificações vêm de uma página do Aubergine aberta no seu navegador; o servidor não envia nenhuma sozinho. Com todas as páginas fechadas, o terminal continua dizendo waiting for you, e o contador está lá quando você abre a página.
  • Nenhum push para o celular. Não há app nem serviço de push. O navegador de um celular pode ser pareado para abrir a mesma página; veja Acompanhe seus agentes pelo celular, que não foi testado em um celular de verdade.
  • O que foi verificado. Os testes de navegador verificam as notificações contra um substituto das notificações do próprio navegador. Como uma notificação real aparece, e se aparece, depende do seu navegador e das configurações do seu sistema para ele.

Perguntas

Como recebo uma notificação quando o Claude Code termina?

Inicie o Claude Code pelo Aubergine e ligue Notify me on the desktop when a terminal starts waiting em Settings → Notifications. A página aberta passa a mostrar uma notificação do navegador quando um terminal começa a esperar por você ou o agente dele terminou. Sem notificação, o terminal diz finished.

O Claude Code pode tocar um som quando precisa de uma entrada?

O Aubergine não toca nenhum som. Uma notificação faz som se o seu navegador ou sistema a fizer soar. Um hook seu nas configurações do Claude Code pode tocar um; o Aubergine nunca escreve nessas configurações.

Como vejo qual sessão do Claude Code está esperando quando rodo várias?

No Aubergine a borda do terminal que espera e o estado dele ficam na cor da espera, a linha dele na lista diz waiting for you, e o contador ao lado de For you diz quantas coisas estão esperando. W vai para a próxima.

Sou avisado quando o navegador está fechado?

Não. As notificações vêm de uma página do Aubergine aberta. O estado é mantido, então os terminais que esperam aparecem marcados quando você abre a página de novo.

Funciona com outros agentes além do Claude Code?

Não sozinho: os hooks são feitos para o Claude Code. Qualquer outro agente pode informar o mesmo com aubergine attention waiting, working e done quando as próprias instruções mandarem; aubergine guide --snippet imprime as linhas para essas instruções.

Funcionando em cinco minutos

Você precisa de macOS com tmux 3.2 ou mais recente e Node.js 22 ou mais recente. brew install tmux node instala os dois.

npm install -g @meatgarden/aubergine
