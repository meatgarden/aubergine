Perguntas frequentes

Respostas curtas. Os guias vão mais fundo.

O que é o Aubergine?

Um canvas local, no navegador, de sessões de terminal. Cada terminal é um nó que você pode organizar e usar, então dá para rodar vários agentes de programação ao mesmo tempo e ver qual está esperando por você.

O Aubergine é grátis e de código aberto?

Sim. Ele é grátis e o código está no GitHub.

Do que eu preciso para rodar o Aubergine?

macOS com tmux 3.2 ou mais recente e Node.js 22 ou mais recente; o instalador também precisa do pnpm. No Linux foi executado só em contêineres. No Windows ele roda só dentro do WSL 2, o que ainda não foi testado: veja o guia para Windows.

Funciona com qualquer agente de programação?

O Aubergine roda terminais comuns, então qualquer agente de linha de comando pode rodar em um deles. O que o Aubergine faz sozinho por um agente, como ver que ele espera, é feito para o Claude Code; qualquer outro agente, o Codex entre eles, pode informar o próprio status pelos comandos aubergine e por uma API local, e pode usar um servidor MCP que lista apenas o que o token dele permite.

O Aubergine envia meus terminais ou meu código para algum lugar?

Não. Tudo roda no seu próprio computador. O servidor escuta apenas em 127.0.0.1.

O Aubergine chama um modelo de IA?

Não. Quem chama são os seus agentes. O Aubergine só roda os terminais deles e os acompanha, e não guarda chave de nenhum modelo.

O que acontece com os meus terminais quando eu fecho o navegador?

Eles continuam rodando. Cada sessão é uma sessão do tmux que sobrevive tanto ao navegador quanto ao servidor do Aubergine.

Como eu sei qual agente está esperando por mim?

Cada terminal mostra se está ocupado, ocioso ou esperando. O contador ao lado de For you, no topo da página, e a lista For you reúnem tudo o que precisa de você.

Como eu evito que dois agentes editem os mesmos arquivos?

Inicie cada terminal na própria cópia de trabalho: o próprio checkout, no próprio branch. O Aubergine nunca faz merge ou push por você.

Posso dar a um agente uma lista de etapas para seguir?

Sim. Um fluxo de trabalho é uma lista ordenada de etapas, com uma faixa que mostra onde o agente está. Uma etapa pode esperar você aprovar ou devolver.

Os agentes podem conversar entre si?

Sim, dentro de limites. As mensagens entre terminais têm remetentes identificados, pausas e bloqueios, e são fechadas por padrão em cada canvas.

Existe uma API?

Sim. Uma API HTTP local com tokens com escopos, um cliente tipado e um servidor MCP que lista apenas as ferramentas que uma credencial pode usar.

Posso abrir um terminal sozinho?

Sim. Tab ↗ no título de um terminal o abre em uma aba do navegador só dele, o mesmo terminal e não uma cópia, com os detalhes e a nota ao lado quando você pede. Fechar a aba não encerra nada.

Posso guardar um ticket ou um responsável junto com um terminal?

Sim. Um terminal tem campos, pares de um rótulo e um valor, nos detalhes dele. O agente que está nele pode definir os próprios com aubergine field set; onde você define o mesmo rótulo, o seu fica.

O Aubergine vai suportar várias pessoas ou agentes na nuvem?

As duas coisas estão planejadas e nenhuma está pronta. Veja o roadmap. Hoje tudo roda em um só computador.

O que o instalador muda no meu computador?

Duas coisas: a pasta de instalação (~/.aubergine) e um link chamado aubergine. Ele nunca usa sudo, nunca edita os arquivos de inicialização do seu shell e nunca instala Node.js, pnpm nem tmux.

Funcionando em cinco minutos

Você precisa de macOS com tmux 3.2 ou mais recente e Node.js 22 ou mais recente. brew install tmux node instala os dois.

npm install -g @meatgarden/aubergine
