Como instalar o Aubergine

Um comando instala, outro inicia. Cerca de cinco minutos, com o tour.

Requisitos

  • macOS. No Linux foi executado só em contêineres: o pacote do npm no Ubuntu 24.04 e a imagem de contêiner no Debian. O Windows em si não é suportado; o Aubergine pode rodar dentro do WSL 2, o que ainda não foi testado: veja Instalar no Windows com WSL.
  • tmux 3.2 ou mais recente e Node.js 22 ou mais recente. O instalador também precisa de pnpm.

Com o Homebrew, uma linha instala os dois (adicione pnpm para o instalador):

brew install tmux node

Instale e inicie

  1. Instale o Aubergine pelo npm (precisa só de tmux e Node.js):

    npm install -g @meatgarden/aubergine

    Ou com o instalador, que também precisa de pnpm e compila a partir do código-fonte:

    curl -fsSL https://raw.githubusercontent.com/thirstyeggplant/aubergine/main/install.sh | sh

  2. Inicie e abra o navegador, já logado.

    aubergine start --open

  3. Faça o tour. Clique em Show me around no meio do canvas vazio. Ele cria um canvas chamado “Demo” com alguns agentes simulados e guia você por oito etapas curtas. Nada na demo é real, e aubergine demo --remove a remove.

Prefere ler o script antes? Baixe-o, leia-o e rode sh install.sh --dry-run para ver o que ele faria sem mudar nada.

O que o instalador muda

Só duas coisas: a pasta de instalação (~/.aubergine, ou AUBERGINE_HOME) e um link chamado aubergine em uma pasta do seu PATH em que você pode escrever. Ele verifica tudo antes e não muda nada se faltar alguma coisa.

Ele não usa sudo, não edita os arquivos de inicialização do seu shell, não instala Node.js, pnpm nem tmux, e não toca na sua pasta de dados.

Se algo der errado

Rode aubergine doctor primeiro. Ele verifica as causas mais comuns.

O que você vêO que fazer
“This browser is not signed in yet” (este navegador ainda não está logado)Abra o link de login uma vez nesse navegador. aubergine open --print o imprime de novo.
Uma página dizendo que o tmux está faltando ou é antigo demaisInstale ou atualize o tmux (brew install tmux) e reinicie o servidor.
O servidor não inicia porque a porta está ocupadaUse outra porta: AUBERGINE_PORT=4700 aubergine start.
aubergine: command not foundO link não está no seu PATH. O instalador imprime a linha que você deve adicionar ao arquivo de inicialização do seu shell.
Um terminal não mostra indicadores de statusO status precisa de zsh, e uma sessão criada antes de uma atualização mantém o shell antigo. Estacione-a e inicie uma nova.

Parar, atualizar, desinstalar

  • Pare o servidor com Ctrl+C. Seus terminais continuam rodando; inicie o servidor de novo e recarregue a página para tê-los de volta.
  • Atualize, se instalou pelo npm, com npm install -g @meatgarden/aubergine@latest; se usou o instalador, com aubergine update. Depois reinicie o servidor.
  • Desinstale com aubergine uninstall. Ele remove o link e, depois de perguntar, a cópia que o instalador fez. Ele nunca remove seus dados e nunca encerra seus terminais.
  • Inicie junto com o login com aubergine service install, e você só precisa abrir o navegador.
