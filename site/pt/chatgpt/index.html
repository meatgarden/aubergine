Codex e ChatGPT

O Codex é o agente de programação de linha de comando da OpenAI. Você mesmo o instala e faz login nele; no Aubergine ele roda em um terminal como qualquer outro programa.

Ainda não testado

Ninguém rodou ainda um Codex de verdade no Aubergine. O que esta página diz é o que o Aubergine faz por qualquer programa em um terminal e pelos comandos aubergine, o que está pronto e testado; como o próprio Codex se comporta ali ainda não foi visto. Se você testar, conte como foi.

Inicie

Abra um terminal com New terminal, ou N, e inicie o Codex nele como faria em qualquer terminal. O Aubergine não chama nenhum modelo e não guarda nenhuma chave: o que o Codex precisa, você deu a ele quando fez login.

O que funciona hoje

Tudo o que o Aubergine faz por qualquer terminal:

  • Lado a lado

    Quantos terminais você quiser em um só canvas, e canvases como abas.

  • Status dos comandos

    Com zsh, o título de um terminal mostra que um comando está rodando, e qual.

  • Cores, notas e campos

    Dê uma cor ao terminal dele, mantenha uma nota com um resumo e um log, e campos como um ticket ou um responsável.

  • Estacionar

    × estaciona o terminal: ele sai do canvas e continua rodando, e Parked (estacionados) o traz de volta.

  • Um terminal sozinho

    Abra o terminal em uma aba do navegador só dele, com os detalhes e a nota ao lado.

  • Uma cópia de trabalho

    Shell in a folder or a working copy…, ou aubergine new --copy, inicia o terminal no próprio checkout, no próprio branch, para que dois agentes nunca editem os mesmos arquivos.

  • Pesquisa na saída

    ⌘K pesquisa o que cada terminal imprimiu, e abre o terminal rolado até o resultado.

O que ele pode dizer pelos comandos

Todo terminal do Aubergine tem o comando aubergine e uma credencial só daquele terminal. Qualquer programa ali, o Codex incluído, pode usá-los:

  • aubergine attention waiting "…"

    Marca o terminal como esperando por você, com o que ele precisa; aubergine attention working e aubergine attention done dizem o resto.

  • aubergine note "…"

    Adiciona uma linha ao log de notas do terminal.

  • aubergine describe

    Dá ao terminal o nome do trabalho e mantém o resumo dele; aubergine link add e aubergine field set adicionam os links e campos do trabalho. O que você mesmo escreveu prevalece.

  • aubergine workflow status

    Lê a etapa atual de um fluxo de trabalho; aubergine workflow done a marca como concluída e imprime a próxima.

  • aubergine task add

    Propõe uma tarefa para a fila, e aubergine ask pede a você algo que só uma pessoa pode fazer. Os dois esperam na sua lista.

Como avisá-lo

O Codex não sabe do Aubergine até que alguém conte. Isto imprime cinco linhas para colar nas instruções que o seu agente lê no início de cada conversa em um projeto; a documentação dele diz onde elas ficam:

aubergine guide --snippet

As linhas dizem a ele para rodar aubergine guide uma vez quando estiver em um terminal do Aubergine, e o guia diz o resto. O Aubergine imprime as linhas e nunca as escreve em nenhum arquivo.

Se o seu agente consegue iniciar um servidor MCP, aubergine mcp oferece o mesmo como ferramentas; dentro de um terminal do Aubergine ele não precisa de endereço nem de token para o trabalho do próprio terminal.

Feito hoje só para o Claude Code

O que o Aubergine faz sozinho por um agente é feito para o Claude Code. Para o Codex, hoje:

  • Ele não está no menu New terminal: você mesmo o inicia em um terminal.
  • O Aubergine não o vê como um agente: ele não é marcado como esperando ou terminado sozinho, só quando roda aubergine attention.
  • Nada é digitado para ele: um fluxo de trabalho iniciado no terminal dele não digita nada e mostra a linha para você mesmo passar a ele, e um resumo ou uma mensagem não é anunciado a ele.
  • A fila não dá tarefa a ele: uma tarefa só vai para um terminal onde um agente é visto e está livre.
  • Não há Resume agent, nem lista de conversas anteriores, nem lista de como ele está configurado, nem caixa de diálogo para as ferramentas do Aubergine.
  • aubergine move e aubergine here --claude trazem apenas o Claude Code.
  • Ele não é lembrado de dar nome ao terminal nem de manter um resumo.

Tudo isso está na página do Claude Code.

ChatGPT no navegador

O ChatGPT em uma aba do navegador é uma página web, não um programa em um terminal, então ele não roda no canvas.

O Aubergine não é afiliado à OpenAI. Codex e ChatGPT são marcas registradas da OpenAI.

Funcionando em cinco minutos

Você precisa de macOS com tmux 3.2 ou mais recente e Node.js 22 ou mais recente. brew install tmux node instala os dois.

npm install -g @meatgarden/aubergine
