Aubergine vs Vibe Kanban

Os dois são de código aberto, rodam no seu próprio computador e são usados em um navegador. O Vibe Kanban parte do trabalho: issues em um quadro, cada uma entregue a um agente. O Aubergine parte dos agentes: terminais lado a lado, com uma fila ao lado deles.

De onde isto vem. O que se diz aqui sobre o Vibe Kanban vem da documentação dele e do repositório dele, lidos em 26 de novembro de 2026. Nós não rodamos o Vibe Kanban. Se algo estiver errado ou desatualizado, nos avise.

Situação do Vibe Kanban. Em 10 de abril de 2026, os criadores dele escreveram que a bloop, a empresa por trás dele, estava encerrando as atividades, que o projeto continua como código aberto mantido pela comunidade e que os serviços remotos dele seriam removidos, enquanto os workspaces locais continuam funcionando. A documentação e a página de preços dele ainda descreviam esses serviços quando isto foi escrito; os lançamentos continuaram.

Qual escolher

Escolha o Vibe Kanban se você pensa em issues: planejar em um quadro, entregar cada cartão a um agente, revisar o diff dele com comentários e fazer o merge.

Escolha o Aubergine se você quer os próprios agentes à vista, como terminais que sobrevivem à janela, e o trabalho distribuído a partir de uma fila só quando você manda.

O que é o Vibe Kanban

Pela própria descrição, um quadro kanban para desenvolvedores acompanharem tarefas de programação com agentes de programação. npx vibe-kanban inicia um servidor local e abre a página dele. Uma issue vira um workspace: worktrees do Git para os repositórios que você escolheu, uma conversa com um dos dez ou mais agentes que ele conhece pelo nome, as mudanças ao lado, e depois um pull request e um merge. Ele está sob a licença Apache-2.0.

Onde eles diferem

Uma conversa ou um terminal. O Vibe Kanban mostra um agente como um painel de conversa com as mudanças dele ao lado. O Aubergine mostra o próprio terminal do agente, e muitos deles de uma vez em um canvas.

Qualquer programa. O Vibe Kanban lista pelo nome os agentes que suporta. Um terminal do Aubergine é um shell: qualquer agente de linha de comando roda nele, e também um build, uma execução de testes ou um servidor. O que o Aubergine faz sozinho por um agente é feito para o Claude Code.

O que fechá-lo encerra. Não encontramos nada na documentação do Vibe Kanban sobre o que acontece com um agente em execução quando o servidor dele para. No Aubergine, cada terminal é uma sessão do tmux, e parar o Aubergine ou fechar o navegador não encerra nada.

O que o Vibe Kanban tem e o Aubergine não

  • Um quadro kanban de issues com prioridades, tags e sub-issues. O Aubergine tem uma fila de tarefas e um quadro de fluxos de trabalho em execução, não um rastreador de issues.
  • Diffs com comentários nas linhas enviados de volta ao agente, e depois pull requests, rebase e merge. O Aubergine mostra o que mudou e nunca faz commit nem merge.
  • Windows entre as plataformas documentadas, sons e uma lista maior de agentes que ele conhece pelo nome.

Perguntas

O Aubergine é uma alternativa ao Vibe Kanban?

Para rodar vários agentes localmente em worktrees do Git e ver qual precisa de você, sim. O formato é outro: o Aubergine tem terminais em um canvas e uma fila de tarefas onde o Vibe Kanban tem um quadro de issues com conversas, e o Aubergine não abre nenhum pull request e não faz merge de nada.

O Vibe Kanban ainda é mantido?

Os criadores dele escreveram em 10 de abril de 2026 que a empresa por trás dele estava encerrando as atividades e que o projeto continua como código aberto mantido pela comunidade. O repositório dele teve lançamentos desde então. Leia o repositório dele para saber a situação atual.

Os dois rodam localmente?

Sim. Cada um é um servidor no seu próprio computador com uma página no seu navegador. O Vibe Kanban documenta um login opcional para os recursos de quadro e de equipe; o Aubergine não tem conta nenhuma.

Quais agentes cada um suporta?

O Vibe Kanban cita mais de dez, entre eles Claude Code, Codex, Gemini CLI, GitHub Copilot, Amp, Cursor e OpenCode. O Aubergine roda qualquer programa de linha de comando em um terminal; iniciar um agente pelo menu, ver que ele espera e retomar a conversa dele são feitos para o Claude Code.

O Aubergine não é afiliado ao Vibe Kanban nem aos seus criadores. Vibe Kanban é o nome do projeto iniciado pela Bloop AI Limited.

Funcionando em cinco minutos

Você precisa de macOS com tmux 3.2 ou mais recente e Node.js 22 ou mais recente. brew install tmux node instala os dois.

npm install -g @meatgarden/aubergine
