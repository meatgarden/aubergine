Retome uma conversa do Claude Code depois de reiniciar

O computador reiniciou, ou você fechou o terminal, e a conversa do Claude Code parece perdida. O Claude Code a guarda. O Aubergine lembra em qual conversa cada terminal estava e a traz de volta com um botão.

O que as pessoas costumam fazer

Em um terminal, na pasta em que a conversa estava: claude --continue continua a conversa mais recente dali, e claude --resume deixa você escolher uma em uma lista, ou aceita o ID de uma conversa. O problema está na pasta e na escolha: com vários agentes em uma pasta, a mais recente nem sempre é a que você queria.

O que o Aubergine faz

Um terminal lembra a conversa dele. Quando o Claude Code foi iniciado pelo Aubergine (New terminal ▾ → Claude Code, ou C), os hooks dele dizem ao Aubergine em qual conversa ele está, e o Aubergine guarda esse ID com o terminal.

Resume agent (retomar o agente) aparece na barra de título do terminal assim que o shell dele volta a um prompt: você saiu do agente, ou o computador reiniciou e o terminal voltou como um shell novo na última pasta. Ele inicia o Claude Code de novo com --resume e esse ID, com o comando de inicialização das suas configurações (agents.claudeCommand, claude por padrão).

Em uma execução de um workflow, Resume agent também conta ao agente sobre a execução de novo, para ele seguir a partir do passo em que ela está.

Past conversations… (conversas anteriores) na paleta (⌘K), ou “Past conversations in this folder…” nos detalhes de um terminal, lista as conversas anteriores do Claude Code em uma pasta: o nome ou a primeira coisa que você disse, quando ela esteve ativa pela última vez, quantas vezes você falou e se um terminal em um canvas está nela agora. Read (ler) a mostra, só para leitura. Open on the canvas (abrir no canvas) inicia um terminal novo naquela pasta, retomado nela, e Open a copy (abrir uma cópia) inicia uma ramificação dela e deixa a original como está. Se já há um terminal nessa conversa, você é consultado antes.

Busca. Digite @ e algumas palavras na paleta para buscar nas conversas anteriores das pastas dos terminais dos seus canvases. Ela lê os registros quando você pede, dentro de limites, e diz quando foi interrompida. Na linha de comando, aubergine history as lista e aubergine history open <id> abre uma.

Onde ele parou. A nota do terminal guarda o resumo e um registro, e cada prompt que você envia é adicionado ao registro. Ask its agent for a recap (pedir uma recapitulação ao agente), nos detalhes, faz o agente escrever onde está com aubergine recap --write, guardado com o terminal. Quando você volta depois de mais de 30 minutos, While you were away (enquanto você estava fora) lista o que mudou nesse meio-tempo.

Uma conversa em um terminal fora do Aubergine

Em uma aba do seu app de terminal, saia do agente e depois rode aubergine here --claude na mesma pasta: um terminal novo no canvas inicia o Claude Code com --continue, agora com o estado à vista. aubergine move lista suas abas do Claude Code e inicia uma cópia de cada conversa no canvas; com --stop ele pede antes a um agente ocioso que saia, depois que você confirma.

O que ele não faz

  • Ele lê os registros do próprio Claude Code, em um formato que não é do Aubergine. O Claude Code chama o formato desses arquivos de interno, e ele muda entre versões. Retomar usa o próprio --resume do Claude Code com o ID; nomes, contagens e transcrições são a leitura que o Aubergine faz dos arquivos, e podem faltar ou ficar mais pobres depois de uma atualização do Claude Code. Um registro que ele não consegue ler é indicado como tal, não mostrado como uma conversa vazia.
  • Nada é copiado nem guardado. Uma lista, uma transcrição ou uma busca é lida quando você pede e descartada quando você a fecha. O Aubergine nunca altera, renomeia nem apaga uma conversa, e nenhum agente ou token consegue ler conversas por meio dele.
  • O trabalho em andamento não é refeito. O que o agente fazia quando parou não é iniciado de novo até você pedir.
  • Nada de Resume agent para outro agente. O Aubergine não conhece a conversa de outro agente, e não lista conversas anteriores dele. Inicie-o de novo no mesmo terminal com o jeito de retomar desse agente, e leia a nota para dizer a ele onde estava.
  • Um claude que você mesmo digitou não é lembrado, a menos que você tenha adicionado às suas próprias configurações do Claude Code os hooks que aubergine hooks print imprime.
  • O que foi verificado. A leitura dos registros de conversa é testada com registros inventados. Ela não foi verificada com todas as versões do Claude Code.

Perguntas

Como retomo uma sessão do Claude Code depois de fechar o terminal?

Na mesma pasta, claude --continue pega a conversa mais recente e claude --resume deixa você escolher. No Aubergine, fechar o navegador não encerra nada, e um terminal de cujo agente você saiu oferece Resume agent na barra de título.

Como retomo uma conversa do Claude Code depois de reiniciar o computador?

Depois de reiniciar, cada terminal do Aubergine volta como um shell novo na última pasta. Onde o Claude Code foi iniciado pelo Aubergine, Resume agent na barra de título o inicia de novo na conversa em que aquele terminal estava.

Como encontro uma conversa antiga do Claude Code?

Past conversations… na paleta as lista para uma pasta, com uma transcrição só para leitura; @ e algumas palavras na paleta buscam nelas. Só é listado o que o Claude Code ainda guarda.

Qual é a diferença entre claude --continue e claude --resume?

--continue continua a conversa mais recente da pasta; --resume pega a que você escolher, ou um ID. Resume agent usa --resume com o ID que o terminal lembrou, então não depende de qual conversa foi a mais recente.

Dois terminais podem continuar a mesma conversa do Claude Code?

O Aubergine não abre uma conversa duas vezes sem perguntar: dois agentes em uma conversa perdem as mensagens um do outro. Você recebe a opção do terminal que já está nela, ou de uma cópia, que ramifica a conversa.

O Aubergine não é afiliado à Anthropic. Claude e Claude Code são marcas registradas da Anthropic.

Funcionando em cinco minutos

Você precisa de macOS com tmux 3.2 ou mais recente e Node.js 22 ou mais recente. brew install tmux node instala os dois.

npm install -g @meatgarden/aubergine
