Aubergine vs. Vibe Kanban

Beide sind Open Source, laufen auf deinem eigenen Rechner und werden im Browser benutzt. Vibe Kanban geht von der Arbeit aus: Issues auf einem Board, jedes einem Agenten übergeben. Aubergine geht von den Agenten aus: Terminals nebeneinander, mit einer Warteschlange daneben.

Woher das stammt. Was hier über Vibe Kanban gesagt wird, stammt aus seiner Dokumentation und seinem Repository, gelesen am 26. November 2026. Wir haben Vibe Kanban nicht ausgeführt. Wenn etwas falsch oder veraltet ist, sag es uns.

Wo Vibe Kanban steht. Am 10. April 2026 schrieben seine Macher, dass bloop, die Firma dahinter, ihren Betrieb einstellt, dass das Projekt als Open Source weitergeht, gepflegt von seiner Community, und dass seine Remote-Dienste entfernt würden, während lokale Workspaces weiter funktionieren. Als dies geschrieben wurde, beschrieben seine Dokumentation und seine Preisseite diese Dienste noch; es sind weiterhin Releases erschienen.

Was du wählen solltest

Wähl Vibe Kanban, wenn du in Issues denkst: auf einem Board planen, jede Karte einem Agenten übergeben, seinen Diff mit Kommentaren prüfen und mergen.

Wähl Aubergine, wenn du die Agenten selbst als Terminals im Blick haben willst, die das Fenster überleben, und Arbeit, die aus einer Warteschlange nur dann verteilt wird, wenn du es sagst.

Was Vibe Kanban ist

Nach eigener Beschreibung ein Kanban-Board, auf dem Entwickler Coding-Aufgaben mit Coding-Agenten verfolgen. npx vibe-kanban startet einen lokalen Server und öffnet seine Seite. Aus einem Issue wird ein Workspace: Git-Worktrees für die Repositorys, die du gewählt hast, eine Unterhaltung mit einem von zehn oder mehr Agenten, die es mit Namen kennt, die Änderungen daneben, dann ein Pull Request und ein Merge. Es steht unter der Apache-2.0-Lizenz.

Wo sie sich unterscheiden

Eine Unterhaltung oder ein Terminal. Vibe Kanban zeigt einen Agenten als Unterhaltungsbereich mit seinen Änderungen daneben. Aubergine zeigt das eigene Terminal des Agenten, und viele davon auf einmal auf einem Canvas.

Jedes Programm. Vibe Kanban führt die Agenten, die es unterstützt, mit Namen auf. Ein Aubergine-Terminal ist eine Shell: Jeder Kommandozeilen-Agent läuft darin, und ebenso ein Build, ein Testlauf oder ein Server. Was Aubergine von sich aus für einen Agenten tut, ist für Claude Code gebaut.

Was das Schließen beendet. Wir haben in der Dokumentation von Vibe Kanban nichts darüber gefunden, was mit einem laufenden Agenten passiert, wenn sein Server anhält. In Aubergine ist jedes Terminal eine tmux-Session, und Aubergine anzuhalten oder den Browser zu schließen beendet nichts.

Was Vibe Kanban hat, das Aubergine nicht hat

  • Ein Kanban-Board mit Issues, mit Prioritäten, Tags und Unter-Issues. Aubergine hat eine Warteschlange von Aufgaben und ein Board laufender Workflows, keinen Issue-Tracker.
  • Diffs mit Inline-Kommentaren, die an den Agenten zurückgehen, dann Pull Requests, Rebase und Merge. Aubergine zeigt, was sich geändert hat, und committet oder merget nie.
  • Windows unter seinen dokumentierten Plattformen, Töne und eine längere Liste von Agenten, die es mit Namen kennt.

Fragen

Ist Aubergine eine Alternative zu Vibe Kanban?

Um mehrere Agenten lokal in Git-Worktrees laufen zu lassen und zu sehen, welcher dich braucht, ja. Es hat eine andere Form: Aubergine hat Terminals auf einem Canvas und eine Warteschlange von Aufgaben, wo Vibe Kanban ein Board mit Issues und Unterhaltungen hat, und Aubergine öffnet keinen Pull Request und merget nichts.

Wird Vibe Kanban noch gepflegt?

Seine Macher schrieben am 10. April 2026, dass die Firma dahinter ihren Betrieb einstellt und dass das Projekt als Open Source weitergeht, gepflegt von seiner Community. Sein Repository hat seitdem Releases gehabt. Sieh in seinem Repository nach, wo es jetzt steht.

Laufen beide lokal?

Ja. Jedes ist ein Server auf deinem eigenen Rechner mit einer Seite in deinem Browser. Vibe Kanban dokumentiert eine optionale Anmeldung für sein Board und seine Team-Funktionen; Aubergine hat überhaupt kein Konto.

Welche Agenten unterstützt jedes?

Vibe Kanban nennt mehr als zehn, darunter Claude Code, Codex, Gemini CLI, GitHub Copilot, Amp, Cursor und OpenCode. Aubergine lässt jedes Kommandozeilen-Programm in einem Terminal laufen; einen Agenten aus dem Menü starten, sehen, dass er wartet, und seine Unterhaltung fortsetzen ist für Claude Code gebaut.

Aubergine ist nicht mit Vibe Kanban oder seinen Machern verbunden. Vibe Kanban ist der Name des Projekts, das Bloop AI Limited begonnen hat.

In fünf Minuten startklar

Du brauchst macOS mit tmux 3.2 oder neuer und Node.js 22 oder neuer. brew install tmux node holt beides.

npm install -g @meatgarden/aubergine
