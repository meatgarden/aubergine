Aubergine vs. Claude Squad

Die beiden stehen auf demselben Boden: jeder Agent in einer tmux-Session, jeder in einem eigenen Git-Worktree, beide kostenlos und Open Source. Claude Squad ist ein Programm in deinem Terminal. Aubergine ist eine Seite in deinem Browser, auf der die Terminals nebeneinanderstehen.

Woher das stammt. Was hier über Claude Squad gesagt wird, stammt aus seinem Repository und seinem README, gelesen am 26. November 2026. Wir haben Claude Squad nicht ausgeführt. Wenn etwas falsch oder veraltet ist, sag es uns.

Was du wählen solltest

Wähl Claude Squad, wenn du im Terminal lebst und dort ein kleines Programm willst, das Agenten in Worktrees startet und ihre Branches pusht, und nichts weiter.

Wähl Aubergine, wenn du mehrere Agenten gleichzeitig arbeiten sehen willst, wissen willst, welcher auf dich wartet, und eine Warteschlange, Zeitpläne und eine API um sie herum haben willst.

Was Claude Squad ist

Nach eigener Beschreibung eine Terminal-App, die mehrere lokale Agenten wie Claude Code, Codex, Gemini und andere in getrennten Workspaces verwaltet. Du startest es als cs: eine Liste von Sessions mit einer Vorschau und einem Diff-Tab, in einem Terminalfenster. Jede Session ist eine tmux-Session in einem Git-Worktree auf einem eigenen Branch. Es braucht tmux und gh und steht unter der AGPL-3.0-Lizenz.

Wo sie sich unterscheiden

Einer nach dem anderen oder alle auf einmal. Claude Squad zeigt eine Liste und eine Vorschau der Session, die du gewählt hast. Aubergine zeichnet jedes Terminal live auf ein Canvas, also sind fünf Agenten fünf Terminals im Blick, und eine Liste sagt den Zustand jedes einzelnen in Worten.

Wer wartet. Wir haben im README von Claude Squad nichts darüber gefunden, dass man erfährt, wenn ein Agent wartet oder fertig ist. Aubergine markiert ein wartendes Terminal farbig, zählt oben, was wartet, springt mit einer Taste zum nächsten und kann von der offenen Seite eine Benachrichtigung schicken.

Was um die Agenten herum ist. Aubergine hat eine Warteschlange von Aufgaben mit einer Grenze, Zeitpläne, Workflows mit Schritten, die ein Mensch freigibt, Notizen und Felder an jedem Terminal, eine HTTP-API und einen MCP-Server. Claude Squad beschränkt sich auf Sessions und ihre Branches.

Was Claude Squad hat, das Aubergine nicht hat

  • Es läuft in dem Terminal, das du schon offen hast, ohne Server und ohne Browser. Es funktioniert über SSH wie jedes Terminal-Programm; Aubergine braucht von anderswo einen Tunnel oder einen Proxy.
  • Es committet und pusht einen Branch für dich und pausiert eine Session, indem es ihre Arbeit committet. Aubergine committet oder pusht nie.
  • Einen experimentellen Modus, der die Prompts eines Agenten von selbst annimmt. Aubergine antwortet einem Agenten nie für dich.

Fragen

Ist Aubergine eine Alternative zu Claude Squad?

Ja, für dieselbe Aufgabe, auf andere Weise erledigt. Beide lassen jeden Agenten in einer tmux-Session laufen und können jedem einen Git-Worktree auf einem eigenen Branch geben. Claude Squad tut es aus einem Programm in deinem Terminal; Aubergine aus einer Seite in deinem Browser, mit jedem Terminal im Blick.

Nutzen beide tmux?

Ja. Claude Squad führt tmux als Voraussetzung auf und legt für jeden Agenten eine tmux-Session an. Aubergine braucht tmux 3.2 oder neuer und betreibt es auf einem eigenen Socket mit eigener Konfiguration, sodass dein eigenes tmux unberührt bleibt.

Funktioniert Claude Squad mit anderen Agenten als Claude Code?

Laut seinem README ist das Standardprogramm claude, und ein anderes, etwa Codex, Gemini oder Aider, wird mit -p angegeben. Aubergine lässt jedes Kommandozeilen-Programm in einem Terminal laufen; was es von sich aus für einen Agenten tut, ist für Claude Code gebaut.

Welche Lizenz hat jedes?

Claude Squad steht unter der AGPL-3.0, Aubergine unter der MIT-Lizenz. Beide sind kostenlos.

Aubergine ist weder mit Claude Squad noch mit Anthropic verbunden. Claude Squad ist der Name des Projekts von smtg-ai; Claude ist eine Marke von Anthropic.

In fünf Minuten startklar

Du brauchst macOS mit tmux 3.2 oder neuer und Node.js 22 oder neuer. brew install tmux node holt beides.

npm install -g @meatgarden/aubergine
