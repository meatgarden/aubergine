Mehr Power für dein Terminal · Kostenlos · Open Source · Läuft auf deinem Rechner

Alle deine Terminals, Seite an Seite. Sieh, welcher Agent dich braucht.

Aubergine legt alle deine Terminals nebeneinander auf ein Canvas in deinem Browser. Starte so viele, wie du willst, mit den Agenten und Modellen, die du schon nutzt. Es hat kein eigenes Modell und fragt nie nach einem Schlüssel.

npm install -g @meatgarden/aubergine

Dann aubergine start --open. Für macOS, mit tmux 3.2 oder neuer und Node.js 22 oder neuer.

Gib deinen Terminals Superkräfte

Die Terminals, die du schon nutzt, mit dem, was ihnen gefehlt hat: einem Ort, an dem sie nebeneinanderstehen, einem Gedächtnis und einem Weg, dir zu sagen, wann sie dich brauchen.

  • Steigere deine Produktivität

    Mehrere Agenten arbeiten gleichzeitig, jeder in seinem eigenen Terminal. Du antwortest dem, der wartet, und lässt die anderen weiterlaufen.

  • Eine bessere Developer Experience

    Jedes Terminal hat einen Namen, eine Farbe, eine Notiz und seinen Platz auf dem Canvas. Schließ den Browser oder starte Aubergine neu: Alles ist noch da.

  • Kein Umstieg nötig

    Deine Shell, deine Tools, deine Agenten und deine Modelle, so wie sie sind. Aubergine legt das Canvas um sie herum und hat kein eigenes Modell.

Bring deinen eigenen Agenten mit

Aubergine führt gewöhnliche Terminals aus. Es ruft kein Modell auf, hält keinen Schlüssel und hat kein Konto: Die Kommandozeilen-Agenten, die du schon nutzt und bei denen du angemeldet bist, laufen in seinen Terminals mit dem Modell, das du für sie gewählt hast. Was Aubergine von sich aus für einen Agenten tut, ist heute für Claude Code gebaut; jeder andere Agent kann dasselbe über die aubergine-Befehle mitteilen.

  • Claude Code

    Starte es über das Menü New terminal, und es meldet von selbst, wenn es arbeitet, auf dich wartet oder fertig ist; Aubergine kann seine Unterhaltungen fortsetzen und zeigen, wie es eingerichtet ist.

  • Codex und ChatGPT

    Codex läuft in einem Terminal wie jedes Programm und meldet sich über die aubergine-Befehle, sobald seine Anweisungen es ihm sagen. ChatGPT im Browser ist kein Terminal-Programm.

  • Jeder andere Kommandozeilen-Agent oder eine einfache Shell

    Jedes Terminal hat den Befehl aubergine, und aubergine guide --snippet gibt fünf Zeilen für die Anweisungen deines Agenten aus.

Was es sonst noch gibt

All das läuft heute auf deinem Rechner.

  • Ein Canvas voller Terminals

    Verschiebe, zoome und ordne echte Terminals an, klick einmal zum Tippen, park eins und hol es später zurück, oder öffne eins für sich in einem Browser-Tab, mit seinen Details und seiner Notiz daneben.

  • Sehen, wer wartet

    Beschäftigt, untätig oder wartend auf dich, bei jedem Terminal; die Liste „For you“ und „next waiting“ bringen dich direkt dorthin, wo ein Mensch gebraucht wird.

  • Warteschlange und Zeitpläne

    Schreib eine Aufgabe einmal und lass einen freien Agenten sie übernehmen, oder plane sie zu einer Uhrzeit an den Tagen, die du wählst.

  • Arbeitskopien

    Gib jedem Agenten seine eigene Kopie eines Repositorys auf einem eigenen Branch, damit zwei Agenten nie dieselben Dateien bearbeiten.

  • Projekte

    Ein Server, mehrere Leitstände: Jedes Projekt hat eigene Canvases, eine eigene Warteschlange, eigene Zeitpläne und Regeln und lässt sich als Datei oder Vorlage speichern.

  • Workflows und Freigaben

    Gib einem Agenten Schritte vor, halte bei einem Schritt an, der auf einen Menschen wartet, und verfolge jeden aktiven Lauf auf einem Board.

  • Nachrichten zwischen Terminals

    Lass Agenten miteinander reden, mit benannten Absendern, Grenzen und Pausen, standardmäßig für jedes Canvas geschlossen.

  • API und MCP-Server

    Eine lokale HTTP-API mit Tokens mit Scopes, ein typisierter Client und ein MCP-Server, der nur die Tools auflistet, die ein Zugang nutzen darf.

  • Eine Kommandozeile

    Der Befehl aubergine startet Terminals, stellt Aufgaben in die Warteschlange, setzt Zeitpläne, liest das Board und gibt Läufe frei, aus jedem Terminal auf dem Rechner.

  • Zusammenfassungen und Verlauf

    Sieh, was sich geändert hat, während du weg warst, durchsuche Terminal-Ausgaben und öffne frühere Unterhaltungen aus der Palette.

Deine Terminals bleiben deine

  • Nur lokal

    Der Server lauscht auf 127.0.0.1 und prüft Host und Origin jeder Anfrage; die Nutzung von einem anderen Gerät bleibt aus, bis du sie einrichtest.

  • Terminals überleben die App

    Jedes Terminal ist eine tmux-Session: Schließ den Browser oder starte Aubergine neu, und deine Arbeit läuft weiter.

  • Kein Modell, kein Schlüssel

    Aubergine wählt kein Modell aus und ruft keines auf, und es hält keinen Schlüssel dafür; deine Agenten bringen ihre eigenen mit.

  • Du entscheidest

    Tokens haben Scopes, was Agenten schreiben, wartet auf deine Prüfung, und Freigaben erteilt ein Mensch.

Was geschützt ist und was nicht

In fünf Minuten startklar

Du brauchst macOS mit tmux 3.2 oder neuer und Node.js 22 oder neuer. brew install tmux node holt beides.

  1. Installieren

    npm install -g @meatgarden/aubergine

    Oder nutze den Installer, der mit pnpm aus dem Quellcode baut.

  2. Starten und Browser öffnen

    aubergine start --open

    Das startet den Server und öffnet deinen Browser, schon angemeldet.

  3. Mach die Tour

    Klick auf dem leeren Canvas auf Show me around. Das legt ein Canvas namens Demo mit Platzhalter-Agenten an und führt dich in acht kurzen Schritten herum; aubergine demo --remove entfernt es wieder.

Der Installer ändert nur ~/.aubergine und einen Link namens aubergine. Er nutzt nie sudo und bearbeitet nie die Startdateien deiner Shell.

Fragen

Was ist Aubergine?

Ein lokales Canvas aus Terminal-Sessions im Browser. Jedes Terminal ist ein Knoten, den du anordnen und benutzen kannst, sodass du mehrere Coding-Agenten gleichzeitig laufen lassen und sehen kannst, welcher auf dich wartet.

Schickt Aubergine meine Terminals oder meinen Code irgendwohin?

Nein. Alles läuft auf deinem eigenen Rechner. Der Server lauscht nur auf 127.0.0.1 und prüft Host und Origin jeder Anfrage.

Was brauche ich, um Aubergine zu nutzen?

macOS mit tmux 3.2 oder neuer und Node.js 22 oder neuer; der Installer braucht außerdem pnpm. Unter Linux lief es bisher nur in Containern. Unter Windows läuft es nur in WSL 2, was noch nicht ausprobiert wurde: siehe die Anleitung für Windows.

Was, wenn ich Claude Code selbst in einem Terminal starte?

Es funktioniert wie jedes Programm: Du tippst wie gewohnt hinein. Aber Aubergine weiß nur dann, dass dort ein Agent ist, wenn es den Agenten selbst gestartet hat (New terminal, dann Claude Code), weil es ein paar kleine Hooks hinzufügt, die melden, was der Agent tut. Von Hand gestartet, erscheint das Terminal nur als beschäftigt mit claude: Es wird nicht als wartend markiert, wenn es etwas fragt, und wenn du dort einen Workflow startest, wird nichts für ihn getippt. Sag ihm selbst, dass es aubergine workflow status ausführen soll, was auch von innen funktioniert, oder starte den Agenten stattdessen über das Menü New terminal.

Ist Aubergine kostenlos?

Ja. Es ist kostenlos und Open Source unter der MIT-Lizenz, und der Quellcode liegt auf GitHub.
