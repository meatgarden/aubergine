Häufige Fragen

Kurze Antworten. Die Anleitungen gehen tiefer.

Was ist Aubergine?

Ein lokales Canvas aus Terminal-Sessions im Browser. Jedes Terminal ist ein Knoten, den du anordnen und benutzen kannst, sodass du mehrere Coding-Agenten gleichzeitig laufen lassen und sehen kannst, welcher auf dich wartet.

Ist Aubergine kostenlos und Open Source?

Ja. Es ist kostenlos, und der Quellcode liegt auf GitHub.

Was brauche ich, um Aubergine zu nutzen?

macOS mit tmux 3.2 oder neuer und Node.js 22 oder neuer; der Installer braucht außerdem pnpm. Unter Linux lief es bisher nur in Containern. Unter Windows läuft es nur in WSL 2, was noch nicht ausprobiert wurde: siehe die Anleitung für Windows.

Funktioniert es mit jedem Coding-Agenten?

Aubergine führt gewöhnliche Terminals aus, also kann jeder Kommandozeilen-Agent darin laufen. Was Aubergine von sich aus für einen Agenten tut, etwa sehen, dass er wartet, ist für Claude Code gebaut; jeder andere Agent, Codex eingeschlossen, kann seinen Status über die aubergine-Befehle und eine lokale API melden und einen MCP-Server nutzen, der nur auflistet, was sein Token erlaubt.

Schickt Aubergine meine Terminals oder meinen Code irgendwohin?

Nein. Alles läuft auf deinem eigenen Rechner. Der Server lauscht nur auf 127.0.0.1.

Ruft Aubergine ein KI-Modell auf?

Nein. Das tun deine Agenten. Aubergine führt nur ihre Terminals aus, behält sie im Blick und hält für kein Modell einen Schlüssel.

Was passiert mit meinen Terminals, wenn ich den Browser schließe?

Sie laufen weiter. Jede Session ist eine tmux-Session, die sowohl den Browser als auch den Aubergine-Server überlebt.

Woher weiß ich, welcher Agent auf mich wartet?

Jedes Terminal zeigt, ob es beschäftigt, untätig oder wartend ist. Die Zahl neben For you oben auf der Seite und die For-you-Liste sammeln alles, was dich braucht.

Wie verhindere ich, dass zwei Agenten dieselben Dateien bearbeiten?

Starte jedes Terminal in einer eigenen Arbeitskopie: einem eigenen Checkout auf einem eigenen Branch. Aubergine merget und pusht nie für dich.

Kann ich einem Agenten eine Liste von Schritten vorgeben?

Ja. Ein Workflow ist eine geordnete Liste von Schritten, mit einem Streifen, der zeigt, wo der Agent steht. Ein Schritt kann darauf warten, dass du ihn freigibst oder zurückschickst.

Können Agenten miteinander reden?

Ja, in Grenzen. Nachrichten zwischen Terminals haben benannte Absender, Pausen und Sperren und sind standardmäßig für jedes Canvas geschlossen.

Gibt es eine API?

Ja. Eine lokale HTTP-API mit Tokens mit Scopes, ein typisierter Client und ein MCP-Server, der nur die Tools auflistet, die ein Zugang nutzen darf.

Kann ich ein Terminal für sich öffnen?

Ja. Tab ↗ im Titel eines Terminals öffnet es in einem eigenen Browser-Tab, dasselbe Terminal und keine Kopie, mit seinen Details und seiner Notiz daneben, wenn du sie willst. Den Tab zu schließen beendet nichts.

Kann ich ein Ticket oder einen Verantwortlichen bei einem Terminal festhalten?

Ja. Ein Terminal hat Felder, Paare aus Bezeichnung und Wert, in seinen Details. Der Agent darin kann seine eigenen mit aubergine field set setzen; wo du dieselbe Bezeichnung gesetzt hast, bleibt deine.

Wird Aubergine mehrere Menschen oder Agenten in der Cloud unterstützen?

Beides ist geplant und keins davon gebaut. Siehe die Roadmap. Heute läuft alles auf einem Rechner.

Was ändert der Installer auf meinem Rechner?

Zwei Dinge: den Installationsordner (~/.aubergine) und einen Link namens aubergine. Er nutzt nie sudo, bearbeitet nie die Startdateien deiner Shell und installiert nie Node.js, pnpm oder tmux.

In fünf Minuten startklar

Du brauchst macOS mit tmux 3.2 oder neuer und Node.js 22 oder neuer. brew install tmux node holt beides.

npm install -g @meatgarden/aubergine
