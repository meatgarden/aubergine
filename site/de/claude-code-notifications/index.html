Wissen, wann Claude Code fertig ist oder auf dich wartet

Du gibst Claude Code eine Aufgabe, wendest dich etwas anderem zu und kommst zwanzig Minuten später zurück, nur um zu sehen, dass es seit Minute zwei auf ein Ja wartet. Aubergine zeigt auf einer Seite, welches Terminal arbeitet, welches auf dich wartet und welches fertig ist.

Was man üblicherweise tut

Claude Code führt Hooks aus, eigene Befehle, zu bestimmten Momenten, etwa wenn es anhält (Stop) oder eine Benachrichtigung sendet (Notification). Die übliche Antwort ist ein Hook in deinen Claude-Code-Einstellungen, der einen Ton abspielt oder eine Desktop-Benachrichtigung zeigt. Das funktioniert, und die Skripte schreibst und pflegst du selbst.

Was Aubergine tut

Starte Claude Code aus Aubergine: New terminal ▾ → Claude Code oben in der Liste der Terminals, oder C. Aubergine startet claude mit einer Einstellungsdatei, die es in seinem eigenen Datenordner erzeugt und auf der Befehlszeile angibt. Deine eigene Claude-Code-Konfiguration wird nicht angefasst. Die Hooks in dieser Datei sagen der Seite, was der Agent tut:

  • wenn du einen Prompt abschickst, zeigt das Terminal working (arbeitet), und der Prompt kommt ins Log seiner Notiz;
  • wenn der Agent dich braucht (eine Berechtigungsfrage, oder er wartet untätig auf Eingabe), nimmt sein Rahmen die Farbe des Wartens an, und sein Titel und seine Zeile in der Liste sagen waiting for you (wartet auf dich);
  • wenn er aufhört, zeigt das Terminal finished (fertig).

Die Zahl bei For you, oben rechts auf der Seite, ist alles, was auf dich wartet, über alle Projekte: Terminals mit einer Frage, außerdem freizugebende Läufe, zu lesende Entwürfe und vorgeschlagene Aufgaben. Ein Klick darauf öffnet Runs, dessen Spalte Waiting for you diese Liste ist. Der Tab eines Canvas zeigt, wie viele seiner Terminals warten.

Das nächste, das wartet. W springt zum nächsten Terminal, das auf dich wartet, solange kein Terminal die Tastatur hat; unter macOS tut ⌃⌘J das auch aus einem Terminal heraus. Sonst steht es in der Palette.

Benachrichtigungen der offenen Seite. Settings → Notifications hat Notify me on the desktop when a terminal starts waiting (auf dem Desktop benachrichtigen, wenn ein Terminal zu warten beginnt). Eingeschaltet zeigt die Seite eine Benachrichtigung deines Browsers, wenn ein Terminal zu warten beginnt oder sein Agent fertig ist, außer du schaust gerade auf dieses Terminal. Der Browser fragt einmal um Erlaubnis.

Regeln. Auf dem Tab Rules von Runs kann eine Regel mit Notify me (mich benachrichtigen) Bescheid geben, wenn eine Aufgabe erledigt ist, eine Aufgabe fehlschlug, eine Aufgabe dich braucht, etwas von dir erfragt wird oder ein Zeitplan ausgelöst wurde oder nicht laufen konnte: eine Benachrichtigung der offenen Seite, mit einem Satz dazu, was passiert ist.

Andere Agenten, und ein selbst getipptes claude

Aubergine liest nicht die Ausgabe eines Terminals, um zu raten. Jeder andere Agent oder jedes Programm sagt dasselbe von sich aus mit aubergine attention waiting "what it needs", aubergine attention working und aubergine attention done in seinem Terminal. aubergine guide --snippet gibt fünf Zeilen für die Datei aus, die dein Agent zu Beginn einer Unterhaltung liest; sie sagen ihm, aubergine guide auszuführen, das diese Befehle erklärt.

Ein Claude Code, das du durch Tippen von claude in einem einfachen Terminal gestartet hast, ist für Aubergine eine Shell, die mit einem Programm beschäftigt ist: kein waiting for you. Starte es stattdessen aus dem Menü, oder trag die Hooks, die aubergine hooks print ausgibt, von Hand in deine eigenen Einstellungen ein; außerhalb eines Aubergine-Terminals tun sie nichts.

Was es nicht tut

  • Kein eigener Ton. Aubergine spielt keinen ab. Eine Benachrichtigung macht nur einen Ton, wenn dein Browser oder dein System das bei Benachrichtigungen tut.
  • Nichts, solange keine Seite offen ist. Benachrichtigungen kommen von einer Aubergine-Seite, die in deinem Browser offen ist; der Server sendet von sich aus keine. Sind alle Seiten zu, sagt das Terminal trotzdem waiting for you, und die Zahl ist da, wenn du die Seite öffnest.
  • Kein Push aufs Handy. Es gibt keine App und keinen Push-Dienst. Der Browser eines Handys kann gekoppelt werden, um dieselbe Seite zu öffnen; siehe Deine Agenten vom Handy aus im Blick, was nicht auf einem echten Handy ausprobiert wurde.
  • Was geprüft wurde. Die Browsertests prüfen die Benachrichtigungen gegen einen Stand-in für die eigenen des Browsers. Wie eine echte aussieht und ob sie überhaupt erscheint, hängt von deinem Browser und den Einstellungen deines Systems dafür ab.

Fragen

Wie bekomme ich eine Benachrichtigung, wenn Claude Code fertig ist?

Starte Claude Code aus Aubergine und schalte dann Notify me on the desktop when a terminal starts waiting unter Settings → Notifications ein. Die offene Seite zeigt dann eine Browser-Benachrichtigung, wenn ein Terminal zu warten beginnt oder sein Agent fertig ist. Ohne Benachrichtigung sagt das Terminal finished.

Kann Claude Code einen Ton abspielen, wenn es eine Eingabe braucht?

Aubergine spielt keinen Ton ab. Eine Benachrichtigung klingt, wenn dein Browser oder System sie klingen lässt. Ein eigener Hook in deinen Claude-Code-Einstellungen kann einen abspielen; Aubergine schreibt nie in diese Einstellungen.

Wie sehe ich, welche Claude-Code-Session wartet, wenn ich mehrere laufen lasse?

In Aubergine sind der Rahmen und der Zustand des wartenden Terminals in der Farbe des Wartens, seine Zeile in der Liste sagt waiting for you, und die Zahl bei For you sagt, wie viele Dinge warten. W springt zum nächsten.

Werde ich benachrichtigt, wenn der Browser geschlossen ist?

Nein. Benachrichtigungen kommen von einer offenen Aubergine-Seite. Der Zustand bleibt erhalten, also sind die wartenden Terminals markiert, wenn du die Seite wieder öffnest.

Funktioniert es mit anderen Agenten als Claude Code?

Nicht von selbst: Die Hooks sind für Claude Code gebaut. Jeder andere Agent kann dasselbe mit aubergine attention waiting, working und done melden, wenn seine eigenen Anweisungen es ihm sagen; aubergine guide --snippet gibt die Zeilen für diese Anweisungen aus.

Aubergine ist nicht mit Anthropic verbunden. Claude und Claude Code sind Marken von Anthropic.
