tmux, ohne tmux zu lernen

tmux hält deine Shells am Laufen, wenn das Fenster zugeht. Es verlangt aber auch, dass du eine Präfix-Taste, einen Kopiermodus und eine Konfigurationsdatei lernst. Aubergine betreibt tmux für dich, und du benutzt jedes Terminal in einer Browserseite wie jedes andere Terminal.

Für wen es ist

Für alle, die wollen, was tmux gibt, Shells, die das Fenster überleben, ohne seine Tasten und seine Konfiguration. Wenn du schon in tmux lebst, bleib dabei: Aubergine lässt dein tmux in Ruhe.

Was man üblicherweise tut

tmux lernen: eine Präfix-Taste (Ctrl+B, wenn du sie nicht änderst) vor jedem Befehl, tmux attach, um zurückzukommen, und Zeilen in ~/.tmux.conf für Maus und Zwischenablage. Oder screen, ein älteres Werkzeug derselben Art. So geht jede alltägliche Sache in tmux mit Standardeinstellungen und in Aubergine:

Was Aubergine tut

Ein eigener Socket und eine eigene Konfiguration. Aubergine startet tmux auf einem eigenen Socket namens aubergine, mit einer eigenen Konfigurationsdatei statt deiner: keine Statusleiste, keine Präfix-Taste, Maus an, 50.000 Zeilen Verlauf. Jedes Terminal ist eine tmux-Session mit einer Shell, deiner Login-Shell. Dein eigenes tmux, seine Sessions und deine ~/.tmux.conf werden nicht angefasst.

Das Mausrad scrollt zurück im Terminal, das die Tastatur hat; überall sonst auf dem Canvas zoomt es.

Markier mit der Maus, und es landet in deiner Zwischenablage, sobald du loslässt: tmux gibt die Markierung mit OSC 52, der Escape-Sequenz, die Terminals für die Zwischenablage nutzen, an die Seite weiter, und die Seite legt sie dort ab. Einfügen mit ⌘V (Ctrl+Shift+V außerhalb von macOS). Ein Einfügen mehrerer Zeilen wird geklammert, sodass eine Shell es nicht Zeile für Zeile ausführt.

Zieh an den Rändern eines Terminals auf dem Canvas, um seine Größe zu ändern, und die Shell bekommt ihre neue Größe. Ein Terminal, das an zwei Orten zugleich offen ist, hat eine Größe, die die Ansicht bestimmt, in die du zuletzt getippt hast.

Darunter ist es immer noch tmux. aubergine attach <name> zeigt ein Terminal in einem Fenster deiner Terminal-App, und Open on desktop (auf dem Desktop öffnen) im Menü eines Terminals tut das für dich (unter macOS in Terminal oder iTerm; unter Linux mit einer Befehlszeile, die du festlegst). Bei angehaltenem Server erreichen tmux -L aubergine ls und tmux -L aubergine attach -t <id> weiterhin jede Shell.

Was du brauchst

tmux 3.2 oder neuer, von dir installiert: brew install tmux unter macOS, das Paket deines Systems unter Linux. Aubergine installiert es nicht und zeigt eine Seite, die das sagt, wenn es fehlt oder älter ist. Mit zsh zeigt der Titel eines Terminals den laufenden Befehl und wie der letzte geendet hat; andere Shells laufen ohne das.

Was es nicht ist

  • Nicht tmux auf einem entfernten Server. Das tmux von Aubergine läuft auf dem Rechner, auf dem sein Server läuft. Für eine Shell auf einer Maschine, die du per SSH erreichst, ist tmux auf dieser Maschine weiterhin das Werkzeug. Aubergine selbst kann auf einer anderen Maschine laufen (Using Aubergine from elsewhere); das wurde nur in Containern ausgeführt.
  • Deine eigenen tmux-Sessions werden nicht gezeigt. Der Canvas hält nur die Terminals von Aubergine. aubergine scan listet die interaktiven Shells, die auf diesem Rechner außerhalb von Aubergine offen sind, und aubergine import oder aubergine here gibt einer davon ein neues Terminal auf dem Canvas im selben Ordner; ein Programm, das im alten läuft, bleibt dort. Die Zeilen, die aubergine shell-hook print für deine .zshrc anbietet, tun innerhalb von tmux nichts.
  • Keine tmux-Tasten und keine Bereiche. Es gibt keine Präfix-Taste, und deine eigenen tmux-Tastenbelegungen gelten nicht. Solange ein Terminal die Tastatur hat, geht jede Taste an das Programm darin, außer ein paar Kombinationen, die so gewählt sind, dass keine Shell, kein Editor und kein tmux sie braucht.
  • Nicht unter Windows selbst. Es braucht tmux und eine Unix-Shell; unter Windows läuft es in WSL 2. Siehe Windows mit WSL.

Fragen

Kann ich tmux nutzen, ohne die Tastenkürzel zu lernen?

Ja. Aubergine betreibt tmux ohne Präfix-Taste und ohne Statusleiste, sodass du nie einen tmux-Befehl tippst: Schließ den Tab, um zu gehen, öffne die Seite, um zurückzukommen, scroll mit dem Mausrad, kopier durch Markieren.

Ändert Aubergine meine tmux-Konfiguration?

Nein. Es betreibt tmux auf einem eigenen Socket, aubergine, mit einer eigenen Konfigurationsdatei. Dein tmux-Server, seine Sessions und deine ~/.tmux.conf bleiben, wie sie sind.

Wie scrolle und kopiere ich in den Terminals von Aubergine?

Klick auf ein Terminal, um ihm die Tastatur zu geben, und scroll dann mit dem Mausrad zurück. Markier Text mit der Maus: Er ist in deiner Zwischenablage, sobald du loslässt. Einfügen mit ⌘V oder Ctrl+Shift+V außerhalb von macOS.

Kann ich mich aus meiner eigenen Terminal-App an ein Aubergine-Terminal hängen?

Ja: aubergine attach <name> oder Open on desktop im Menü des Terminals. Es ist an beiden Orten dasselbe Terminal; was du in einem tippst, erscheint im anderen.

Kann Aubergine tmux auf einem Server ersetzen, auf den ich mich per SSH verbinde?

Nicht als solches: Seine Terminals sind auf der Maschine, auf der sein Server läuft. Es kann auf einem Server laufen und aus deinem Browser über einen SSH-Tunnel oder einen Proxy benutzt werden, was nur in Containern ausgeführt wurde, nie auf einer Cloud-Maschine.
