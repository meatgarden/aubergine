Eine Claude-Code-Unterhaltung nach einem Neustart fortsetzen

Der Rechner ist neu gestartet, oder du hast das Terminal geschlossen, und die Unterhaltung mit Claude Code scheint weg. Claude Code behält sie. Aubergine merkt sich, in welcher Unterhaltung jedes Terminal war, und holt sie mit einem Knopf zurück.

Was man üblicherweise tut

In einem Terminal, im Ordner, in dem die Unterhaltung war: claude --continue setzt die neueste Unterhaltung dort fort, und claude --resume lässt dich eine aus einer Liste wählen oder nimmt die ID einer Unterhaltung. Der Haken sind der Ordner und die Wahl: Mit mehreren Agenten in einem Ordner ist die neueste nicht immer die, die du meintest.

Was Aubergine tut

Ein Terminal merkt sich seine Unterhaltung. Wenn Claude Code aus Aubergine gestartet wurde (New terminal ▾ → Claude Code, oder C), sagen seine Hooks Aubergine, in welcher Unterhaltung es ist, und Aubergine behält diese ID beim Terminal.

Resume agent (Agent fortsetzen) erscheint in der Titelleiste des Terminals, sobald seine Shell wieder am Prompt ist: Du hast den Agenten beendet, oder der Rechner ist neu gestartet und das Terminal kam als frische Shell in seinem letzten Ordner zurück. Es startet Claude Code wieder mit --resume und dieser ID, mit dem Startbefehl aus deinen Einstellungen (agents.claudeCommand, standardmäßig claude).

Bei einem Lauf eines Workflows erzählt Resume agent dem Agenten auch noch einmal vom Lauf, damit er bei dem Schritt weitermacht, an dem der Lauf steht.

Past conversations… (frühere Unterhaltungen) in der Palette (⌘K) oder „Past conversations in this folder…“ in den Details eines Terminals listet die früheren Unterhaltungen von Claude Code in einem Ordner: den Namen oder das Erste, was du gesagt hast, wann sie zuletzt aktiv war, wie oft du etwas gesagt hast und ob gerade ein Terminal auf einem Canvas an ihr ist. Read (lesen) zeigt sie, nur zum Lesen. Open on the canvas (auf dem Canvas öffnen) startet ein neues Terminal in diesem Ordner, das sie fortsetzt, und Open a copy (eine Kopie öffnen) startet einen Zweig davon und lässt das Original, wie es ist. Ist schon ein Terminal an dieser Unterhaltung, wirst du vorher gefragt.

Suche. Tipp @ und ein paar Wörter in die Palette, um frühere Unterhaltungen in den Ordnern der Terminals auf deinen Canvases zu durchsuchen. Sie liest die Aufzeichnungen, wenn du fragst, in Grenzen, und sagt, wenn sie abgebrochen wurde. Auf der Befehlszeile listet aubergine history sie, und aubergine history open <id> öffnet eine.

Wo sie stand. Die Notiz des Terminals hält seine Zusammenfassung und ein Log, und jeder Prompt, den du schickst, kommt ins Log. Ask its agent for a recap (den Agenten um eine Zusammenfassung bitten) in seinen Details lässt den Agenten mit aubergine recap --write aufschreiben, wo er steht, und das bleibt beim Terminal. Kommst du nach mehr als 30 Minuten zurück, listet While you were away (während du weg warst), was sich inzwischen geändert hat.

Eine Unterhaltung in einem Terminal außerhalb von Aubergine

Beende in einem Tab deiner Terminal-App den Agenten und führ dann im selben Ordner aubergine here --claude aus: Ein neues Terminal auf dem Canvas startet Claude Code mit --continue, jetzt mit sichtbarem Zustand. aubergine move listet deine Claude-Code-Tabs und startet eine Kopie jeder Unterhaltung auf dem Canvas; mit --stop bittet es einen untätigen Agenten zuerst, sich zu beenden, nachdem du bestätigt hast.

Was es nicht tut

  • Es liest die eigenen Aufzeichnungen von Claude Code, in einem Format, das nicht das von Aubergine ist. Claude Code nennt das Format dieser Dateien intern, und es ändert sich zwischen Versionen. Das Fortsetzen nutzt das eigene --resume von Claude Code mit der ID; Namen, Zählungen und Verläufe sind Aubergines Lesart der Dateien und können nach einem Update von Claude Code fehlen oder dünner sein. Eine Aufzeichnung, die es nicht lesen kann, wird als solche benannt, nicht als leere Unterhaltung gezeigt.
  • Nichts wird kopiert oder behalten. Eine Liste, ein Verlauf oder eine Suche wird gelesen, wenn du fragst, und verworfen, wenn du sie schließt. Aubergine ändert, benennt oder löscht nie eine Unterhaltung, und kein Agent und kein Token kann über Aubergine Unterhaltungen lesen.
  • Die laufende Arbeit wird nicht wiederholt. Was der Agent tat, als er anhielt, wird erst wieder begonnen, wenn du ihn darum bittest.
  • Kein Resume agent für einen anderen Agenten. Aubergine kennt die Unterhaltung eines anderen Agenten nicht und listet für ihn keine früheren Unterhaltungen. Starte ihn im selben Terminal mit der eigenen Fortsetzen-Funktion dieses Agenten wieder und lies die Notiz, um ihm zu sagen, wo er stand.
  • Ein claude, das du selbst getippt hast, wird nicht gemerkt, außer du hast die Hooks, die aubergine hooks print ausgibt, in deine eigenen Claude-Code-Einstellungen eingetragen.
  • Was geprüft wurde. Das Lesen der Aufzeichnungen von Unterhaltungen wird an erfundenen Aufzeichnungen getestet. Es wurde nicht mit jeder Version von Claude Code geprüft.

Fragen

Wie setze ich eine Claude-Code-Session fort, nachdem ich das Terminal geschlossen habe?

Im selben Ordner nimmt claude --continue die neueste Unterhaltung, und claude --resume lässt dich wählen. In Aubergine beendet das Schließen des Browsers nichts, und ein Terminal, dessen Agenten du beendet hast, bietet in seiner Titelleiste Resume agent an.

Wie setze ich eine Claude-Code-Unterhaltung nach einem Neustart fort?

Nach einem Neustart kommt jedes Aubergine-Terminal als frische Shell in seinem letzten Ordner zurück. Wo Claude Code aus Aubergine gestartet wurde, startet Resume agent in der Titelleiste es wieder in der Unterhaltung, in der dieses Terminal war.

Wie finde ich eine alte Claude-Code-Unterhaltung?

Past conversations… in der Palette listet sie für einen Ordner, mit einem Verlauf nur zum Lesen; @ und ein paar Wörter in der Palette durchsuchen sie. Gelistet wird nur, was Claude Code noch aufbewahrt.

Was ist der Unterschied zwischen claude --continue und claude --resume?

--continue setzt die neueste Unterhaltung im Ordner fort; --resume nimmt die, die du wählst, oder eine ID. Resume agent nutzt --resume mit der ID, die sich das Terminal gemerkt hat, und hängt also nicht davon ab, welche Unterhaltung die neueste war.

Können zwei Terminals dieselbe Claude-Code-Unterhaltung fortsetzen?

Aubergine öffnet eine nicht ohne Nachfrage zweimal: Zwei Agenten in einer Unterhaltung verlieren die Nachrichten des anderen. Dir wird das Terminal angeboten, das schon daran ist, oder eine Kopie, die die Unterhaltung verzweigt.
