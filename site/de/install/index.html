Aubergine installieren

Ein Befehl installiert es, einer startet es. Etwa fünf Minuten, Tour eingeschlossen.

Voraussetzungen

  • macOS. Linux sollte genauso funktionieren, ist aber noch nicht getestet.
  • tmux 3.2 oder neuer und Node.js 22 oder neuer. Der Installer braucht außerdem pnpm.

Mit Homebrew holt eine Zeile beides (füg pnpm für den Installer hinzu):

brew install tmux node

Installieren und starten

  1. Installiere Aubergine über npm (braucht nur tmux und Node.js):

    npm install -g @meatgarden/aubergine

    Oder mit dem Installer, der zusätzlich pnpm braucht und aus dem Quellcode baut:

    curl -fsSL https://raw.githubusercontent.com/thirstyeggplant/aubergine/main/install.sh | sh

  2. Starte es und öffne deinen Browser, schon angemeldet.

    aubergine start --open

  3. Mach die Tour. Klick in der Mitte des leeren Canvas auf Show me around. Das legt ein Canvas namens „Demo“ mit ein paar Platzhalter-Agenten an und führt dich in acht kurzen Schritten herum. Nichts in der Demo ist echt, und aubergine demo --remove entfernt sie wieder.

Lieber erst das Skript lesen? Lad es herunter, lies es und führ sh install.sh --dry-run aus, um zu sehen, was es tun würde, ohne etwas zu ändern.

Was der Installer ändert

Nur zwei Dinge: den Installationsordner (~/.aubergine oder AUBERGINE_HOME) und einen Link namens aubergine in einem Ordner auf deinem PATH, in den du schreiben darfst. Er prüft vorher alles und ändert nichts, wenn etwas fehlt.

Er nutzt nicht sudo, bearbeitet nicht die Startdateien deiner Shell, installiert weder Node.js noch pnpm noch tmux und rührt deinen Datenordner nicht an.

Wenn etwas schiefgeht

Führ zuerst aubergine doctor aus. Es prüft die üblichen Ursachen.

Ein Terminal zeigt keinen Status anDer Status braucht zsh, und eine Session aus der Zeit vor einem Update behält ihre alte Shell. Park sie und starte eine neue.

Stoppen, aktualisieren, deinstallieren

  • Stoppe den Server mit Ctrl+C. Deine Terminals laufen weiter; starte den Server wieder und lade die Seite neu, um sie zurückzubekommen.
  • Aktualisiere, wenn du mit npm installiert hast, mit npm install -g @meatgarden/aubergine@latest; wenn du den Installer benutzt hast, mit aubergine update. Starte danach den Server neu.
  • Deinstalliere mit aubergine uninstall. Es entfernt den Link und, nach Rückfrage, die Kopie, die der Installer angelegt hat. Es entfernt nie deine Daten und beendet nie deine Terminals.
  • Starte es bei der Anmeldung mit aubergine service install, dann musst du nur noch den Browser öffnen.
