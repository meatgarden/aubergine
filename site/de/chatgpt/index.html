Codex und ChatGPT

Codex ist der Kommandozeilen-Coding-Agent von OpenAI. Du installierst ihn und meldest dich selbst an; in Aubergine läuft er in einem Terminal wie jedes andere Programm.

Noch nicht ausprobiert

Bisher hat niemand ein echtes Codex in Aubergine laufen lassen. Was diese Seite sagt, ist das, was Aubergine für jedes Programm in einem Terminal und für die aubergine-Befehle tut, und das ist gebaut und getestet; wie sich Codex selbst dort verhält, hat noch niemand gesehen. Wenn du es ausprobierst, erzähl uns, wie es lief.

Starten

Öffne ein Terminal mit New terminal oder N und starte Codex darin wie in jedem Terminal. Aubergine ruft kein Modell auf und hält keinen Schlüssel: Was Codex braucht, hast du ihm bei der Anmeldung gegeben.

Was heute funktioniert

Alles, was Aubergine für jedes Terminal tut:

  • Nebeneinander

    So viele Terminals, wie du willst, auf einem Canvas, und Canvases als Tabs.

  • Befehlsstatus

    Mit zsh zeigt der Titel eines Terminals, dass ein Befehl läuft, und welcher.

  • Farben, Notizen und Felder

    Gib seinem Terminal eine Farbe, führ eine Notiz mit Zusammenfassung und Protokoll, und Felder wie ein Ticket oder einen Verantwortlichen.

  • Parken

    × parkt das Terminal: Es verlässt das Canvas und läuft weiter, und Parked holt es zurück.

  • Ein Terminal für sich

    Öffne das Terminal in einem eigenen Browser-Tab, mit seinen Details und seiner Notiz daneben.

  • Eine Arbeitskopie

    Shell in a folder or a working copy… oder aubergine new --copy startet das Terminal in einem eigenen Checkout auf einem eigenen Branch, damit zwei Agenten nie dieselben Dateien bearbeiten.

  • Suche in der Ausgabe

    ⌘K durchsucht, was jedes Terminal ausgegeben hat, und öffnet das Terminal zurückgescrollt bis zum Treffer.

Was er über die Befehle sagen kann

Jedes Aubergine-Terminal hat den Befehl aubergine und einen Zugang nur für dieses Terminal. Jedes Programm darin, Codex eingeschlossen, kann sie nutzen:

  • aubergine attention waiting "…"

    Markiert das Terminal als wartend auf dich, mit dem, was es braucht; aubergine attention working und aubergine attention done sagen den Rest.

  • aubergine note "…"

    Fügt dem Notizprotokoll des Terminals eine Zeile hinzu.

  • aubergine describe

    Benennt das Terminal nach der Arbeit und führt seine Zusammenfassung; aubergine link add und aubergine field set fügen Links und Felder der Arbeit hinzu. Was du selbst geschrieben hast, gewinnt.

  • aubergine workflow status

    Liest den aktuellen Schritt eines Workflows; aubergine workflow done meldet ihn als erledigt und gibt den nächsten aus.

  • aubergine task add

    Schlägt eine Aufgabe für die Warteschlange vor, und aubergine ask bittet dich um etwas, das nur ein Mensch tun kann. Beides wartet auf deiner Liste.

Wie du es ihm sagst

Codex weiß nichts von Aubergine, bis man es ihm sagt. Das hier gibt fünf Zeilen aus, die du in die Anweisungen einfügst, die dein Agent zu Beginn jeder Unterhaltung in einem Projekt liest; wohin sie gehören, steht in seiner eigenen Dokumentation:

aubergine guide --snippet

Die Zeilen sagen ihm, einmal aubergine guide auszuführen, wenn er in einem Aubergine-Terminal ist, und die Anleitung sagt den Rest. Aubergine gibt die Zeilen aus und schreibt sie nie in eine Datei.

Wenn dein Agent einen MCP-Server starten kann, bietet aubergine mcp dasselbe als Tools an; in einem Aubergine-Terminal braucht er für die eigene Arbeit des Terminals keine Adresse und kein Token.

Heute nur für Claude Code gebaut

Was Aubergine von sich aus für einen Agenten tut, ist für Claude Code gebaut. Für Codex gilt heute:

  • Er steht nicht im Menü New terminal: Du startest ihn selbst in einem Terminal.
  • Aubergine sieht ihn nicht als Agenten: Er wird nicht von selbst als wartend oder fertig markiert, nur wenn er aubergine attention ausführt.
  • Nichts wird für ihn getippt: Ein Workflow, der in seinem Terminal gestartet wird, tippt nichts und zeigt die Zeile, die du ihm selbst gibst, und eine Zusammenfassung oder Nachricht wird ihm nicht angekündigt.
  • Die Warteschlange gibt ihm keine Aufgabe: Eine Aufgabe geht nur an ein Terminal, in dem ein Agent zu sehen und frei ist.
  • Es gibt kein Resume agent, keine Liste früherer Unterhaltungen, keine Liste, wie er eingerichtet ist, und keinen Dialog für Aubergines Tools.
  • aubergine move und aubergine here --claude holen nur Claude Code herüber.
  • Er wird nicht daran erinnert, sein Terminal zu benennen oder eine Zusammenfassung zu führen.

Alles dazu steht auf der Seite Claude Code.

ChatGPT im Browser

ChatGPT in einem Browser-Tab ist eine Webseite, kein Programm in einem Terminal, und läuft daher nicht auf dem Canvas.

Aubergine ist nicht mit OpenAI verbunden. Codex und ChatGPT sind Marken von OpenAI.

In fünf Minuten startklar

Du brauchst macOS mit tmux 3.2 oder neuer und Node.js 22 oder neuer. brew install tmux node holt beides.

npm install -g @meatgarden/aubergine
