استأنف محادثة Claude Code بعد إعادة التشغيل

أُعيد تشغيل الحاسوب، أو أغلقت الطرفية، فبدت محادثة Claude Code ضائعة. لكن Claude Code يحتفظ بها. ويتذكر Aubergine المحادثة التي كانت فيها كل طرفية ويعيدها بزر واحد.

ما يفعله الناس عادةً

في طرفية، داخل المجلد الذي كانت فيه المحادثة: يتابع claude --continue أحدث محادثة هناك، ويتيح لك claude --resume اختيار واحدة من قائمة، أو يأخذ معرّف محادثة. والعقبة هي المجلد والاختيار: مع عدة وكلاء في مجلد واحد، ليست الأحدث دائمًا هي التي قصدتها.

ما يفعله Aubergine

الطرفية تتذكر محادثتها. حين يُشغَّل Claude Code من Aubergine (New terminal ▾ → Claude Code، أو C)، تخبر خطافاتُه Aubergine بالمحادثة التي هو فيها، ويحفظ Aubergine ذلك المعرّف مع الطرفية.

يُعرض Resume agent (استئناف الوكيل) في شريط عنوان الطرفية بمجرد أن تعود صدفتها إلى المحث: خرجت من الوكيل، أو أُعيد تشغيل الحاسوب فعادت الطرفية صدفةً جديدة في آخر مجلد لها. ويشغّل Claude Code من جديد مع --resume وذلك المعرّف، بأمر التشغيل الذي في إعداداتك (agents.claudeCommand، وهو claude افتراضيًا).

في تشغيل لسير عمل، يخبر Resume agent الوكيلَ بالتشغيل من جديد أيضًا، فيتابع من الخطوة التي بلغها التشغيل.

يسرد Past conversations…‎ في لوحة الأوامر (⌘K)، أو «Past conversations in this folder…‎» في تفاصيل الطرفية، محادثات Claude Code السابقة في مجلد: الاسم أو أول ما قلته، ومتى كانت آخر مرة نشطت فيها، وكم مرة تحدثت، وهل توجد الآن طرفية على لوحة تعمل فيها. يعرضها Read (قراءة) للقراءة فقط. ويشغّل Open on the canvas (افتح على اللوحة) طرفية جديدة في ذلك المجلد مستأنفة فيها، ويبدأ Open a copy (افتح نسخة) فرعًا منها ويترك الأصل كما هو. وإن كانت طرفية في تلك المحادثة من قبل، تُسأل أولًا.

البحث. اكتب @ وبعض الكلمات في لوحة الأوامر للبحث في المحادثات السابقة في مجلدات الطرفيات التي على لوحاتك. يقرأ السجلات حين تطلب، ضمن حدود، ويقول متى اقتُطع البحث. وفي سطر الأوامر، يسردها aubergine history ويفتح aubergine history open <id> إحداها.

أين توقف. تحفظ ملاحظة الطرفية ملخصها وسجلًا، ويُضاف كل موجّه ترسله إلى السجل. ويجعل Ask its agent for a recap (اطلب من وكيلها ملخص الحالة) في تفاصيلها الوكيلَ يكتب أين وصل بالأمر aubergine recap --write، ويُحفظ ذلك مع الطرفية. وحين تعود بعد أكثر من 30 دقيقة، يسرد While you were away (في غيابك) ما تغيّر في أثناء ذلك.

محادثة في طرفية خارج Aubergine

في تبويب من تطبيق الطرفية لديك، اخرج من الوكيل، ثم شغّل aubergine here --claude في المجلد نفسه: تشغّل طرفية جديدة على اللوحة Claude Code مع --continue، وحالته الآن ظاهرة. ويسرد aubergine move تبويبات Claude Code لديك ويبدأ نسخة من كل محادثة على اللوحة؛ ومع --stop يطلب من الوكيل الخامل أن يخرج أولًا، بعد أن تؤكد.

ما لا يفعله

  • يقرأ سجلات Claude Code نفسها، بشكل ليس من وضع Aubergine. يصف Claude Code شكل تلك الملفات بأنه داخلي، وهو يتغيّر بين الإصدارات. يستخدم الاستئناف --resume الخاص بـ Claude Code مع المعرّف؛ أما الأسماء والأعداد والنصوص فهي قراءة Aubergine للملفات، وقد تغيب أو تقلّ بعد تحديث Claude Code. والسجل الذي لا يستطيع قراءته يُقال عنه ذلك، ولا يُعرض محادثةً فارغة.
  • لا يُنسخ شيء ولا يُحفظ. القائمة أو النص أو البحث يُقرأ حين تطلب ويُترك حين تغلقه. ولا يغيّر Aubergine أي محادثة ولا يعيد تسميتها ولا يحذفها، ولا يستطيع أي وكيل أو رمز قراءة المحادثات عبره.
  • العمل الجاري لا يُعاد. ما كان الوكيل يفعله حين توقف لا يُبدأ من جديد حتى تطلبه منه.
  • لا Resume agent لوكيل آخر. لا يعرف Aubergine محادثة وكيل آخر، ولا يسرد له محادثات سابقة. شغّله من جديد في الطرفية نفسها بطريقة الاستئناف الخاصة بذلك الوكيل، واقرأ الملاحظة لتخبره أين توقف.
  • الأمر claude الذي كتبته بنفسك لا يُتذكَّر، إلا إن أضفت إلى إعدادات Claude Code الخاصة بك الخطافات التي يطبعها aubergine hooks print.
  • ما الذي تُحقّق منه. قراءة سجلات المحادثات مختبرة على سجلات مصطنعة. ولم يُتحقَّق منها مع كل إصدار من Claude Code.

أسئلة

كيف أستأنف جلسة Claude Code بعد إغلاق الطرفية؟

في المجلد نفسه، يأخذ claude --continue أحدث محادثة ويتيح لك claude --resume الاختيار. وفي Aubergine، لا يُنهي إغلاق المتصفح شيئًا، والطرفية التي خرجت من وكيلها تعرض Resume agent في شريط عنوانها.

كيف أستأنف محادثة Claude Code بعد إعادة التشغيل؟

بعد إعادة التشغيل تعود كل طرفية في Aubergine صدفةً جديدة في آخر مجلد لها. وحيث شُغّل Claude Code من Aubergine، يشغّله Resume agent في شريط العنوان من جديد في المحادثة التي كانت فيها تلك الطرفية.

كيف أعثر على محادثة قديمة في Claude Code؟

يسردها Past conversations…‎ في لوحة الأوامر لمجلد ما، مع نص للقراءة فقط؛ وكتابة @ وبعض الكلمات في لوحة الأوامر تبحث فيها. ولا يُسرد إلا ما لا يزال Claude Code يحتفظ به.

ما الفرق بين claude --continue وclaude --resume؟

يتابع --continue أحدث محادثة في المجلد؛ ويأخذ --resume التي تختارها، أو معرّفًا. ويستخدم Resume agent الخيار --resume مع المعرّف الذي تذكّرته الطرفية، فلا يعتمد على أيّ المحادثات كانت الأحدث.

هل يمكن لطرفيتين متابعة محادثة Claude Code نفسها؟

لا يفتح Aubergine محادثة مرتين دون أن يسأل: وكيلان في محادثة واحدة يضيّع كلٌّ منهما رسائل الآخر. ويُعرض عليك الطرفية التي فيها المحادثة من قبل، أو نسخة، تتفرع بها المحادثة.
