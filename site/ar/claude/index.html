ما يفعله Aubergine لـ Claude Code

يعمل Claude Code في طرفية Aubergine مثل أي برنامج. وإذا شُغّل من Aubergine، يخبر اللوحة أيضًا بما يفعله، ويستطيع Aubergine أن يطلعه على المطلوب، وأن يستأنفه، وأن يعرض طريقة إعداده. هذا كل شيء، بالترتيب الذي تلقاه به.

تثبّت Claude Code وتسجّل الدخول إليه بنفسك. لا يستدعي Aubergine أي نموذج ولا يحتفظ بأي مفتاح: إنه يشغّل الأمر claude الموجود لديك أصلًا.

شغّله من القائمة

New terminal ▾ → Claude Code، أو C حين لا تكون لوحة المفاتيح مع أي طرفية، يشغّل claude في طرفية جديدة مع ملف إعدادات يكتبه Aubergine في مجلد بياناته الخاص. إعدادات Claude Code الخاصة بك لا تُمس.

الأمر الذي يشغّله هو agents.claudeCommand في الإعدادات، وهو claude ما لم تغيّره؛ ويضيف Aubergine خياراته الخاصة في آخره.

أين: القائمة بجانب New terminal، أعلى قائمة الطرفيات.

اعرف متى يعمل وينتظر وينتهي

الخطافات في ملف الإعدادات ذاك تخبر اللوحة بما يفعله الوكيل. حين ترسل موجّهًا، يُضاف الموجّه إلى سجل ملاحظات الطرفية وتُظهر الطرفية working (يعمل). وحين يحتاج إليك الوكيل، بسؤال عن إذن أو لأنه خامل ينتظر مدخلات، يتحوّل إطاره إلى لون الانتظار ويقول عنوانه وصفّه waiting for you (بانتظارك). وحين يتوقف، يُظهر finished (انتهى).

المفتاح W ينتقل إلى الطرفية التالية التي تنتظر، وNotify يشغّل إشعارات سطح المكتب للطرفيات التي تبدأ الانتظار. قد تحوي الموجّهات أسرارًا: "agents": { "logPrompts": false } في config.json يُبقيها خارج سجل الملاحظات.

أين: عنوان الطرفية، وصفّها في القائمة، والعدد بجانب For you في الأعلى.

Claude Code شغّلته بنفسك

إذا كُتب claude يدويًا في طرفية عادية فإنه يعمل مثل أي برنامج، لكن Aubergine لا يرى إلا صدفة مشغولة بتشغيله: لا waiting for you، ولا يُكتب له شيء حين تبدأ سير عمل فيها. لتغيير ذلك، اطبع الخطافات وأضفها يدويًا إلى إعدادات Claude Code الخاصة بك. لا تفعل شيئًا خارج طرفية Aubergine.

يسمّي نفسه ويحتفظ بملخص

الوكيل الذي يشغّله Aubergine يُطلب منه عند بدئه أن يسمّي طرفيته باسم العمل وأن يحتفظ بملخص، باستخدام aubergine describe وaubergine link add وaubergine field set، ويُذكَّر مرة واحدة حين يتوقف بلا اسم من عنده أو بلا ملخص. ما تكتبه أنت يغلب؛ وما يقوله الوكيل عن الشيء نفسه ينتظر بجانبه مع Use this (استخدم هذا). ويمكن إيقاف التذكير في Settings.

أين: تفاصيل الطرفية، مع اسمها وملخصها وحقولها وروابطها.

سير العمل والمهام والملخصات والرسائل تصل إليه

يكتب Aubergine أربع جمل ثابتة في الطرفية، وهذه فقط: أن سير عمل قد بدأ، وأن الوكيل طُلب منه كتابة شيء، وأنك طلبت ملخصًا، وأن رسالة تنتظر. كل جملة تسمّي أمرًا واحدًا يشغّله الوكيل. ولا تُكتب جملة إلا حيث يُرى أن لوحة المفاتيح مع وكيل: وكيل شغّله Aubergine، أو وكيل في إعداداته الخطافات الناتجة عن aubergine hooks print.

وبالطريقة نفسها، لا تذهب مهمة من الطابور إلا إلى طرفية فيها وكيل كهذا في الواجهة ومتفرغ، وClaude Code on a workflow…‎ يشغّل طرفية جديدة يُخبَر وكيلها بالتشغيل في أول موجّه له.

أين: Run a workflow…‎ في قائمة عنوان الطرفية، وRuns في أعلى الصفحة.

Resume agent (استئناف الوكيل)

يتذكر Aubergine المحادثة التي كانت فيها طرفية الوكيل. حين تعود صدفتها إلى المحث، لأنك خرجت من الوكيل أو أُعيد تشغيل الحاسوب، تعرض الطرفية Resume agent، الذي يشغّل الوكيل من جديد في تلك المحادثة. وفي طرفية مرتبطة بتشغيل، يخبر الوكيل بالتشغيل من جديد أيضًا.

أين: شريط عنوان الطرفية.

المحادثات السابقة

Past conversations…‎ يعرض المحادثات السابقة للوكيل في مجلد: اقرأ واحدة، أو افتحها على اللوحة، أو افتح نسخة تترك الأصل كما هو. اكتب @ وبعض الكلمات في لوحة الأوامر للبحث فيها؛ والأمر aubergine history يعرضها في سطر الأوامر. لا يُحتفظ بشيء مما يُقرأ، ولا يستطيع أي رمز ولا أي وكيل قراءة المحادثات عبر Aubergine.

يقرأ الملفات التي يحتفظ بها Claude Code. وشكلها داخلي خاص بـ Claude Code ويتغيّر بين الإصدارات. بعد تحديث الوكيل قد تقلّ الأسماء والنصوص، والسجل الذي لا يستطيع Aubergine قراءته يُقال عنه ذلك، ولا يُعرض فارغًا أبدًا.

أين: لوحة الأوامر (⌘K)، و«Past conversations in this folder…‎» في تفاصيل الطرفية.

طريقة إعداده

قائمة بما تقول ملفات إعدادات الوكيل إنه أُعطيه: خوادم MCP، والإضافات، والخطافات، والمهارات، وقواعد الأذونات، وملفات الإعدادات، كلٌّ مع مصدره، وما أضافه Aubergine. أسماء فقط، لا قيمة ولا سرّ أبدًا. تقول كيف أُعدّ الوكيل، لا ما حمّله الوكيل الجاري، وتقول صراحة ما لا يمكنها معرفته، مثل الموصلات التي تأتي مع حسابك.

أين: ‎⚙ on على الطرفية، و«What is switched on for this agent…‎» في لوحة الأوامر، وتفاصيل الطرفية.

أدوات Aubergine له

Claude Code with Aubergine tools…‎ يسأل أولًا عمّا يجوز للوكيل فعله: None (لا شيء)؛ أو Its own work only (عمله فقط)، ببيانات اعتماد الطرفية نفسها؛ أو More…‎ (المزيد)، نطاقات تختارها، يُصنع لها رمز لتلك الطرفية وحدها ويُلغى حين تُنهى الطرفية نهائيًا. الأدوات هي aubergine mcp، تُمرَّر إلى الوكيل في سطر تشغيله؛ ولا تُكتب إعداداته الخاصة.

أين: القائمة بجانب New terminal.

انقل Claude Code مفتوحًا لديك أصلًا

لا يمكن نقل وكيل يعمل، لكن يمكن نقل محادثته. Open elsewhere يعرض علامات تبويب Claude Code لديك، مع Fork to canvas و، لوكيل خامل، Stop and resume here، الذي يسألك أولًا. ومن طرفية، يفعل aubergine move الشيء نفسه، وaubergine here --claude يشغّل Claude Code على اللوحة مكمّلًا آخر محادثة في ذلك المجلد.

أين: Open elsewhere في الشريط فوق اللوحة، أو O.

في نسخة عمل خاصة به

الأمر aubergine here --copy --claude يشغّل Claude Code في نسخته المسحوبة الخاصة من المستودع، على فرعه الخاص، فلا يعدّل وكيلان الملفات نفسها أبدًا. ونافذة طرفية Claude Code مع الأدوات فيها الخيار نفسه.

ما الذي جُرّب

العرض التجريبي المرفق مع Aubergine يستخدم بدلاء، نصوصًا برمجية قصيرة تشغّل الأوامر والخطافات نفسها التي يشغّلها وكيل حقيقي، لا Claude Code حقيقيًا. ومع وكيل حقيقي، لم تُجرَّب بعدُ الموافقة، ونسخة العمل، والمهمة من الطابور، والجدول الزمني.
