كيف تثبّت Aubergine

أمر واحد يثبّته، وأمر واحد يشغّله. نحو خمس دقائق، مع الجولة.

المتطلبات

  • macOS. على Linux شُغّل داخل حاويات فقط: حزمة npm على Ubuntu 24.04 وصورة الحاوية على Debian. Windows نفسه غير مدعوم؛ يمكن أن يعمل Aubergine داخل WSL 2، ولم يُجرَّب ذلك بعد: راجع التثبيت على Windows باستخدام WSL.
  • tmux 3.2 أو أحدث، ومعه Node.js 22 أو أحدث. ويحتاج المثبِّت أيضًا إلى pnpm.

مع Homebrew، سطر واحد يثبّت الاثنين (أضف pnpm من أجل المثبِّت):

brew install tmux node

التثبيت والتشغيل

  1. ثبّت Aubergine من npm (يحتاج إلى tmux وNode.js فقط):

    npm install -g @meatgarden/aubergine

    أو بالمثبِّت، الذي يحتاج أيضًا إلى pnpm ويبني من الشيفرة المصدرية:

    curl -fsSL https://raw.githubusercontent.com/thirstyeggplant/aubergine/main/install.sh | sh

  2. شغّله وافتح متصفحك، وأنت مسجَّل الدخول.

    aubergine start --open

  3. خذ الجولة. انقر Show me around في وسط اللوحة الفارغة. يصنع لوحة اسمها «Demo» فيها بضعة وكلاء بدلاء ويمرّ بك عبر ثماني خطوات قصيرة. لا شيء في العرض التجريبي حقيقي، والأمر aubergine demo --remove يزيله.

تفضّل قراءة النص البرمجي أولًا؟ نزّله، واقرأه، وشغّل sh install.sh --dry-run لترى ما سيفعله دون تغيير أي شيء.

ما يغيّره المثبِّت

شيئان فقط: مجلد التثبيت (~/.aubergine، أو AUBERGINE_HOME) ورابط واحد اسمه aubergine في مجلد على PATH لديك تستطيع الكتابة فيه. يتحقق من كل شيء أولًا ولا يغيّر شيئًا إذا نقص شيء.

لا يستخدم sudo، ولا يعدّل ملفات بدء الصدفة لديك، ولا يثبّت Node.js أو pnpm أو tmux، ولا يمس مجلد بياناتك.

إذا حدث خطأ

شغّل aubergine doctor أولًا. يتحقق من الأسباب المعتادة.

ما تراهما تفعله
«This browser is not signed in yet» (هذا المتصفح لم يسجّل الدخول بعد)افتح رابط تسجيل الدخول مرة واحدة في ذلك المتصفح. الأمر aubergine open --print يطبعه من جديد.
صفحة تقول إن tmux غير موجود أو قديم جدًاثبّت tmux أو حدّثه (brew install tmux)، ثم أعد تشغيل الخادم.
الخادم لا يبدأ لأن المنفذ مشغولاستخدم منفذًا آخر: AUBERGINE_PORT=4700 aubergine start.
aubergine: command not foundالرابط ليس على PATH لديك. يطبع المثبِّت السطر الواحد الذي تضيفه إلى ملف بدء الصدفة.
طرفية لا تُظهر شارات الحالةتحتاج الحالة إلى zsh، والجلسة التي أُنشئت قبل تحديثٍ تبقى بصدفتها القديمة. اركنها وابدأ واحدة جديدة.

الإيقاف والتحديث وإلغاء التثبيت

  • أوقف الخادم بـ Ctrl+C. تبقى طرفياتك تعمل؛ شغّل الخادم من جديد وأعد تحميل الصفحة لتستعيدها.
  • حدّث، إن ثبّتّ بـ npm، بالأمر npm install -g @meatgarden/aubergine@latest؛ وإن استخدمت المثبِّت، بالأمر aubergine update. ثم أعد تشغيل الخادم.
  • ألغِ التثبيت بالأمر aubergine uninstall. يزيل الرابط، وبعد أن يسألك، النسخة التي صنعها المثبِّت. لا يزيل بياناتك أبدًا ولا يُنهي طرفياتك أبدًا.
  • شغّله عند تسجيل الدخول بالأمر aubergine service install، فلا يبقى عليك إلا فتح المتصفح.
