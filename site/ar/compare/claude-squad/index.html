Aubergine مقابل Claude Squad

يقف الاثنان على الأرض نفسها: كل وكيل في جلسة tmux، وكلٌّ في شجرة عمل Git خاصة به، وكلاهما مجاني ومفتوح المصدر. Claude Squad برنامج داخل طرفيتك. وAubergine صفحة في متصفحك تقف فيها الطرفيات جنبًا إلى جنب.

من أين جاء هذا. ما يُقال هنا عن Claude Squad مأخوذ من مستودعه وملف README فيه كما قُرئا في 26 نوفمبر 2026. لم نشغّل Claude Squad. إن كان شيء خاطئًا أو قديمًا، أخبرنا.

أيهما تختار

اختر Claude Squad إن كنت تعيش في طرفية وتريد فيها برنامجًا صغيرًا واحدًا يشغّل الوكلاء في أشجار عمل ويدفع فروعهم، ولا شيء أكثر.

اختر Aubergine إن أردت أن ترى عدة وكلاء يعملون في آن واحد، وتعرف أيهم ينتظرك، ويكون حولهم طابور وجداول زمنية وواجهة API.

ما هو Claude Squad

بحسب وصفه لنفسه، تطبيق طرفية يدير عدة وكلاء محليين من Claude Code وCodex وGemini وغيرها في مساحات عمل منفصلة. تشغّله بالأمر cs: قائمة جلسات مع معاينة وعلامة تبويب للفروق، في نافذة طرفية واحدة. كل جلسة جلسة tmux في شجرة عمل Git على فرعها الخاص. يحتاج إلى tmux وgh، وهو بموجب رخصة AGPL-3.0.

أين يختلفان

واحدة تلو الأخرى، أو كلها معًا. يعرض Claude Squad قائمة ومعاينة للجلسة التي اخترتها. ويرسم Aubergine كل طرفية حيّةً على لوحة، فخمسة وكلاء هم خمس طرفيات أمام عينيك، وقائمة واحدة تقول حالة كلٍّ منها بالكلمات.

من ينتظر. لم نجد شيئًا في ملف README الخاص بـ Claude Squad عن إخبارك بأن وكيلًا ينتظر أو انتهى. أما Aubergine فيعلّم الطرفية المنتظرة باللون، ويعدّ ما ينتظر في الأعلى، وينتقل إلى التالية بمفتاح، ويستطيع إرسال إشعار من الصفحة المفتوحة.

ما حول الوكلاء. في Aubergine طابور مهام بحدّ، وجداول زمنية، وسير عمل بخطوات يوافق عليها إنسان، وملاحظات وحقول على كل طرفية، وواجهة HTTP API، وخادم MCP. ويقتصر Claude Squad على الجلسات وفروعها.

ما لدى Claude Squad مما ليس لدى Aubergine

  • يعمل داخل الطرفية المفتوحة لديك أصلًا، بلا خادم ولا متصفح. ويعمل عبر SSH مثل أي برنامج طرفية؛ أما Aubergine من مكان آخر فيحتاج إلى نفق أو خادم وسيط.
  • يودِع فرعًا ويدفعه نيابة عنك، ويوقف جلسة مؤقتًا بإيداع عملها. ولا يودِع Aubergine ولا يدفع أبدًا.
  • نمط تجريبي يقبل مطالبات الوكيل من تلقاء نفسه. ولا يجيب Aubergine وكيلًا نيابة عنك أبدًا.

أسئلة

هل Aubergine بديل لـ Claude Squad؟

نعم، للعمل نفسه بطريقة أخرى. كلاهما يشغّل كل وكيل في جلسة tmux ويستطيع أن يعطي كلًّا منهم شجرة عمل Git على فرعه الخاص. يفعل Claude Squad ذلك من برنامج في طرفيتك؛ ويفعله Aubergine من صفحة في متصفحك وكل طرفية أمام عينيك.

هل يستخدم كلاهما tmux؟

نعم. يذكر Claude Squad أن tmux متطلَّب مسبق، ويصنع جلسة tmux لكل وكيل. ويحتاج Aubergine إلى tmux 3.2 أو أحدث، ويشغّله على مقبس خاص به بإعداداته الخاصة، فلا يُمس tmux الخاص بك.

هل يعمل Claude Squad مع وكلاء غير Claude Code؟

يقول ملف README الخاص به إن البرنامج الافتراضي هو claude، وإن غيره، مثل Codex أو Gemini أو Aider، يُسمّى بالخيار -p. ويشغّل Aubergine أي برنامج لسطر الأوامر في طرفية؛ وما يفعله من تلقاء نفسه لوكيل مبني لـ Claude Code.

ما رخصة كلٍّ منهما؟

Claude Squad بموجب AGPL-3.0، وAubergine بموجب رخصة MIT. وكلاهما مجاني.

Aubergine غير تابع لـ Claude Squad ولا لـ Anthropic. Claude Squad اسم مشروع smtg-ai؛ وClaude علامة تجارية لـ Anthropic.

جاهز للعمل في خمس دقائق

تحتاج إلى macOS مع tmux 3.2 أو أحدث، ومعه Node.js 22 أو أحدث. الأمر brew install tmux node يثبّت الاثنين.
