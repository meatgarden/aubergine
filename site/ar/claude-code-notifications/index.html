اعرف متى ينتهي Claude Code أو ينتظرك

تعطي Claude Code مهمة، وتنصرف إلى شيء آخر، ثم تعود بعد عشرين دقيقة فتجده ينتظر موافقتك منذ الدقيقة الثانية. يُظهر Aubergine في صفحة واحدة أيّ طرفية تعمل، وأيّها بانتظارك، وأيّها انتهت.

ما يفعله الناس عادةً

يشغّل Claude Code خطافات، وهي أوامر من عندك، في لحظات مثل توقفه (Stop) أو إرساله إشعارًا (Notification). والحل المعتاد خطاف في إعدادات Claude Code الخاصة بك يُصدر صوتًا أو يُظهر إشعارًا على سطح المكتب. وهذا يعمل، والنصوص البرمجية عليك أنت كتابتها وصيانتها.

ما يفعله Aubergine

شغّل Claude Code من Aubergine: New terminal ▾ → Claude Code أعلى قائمة الطرفيات، أو C. يشغّل Aubergine الأمر claude مع ملف إعدادات يولّده في مجلد بياناته الخاص ويسمّيه في سطر الأوامر. إعدادات Claude Code الخاصة بك لا تُمس. والخطافات في ذلك الملف تخبر الصفحة بما يفعله الوكيل:

  • حين ترسل موجّهًا، تُظهر الطرفية working (يعمل)، ويُضاف الموجّه إلى سجل ملاحظتها؛
  • حين يحتاج إليك الوكيل (سؤال عن إذن، أو لأنه خامل ينتظر مدخلات)، يأخذ حدّها لون الانتظار، ويقول عنوانها وصفّها في القائمة waiting for you (بانتظارك)؛
  • حين يتوقف، تُظهر الطرفية finished (انتهى).

العدد بجانب For you، أعلى يمين الصفحة، هو كل ما ينتظرك، في كل المشاريع: طرفيات فيها سؤال، وتشغيلات تنتظر موافقتك، ومسودات للقراءة، ومهام مقترحة. الضغط عليه يفتح Runs، وعمود Waiting for you فيها هو تلك القائمة. وتُظهر علامة تبويب اللوحة كم طرفية فيها تنتظر.

التالية التي تنتظر. ينتقل W إلى الطرفية التالية التي بانتظارك حين لا تكون لوحة المفاتيح مع أي طرفية؛ وعلى macOS يفعل ⌃⌘J ذلك من داخل طرفية أيضًا. وفي غيره تجده في لوحة الأوامر.

إشعارات من الصفحة المفتوحة. في Settings → Notifications الخيار Notify me on the desktop when a terminal starts waiting (أشعرني على سطح المكتب حين تبدأ طرفية الانتظار). وإذا شُغّل، تُظهر الصفحة إشعارًا من متصفحك حين تبدأ طرفية الانتظار أو ينتهي وكيلها، إلا إن كنت تنظر إلى تلك الطرفية. ويطلب المتصفح إذنك مرة واحدة.

القواعد. في تبويب Rules من Runs، تستطيع قاعدة أن تُطلق Notify me (أشعرني) حين تنتهي مهمة، أو تفشل مهمة، أو تحتاج مهمة إليك، أو يُطلب منك شيء، أو ينطلق جدول أو يتعذّر تشغيله: إشعار من الصفحة المفتوحة، مع جملة عمّا حدث.

الوكلاء الآخرون، وclaude كتبته بنفسك

لا يقرأ Aubergine مخرجات الطرفية ليخمّن. أي وكيل آخر، أو أي برنامج، يقول الشيء نفسه بنفسه بالأوامر aubergine attention waiting "what it needs" وaubergine attention working وaubergine attention done في طرفيته. ويطبع aubergine guide --snippet خمسة أسطر للملف الذي يقرؤه وكيلك في بداية المحادثة؛ وهي تطلب منه أن يشغّل aubergine guide، الذي يشرح هذه الأوامر.

Claude Code الذي شغّلته بكتابة claude في طرفية عادية هو، بالنسبة إلى Aubergine، صدفة مشغولة ببرنامج: لا waiting for you. شغّله من القائمة بدلًا من ذلك، أو أضف يدويًا إلى إعداداتك الخطافات التي يطبعها aubergine hooks print؛ ولا تفعل شيئًا خارج طرفية Aubergine.

ما لا يفعله

  • لا صوت خاصًا به. لا يُصدر Aubergine أي صوت. ولا يُصدر الإشعار صوتًا إلا إن كان متصفحك أو نظامك يفعل ذلك للإشعارات.
  • لا شيء ما دامت لا توجد صفحة مفتوحة. تأتي الإشعارات من صفحة Aubergine مفتوحة في متصفحك؛ ولا يرسل الخادم أيًّا منها بنفسه. وإذا أُغلقت كل الصفحات، تظل الطرفية تقول waiting for you، ويكون العدد موجودًا حين تفتح الصفحة.
  • لا إشعارات فورية إلى الهاتف. لا يوجد تطبيق ولا خدمة إشعارات فورية. يمكن إقران متصفح الهاتف ليفتح الصفحة نفسها؛ راجع اطّلع على وكلائك من هاتفك، ولم يُجرَّب ذلك على هاتف حقيقي.
  • ما الذي تُحقّق منه. تتحقق اختبارات المتصفح من الإشعارات مقابل بديل عن إشعارات المتصفح نفسه. أما شكل الإشعار الحقيقي، وهل يظهر أصلًا، فأمرهما لمتصفحك ولإعدادات نظامك الخاصة به.

أسئلة

كيف أتلقى إشعارًا حين ينتهي Claude Code؟

شغّل Claude Code من Aubergine، ثم فعّل Notify me on the desktop when a terminal starts waiting تحت Settings → Notifications. عندها تُظهر الصفحة المفتوحة إشعارًا من المتصفح حين تبدأ طرفية انتظارك أو ينتهي وكيلها. ودون إشعار، تقول الطرفية finished.

هل يمكن أن يُصدر Claude Code صوتًا حين يحتاج إلى مدخلات؟

لا يُصدر Aubergine أي صوت. ويُصدر الإشعار صوتًا إن جعله متصفحك أو نظامك يفعل ذلك. ويستطيع خطاف من عندك في إعدادات Claude Code الخاصة بك أن يُصدر صوتًا؛ ولا يكتب Aubergine في تلك الإعدادات أبدًا.

كيف أعرف أيّ جلسة Claude Code تنتظر حين أشغّل عدة جلسات؟

في Aubergine يكون حدّ الطرفية المنتظرة وحالتها بلون الانتظار، ويقول صفّها في القائمة waiting for you، ويقول العدد بجانب For you كم شيئًا ينتظر. وينتقل W إلى التالية.

هل أتلقى إشعارًا والمتصفح مغلق؟

لا. تأتي الإشعارات من صفحة Aubergine مفتوحة. والحالة محفوظة، فتكون الطرفيات المنتظرة معلَّمة حين تفتح الصفحة من جديد.

هل يعمل مع وكلاء غير Claude Code؟

ليس من تلقاء نفسه: الخطافات مبنية لـ Claude Code. ويستطيع أي وكيل آخر أن يبلّغ بالشيء نفسه بالأوامر aubergine attention waiting وworking وdone حين تطلب منه تعليماته ذلك؛ ويطبع aubergine guide --snippet الأسطر اللازمة لتلك التعليمات.
