गाइड

छोटी, काम की गाइड। पूरा संदर्भ README है।

  • Aubergine इंस्टॉल करें

    ज़रूरतें, एक लाइन वाला इंस्टॉलर, वह क्या बदलता है, और आम समस्याओं के हल।

  • WSL के साथ Windows पर इंस्टॉल करें

    Aubergine को WSL 2 के अंदर चलाएँ और अपने Windows ब्राउज़र से इस्तेमाल करें। Linux वाले कदम चलाए गए हैं; Windows पर अभी कुछ नहीं आज़माया गया।

  • एक साथ कई कोडिंग एजेंट चलाएँ

    कैनवस, इंतज़ार की गिनती, क्यू, वर्किंग कॉपी और वर्कफ़्लो, एक ही टूर में।

  • Aubergine में Claude Code

    Aubergine Claude Code के लिए खुद से क्या करता है, और हर चीज़ कहाँ है।

  • Codex और ChatGPT

    किसी भी प्रोग्राम की तरह टर्मिनल में Codex, यह क्या रिपोर्ट कर सकता है, और क्या सिर्फ़ Claude Code के लिए बना है।

  • वर्किंग कॉपी

    हर एजेंट को उसका अपना चेकआउट और ब्रांच दें, ताकि दो एजेंट कभी एक ही फ़ाइलें न बदलें।

  • रीस्टार्ट के बाद भी टर्मिनल बनाए रखें

    ब्राउज़र बंद करना, Aubergine को रीस्टार्ट करना और कंप्यूटर को रीस्टार्ट करना, हर एक क्या बचाए रखता है, और जहाँ थे वहीं से फिर कैसे शुरू करें।

  • Keep a process running after you close the terminal

    Close the tab, the window or the browser and nothing ends: what tmux gives, without learning tmux.

  • tmux without learning tmux

    Shells that outlive the window, with no prefix key and no configuration, and your own tmux left alone.

  • Know when Claude Code is done or waiting

    Working, waiting for you and finished on every terminal, the For you count, the next waiting key and notifications in the open page.

  • Resume a Claude Code conversation

    Resume agent on the terminal it ran in, past conversations in a folder, and what tells you where it stood.

  • Find the right terminal when you have too many

    A canvas, one list of every terminal with its state in words, filters, tags and search of what terminals printed.

  • Check on your agents from your phone

    Reaching Aubergine from another device, each one paired with a code. Run once on one Mac; not tried on a real phone.

  • क्यू, For you और शेड्यूल

    काम एक बार बाँटें, वह सब देखें जो आपका इंतज़ार कर रहा है, और टास्क तय समय पर चलाएँ।

    क्या सुरक्षित है, और क्या नहीं।
