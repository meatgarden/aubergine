Aubergine खुद अंग्रेज़ी में है: उसके बटन, मेन्यू और तस्वीरें अंग्रेज़ी वाली ही हैं।

इस पेज का अंग्रेज़ी से अनुवाद मशीन ने किया है। सुधार भेजें।

WSL के साथ Windows पर Aubergine इंस्टॉल करें

Aubergine सीधे Windows पर नहीं चलता। यह WSL 2 के अंदर चलता है, जो Windows का दिया हुआ Linux है, और आप इसे अपने Windows ब्राउज़र से इस्तेमाल करते हैं।

क्या आज़माया गया। Linux वाले कदम 25 नवंबर 2026 को एक कंटेनर में Ubuntu 24.04.5 (x86_64) पर चलाए गए, WSL में नहीं, npm से Aubergine 0.2.2 के साथ: इसने अपनी टर्मिनल लाइब्रेरी कंपाइल की, शुरू हुआ, एक ब्राउज़र साइन इन किया, और एक टर्मिनल और डेमो चलाया। nvm से Node.js इंस्टॉल करना वहाँ नहीं चलाया गया, क्योंकि Node.js 22 पहले से इंस्टॉल था। इस पेज की कोई भी चीज़ अभी Windows पर नहीं चलाई गई है। अगर आप आज़माएँ, तो हमें बताएँ कि कैसा रहा।

आपको क्या चाहिए

Windows 11, या Windows 10 वर्शन 2004 (बिल्ड 19041) या नया, जहाँ WSL 2 एक कमांड से इंस्टॉल हो जाता है। ब्योरे Microsoft के WSL इंस्टॉल करने वाले पेज पर हैं।

इंस्टॉल करें और शुरू करें

  1. WSL इंस्टॉल करें। PowerShell को एडमिनिस्ट्रेटर के रूप में खोलें, यह चलाएँ, और पूरा होने पर Windows रीस्टार्ट करें। यह Ubuntu के साथ WSL 2 इंस्टॉल करता है।

    wsl --install

    रीस्टार्ट के बाद, Start मेन्यू से Ubuntu खोलें और उसके लिए एक यूज़र नेम और पासवर्ड चुनें। नीचे की हर कमांड वहीं, Ubuntu में टाइप होती है।

  2. Aubergine की ज़रूरत की चीज़ें इंस्टॉल करें: tmux, zsh और Git, और वे टूल जो इसकी टर्मिनल लाइब्रेरी कंपाइल करते हैं, क्योंकि Linux के लिए उसका कुछ भी पहले से बना नहीं है।

    sudo apt update

    sudo apt install -y tmux zsh git build-essential python3

    Node.js 22 इंस्टॉल करें। Ubuntu का अपना पैकेज वर्शन 18 है, जो बहुत पुराना है। एक जाना-माना तरीका nvm है: उसे इंस्टॉल करें, एक नई Ubuntu विंडो खोलें, फिर Node.js 22 इंस्टॉल करें।

    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash

    nvm install 22

    अब node -v को v22 या नया दिखाना चाहिए।

  3. npm से Aubergine इंस्टॉल करें। इंस्टॉल होते समय यह अपनी टर्मिनल लाइब्रेरी कंपाइल करता है; ट्रायल में पूरा इंस्टॉल 13 सेकंड में हुआ।

    npm install -g @meatgarden/aubergine

  4. इसे शुरू करें, और वह विंडो खुली छोड़ दें:

    aubergine start

    अपना ब्राउज़र साइन इन करें। एक दूसरी Ubuntu विंडो में साइन-इन पता प्रिंट करें, फिर उसे Windows पर अपने ब्राउज़र में खोलें। यह उस ब्राउज़र को साइन इन करता है, इसलिए इसे पासवर्ड की तरह रखें।

    aubergine open --print

    उसके बाद, उस ब्राउज़र में http://127.0.0.1:4600 अपने आप काम करता है। खाली कैनवस पर Show me around टूर शुरू करता है।

जानने लायक

  • अपने प्रोजेक्ट Ubuntu में रखें, उसके होम फ़ोल्डर में, /mnt/c के नीचे नहीं, जहाँ Windows की फ़ाइलों तक एक धीमे पुल से पहुँचा जाता है।
  • अपने एजेंट Ubuntu के अंदर इंस्टॉल करें, Claude Code, Codex या कोई और, जैसे किसी भी Linux पर। Windows में इंस्टॉल किया गया एजेंट Aubergine के टर्मिनलों में नहीं होता।
  • टर्मिनल तब तक चलते हैं जब तक WSL चलता है। ब्राउज़र बंद करने से कुछ खत्म नहीं होता, और aubergine start की विंडो में Ctrl+C सिर्फ़ सर्वर रोकता है। जब WSL रुकता है, Windows रीस्टार्ट होने से या wsl --shutdown के बाद, तो टर्मिनल खत्म हो जाते हैं, और अगला aubergine start उनके आख़िरी फ़ोल्डरों में नए शेल खोलता है, जैसे Mac रीस्टार्ट होने के बाद।
  • bash या zsh। Ubuntu का शेल bash है, और टर्मिनल उसमें ठीक चलते हैं। टर्मिनल पर कमांड का स्टेटस (व्यस्त, फ़ेल हुई कमांड का एग्ज़िट कोड) सिर्फ़ zsh से आता है: ट्रायल में एक zsh टर्मिनल ने फ़ेल हुई कमांड के बाद exit 3 दिखाया। यह पाने के लिए Ubuntu में zsh को अपना शेल बनाएँ।
  • जो वहाँ नहीं है: लॉगिन पर शुरू होना सिर्फ़ macOS पर काम करता है (aubergine service install यही बताता है), और Open on desktop में Windows के टर्मिनल ऐप की कोई सेटिंग नहीं है। ट्रायल में aubergine open को खोलने के लिए कोई ब्राउज़र नहीं मिला; aubergine open --print हमेशा काम करता है।
  • Windows पर कीज़ ब्राउज़रों के दस्तावेज़ों के आधार पर चुनी गई हैं और मापी नहीं गईं: देखें docs/keys.md। पैलेट हमेशा काम करता है।

अगर कुछ गड़बड़ हो

पहले Ubuntu में aubergine doctor चलाएँ। यह Node.js, tmux, Git और सर्वर जाँचता है।

आपको क्या दिखता हैक्या करें
Aubergine इंस्टॉल करते समय node-pty कंपाइल करने में फ़ेल होता हैबिल्ड टूल नहीं हैं। कदम 2 की apt वाली लाइनें चलाएँ, फिर Aubergine दोबारा इंस्टॉल करें।
एक पेज जो कहता है कि tmux नहीं है या बहुत पुराना हैUbuntu 24.04 का tmux 3.4 है, जो काफ़ी नया है: sudo apt install -y tmux, फिर सर्वर दोबारा शुरू करें।
node -v v22 से पुराना वर्शन दिखाता हैकदम 2 की तरह Node.js 22 इंस्टॉल करें, एक नई Ubuntu विंडो खोलें, और Aubergine दोबारा इंस्टॉल करें।
पता Windows के ब्राउज़र में नहीं खुलताजाँचें कि aubergine start अब भी Ubuntu में चल रहा है। फिर Microsoft का WSL में नेटवर्किंग वाला पेज देखें; इसे Aubergine के साथ आज़माया नहीं गया है।
