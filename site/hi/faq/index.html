Aubergine खुद अंग्रेज़ी में है: उसके बटन, मेन्यू और तस्वीरें अंग्रेज़ी वाली ही हैं।

इस पेज का अंग्रेज़ी से अनुवाद मशीन ने किया है। सुधार भेजें।

  2. सवाल-जवाब

अक्सर पूछे जाने वाले सवाल

छोटे जवाब। गाइड ज़्यादा गहराई में जाती हैं।

Aubergine क्या है?

टर्मिनल सेशनों का एक लोकल, ब्राउज़र में चलने वाला कैनवस। हर टर्मिनल एक नोड है जिसे आप सजा और इस्तेमाल कर सकते हैं, ताकि आप एक साथ कई कोडिंग एजेंट चला सकें और देख सकें कि कौन-सा आपका इंतज़ार कर रहा है।

क्या Aubergine मुफ़्त और ओपन सोर्स है?

हाँ। यह मुफ़्त है और इसका सोर्स GitHub पर है।

Aubergine चलाने के लिए मुझे क्या चाहिए?

tmux 3.2 या नया और Node.js 22 या नया वाला macOS; इंस्टॉलर को pnpm भी चाहिए। Linux पर इसे अभी तक सिर्फ़ कंटेनर में चलाया गया है। Windows पर यह सिर्फ़ WSL 2 के अंदर चलता है, जिसे अभी आज़माया नहीं गया है: देखें Windows की गाइड।

क्या यह किसी भी कोडिंग एजेंट के साथ काम करता है?

Aubergine साधारण टर्मिनल चलाता है, इसलिए कोई भी कमांड-लाइन एजेंट उनमें चल सकता है। Aubergine किसी एजेंट के लिए खुद से जो करता है, जैसे यह देखना कि वह इंतज़ार कर रहा है, वह Claude Code के लिए बना है; कोई भी दूसरा एजेंट, Codex भी, अपनी स्थिति aubergine कमांड और एक लोकल API से बता सकता है, और ऐसा MCP सर्वर इस्तेमाल कर सकता है जो सिर्फ़ वही दिखाता है जिसकी उसका टोकन अनुमति देता है।

क्या Aubergine मेरे टर्मिनल या कोड कहीं भेजता है?

नहीं। सब कुछ आपके अपने कंप्यूटर पर चलता है। सर्वर सिर्फ़ 127.0.0.1 पर सुनता है।

क्या Aubergine किसी AI मॉडल को कॉल करता है?

नहीं। आपके एजेंट करते हैं। Aubergine बस उनके टर्मिनल चलाता है और उन पर नज़र रखता है, और किसी मॉडल की कोई key नहीं रखता।

ब्राउज़र बंद करने पर मेरे टर्मिनलों का क्या होता है?

वे चलते रहते हैं। हर सेशन एक tmux सेशन है जो ब्राउज़र और Aubergine सर्वर दोनों से ज़्यादा चलता है।

मुझे कैसे पता चले कि कौन-सा एजेंट मेरा इंतज़ार कर रहा है?

हर टर्मिनल दिखाता है कि वह busy है, idle है या waiting। पेज के ऊपर For you के बगल वाली गिनती और For you सूची वह सब इकट्ठा करती हैं जिसे आपकी ज़रूरत है।

मैं दो एजेंटों को एक ही फ़ाइलें बदलने से कैसे रोकूँ?

हर टर्मिनल को उसकी अपनी वर्किंग कॉपी में शुरू करें: उसका अपना चेकआउट, उसकी अपनी ब्रांच पर। Aubergine आपके लिए कभी merge या push नहीं करता।

क्या मैं किसी एजेंट को पालन करने के लिए स्टेप की सूची दे सकता हूँ?

हाँ। वर्कफ़्लो स्टेप की एक क्रमवार सूची है, एक पट्टी के साथ जो दिखाती है कि एजेंट कहाँ है। कोई स्टेप आपके मंज़ूर करने या वापस भेजने का इंतज़ार कर सकता है।

क्या एजेंट एक-दूसरे से बात कर सकते हैं?

हाँ, सीमाओं के अंदर। टर्मिनलों के बीच संदेशों में नाम वाले भेजने वाले, विराम और ब्लॉक होते हैं, और हर कैनवस के लिए ये डिफ़ॉल्ट रूप से बंद होते हैं।

क्या कोई API है?

हाँ। स्कोप वाले टोकन के साथ एक लोकल HTTP API, एक टाइप्ड क्लाइंट, और एक MCP सर्वर जो सिर्फ़ वही टूल दिखाता है जिन्हें कोई क्रेडेंशियल इस्तेमाल कर सकता है।

क्या मैं एक टर्मिनल अकेले खोल सकता हूँ?

हाँ। टर्मिनल के टाइटल में Tab ↗ उसे उसके अपने ब्राउज़र टैब में खोलता है, वही टर्मिनल, कॉपी नहीं, और आप माँगें तो उसकी जानकारी और नोट बगल में। टैब बंद करने से कुछ बंद नहीं होता।

क्या मैं किसी टर्मिनल के साथ टिकट या मालिक रख सकता हूँ?

हाँ। टर्मिनल की जानकारी में फ़ील्ड होते हैं, लेबल और वैल्यू की जोड़ियाँ। उसमें मौजूद एजेंट aubergine field set से अपने फ़ील्ड सेट कर सकता है; जहाँ आपने वही लेबल सेट किया है, वहाँ आपका रहता है।

क्या Aubergine कई लोगों या क्लाउड में एजेंटों को सपोर्ट करेगा?

दोनों योजना में हैं और कोई भी बना नहीं है। रोडमैप देखें। आज सब कुछ एक कंप्यूटर पर चलता है।

इंस्टॉलर मेरे कंप्यूटर पर क्या बदलता है?

दो चीज़ें: इंस्टॉल फ़ोल्डर (~/.aubergine) और aubergine नाम का एक लिंक। यह कभी sudo इस्तेमाल नहीं करता, कभी आपकी शेल स्टार्टअप फ़ाइलें नहीं बदलता और कभी Node.js, pnpm या tmux इंस्टॉल नहीं करता।

पाँच मिनट में तैयार

आपको macOS चाहिए, tmux 3.2 या नए और Node.js 22 या नए के साथ। brew install tmux node दोनों ले आता है।

npm install -g @meatgarden/aubergine
