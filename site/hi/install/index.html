Aubergine खुद अंग्रेज़ी में है: उसके बटन, मेन्यू और तस्वीरें अंग्रेज़ी वाली ही हैं।

इस पेज का अंग्रेज़ी से अनुवाद मशीन ने किया है। सुधार भेजें।

  1. Aubergine
  2. इंस्टॉल

Aubergine कैसे इंस्टॉल करें

एक कमांड इसे इंस्टॉल करता है, एक शुरू करता है। टूर मिलाकर लगभग पाँच मिनट।

ज़रूरतें

  • macOS. Linux पर इसे अभी तक सिर्फ़ कंटेनर में चलाया गया है: Ubuntu 24.04 पर npm पैकेज और Debian पर कंटेनर इमेज। Windows अपने आप में समर्थित नहीं है; Aubergine WSL 2 के अंदर चल सकता है, जिसे अभी आज़माया नहीं गया है: देखें WSL के साथ Windows पर इंस्टॉल करें।
  • tmux 3.2 या नया और Node.js 22 या नया। इंस्टॉलर को pnpm भी चाहिए।

Homebrew के साथ, एक लाइन दोनों ले आती है (इंस्टॉलर के लिए pnpm जोड़ें):

brew install tmux node

इंस्टॉल करें और शुरू करें

  1. npm से Aubergine इंस्टॉल करें (सिर्फ़ tmux और Node.js चाहिए):

    npm install -g @meatgarden/aubergine

    या इंस्टॉलर से, जिसे pnpm भी चाहिए और जो सोर्स से बिल्ड करता है:

    curl -fsSL https://raw.githubusercontent.com/thirstyeggplant/aubergine/main/install.sh | sh

  2. इसे शुरू करें और अपना ब्राउज़र साइन इन किया हुआ खोलें।

    aubergine start --open

  3. टूर लें। खाली कैनवस के बीच में Show me around पर क्लिक करें। यह “Demo” नाम का एक कैनवस बनाता है जिसमें कुछ नकली एजेंट होते हैं, और आपको आठ छोटे स्टेप में घुमाता है। डेमो में कुछ भी असली नहीं है, और aubergine demo --remove उसे हटा देता है।

पहले स्क्रिप्ट पढ़ना चाहते हैं? उसे डाउनलोड करें, पढ़ें, और sh install.sh --dry-run चलाएँ, यह देखने के लिए कि वह कुछ बदले बिना क्या करेगी।

इंस्टॉलर क्या बदलता है

सिर्फ़ दो चीज़ें: इंस्टॉल फ़ोल्डर (~/.aubergine, या AUBERGINE_HOME) और aubergine नाम का एक लिंक, आपके PATH के किसी ऐसे फ़ोल्डर में जिसमें आप लिख सकते हैं। यह पहले सब कुछ जाँचता है, और अगर कुछ कमी हो तो कुछ नहीं बदलता।

यह नहीं करता: sudo का इस्तेमाल, आपकी शेल स्टार्टअप फ़ाइलों में बदलाव, Node.js, pnpm या tmux इंस्टॉल करना, या आपके डेटा फ़ोल्डर को छूना।

अगर कुछ गड़बड़ हो

पहले aubergine doctor चलाएँ। यह आम कारण जाँचता है।

आपको क्या दिखता हैक्या करें
“This browser is not signed in yet”उस ब्राउज़र में साइन-इन लिंक एक बार खोलें। aubergine open --print उसे फिर से प्रिंट करता है।
एक पेज जो कहता है कि tmux नहीं है या बहुत पुराना हैtmux इंस्टॉल या अपग्रेड करें (brew install tmux), फिर सर्वर रीस्टार्ट करें।
सर्वर शुरू नहीं होता क्योंकि पोर्ट पहले से इस्तेमाल में हैदूसरा पोर्ट इस्तेमाल करें: AUBERGINE_PORT=4700 aubergine start।
aubergine: command not foundलिंक आपके PATH पर नहीं है। इंस्टॉलर वह एक लाइन प्रिंट करता है जो आपकी शेल की स्टार्टअप फ़ाइल में जोड़नी है।
टर्मिनल कोई स्टेटस बैज नहीं दिखातास्टेटस के लिए zsh चाहिए, और अपडेट से पहले बना सेशन अपना पुराना शेल रखता है। उसे पार्क करें और नया शुरू करें।

रोकें, अपडेट करें, अनइंस्टॉल करें

  • सर्वर को Ctrl+C से रोकें। आपके टर्मिनल चलते रहते हैं; उन्हें वापस पाने के लिए सर्वर फिर शुरू करें और पेज रीलोड करें।
  • अपडेट करें: अगर आपने npm से इंस्टॉल किया, तो npm install -g @meatgarden/aubergine@latest से; अगर इंस्टॉलर इस्तेमाल किया, तो aubergine update से। फिर सर्वर रीस्टार्ट करें।
  • अनइंस्टॉल करें: aubergine uninstall से। यह लिंक हटाता है और, पूछने के बाद, वह कॉपी जो इंस्टॉलर ने बनाई। यह कभी आपका डेटा नहीं हटाता और कभी आपके टर्मिनल बंद नहीं करता।
  • लॉगिन पर शुरू करें: aubergine service install से, ताकि आपको बस ब्राउज़र खोलना पड़े।

आगे

पढ़ें एक साथ कई कोडिंग एजेंट कैसे चलाएँ, या गाइड। पूरा संदर्भ README में है।

npm install -g @meatgarden/aubergine
