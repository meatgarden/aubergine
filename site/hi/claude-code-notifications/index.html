Aubergine खुद अंग्रेज़ी में है: उसके बटन, मेन्यू और तस्वीरें अंग्रेज़ी वाली ही हैं।

इस पेज का अंग्रेज़ी से अनुवाद मशीन ने किया है। सुधार भेजें।

  1. Aubergine
  2. गाइड
  3. पूरा या इंतज़ार में

जानें कब Claude Code पूरा हुआ या आपका इंतज़ार कर रहा है

आप Claude Code को कोई काम देते हैं, किसी और चीज़ में लग जाते हैं, और बीस मिनट बाद लौटकर पाते हैं कि वह दूसरे मिनट से एक हाँ का इंतज़ार कर रहा था। Aubergine एक ही पेज पर दिखाता है कि कौन-सा टर्मिनल काम कर रहा है, कौन आपका इंतज़ार कर रहा है और कौन पूरा हो गया।

लोग आम तौर पर क्या करते हैं

Claude Code कुछ खास पलों पर हुक, यानी आपकी अपनी कमांड, चलाता है, जैसे जब वह रुकता है (Stop) या कोई नोटिफ़िकेशन भेजता है (Notification)। आम उपाय है आपकी Claude Code सेटिंग्स में एक हुक जो आवाज़ बजाए या डेस्कटॉप नोटिफ़िकेशन दिखाए। यह काम करता है, और स्क्रिप्ट लिखना और सँभालना आपका काम है।

Aubergine क्या करता है

Claude Code को Aubergine से शुरू करें: टर्मिनलों की सूची में सबसे ऊपर New terminal ▾ → Claude Code, या C। Aubergine claude को एक सेटिंग्स फ़ाइल के साथ शुरू करता है, जिसे वह अपने डेटा फ़ोल्डर में बनाता है और कमांड लाइन पर बताता है। आपकी अपनी Claude Code कॉन्फ़िगरेशन को छुआ नहीं जाता। उस फ़ाइल के हुक पेज को बताते हैं कि एजेंट क्या कर रहा है:

  • जब आप कोई प्रॉम्प्ट भेजते हैं, टर्मिनल working (काम कर रहा) दिखाता है, और प्रॉम्प्ट उसके नोट के लॉग में जुड़ जाता है;
  • जब एजेंट को आपकी ज़रूरत होती है (अनुमति का कोई सवाल, या वह इनपुट के इंतज़ार में idle है), उसकी लाइन इंतज़ार के रंग की हो जाती है, और उसके टाइटल और सूची में उसकी पंक्ति में waiting for you (आपका इंतज़ार) लिखा आता है;
  • जब वह रुकता है, टर्मिनल finished (पूरा) दिखाता है।

For you के बगल वाली गिनती, पेज के ऊपर दाईं ओर, वह सब है जो आपका इंतज़ार कर रहा है, हर प्रोजेक्ट में: सवाल वाले टर्मिनल, और मंज़ूरी वाले रन, पढ़ने वाले ड्राफ़्ट और प्रस्तावित टास्क। उसे दबाने से Runs खुलता है, जिसका Waiting for you कॉलम यही सूची है। किसी कैनवस का टैब दिखाता है कि उसके कितने टर्मिनल इंतज़ार कर रहे हैं।

अगला जो इंतज़ार कर रहा है। जब किसी टर्मिनल के पास कीबोर्ड न हो, W अगले उस टर्मिनल पर ले जाता है जो आपका इंतज़ार कर रहा है; macOS पर ⌃⌘J यही टर्मिनल के अंदर से भी करता है। बाकी जगह यह पैलेट में है।

खुले पेज से नोटिफ़िकेशन। Settings → Notifications में Notify me on the desktop when a terminal starts waiting (कोई टर्मिनल इंतज़ार करने लगे तो डेस्कटॉप पर बताएँ) है। इसे चालू करने पर, जब कोई टर्मिनल इंतज़ार करने लगे या उसका एजेंट पूरा कर ले, पेज आपके ब्राउज़र का नोटिफ़िकेशन दिखाता है, जब तक आप उसी टर्मिनल को न देख रहे हों। ब्राउज़र एक बार आपकी अनुमति माँगता है।

नियम। Runs के Rules टैब पर, कोई नियम Notify me (मुझे बताएँ) कर सकता है जब कोई टास्क पूरा हो, कोई टास्क फ़ेल हो, किसी टास्क को आपकी ज़रूरत हो, आपसे कुछ पूछा जाए, या कोई शेड्यूल चला या नहीं चल सका: खुले पेज से एक नोटिफ़िकेशन, एक वाक्य के साथ कि क्या हुआ।

दूसरे एजेंट, और खुद टाइप किया claude

Aubergine अंदाज़ा लगाने के लिए टर्मिनल का आउटपुट नहीं पढ़ता। कोई भी दूसरा एजेंट, या कोई भी प्रोग्राम, अपने टर्मिनल में aubergine attention waiting "what it needs", aubergine attention working और aubergine attention done से खुद यही बताता है। aubergine guide --snippet उस फ़ाइल के लिए पाँच लाइनें प्रिंट करता है जिसे आपका एजेंट बातचीत की शुरुआत में पढ़ता है; वे उसे aubergine guide चलाने को कहती हैं, जो ये कमांड समझाता है।

सादे टर्मिनल में claude टाइप करके शुरू किया Claude Code, Aubergine के लिए बस एक प्रोग्राम में busy शेल है: कोई waiting for you नहीं। इसके बजाय उसे मेन्यू से शुरू करें, या aubergine hooks print जो हुक प्रिंट करता है उन्हें हाथ से अपनी सेटिंग्स में जोड़ें; Aubergine टर्मिनल के बाहर वे कुछ नहीं करते।

यह क्या नहीं करता

  • अपनी कोई आवाज़ नहीं। Aubergine कोई आवाज़ नहीं बजाता। नोटिफ़िकेशन तभी आवाज़ करता है जब आपका ब्राउज़र या सिस्टम नोटिफ़िकेशन के लिए ऐसा करता हो।
  • कोई पेज खुला न हो तो कुछ नहीं। नोटिफ़िकेशन आपके ब्राउज़र में खुले Aubergine पेज से आते हैं; सर्वर खुद कोई नहीं भेजता। सारे पेज बंद होने पर भी टर्मिनल waiting for you कहता है, और पेज खोलने पर गिनती वहाँ होती है।
  • फ़ोन पर कोई पुश नहीं। न कोई ऐप है, न कोई पुश सर्विस। फ़ोन के ब्राउज़र को वही पेज खोलने के लिए जोड़ा जा सकता है; देखें अपने फ़ोन से एजेंटों पर नज़र रखें, जिसे असली फ़ोन पर आज़माया नहीं गया है।
  • क्या जाँचा गया। ब्राउज़र टेस्ट नोटिफ़िकेशन को ब्राउज़र के अपने नोटिफ़िकेशन की एक नकल के सामने जाँचते हैं। असली नोटिफ़िकेशन कैसा दिखता है, और दिखता भी है या नहीं, यह आपके ब्राउज़र और उसके लिए आपके सिस्टम की सेटिंग्स पर निर्भर है।

सवाल

Claude Code पूरा होने पर नोटिफ़िकेशन कैसे पाऊँ?

Claude Code को Aubergine से शुरू करें, फिर Settings → Notifications में Notify me on the desktop when a terminal starts waiting चालू करें। तब खुला पेज ब्राउज़र नोटिफ़िकेशन दिखाता है जब कोई टर्मिनल आपका इंतज़ार करने लगे या उसका एजेंट पूरा कर ले। नोटिफ़िकेशन के बिना, टर्मिनल finished कहता है।

क्या Claude Code इनपुट चाहिए होने पर आवाज़ बजा सकता है?

Aubergine कोई आवाज़ नहीं बजाता। नोटिफ़िकेशन तब आवाज़ करता है जब आपका ब्राउज़र या सिस्टम ऐसा करे। आपकी Claude Code सेटिंग्स में आपका अपना हुक आवाज़ बजा सकता है; Aubergine उन सेटिंग्स में कभी नहीं लिखता।

कई Claude Code सेशन चलाते हुए कैसे देखूँ कि कौन-सा इंतज़ार कर रहा है?

Aubergine में इंतज़ार कर रहे टर्मिनल की लाइन और उसकी स्थिति इंतज़ार के रंग में होती है, सूची में उसकी पंक्ति waiting for you कहती है, और For you के बगल वाली गिनती बताती है कि कितनी चीज़ें इंतज़ार कर रही हैं। W अगले पर ले जाता है।

क्या ब्राउज़र बंद होने पर मुझे सूचना मिलती है?

नहीं। नोटिफ़िकेशन खुले Aubergine पेज से आते हैं। स्थिति बनी रहती है, इसलिए पेज फिर खोलने पर इंतज़ार कर रहे टर्मिनल चिह्नित होते हैं।

क्या यह Claude Code के अलावा दूसरे एजेंटों के साथ काम करता है?

अपने आप नहीं: हुक Claude Code के लिए बने हैं। कोई भी दूसरा एजेंट, जब उसके अपने निर्देश कहें, aubergine attention waiting, working और done से यही बता सकता है; aubergine guide --snippet उन निर्देशों के लिए लाइनें प्रिंट करता है।

संबंधित: Aubergine में Claude Code · Claude Code की बातचीत फिर शुरू करें · बहुत सारे टर्मिनल
