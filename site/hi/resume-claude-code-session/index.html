Aubergine खुद अंग्रेज़ी में है: उसके बटन, मेन्यू और तस्वीरें अंग्रेज़ी वाली ही हैं।

इस पेज का अंग्रेज़ी से अनुवाद मशीन ने किया है। सुधार भेजें।

  2. गाइड
  3. बातचीत फिर शुरू करें

रीस्टार्ट के बाद Claude Code की बातचीत फिर शुरू करें

कंप्यूटर रीस्टार्ट हुआ, या आपने टर्मिनल बंद कर दिया, और Claude Code की बातचीत गायब लगती है। Claude Code उसे रखता है। Aubergine याद रखता है कि हर टर्मिनल किस बातचीत में था और एक बटन से उसे वापस लाता है।

लोग आम तौर पर क्या करते हैं

किसी टर्मिनल में, उसी फ़ोल्डर में जिसमें बातचीत थी: claude --continue वहाँ की सबसे हाल की बातचीत आगे बढ़ाता है, और claude --resume आपको सूची से एक चुनने देता है, या बातचीत का ID लेता है। मुश्किल फ़ोल्डर और चुनाव की है: एक फ़ोल्डर में कई एजेंट हों, तो सबसे हाल की बातचीत हमेशा वही नहीं होती जो आप चाहते थे।

Aubergine क्या करता है

टर्मिनल अपनी बातचीत याद रखता है। जब Claude Code को Aubergine से शुरू किया गया हो (New terminal ▾ → Claude Code, या C), उसके हुक Aubergine को बताते हैं कि वह किस बातचीत में है, और Aubergine वह ID टर्मिनल के साथ रखता है।

Resume agent (एजेंट फिर शुरू करें) टर्मिनल की टाइटल बार में तब दिखता है जब उसका शेल फिर प्रॉम्प्ट पर हो: आप एजेंट से बाहर निकले, या कंप्यूटर रीस्टार्ट हुआ और टर्मिनल अपने आख़िरी फ़ोल्डर में नए शेल के रूप में लौटा। यह Claude Code को --resume और उस ID के साथ फिर शुरू करता है, आपकी सेटिंग्स की लॉन्च कमांड से (agents.claudeCommand, डिफ़ॉल्ट claude)।

किसी वर्कफ़्लो के रन पर, Resume agent एजेंट को रन के बारे में फिर से बताता भी है, ताकि वह उसी स्टेप से आगे बढ़े जिस पर रन है।

Past conversations… (पिछली बातचीत), पैलेट (⌘K) में, या टर्मिनल की जानकारी में “Past conversations in this folder…”, किसी फ़ोल्डर में Claude Code की पिछली बातचीत की सूची दिखाता है: नाम या आपकी कही पहली बात, वह आख़िरी बार कब सक्रिय थी, आपने कितनी बार बात की, और क्या अभी किसी कैनवस का कोई टर्मिनल उस पर है। Read उसे सिर्फ़ पढ़ने के लिए दिखाता है। Open on the canvas उस फ़ोल्डर में एक नया टर्मिनल शुरू करता है जिसमें वह बातचीत फिर शुरू होती है, और Open a copy उसकी एक शाखा शुरू करता है और असली को वैसा ही छोड़ देता है। अगर कोई टर्मिनल पहले से उस बातचीत पर है, तो पहले आपसे पूछा जाता है।

खोज। आपके कैनवस के टर्मिनलों के फ़ोल्डरों में पुरानी बातचीत खोजने के लिए पैलेट में @ और कुछ शब्द टाइप करें। यह आपके माँगने पर, सीमाओं के भीतर, रिकॉर्ड पढ़ता है, और बताता है कि खोज कब बीच में रोकी गई। कमांड लाइन पर aubergine history उनकी सूची दिखाता है और aubergine history open <id> किसी एक को खोलता है।

काम कहाँ था। टर्मिनल का नोट उसका सारांश और एक लॉग रखता है, और आपका भेजा हर प्रॉम्प्ट लॉग में जुड़ता है। उसकी जानकारी में Ask its agent for a recap (उसके एजेंट से रीकैप माँगें) से एजेंट aubergine recap --write के ज़रिए लिखता है कि वह कहाँ है, और यह टर्मिनल के साथ रहता है। 30 मिनट से ज़्यादा बाद लौटने पर While you were away (जब आप दूर थे) दिखाता है कि इस बीच क्या बदला।

Aubergine के बाहर किसी टर्मिनल की बातचीत

अपने टर्मिनल ऐप के किसी टैब में, एजेंट से बाहर निकलें, फिर उसी फ़ोल्डर में aubergine here --claude चलाएँ: कैनवस पर एक नया टर्मिनल Claude Code को --continue के साथ शुरू करता है, अब उसकी स्थिति दिखती है। aubergine move आपके Claude Code टैब की सूची दिखाता है और हर बातचीत की एक कॉपी कैनवस पर शुरू करता है; --stop के साथ वह आपकी पुष्टि के बाद idle एजेंट से पहले बाहर निकलने को कहता है।

यह क्या नहीं करता

  • यह Claude Code के अपने रिकॉर्ड पढ़ता है, ऐसे फ़ॉर्मैट में जो Aubergine का नहीं है। Claude Code उन फ़ाइलों के फ़ॉर्मैट को आंतरिक कहता है, और वह वर्ज़न के बीच बदलता है। फिर शुरू करना Claude Code के अपने --resume को ID के साथ इस्तेमाल करता है; नाम, गिनती और ट्रांसक्रिप्ट Aubergine का फ़ाइलों को पढ़ना है, और Claude Code के अपडेट के बाद ग़ायब या कम हो सकते हैं। जो रिकॉर्ड वह नहीं पढ़ पाता, उसके बारे में यही कहा जाता है, उसे खाली बातचीत के रूप में नहीं दिखाया जाता।
  • कुछ भी कॉपी या रखा नहीं जाता। सूची, ट्रांसक्रिप्ट या खोज आपके माँगने पर पढ़ी जाती है और बंद करने पर छोड़ दी जाती है। Aubergine किसी बातचीत को कभी बदलता, नाम बदलता या मिटाता नहीं, और कोई एजेंट या टोकन इसके ज़रिए बातचीत नहीं पढ़ सकता।
  • अधूरा काम दोबारा नहीं किया जाता। एजेंट रुकते समय जो कर रहा था, वह तब तक फिर शुरू नहीं होता जब तक आप उससे न कहें।
  • दूसरे एजेंट के लिए Resume agent नहीं। Aubergine दूसरे एजेंट की बातचीत नहीं जानता, और उसकी पुरानी बातचीत की सूची नहीं दिखाता। उसे उसी टर्मिनल में उस एजेंट के अपने फिर-शुरू करने के तरीके से चलाएँ, और नोट पढ़कर उसे बताएँ कि वह कहाँ था।
  • खुद टाइप किया claude याद नहीं रखा जाता, जब तक आपने aubergine hooks print के प्रिंट किए हुक अपनी Claude Code सेटिंग्स में न जोड़े हों।
  • क्या जाँचा गया। बातचीत के रिकॉर्ड पढ़ने की जाँच बनावटी रिकॉर्ड पर की गई है। Claude Code के हर वर्ज़न पर इसकी जाँच नहीं हुई है।

सवाल

टर्मिनल बंद करने के बाद Claude Code सेशन फिर कैसे शुरू करूँ?

उसी फ़ोल्डर में, claude --continue सबसे हाल की बातचीत लेता है और claude --resume आपको चुनने देता है। Aubergine में ब्राउज़र बंद करने से कुछ खत्म नहीं होता, और जिस टर्मिनल के एजेंट से आप बाहर निकले, वह अपनी टाइटल बार में Resume agent देता है।

रीबूट के बाद Claude Code की बातचीत फिर कैसे शुरू करूँ?

रीस्टार्ट के बाद हर Aubergine टर्मिनल अपने आख़िरी फ़ोल्डर में एक नए शेल के रूप में लौटता है। जहाँ Claude Code को Aubergine से शुरू किया गया था, वहाँ टाइटल बार में Resume agent उसे उसी बातचीत में फिर शुरू करता है जिसमें वह टर्मिनल था।

Claude Code की कोई पुरानी बातचीत कैसे ढूँढूँ?

पैलेट में Past conversations… किसी फ़ोल्डर के लिए उनकी सूची दिखाता है, सिर्फ़ पढ़ने वाली ट्रांसक्रिप्ट के साथ; पैलेट में @ और कुछ शब्द उनमें खोजते हैं। सिर्फ़ वही दिखता है जो Claude Code अब भी रखता है।

claude --continue और claude --resume में क्या फ़र्क है?

--continue फ़ोल्डर की सबसे हाल की बातचीत आगे बढ़ाता है; --resume वह लेता है जो आप चुनें, या कोई ID। Resume agent टर्मिनल के याद रखे ID के साथ --resume इस्तेमाल करता है, इसलिए यह इस पर निर्भर नहीं करता कि सबसे हाल की बातचीत कौन-सी थी।

क्या दो टर्मिनल एक ही Claude Code बातचीत आगे बढ़ा सकते हैं?

Aubergine पूछे बिना एक बातचीत दो बार नहीं खोलता: एक बातचीत में दो एजेंट एक-दूसरे के संदेश खो देते हैं। आपको वह टर्मिनल दिया जाता है जो पहले से उस पर है, या एक कॉपी, जो बातचीत की शाखा बनाती है।
