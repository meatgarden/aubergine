Aubergine vs Claude Squad

दोनों एक ही ज़मीन पर खड़े हैं: हर एजेंट एक tmux सेशन में, हर एक अपने Git worktree में, दोनों मुफ़्त और ओपन सोर्स। Claude Squad आपके टर्मिनल के अंदर एक प्रोग्राम है। Aubergine आपके ब्राउज़र में एक पेज है जहाँ टर्मिनल साथ-साथ खड़े रहते हैं।

यह कहाँ से है। यहाँ Claude Squad के बारे में जो कहा गया है, वह उसकी रिपॉज़िटरी और README से है, जैसे 26 नवंबर 2026 को पढ़ा गया। हमने Claude Squad नहीं चलाया है। अगर कुछ गलत या पुराना है, तो हमें बताएँ।

कौन-सा चुनें

Claude Squad चुनें अगर आप टर्मिनल में ही रहते हैं और वहाँ एक छोटा प्रोग्राम चाहते हैं जो worktree में एजेंट शुरू करे और उनकी ब्रांच push करे, और इससे ज़्यादा कुछ नहीं।

Aubergine चुनें अगर आप कई एजेंटों को एक साथ काम करते देखना चाहते हैं, जानना चाहते हैं कि कौन-सा आपका इंतज़ार कर रहा है, और उनके आसपास एक क्यू, शेड्यूल और एक API चाहते हैं।

Claude Squad क्या है

उसके अपने वर्णन के अनुसार, एक टर्मिनल ऐप जो अलग-अलग वर्कस्पेस में कई Claude Code, Codex, Gemini और दूसरे लोकल एजेंटों को संभालता है। आप इसे cs के रूप में शुरू करते हैं: एक टर्मिनल विंडो में, प्रीव्यू और diff टैब के साथ सेशनों की एक सूची। हर सेशन अपनी ब्रांच पर एक Git worktree में एक tmux सेशन है। इसे tmux और gh चाहिए, और यह AGPL-3.0 लाइसेंस के तहत है।

वे कहाँ अलग हैं

एक बार में एक, या सब एक साथ। Claude Squad एक सूची और आपके चुने सेशन का प्रीव्यू दिखाता है। Aubergine हर टर्मिनल को कैनवस पर लाइव दिखाता है, तो पाँच एजेंट नज़र के सामने पाँच टर्मिनल हैं, और एक सूची हर एक की स्थिति शब्दों में बताती है।

कौन इंतज़ार कर रहा है। Claude Squad के README में हमें यह बताए जाने के बारे में कुछ नहीं मिला कि कोई एजेंट इंतज़ार कर रहा है या पूरा हो गया है। Aubergine इंतज़ार कर रहे टर्मिनल को रंग से चिह्नित करता है, ऊपर गिनता है कि क्या इंतज़ार कर रहा है, एक key से अगले पर जाता है, और खुले पेज से नोटिफ़िकेशन भेज सकता है।

एजेंटों के आसपास क्या है। Aubergine में सीमा वाली टास्क की एक क्यू, शेड्यूल, ऐसे स्टेप वाले वर्कफ़्लो जिन्हें इंसान मंज़ूर करता है, हर टर्मिनल पर नोट और फ़ील्ड, एक HTTP API और एक MCP सर्वर है। Claude Squad सेशनों और उनकी ब्रांचों तक सीमित रहता है।

Claude Squad में क्या है जो Aubergine में नहीं है

  • यह उसी टर्मिनल के अंदर चलता है जो आपके पास पहले से खुला है, बिना सर्वर और बिना ब्राउज़र के। यह किसी भी टर्मिनल प्रोग्राम की तरह SSH पर काम करता है; Aubergine को कहीं और से इस्तेमाल करने के लिए टनल या प्रॉक्सी चाहिए।
  • यह आपके लिए ब्रांच कमिट और push करता है, और किसी सेशन को उसका काम कमिट करके रोकता है। Aubergine कभी कमिट या push नहीं करता।
  • एक प्रयोगात्मक मोड जो एजेंट के प्रॉम्प्ट खुद मान लेता है। Aubergine कभी आपकी जगह एजेंट को जवाब नहीं देता।

सवाल

क्या Aubergine, Claude Squad का विकल्प है?

हाँ, वही काम दूसरे तरीके से। दोनों हर एजेंट को एक tmux सेशन में चलाते हैं और हर एक को उसकी अपनी ब्रांच पर एक Git worktree दे सकते हैं। Claude Squad यह आपके टर्मिनल के एक प्रोग्राम से करता है; Aubergine आपके ब्राउज़र के एक पेज से, जहाँ हर टर्मिनल नज़र के सामने होता है।

क्या दोनों tmux इस्तेमाल करते हैं?

हाँ। Claude Squad, tmux को ज़रूरी चीज़ों में गिनाता है और हर एजेंट के लिए एक tmux सेशन बनाता है। Aubergine को tmux 3.2 या नया चाहिए और वह इसे अपने अलग सॉकेट पर अपनी कॉन्फ़िगरेशन के साथ चलाता है, ताकि आपके अपने tmux को छुआ न जाए।

क्या Claude Squad, Claude Code के अलावा दूसरे एजेंटों के साथ काम करता है?

उसका README कहता है कि डिफ़ॉल्ट प्रोग्राम claude है और कोई दूसरा, जैसे Codex, Gemini या Aider, -p से बताया जाता है। Aubergine किसी भी कमांड-लाइन प्रोग्राम को टर्मिनल में चलाता है; किसी एजेंट के लिए यह खुद से जो करता है, वह Claude Code के लिए बना है।

हर एक का लाइसेंस कौन-सा है?

Claude Squad, AGPL-3.0 के तहत है, Aubergine, MIT लाइसेंस के तहत। दोनों मुफ़्त हैं।

Aubergine का Claude Squad या Anthropic से कोई संबंध नहीं है। Claude Squad, smtg-ai प्रोजेक्ट का नाम है; Claude, Anthropic का ट्रेडमार्क है।
