Instalar Aubergine en Windows con WSL

Aubergine no funciona en Windows en sí. Funciona dentro de WSL 2, el Linux que ofrece Windows, y lo usas desde tu navegador de Windows.

Qué se probó. Los pasos de Linux se ejecutaron el 25 de noviembre de 2026 en Ubuntu 24.04.5 (x86_64) dentro de un contenedor, no en WSL, con Aubergine 0.2.2 desde npm: compiló su biblioteca de terminal, arrancó, inició sesión en un navegador y ejecutó un terminal y la demo. La instalación de Node.js con nvm no se ejecutó allí, porque Node.js 22 ya estaba instalado. Nada de esta página se ha ejecutado todavía en Windows. Si lo pruebas, cuéntanos cómo te fue.

Qué necesitas

Windows 11, o Windows 10 versión 2004 (compilación 19041) o posterior, donde WSL 2 se instala con un solo comando. La página de Microsoft sobre cómo instalar WSL tiene los detalles.

Instalar e iniciar

  1. Instala WSL. Abre PowerShell como administrador, ejecuta esto y reinicia Windows cuando termine. Instala WSL 2 con Ubuntu.

    wsl --install

    Tras reiniciar, abre Ubuntu desde el menú Inicio y elige un nombre de usuario y una contraseña. Todos los comandos siguientes se escriben allí, en Ubuntu.

  2. Instala lo que Aubergine necesita: tmux, zsh y Git, y las herramientas que compilan su biblioteca de terminal, que no trae nada ya compilado para Linux.

    sudo apt update

    sudo apt install -y tmux zsh git build-essential python3

    Instala Node.js 22. El paquete propio de Ubuntu es la versión 18, demasiado antigua. Una forma muy conocida es nvm: instálalo, abre una nueva ventana de Ubuntu e instala Node.js 22.

    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash

    nvm install 22

    node -v debería decir ahora v22 o posterior.

  3. Instala Aubergine desde npm. Compila su biblioteca de terminal mientras se instala; en la prueba, toda la instalación tardó 13 segundos.

    npm install -g @meatgarden/aubergine

  4. Inícialo y deja esa ventana abierta:

    aubergine start

    Inicia sesión en tu navegador. En una segunda ventana de Ubuntu, muestra la dirección de inicio de sesión y ábrela en tu navegador de Windows. Inicia la sesión de ese navegador, así que trátala como una contraseña.

    aubergine open --print

    Después, http://127.0.0.1:4600 funciona por sí solo en ese navegador. En un lienzo vacío, Show me around inicia el recorrido.

Conviene saber

  • Guarda tus proyectos en Ubuntu, en su carpeta personal, no en /mnt/c, donde los archivos de Windows se alcanzan a través de un puente más lento.
  • Instala tus agentes dentro de Ubuntu, Claude Code, Codex o cualquier otro, como en cualquier Linux. Un agente instalado en Windows no está en los terminales de Aubergine.
  • Los terminales viven mientras WSL siga en marcha. Cerrar el navegador no termina nada, y Ctrl+C en la ventana de aubergine start detiene solo el servidor. Cuando WSL se detiene, porque Windows se reinicia o tras wsl --shutdown, los terminales terminan, y el siguiente aubergine start abre shells nuevos en sus últimas carpetas, como tras reiniciar un Mac.
  • bash o zsh. El shell de Ubuntu es bash, y los terminales funcionan con él. El estado de los comandos en un terminal (ocupado, el código de salida de un comando que falló) viene solo de zsh: en la prueba, un terminal con zsh mostró exit 3 tras un comando fallido. Haz de zsh tu shell en Ubuntu para tenerlo.
  • Lo que no hay: el inicio al arrancar la sesión funciona solo en macOS (aubergine service install lo dice), y Open on desktop no tiene ajuste para una aplicación de terminal de Windows. aubergine open no encontró un navegador que abrir en la prueba; aubergine open --print siempre funciona.
  • Las teclas en Windows se eligieron según lo que documentan los navegadores y no se han medido: consulta docs/keys.md. La paleta siempre funciona.

Si algo sale mal

Ejecuta primero aubergine doctor en Ubuntu. Comprueba Node.js, tmux, Git y el servidor.

Lo que vesQué hacer
La instalación de Aubergine falla al compilar node-ptyFaltan las herramientas de compilación. Ejecuta las líneas de apt del paso 2 e instala Aubergine de nuevo.
Una página que dice que falta tmux o que es demasiado antiguoEl tmux de Ubuntu 24.04 es la versión 3.4, suficientemente nueva: sudo apt install -y tmux y vuelve a iniciar el servidor.
node -v muestra una versión anterior a v22Instala Node.js 22 como en el paso 2, abre una nueva ventana de Ubuntu e instala Aubergine de nuevo.
La dirección no se abre en el navegador de WindowsComprueba que aubergine start sigue en marcha en Ubuntu. Luego consulta la página de Microsoft sobre redes en WSL; esto no se ha probado con Aubergine.
