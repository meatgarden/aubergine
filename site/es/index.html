Todas tus terminales, una al lado de la otra. Trae tus propios agentes.

Aubergine pone todas tus terminales una al lado de la otra en un solo lienzo, en tu navegador. Ejecuta tantas como quieras, con los agentes y modelos que ya usas. No tiene modelo propio y nunca te pide una clave.

npm install -g @meatgarden/aubergine

InstalarLeer el código

Después, aubergine start --open. Para macOS, con tmux 3.2 o posterior y Node.js 22 o posterior.

Las terminales que ya usas, con lo que les faltaba: un sitio donde estar una al lado de la otra, una memoria y una forma de avisarte cuando te necesitan.

Trae tu propio agente

Aubergine ejecuta terminales normales. No llama a ningún modelo, no guarda ninguna clave y no tiene cuentas: los agentes de línea de comandos que ya usas, con tu sesión iniciada, se ejecutan en sus terminales con el modelo que hayas elegido para ellos. Lo que Aubergine hace por sí mismo para un agente está hecho hoy para Claude Code; cualquier otro agente puede decir lo mismo con los comandos aubergine.

  • Claude Code

    Inícialo desde el menú New terminal y dirá por sí mismo cuándo trabaja, cuándo te espera o cuándo termina; Aubergine puede reanudar sus conversaciones y mostrar cómo está configurado.

  • Codex y ChatGPT

    Codex se ejecuta en una terminal como cualquier programa, e informa mediante los comandos aubergine una vez que sus instrucciones se lo indican. ChatGPT en un navegador no es un programa de terminal.

  • Cualquier otro agente de línea de comandos, o una shell sin más

    Todas las terminales tienen el comando aubergine, y aubergine guide --snippet imprime cinco líneas para las propias instrucciones de tu agente.

Qué más ya está hecho

Todo esto funciona hoy en tu ordenador.

  • Un lienzo de terminales

    Desplaza, haz zoom y coloca terminales reales; un clic para escribir; aparca una y tráela de vuelta más tarde, o abre una sola en una pestaña del navegador con sus detalles y su nota al lado.

  • Mira quién está esperando

    Ocupada, inactiva o esperándote, en cada terminal; y la lista «For you» y «next waiting» te llevan directamente a lo que necesita a una persona.

  • Cola y programaciones

    Escribe una tarea una vez y deja que la tome un agente libre, o prográmala para una hora del día en los días que elijas.

  • Copias de trabajo

    Dale a cada agente su propia copia de un repositorio en su propia rama, para que dos agentes nunca editen los mismos archivos.

  • Proyectos

    Un servidor, varias salas de control: cada proyecto tiene sus propios lienzos, cola, programaciones y reglas, y se puede guardar como archivo o como plantilla.

  • Flujos de trabajo y aprobaciones

    Dale a un agente pasos que seguir, detente en un paso que espera a una persona y sigue cada ejecución en curso en un solo tablero.

  • Mensajes entre terminales

    Deja que los agentes hablen entre sí con remitentes con nombre, límites y pausas, cerrado por defecto en cada lienzo.

  • API y servidor MCP

    Una API HTTP local con tokens con alcances, un cliente tipado y un servidor MCP que solo lista las herramientas que una credencial puede usar.

  • Una línea de comandos

    El comando aubergine inicia terminales, pone tareas en cola, define programaciones, lee el tablero y aprueba ejecuciones, desde cualquier terminal de la máquina.

  • Resúmenes e historial

    Mira qué cambió mientras no estabas, busca en la salida de las terminales y vuelve a abrir conversaciones pasadas desde la paleta.

Tus terminales siguen siendo tuyas

Qué está protegido y qué no

  • Solo local

    El servidor escucha en 127.0.0.1 y comprueba el Host y el Origin de cada petición; el uso desde otro dispositivo está desactivado hasta que lo configures.

  • Las terminales sobreviven a la app

    Cada terminal es una sesión de tmux: cierra el navegador o reinicia Aubergine y tu trabajo sigue en marcha.

  • Sin modelo, sin clave

    Aubergine no elige ni llama a ningún modelo, y no guarda ninguna clave para uno; tus agentes traen los suyos.

  • Tú decides

    Los tokens tienen alcances, lo que escriben los agentes espera tu revisión y las aprobaciones las da una persona.

Preguntas

Todas las preguntas

¿Qué es Aubergine?

Un lienzo local, en el navegador, de sesiones de terminal. Cada terminal es un nodo que puedes colocar y usar, así que puedes ejecutar varios agentes de programación a la vez y ver cuál te está esperando.

¿Envía Aubergine mis terminales o mi código a algún sitio?

No. Todo se ejecuta en tu propio ordenador. El servidor escucha solo en 127.0.0.1 y comprueba el Host y el Origin de cada petición.

¿Qué necesito para ejecutar Aubergine?

macOS con tmux 3.2 o posterior y Node.js 22 o posterior; el instalador también necesita pnpm. En Linux se ha ejecutado solo en contenedores. En Windows funciona solo dentro de WSL 2, algo que aún no se ha probado: consulta la guía para Windows.

¿Y si inicio Claude Code yo mismo en una terminal?

Funciona como cualquier programa: le escribes como siempre. Pero Aubergine solo sabe que hay un agente cuando lo inició él mismo (New terminal y luego Claude Code), porque añade unos pequeños hooks que informan de lo que hace el agente. Si lo inicias a mano, la terminal solo aparece ocupada ejecutando claude: no se marca como esperándote cuando pregunta algo, y cuando inicias un flujo de trabajo ahí, no se escribe nada para él. Dile tú mismo que ejecute aubergine workflow status, que sigue funcionando desde dentro, o inicia el agente desde el menú New terminal.

¿Aubergine es gratis?

Sí. Es libre y de código abierto bajo la licencia MIT, y su código está en GitHub.

Qué está previsto

El modo multijugador, los agentes en la nube, los modos de aprobación y más cosas están previstos y no están hechos. Mira la hoja de ruta.

En marcha en cinco minutos

Necesitas macOS con tmux 3.2 o posterior y Node.js 22 o posterior. brew install tmux node instala ambos.

  1. Instala

    npm install -g @meatgarden/aubergine

    O usa el instalador, que compila desde el código fuente con pnpm.

  2. Inícialo y abre tu navegador

    aubergine start --open

    Inicia el servidor y abre tu navegador con la sesión iniciada.

  3. Haz el recorrido

    Haz clic en Show me around (enséñame cómo funciona) en el lienzo vacío. Crea un lienzo Demo con agentes simulados y te guía en ocho pasos cortos; aubergine demo --remove lo quita.

El instalador solo cambia ~/.aubergine y un enlace llamado aubergine. Nunca usa sudo y nunca edita los archivos de inicio de tu shell.
