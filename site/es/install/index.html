Cómo instalar Aubergine

Un comando lo instala y otro lo inicia. Unos cinco minutos, recorrido incluido.

Requisitos

  • macOS. En Linux se ha ejecutado solo en contenedores: el paquete de npm en Ubuntu 24.04 y la imagen de contenedor en Debian. Windows en sí no es compatible; Aubergine puede ejecutarse dentro de WSL 2, algo que aún no se ha probado: consulta Instalar en Windows con WSL.
  • tmux 3.2 o posterior y Node.js 22 o posterior. El instalador también necesita pnpm.

Con Homebrew, una línea instala ambos (añade pnpm para el instalador):

brew install tmux node

Instala e inicia

  1. Instala Aubergine desde npm (solo necesita tmux y Node.js):

    npm install -g @meatgarden/aubergine

    O con el instalador, que también necesita pnpm y compila desde el código fuente:

    curl -fsSL https://raw.githubusercontent.com/thirstyeggplant/aubergine/main/install.sh | sh

  2. Inícialo y abre tu navegador con la sesión iniciada.

    aubergine start --open

  3. Haz el recorrido. Haz clic en Show me around en el centro del lienzo vacío. Crea un lienzo llamado «Demo» con unos cuantos agentes simulados y te guía en ocho pasos cortos. Nada de la demo es real, y aubergine demo --remove la quita.

¿Prefieres leer el script antes? Descárgalo, léelo y ejecuta sh install.sh --dry-run para ver qué haría sin cambiar nada.

Qué cambia el instalador

Solo dos cosas: la carpeta de instalación (~/.aubergine, o AUBERGINE_HOME) y un enlace llamado aubergine en una carpeta de tu PATH en la que puedas escribir. Lo comprueba todo antes y no cambia nada si falta algo.

No usa sudo, no edita los archivos de inicio de tu shell, no instala Node.js, pnpm ni tmux, y no toca tu carpeta de datos.

Si algo sale mal

Ejecuta primero aubergine doctor. Comprueba las causas habituales.

Lo que vesQué hacer
«This browser is not signed in yet» (este navegador aún no tiene la sesión iniciada)Abre una vez el enlace de inicio de sesión en ese navegador. aubergine open --print lo vuelve a imprimir.
Una página que dice que falta tmux o que es demasiado antiguoInstala o actualiza tmux (brew install tmux) y reinicia el servidor.
El servidor no arranca porque el puerto está ocupadoUsa otro puerto: AUBERGINE_PORT=4700 aubergine start.
aubergine: command not foundEl enlace no está en tu PATH. El instalador imprime la línea que debes añadir al archivo de inicio de tu shell.
Una terminal no muestra indicadores de estadoEl estado necesita zsh, y una sesión creada antes de una actualización conserva su shell antigua. Apárcala e inicia una nueva.

Detener, actualizar, desinstalar

  • Detén el servidor con Ctrl+C. Tus terminales siguen en marcha; vuelve a iniciar el servidor y recarga la página para recuperarlas.
  • Actualiza, si instalaste con npm, con npm install -g @meatgarden/aubergine@latest; si usaste el instalador, con aubergine update. Después reinicia el servidor.
  • Desinstala con aubergine uninstall. Quita el enlace y, tras preguntar, la copia que hizo el instalador. Nunca borra tus datos y nunca cierra tus terminales.
  • Inícialo al arrancar la sesión con aubergine service install, y así solo tendrás que abrir el navegador.
