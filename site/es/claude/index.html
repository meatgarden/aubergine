Qué hace Aubergine por Claude Code

Claude Code se ejecuta en una terminal de Aubergine como cualquier programa. Si lo inicias desde Aubergine, además le dice al lienzo qué está haciendo, y Aubergine puede ponerlo al tanto, reanudarlo y mostrar cómo está configurado. Esto es todo, en el orden en que te lo encuentras.

Tú instalas Claude Code e inicias sesión en él. Aubergine no llama a ningún modelo ni guarda ninguna clave: inicia el comando claude que ya tienes.

  1. Inícialo desde el menú

    New terminal ▾ → Claude Code, o C mientras ninguna terminal tiene el teclado, inicia claude en una terminal nueva con un archivo de ajustes que Aubergine escribe en su propia carpeta de datos. Tu propia configuración de Claude Code no se toca.

    El comando que inicia es agents.claudeCommand en los ajustes, claude salvo que lo cambies; Aubergine añade sus propias opciones al final.

    Dónde: el menú junto a New terminal, arriba de la lista de terminales.

  2. Mira cuándo trabaja, espera y termina

    Los hooks de ese archivo de ajustes le dicen al lienzo qué está haciendo el agente. Cuando envías un prompt, se añade al registro de notas de la terminal y la terminal muestra working (trabajando). Cuando el agente te necesita, por una pregunta de permisos o porque está inactivo esperando una entrada, su borde toma el color de la espera y su título y su fila dicen waiting for you (te está esperando). Cuando se detiene, muestra finished (terminado).

    W va a la siguiente terminal que espera, y Notify activa las notificaciones de escritorio para las terminales que empiezan a esperar. Los prompts pueden contener secretos: "agents": { "logPrompts": false } en config.json los deja fuera del registro de notas.

    Dónde: el título de la terminal, su fila en la lista y el contador junto a For you, arriba.

  3. Un Claude Code que iniciaste tú

    Si lo escribes a mano en una terminal normal, claude funciona como cualquier programa, pero Aubergine solo ve una shell ocupada ejecutándolo: no hay waiting for you, y no se escribe nada para él cuando inicias ahí un flujo de trabajo. Para cambiarlo, imprime los hooks y añádelos a mano a tus propios ajustes de Claude Code. Fuera de una terminal de Aubergine no hacen nada.

    aubergine hooks print

  4. Se pone nombre y mantiene un resumen

    A un agente que inicia Aubergine se le dice, al empezar, que ponga a su terminal el nombre del trabajo y mantenga un resumen, con aubergine describe, aubergine link add y aubergine field set, y se le recuerda una vez cuando se detiene sin nombre propio o sin resumen. Lo que escribes tú gana; lo que el agente dice sobre lo mismo espera al lado con Use this (usar esto). El recordatorio se puede desactivar en Settings.

    Dónde: los detalles de la terminal, con su nombre, resumen, campos y enlaces.

  5. Le llegan flujos de trabajo, tareas, resúmenes y mensajes

    Aubergine escribe cuatro frases fijas en una terminal, y solo estas: que se inició un flujo de trabajo, que se le pidió al agente que escribiera algo, que pediste un resumen y que hay un mensaje esperando. Cada una nombra un comando para que el agente lo ejecute. Una frase solo se escribe donde se ve que un agente tiene el teclado: uno que inició Aubergine, o uno cuyos ajustes tienen los hooks de aubergine hooks print.

    Del mismo modo, una tarea de la cola solo va a una terminal donde un agente así está delante y libre, y Claude Code on a workflow… inicia una terminal nueva a cuyo agente se le habla de la ejecución en su primer prompt.

    Dónde: Run a workflow… en el menú del título de una terminal, y Runs arriba de la página.

  6. Resume agent

    Aubergine recuerda en qué conversación estaba una terminal de agente. Cuando su shell vuelve a un prompt, porque saliste del agente o se reinició el ordenador, la terminal ofrece Resume agent (reanudar el agente), que vuelve a iniciar el agente en esa conversación. En una terminal que está en una ejecución, también le vuelve a hablar al agente de la ejecución.

    Dónde: la barra de título de la terminal.

  7. Conversaciones pasadas

    Past conversations… lista las conversaciones anteriores del agente en una carpeta: lee una, ábrela en el lienzo o abre una copia que deja el original como está. Escribe @ y algunas palabras en la paleta para buscarlas; aubergine history las lista en la línea de comandos. No se guarda nada de lo leído, y ningún token ni ningún agente puede leer conversaciones a través de Aubergine.

    Lee los archivos que guarda Claude Code. Su formato es interno de Claude Code y cambia entre versiones. Tras una actualización del agente, los nombres y las transcripciones pueden salir más escuetos, y de un registro que Aubergine no puede leer se dice que no se puede leer, nunca se muestra como vacío.

    Dónde: la paleta (⌘K), y «Past conversations in this folder…» en los detalles de una terminal.

  8. Cómo está configurado

    Una lista de lo que los archivos de configuración del agente dicen que se le ha dado: servidores MCP, plugins, hooks, skills, reglas de permisos y archivos de ajustes, cada uno con su origen, y lo que añadió Aubergine. Solo nombres, nunca un valor ni un secreto. Dice cómo está configurado el agente, no qué ha cargado el agente en ejecución, y dice claramente lo que no puede saber, como los conectores que vienen con tu cuenta.

    Dónde: ⚙ on en la terminal, «What is switched on for this agent…» en la paleta, y los detalles de la terminal.

  9. Las herramientas de Aubergine para él

    Claude Code with Aubergine tools… pregunta primero qué puede hacer el agente: None (nada); Its own work only (solo su propio trabajo), con la credencial propia de la terminal; o More… (más), alcances que tú eliges, para los que se crea un token solo para esa terminal, que se revoca cuando la terminal se cierra definitivamente. Las herramientas son aubergine mcp, que se pasa al agente en su línea de arranque; su propia configuración no se escribe.

    Dónde: el menú junto a New terminal.

  10. Trae un Claude Code que ya tienes abierto

    Un agente en ejecución no se puede mover, pero su conversación sí. Open elsewhere (abiertas en otro sitio) lista tus pestañas de Claude Code, con Fork to canvas (bifurcar al lienzo) y, para un agente inactivo, Stop and resume here (detener y reanudar aquí), que te pregunta antes. Desde una terminal, aubergine move hace lo mismo, y aubergine here --claude inicia Claude Code en el lienzo continuando la última conversación de esa carpeta.

    Dónde: Open elsewhere en la barra sobre el lienzo, o O.

  11. En una copia de trabajo propia

    aubergine here --copy --claude inicia Claude Code en su propio checkout del repositorio, en su propia rama, para que dos agentes nunca editen los mismos archivos. El diálogo de una terminal de Claude Code con herramientas ofrece la misma opción.

Qué se ha probado

La demo que viene con Aubergine usa agentes simulados, scripts cortos que ejecutan los mismos comandos y hooks que un agente real, no un Claude Code real. Con un agente real aún no se han probado una aprobación, una copia de trabajo, una tarea de la cola ni una programación.

Otro agente puede decir casi todo esto mediante los comandos aubergine: mira Codex y ChatGPT.

Aubergine no está afiliado a Anthropic. Claude y Claude Code son marcas registradas de Anthropic.

En marcha en cinco minutos

Necesitas macOS con tmux 3.2 o posterior y Node.js 22 o posterior. brew install tmux node instala ambos.

npm install -g @meatgarden/aubergine
