Reanudar una conversación de Claude Code tras un reinicio

El ordenador se reinició, o cerraste la terminal, y la conversación de Claude Code parece perdida. Claude Code la conserva. Aubergine recuerda en qué conversación estaba cada terminal y la recupera con un botón.

Lo que se suele hacer

En una terminal, en la carpeta donde estaba la conversación: claude --continue sigue con la conversación más reciente de ahí, y claude --resume te deja elegir una de una lista, o acepta el ID de una conversación. La pega está en la carpeta y en la elección: con varios agentes en una carpeta, la más reciente no siempre es la que querías.

Lo que hace Aubergine

Una terminal recuerda su conversación. Cuando Claude Code se inició desde Aubergine (New terminal ▾ → Claude Code, o C), sus hooks le dicen a Aubergine en qué conversación está, y Aubergine guarda ese ID con la terminal.

Resume agent (reanudar el agente) aparece en la barra de título de la terminal en cuanto su shell vuelve a un prompt: saliste del agente, o el ordenador se reinició y la terminal volvió como un shell nuevo en su última carpeta. Vuelve a iniciar Claude Code con --resume y ese ID, con el comando de arranque de tus ajustes (agents.claudeCommand, claude por defecto).

En una ejecución de un flujo de trabajo, Resume agent también le vuelve a hablar al agente de la ejecución, para que siga desde el paso en que está.

Past conversations… (conversaciones pasadas) en la paleta (⌘K), o «Past conversations in this folder…» en los detalles de una terminal, lista las conversaciones anteriores de Claude Code en una carpeta: el nombre o lo primero que dijiste, cuándo estuvo activa por última vez, cuántas veces hablaste, y si una terminal de un lienzo está en ella ahora. Read (leer) la muestra, solo lectura. Open on the canvas (abrir en el lienzo) inicia una terminal nueva en esa carpeta, reanudada en ella, y Open a copy (abrir una copia) inicia una bifurcación de ella y deja la original como está. Si ya hay una terminal en esa conversación, se te pregunta antes.

Búsqueda. Escribe @ y algunas palabras en la paleta para buscar en las conversaciones pasadas de las carpetas de las terminales de tus lienzos. Lee los registros cuando lo pides, con límites, y dice cuándo se cortó. En la línea de comandos, aubergine history las lista y aubergine history open <id> abre una.

Dónde se quedó. La nota de la terminal guarda su resumen y un registro, y cada prompt que envías se añade al registro. Ask its agent for a recap (pedir una recapitulación a su agente), en sus detalles, hace que el agente escriba dónde está con aubergine recap --write, y se guarda con la terminal. Cuando vuelves después de más de 30 minutos, While you were away (mientras no estabas) lista lo que cambió entretanto.

Una conversación en una terminal fuera de Aubergine

En una pestaña de tu aplicación de terminal, sal del agente y luego ejecuta aubergine here --claude en la misma carpeta: una terminal nueva en el lienzo inicia Claude Code con --continue, ahora con su estado a la vista. aubergine move lista tus pestañas de Claude Code e inicia una copia de cada conversación en el lienzo; con --stop le pide antes a un agente inactivo que salga, después de que lo confirmes.

Lo que no hace

  • Lee los registros propios de Claude Code, en un formato que no es de Aubergine. Claude Code dice que el formato de esos archivos es interno, y cambia entre versiones. Reanudar usa el propio --resume de Claude Code con el ID; los nombres, los recuentos y las transcripciones son la lectura que Aubergine hace de los archivos, y pueden faltar o ser más pobres tras una actualización de Claude Code. Un registro que no puede leer se indica como tal, no se muestra como una conversación vacía.
  • No se copia ni se guarda nada. Una lista, una transcripción o una búsqueda se leen cuando lo pides y se descartan cuando las cierras. Aubergine nunca cambia, renombra ni borra una conversación, y ningún agente ni token puede leer conversaciones a través de él.
  • El trabajo en curso no se rehace. Lo que el agente hacía cuando se detuvo no se vuelve a iniciar hasta que se lo pidas.
  • No hay Resume agent para otro agente. Aubergine no conoce la conversación de otro agente, y no lista conversaciones pasadas suyas. Vuelve a iniciarlo en la misma terminal con la forma de reanudar de ese agente, y lee la nota para decirle dónde se quedó.
  • Un claude que escribiste tú no se recuerda, salvo que hayas añadido a tus propios ajustes de Claude Code los hooks que imprime aubergine hooks print.
  • Lo que se comprobó. La lectura de los registros de conversaciones se prueba con registros inventados. No se ha comprobado con todas las versiones de Claude Code.

Preguntas

¿Cómo reanudo una sesión de Claude Code después de cerrar la terminal?

En la misma carpeta, claude --continue toma la conversación más reciente y claude --resume te deja elegir. En Aubergine, cerrar el navegador no termina nada, y una terminal de cuyo agente saliste ofrece Resume agent en su barra de título.

¿Cómo reanudo una conversación de Claude Code tras reiniciar?

Tras un reinicio, cada terminal de Aubergine vuelve como un shell nuevo en su última carpeta. Donde Claude Code se inició desde Aubergine, Resume agent en la barra de título lo vuelve a iniciar en la conversación en la que estaba esa terminal.

¿Cómo encuentro una conversación antigua de Claude Code?

Past conversations… en la paleta las lista para una carpeta, con una transcripción de solo lectura; @ y algunas palabras en la paleta buscan en ellas. Solo se lista lo que Claude Code todavía conserva.

¿Qué diferencia hay entre claude --continue y claude --resume?

--continue sigue con la conversación más reciente de la carpeta; --resume toma la que eliges, o un ID. Resume agent usa --resume con el ID que recordó la terminal, así que no depende de cuál fue la conversación más reciente.

¿Pueden dos terminales continuar la misma conversación de Claude Code?

Aubergine no abre una dos veces sin preguntar: dos agentes en una conversación pierden los mensajes del otro. Se te ofrece la terminal que ya está en ella, o una copia, que bifurca la conversación.
