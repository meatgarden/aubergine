Aubergine vs Claude Squad

The two stand on the same ground: each agent in a tmux session, each in its own Git worktree, both free and open source. Claude Squad is a program inside your terminal. Aubergine is a page in your browser where the terminals stand side by side.

Where this comes from. What is said here about Claude Squad is from its repository and README as read on 26 November 2026. We have not run Claude Squad. If something is wrong or out of date, tell us.

Which to pick

Pick Claude Squad if you live in a terminal and want one small program there that starts agents in worktrees and pushes their branches, and nothing more.

Pick Aubergine if you want to see several agents working at once, know which one waits for you, and have a queue, schedules and an API around them.

What Claude Squad is

By its own description, a terminal app that manages several Claude Code, Codex, Gemini and other local agents in separate workspaces. You start it as cs: a list of sessions with a preview and a diff tab, in one terminal window. Each session is a tmux session in a Git worktree on its own branch. It needs tmux and gh, and is under the AGPL-3.0 license.

Where they differ

One at a time, or all at once. Claude Squad shows a list and a preview of the session you chose. Aubergine draws every terminal live on a canvas, so five agents are five terminals in sight, and one list says the state of each in words.

Who waits. We found nothing in Claude Squad's README about being told that an agent waits or is done. Aubergine marks a waiting terminal in color, counts what waits at the top, goes to the next one with a key, and can send a notification from the open page.

What is around the agents. Aubergine has a queue of tasks with a limit, schedules, workflows with steps a person approves, notes and fields on each terminal, an HTTP API and an MCP server. Claude Squad keeps to sessions and their branches.

What Claude Squad has that Aubergine does not

  • It runs inside the terminal you already have open, with no server and no browser. It works over SSH like any terminal program; Aubergine from elsewhere needs a tunnel or a proxy.
  • It commits and pushes a branch for you, and pauses a session by committing its work. Aubergine never commits or pushes.
  • An experimental mode that accepts an agent's prompts by itself. Aubergine never answers an agent for you.

Questions

Is Aubergine an alternative to Claude Squad?

Yes, for the same job done another way. Both run each agent in a tmux session and can give each a Git worktree on its own branch. Claude Squad does it from a program in your terminal; Aubergine from a page in your browser with every terminal in sight.

Do both use tmux?

Yes. Claude Squad lists tmux as a prerequisite and makes a tmux session for each agent. Aubergine needs tmux 3.2 or newer and runs it on a socket of its own with its own configuration, so your own tmux is left alone.

Does Claude Squad work with agents other than Claude Code?

Its README says the default program is claude and that another, such as Codex, Gemini or Aider, is named with -p. Aubergine runs any command-line program in a terminal; what it does by itself for an agent is built for Claude Code.

Which license does each have?

Claude Squad is under the AGPL-3.0, Aubergine under the MIT license. Both are free.

Aubergine is not affiliated with Claude Squad or with Anthropic. Claude Squad is the name of the smtg-ai project; Claude is a trademark of Anthropic.

Up and running in five minutes

You need macOS with tmux 3.2 or newer and Node.js 22 or newer. brew install tmux node gets both.

npm install -g @meatgarden/aubergine
