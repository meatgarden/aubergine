Aubergine vs Paradev, formerly Superset

Paradev is the desktop app that was called Superset until October 2026. Like Aubergine it is under the MIT license, runs any command-line agent and works in Git worktrees. It is an app with plans, phone apps and a cloud; Aubergine is a server on your own computer and a page in your browser, with none of those.

Where this comes from. What is said here about Paradev is from its documentation, its changelog and its repository as read on 26 November 2026. We have not run Paradev. If something is wrong or out of date, tell us.

The name. Its changelog for 25 October 2026 says Superset is now Paradev and that accounts, workspaces, settings and the superset command carry over. It is not Apache Superset, the data tool.

Which to pick

Pick Paradev if you want a desktop app that makes a worktree for every task and takes it through diff, checks and merge, with phone apps and a cloud when you pay for them.

Pick Aubergine if you want every part free on your own computer with no account: terminals side by side, a queue, schedules and use from another device.

What Paradev is

By its own description, the open-source workspace for Claude Code, Codex and any coding agent: a desktop app, not a terminal app, in which agents run as a chat or in a terminal. Every task has its own worktree, branch and terminal; one sidebar shows every session by project. It has a diff viewer with pull request checks and merging, a command, an SDK and an MCP server, and on paid plans phone apps, remote access, cloud workspaces and automations.

Where they differ

What is free. Paradev lists a free plan for one person with local workspaces, the app and the command; automations, phone apps and remote access are on paid plans. Aubergine has no plans: its queue, its schedules and use from another device are all in the one MIT-licensed program, with no account.

A sidebar or a canvas. Paradev shows sessions in a sidebar with tabs and panes. Aubergine places terminals on a canvas you pan and zoom, so many are live in sight at once, with one list of them all beside it.

How terminals outlive the window. Both keep agents running when the window closes: Paradev through its own background daemon, which its documentation says ends every terminal when you quit Paradev completely; Aubergine through tmux, which goes on when Aubergine itself is stopped. A restart of the computer ends them in both.

What Paradev has that Aubergine does not

  • A diff viewer in which you comment on and edit an agent's changes, watch a pull request's checks and merge. Aubergine shows what changed and never commits, pushes or merges.
  • A desktop app, iOS and Android apps, cloud workspaces, and a chime and a dock badge when an agent needs you. Aubergine is a browser page and plays no sound.
  • Automations set off by a review request, a Slack message, an issue or a webhook, and hooks it installs so that many agents report their state. Aubergine starts nothing from outside, and sees an agent wait by itself only for Claude Code.

Questions

Is Aubergine an alternative to Paradev (Superset)?

For running several command-line agents locally, each in its own Git worktree, yes, and with every feature free. It is not a like-for-like replacement: Aubergine has no desktop or phone app, no diff comments, no pull requests or merging and no cloud.

Is Superset the same as Paradev?

Yes. Its changelog for 25 October 2026 says Superset is now Paradev, and its README says the command is still superset. Neither is related to Apache Superset.

Are both open source?

Both are under the MIT license. Paradev also sells plans for its phone apps, remote access, cloud and automations; Aubergine sells nothing.

Does Paradev run on Linux or Windows?

Its documentation says macOS, with an experimental Linux build, and that Windows is not yet available. Aubergine is built for macOS, has been run on Linux in containers only, and on Windows runs only inside WSL 2, which has not been tried.

Aubergine is not affiliated with Paradev or its makers, Superset Inc. Paradev and Superset are their names; neither they nor Aubergine are related to Apache Superset.

Up and running in five minutes

You need macOS with tmux 3.2 or newer and Node.js 22 or newer. brew install tmux node gets both.

npm install -g @meatgarden/aubergine
